Git Basic Operations

git cloneis a command used to clone a remote Git repository to the local machine.

git cloneIt can copy a remote Git repository to the local machine, allowing you to view the project or make modifications.

git cloneThe command allows you to copy all the code and history of the remote repository, and create a local repository copy identical to the remote repository.

The command format for copying a project is as follows:

 git clone [url]

[url]is the project you want to copy.

For example, let's clone a project from GitHub:

$ git clone https://github.com/tianqixin/example-git-test
Cloning into 'example-git-test'...
remote: Enumerating objects: 12, done.
remote: Total 12 (delta 0), reused 0 (delta 0), pack-reused 12
Unpacking objects: 100% (12/12), done.

After performing the above steps, Git will clone the remote repository to your local machine and create a folder with the same name as the remote repository in the current directory (for example, the example-git-test folder in the example above).

Once the above command is executed, a example-git-test directory will be generated in the current directory:

$ cd simplegit/
$ ls
README.md    example-test.txt    test.txt

The above operation will copy all records of the project.

$ ls -a
.        ..        .git        README.md    example-test.txt    test.txt
$ cd .git 
$ ls
HEAD        description    index        logs        packed-refs
config        hooks        info        objects        refs

git cloneThe command will automatically copy all branches and history of the remote repository to your local machine. You can use other Git commands (such as git checkout, git pull, etc.) to operate on the local repository.

By default, Git will create your local project directory based on the name of the project pointed to by the URL you provide. This is usually the project name after the last / in the URL. If you want a different name, you can append the desired name after the command.

For example, the following example copies a remote Git project, and the local project name isanother-example-name：

$ git clone https://github.com/tianqixin/example-git-test another-example-name
Cloning into 'another-example-name'...
remote: Enumerating objects: 12, done.
remote: Total 12 (delta 0), reused 0 (delta 0), pack-reused 12
Unpacking objects: 100% (12/12), done.
