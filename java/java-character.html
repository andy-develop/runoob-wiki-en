Java Character Class

The Character class is used to operate on individual characters.

The Character class wraps a primitive type in an objectcharvalue

Example

char ch = 'a'; //Unicode Character Representation char uniChar = '\u039A'; //Character Array char[] charArray ={ 'a', 'b', 'c', 'd', 'e' };

However, in the actual development process, we often encounter situations where we need to use objects rather than built-in data types. To solve this problem, the Java language provides a wrapper class, the Character class, for the built-in data type char.

The Character class provides a series of methods to manipulate characters. You can use the Character constructor to create a Character class object, for example:

Character ch = new Character('a');

In certain cases, the Java compiler will automatically create a Character object.

For example, when passing a char type parameter to a method that requires a Character type parameter, the compiler will automatically convert the char type parameter into a Character object. This feature is called boxing, and the reverse is called unboxing.

Example

//The primitive character 'a' is boxed into the Character object ch Character ch = 'a'; //The primitive character 'x' is boxed using the test method //The unboxed value is returned to 'c' char c = test('x');

Escape Sequences

Characters preceded by a backslash (\) represent escape characters, which have special meaning to the compiler.

The following list shows Java's escape sequences:

Escape Sequence Description
\t Insert a tab key at that point in the text
\b Insert a backspace key at that point in the text
\n Insert a newline at that point in the text
\r Insert a carriage return at that point in the text
\f Insert a form feed at that point in the text
\' Insert a single quote at that point in the text
\" Insert a double quote at that point in the text
\\ Insert a backslash at that point in the text

Example

When a print statement encounters an escape sequence, the compiler can interpret it correctly.

The following example escapes double quotes and outputs:

Test.java file code:

public class Test { public static void main(String[] args) { System.out.println("Visit\"Runoob!\""); } }

The compilation and execution result of the above example is as follows:

Visit "Runoob Tutorial!"

    \r: return to the leftmost of the current line.

    \n: newline moves down one line, without moving left or right.

    In Linux\nrepresents: carriage return + line feed;

    In Windows\r\nrepresents: carriage return + line feed.

    In Mac\rrepresents: carriage return + line feed.

    History:

    The origin and difference of the two concepts of "Carriage Return" and "Line Feed". Before the advent of computers, there was a device called a teletypewriter (Teletype Model 33, from which the tty concept under linux/Unix also originates) that could type 10 characters per second. But it had a problem: when finishing a line and moving to the next, it took 0.2 seconds, which was just enough to type two characters. If new characters were transmitted during these 0.2 seconds, that character would be lost. Therefore, the researchers came up with a way to solve this problem: add two characters indicating the end after each line. One was called "carriage return", which told the typewriter to position the print head at the left boundary; the other was called "line feed", which told the typewriter to move the paper down one line. This is the origin of "line feed" and "carriage return", and you can also see a bit of it from their English names.

    Soft return and hard return:

    Let me expand a bit more on some knowledge about carriage returns.

    A hard return is what we normally produce by pressing Enter. While changing lines, it also serves to separate paragraphs.

    A soft return is produced using Shift + Enter. It changes lines but does not change paragraphs, meaning the text before and after belongs to the same "paragraph" in Word. You will realize this when applying formatting.

    A soft return can greatly reduce the line spacing between the two lines before and after, because it is not a paragraph mark and needs to be distinguished from the official paragraph mark - the hard return. The HTML code for a hard return is <p>..</p>, with the paragraph content sandwiched inside, while the code for a soft return is very concise: <br>. If the text on a web page is copied into Word, hard returns become curved arrows, and soft returns become downward arrows.

    Extract uppercase and lowercase letters from characters:

    public class UpperLowerCase {
    public static void main(String []args) {
        String StrA="I am Tom.I am from China.";
        String StrB="";
        String StrC="";
        for(int i=0;i<StrA.length();i++){
            if(Character.isUpperCase(StrA.charAt(i)))
                StrB +=StrA.charAt(i)+"  ";
            if(Character.isLowerCase(StrA.charAt(i)))
                StrC +=StrA.charAt(i)+"  ";
            }
        System.out.println("字符串中大写字母有："+StrB);
        System.out.println("字符串中小写字母有："+StrC);
    }
}

    The output result is:

    字符串中大写字母有：I  T  I  C  
字符串中小写字母有：a  m  o  m  a  m  f  r  o  m  h  i  n  a

    Use Character to extract uppercase and lowercase letters from a string:

    public class UpperLowerCase {
    
    /*
     * 利用Character类提取字符串中的大写字母和小写字母
     * @auther Anthony-Z
     */

    public static void main(String[] args) {
        
        String sr1 = "I Like JAVA ! I learn Java everyday.";
        String sr2 = "";
        String sr3 = "";
        
        for (int i = 0; i < sr1.length(); i++) {//获取字符串的长度用的是length();
            if(Character.isUpperCase(sr1.charAt(i))){//先将String类型的字符串转换成char类型                                                                            再获取每一个字符元素，用charAt(i)实现
                sr2 += sr1.charAt(i) + " ";//提取大写字母
            }
            
            if(Character.isLowerCase(sr1.charAt(i))){
                sr3 += sr1.charAt(i) + " ";//提取小写字母
            }
        }
        
        System.out.println("大写字母有：" + sr2);
        System.out.println("小写字母有：" + sr3);

    }

}

    Running result:

    大写字母有：I L J A V A I J 
小写字母有：i k e l e a r n a v a e v e r y d a y
