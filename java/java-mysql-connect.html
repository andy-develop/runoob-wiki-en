Java MySQL Connection

In this chapter, we will introduce how Java uses JDBC to connect to a MySQL database.

Java requires a driver package to connect to MySQL. The latest version download address is:http://dev.mysql.com/downloads/connector/j/After decompressing, you get the jar library file, then import it into your corresponding project.

You can download the jar package provided by this site:mysql-connector-java-5.1.39-bin.jar

This example uses Eclipse to import the jar package:

Database connection for MySQL 8.0 and above is different:

  • 1. Driver package version for MySQL 8.0 and abovemysql-connector-java-8.0.16.jar。

  • 2、com.mysql.jdbc.Driverchanged tocom.mysql.cj.jdbc.Driver。

  • MySQL 8.0 and above does not require establishing an SSL connection; you need to explicitly disable it.

  • allowPublicKeyRetrieval=true allows the client to retrieve the public key from the server.

  • Finally, you also need to set CST.

The way to load the driver and connect to the database is as follows:

Class.forName("com.mysql.cj.jdbc.Driver");
conn = DriverManager.getConnection("jdbc:mysql://localhost:3306/test_demo?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC","root","password");

Connect to Database

The following example uses JDBC to connect to a MySQL database. Note that some data such as username and password need to be configured according to your development environment:

MySQLDemo.java file code:

package com.runoob.test; import java.sql.*; public class MySQLDemo { //MySQL versions below 8.0 - JDBC driver name and database URL static final String JDBC_DRIVER = "com.mysql.jdbc.Driver"; static final String DB_URL = "jdbc:mysql://localhost:3306/RUNOOB"; //MySQL 8.0 and above - JDBC driver name and database URL //static final String JDBC_DRIVER = "com.mysql.cj.jdbc.Driver"; //static final String DB_URL = "jdbc:mysql://localhost:3306/RUNOOB?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC"; //The database username and password need to be set according to your own settings static final String USER = "root"; static final String PASS = "123456"; public static void main(String[] args) { Connection conn = null; Statement stmt = null; try{ //Register JDBC driver Class.forName(JDBC_DRIVER); //Open connection System.out.println("Connecting to database..."); conn = DriverManager.getConnection(DB_URL,USER,PASS); //Execute query System.out.println("Instantiate Statement object..."); stmt = conn.createStatement(); String sql; sql = "SELECT id, name, url FROM websites"; ResultSet rs = stmt.executeQuery(sql); //Expand the result set database while(rs.next()){ //Retrieve by field int id = rs.getInt("id"); String name = rs.getString("name"); String url = rs.getString("url"); //Output data System.out.print("ID: " + id); System.out.print(", site name:" + name); System.out.print(", site URL:" + url); System.out.print("\n"); } //Close after completion rs.close(); stmt.close(); conn.close(); }catch(SQLException se){ //Handle JDBC errors se.printStackTrace(); }catch(Exception e){ //Handle Class.forName errors e.printStackTrace(); }finally{ //Close resources try{ if(stmt!=null) stmt.close(); }catch(SQLException se2){ }//Do nothing try{ if(conn!=null) conn.close(); }catch(SQLException se){ se.printStackTrace(); } } System.out.println("Goodbye!"); } }

    DAO Pattern

    DAO (DataAccessobjects, data access objects) refers to implementing access to persistent data located between business logic and persistent data. In simple terms, it encapsulates all database operations.

    Provide corresponding interfaces to the outside

    In object-oriented design, there are some "routines" used to solve specific problems, called patterns.

    The DAO pattern provides interfaces for operations required to access relational database systems, separates data access from business logic, and provides an object-oriented data access interface to the upper layer.

    From the use of the DAO pattern above, it can be seen that the advantage of the DAO pattern is that it achieves two levels of isolation.

    • 1. It isolates data access code and business logic code. Business logic code can directly call DAO methods without being aware of the existence of database tables. The division of labor is clear; changes in the data access layer code do not affect business logic code. This conforms to the single responsibility principle, reduces coupling, and improves reusability.
    • 2. It isolates different database implementations. By adopting interface-oriented programming, if the underlying database changes, such as from MySQL to Oracle, you only need to add a new implementation class of the DAO interface; the original MySQL implementation does not need to be modified. This conforms to the"Open-Closed"principle. This principle reduces code coupling, improves code extensibility, and system portability.

    A typical DAO pattern mainly consists of the following parts.

    • 1. DAO interface: Defines all database operations as abstract methods and can provide multiple implementations.
    • 2. DAO implementation class: Provides specific implementations of the methods defined in the DAO interface for different databases.
    • 3. Entity class: Used to store and transfer object data.
    • 4. Database connection and closing utility class: Avoids duplicate database connection and closing code, making modifications convenient.

    DAO interface:

    public interface PetDao {
    /**
     * 查询所有宠物
     */
    List<Pet> findAllPets() throws Exception;
}

    DAO implementation class:

    public class PetDaoImpl extends BaseDao implements PetDao {
    /**
     * 查询所有宠物
     */
    public List<Pet> findAllPets() throws Exception {
        Connection conn=BaseDao.getConnection();
        String sql="select * from pet";
        PreparedStatement stmt= conn.prepareStatement(sql);
        ResultSet rs=    stmt.executeQuery();
        List<Pet> petList=new ArrayList<Pet>();
        while(rs.next()) {
            Pet pet=new Pet(
                    rs.getInt("id"),
                    rs.getInt("owner_id"),
                    rs.getInt("store_id"),
                    rs.getString("name"),
                    rs.getString("type_name"),
                    rs.getInt("health"),
                    rs.getInt("love"),
                    rs.getDate("birthday")
                    );
                petList.add(pet);
        }
        BaseDao.closeAll(conn, stmt, rs);
        return petList;
    }
}

    public class BaseDao {
    private static String driver="com.mysql.jdbc.Driver";

        static {

    public static Connection getConnection() throws SQLException {
        return DriverManager.getConnection(url, user, password);

    public static void closeAll(Connection conn,Statement stmt,ResultSet rs) throws SQLException {
        if(rs!=null) {
            rs.close();
        }
        if(stmt!=null) {
            stmt.close();
        }
        if(conn!=null) {
            conn.close();
        }
    }
    

    public int executeSQL(String preparedSql, Object[] param) throws ClassNotFoundException {
        Connection conn = null;
        PreparedStatement pstmt = null;
        /* 处理SQL,执行SQL */
        try {
            conn = getConnection(); // 得到数据库连接
            pstmt = conn.prepareStatement(preparedSql); // 得到PreparedStatement对象
            if (param != null) {
                for (int i = 0; i < param.length; i++) {
                    pstmt.setObject(i + 1, param[i]); // 为预编译sql设置参数
                }
            }
        ResultSet num = pstmt.executeQuery(); // 执行SQL语句
        } catch (SQLException e) {
            e.printStackTrace(); // 处理SQLException异常
        } finally {
            try {
                BaseDao.closeAll(conn, pstmt, null);
            } catch (SQLException e) {    
                e.printStackTrace();
            }
        }
        return 0;
    }

    MySQL 8.0 and above:

    Driver package versionmysql-connector-java-8.0.12.jar。

    The database URL needs to declare whether to use SSL security verification and specify the time zone on the server:

    static final String DB_URL = jdbc:mysql://localhost:3306/runoob?useSSL=false&serverTimezone=UTC;
conn = DriverManager.getConnection(DB_URL,USER,PASS);

    The original driver was:

    Class.forName("com.mysql.jdbc.Driver");

    The prompt in IDEA is: Loading class `com.mysql.jdbc.Driver'. This is deprecated. The new driver class is `com.mysql.cj.jdbc.Driver'. The driver is automatically registered via the SPI and manual loading of the driver class is generally unnecessary

    It means the original driver is deprecated or obsolete, and it automatically switched to the new driver com.mysql.cj.jdbc.Driver

    Class.forName("com.mysql.cj.jdbc.Driver");

    Use Maven to automatically download mysql-connector-java.

    In the pom.xml of a Maven project, add the mysql-connector-java dependency. You only need to fill in the desired version number, and the corresponding jar package will be downloaded automatically, which is more convenient.

    <dependency>
    <groupId>mysql</groupId>
    <artifactId>mysql-connector-java</artifactId>
    <version>8.0.16</version>
</dependency>
