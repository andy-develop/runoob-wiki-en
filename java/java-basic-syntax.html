Java Objects and Classes

Java Basic Syntax

A Java program can be considered as a collection of objects that work together by calling each other's methods. The following briefly introduces the concepts of classes, objects, methods, and instance variables.

  • Object: An object is an instance of a class, with state and behavior. For example, a dog is an object; its states include color, name, breed; its behaviors include wagging its tail, barking, eating, etc.
  • 类: A class is a template that describes the behavior and state of a class of objects.
  • Method: Methods are behaviors. A class can have many methods. Logical operations, data modifications, and all actions are completed within methods.
  • Instance Variables: Each object has unique instance variables. The state of an object is determined by the values of these instance variables.

First Java Program

Below is a simple Java program that will output the stringHello World

Example

public class HelloWorld { /*First Java program * It will output the string Hello World*/ public static void main(String[] args) { System.out.println("Hello World"); //Output Hello World } }

Run Example »

Below is a step-by-step guide on how to save, compile, and run this program:

  • Open a code editor, and add the above code to it;
  • Save the file name as: HelloWorld.java;
  • Open the cmd command window, and navigate to the location of the target file, for example C:\
  • In the command line window, typejavac HelloWorld.javaPress Enter to compile the code. If there are no errors in the code, the cmd command prompt will move to the next line (assuming the environment variables are set up correctly).
  • Then typejava HelloWorldPress Enter to run the program.

You will see Hello World in the window.

$ javac HelloWorld.java
$ java HelloWorld 
Hello World

If you encounter encoding problems, we can use-encodingthe option settingutf-8to compile:

javac -encoding UTF-8 HelloWorld.java 
java HelloWorld

Basic Syntax

When writing Java programs, you should pay attention to the following points:

  • Case sensitivity: Java is case-sensitive, which means the identifiers Hello and hello are different.
  • Class name: For all classes, the first letter of the class name should be capitalized. If the class name consists of several words, the first letter of each word should be capitalized, for exampleMyFirstJavaClass 。
  • Method name: All method names should start with a lowercase letter. If a method name contains several words, the first letter of each subsequent word should be capitalized.
  • Source file name: The source file name must be the same as the class name. When saving the file, you should use the class name as the file name (remember that Java is case-sensitive). The file extension is.java. (If the file name and the class name are not the same, it will cause a compilation error).
  • Main method entry: All Java programs start executing from thepublic static void main(String[] args)method.

Java Identifiers

All components of Java require names. Class names, variable names, and method names are all called identifiers.

Regarding Java identifiers, there are several points to note:

  • All identifiers should begin with a letter (A-Z or a-z), a dollar sign ($), or an underscore (_)
  • After the first character, it can be any combination of letters (A-Z or a-z), dollar signs ($), underscores (_), or digits
  • Keywords cannot be used as identifiers
  • Identifiers are case-sensitive
  • Examples of legal identifiers: age, $salary, _value, __1_value
  • Examples of illegal identifiers: 123abc, -salary

Java Modifiers

Like other languages, Java can use modifiers to modify methods and attributes in classes. There are mainly two types of modifiers:

  • Access control modifiers: default, public, protected, private
  • Non-access control modifiers: final, abstract, static, synchronized

We will discuss Java modifiers in depth in later chapters.

Java Variables

Java mainly has the following types of variables
  • Local variables
  • Class variables (static variables)
  • Member variables (non-static variables)

Java Arrays

Arrays are objects stored on the heap that can hold multiple variables of the same type. In later chapters, we will learn how to declare, construct, and initialize an array.

Java Enums

Java 5.0 introduced enums. Enums restrict variables to only pre-set values. Using enums can reduce bugs in code.

For example, if we design a program for a juice shop, it will restrict juice to small, medium, and large cups. This means it does not allow customers to order juice in any size other than these three.

Example

class FreshJuice { enum FreshJuiceSize{ SMALL, MEDIUM , LARGE } FreshJuiceSize size; } public class FreshJuiceTest { public static void main(String[] args){ FreshJuice juice = new FreshJuice(); juice.size = FreshJuice.FreshJuiceSize.MEDIUM ; } }

Note:Enums can be declared separately or within a class. Methods, variables, and constructors can also be defined in enums.

Java Comments

Similar to C/C++, Java also supports single-line and multi-line comments.

Characters in comments will be ignored by the Java compiler.

public class HelloWorld { /*This is the first Java program * It will output Hello World * This is an example of a multi-line comment*/ public static void main(String[] args){ //This is an example of a single-line comment /*This is also an example of a single-line comment*/ System.out.println("Hello World"); } }

For more content, you can refer to:Java Comments。

Java Blank Lines

Blank lines or lines with comments will be ignored by the Java compiler.

Inheritance

In Java, a class can be derived from other classes. If you want to create a class and there is already a class that has the properties or methods you need, you can have the newly created class inherit that class.

Using inheritance, you can reuse the methods and properties of existing classes without rewriting the code. The inherited class is called the super class, and the derived class is called the subclass.

Interface

In Java, an interface can be understood as a protocol for communication between objects. Interfaces play a very important role in inheritance.

An interface only defines the methods to be used by derived classes, but the specific implementation of the methods depends entirely on the derived class.

    Data type overflow

    In Java, only numeric types can participate in operations. But every data type has its value range.

    For example, the byte data type has a value range of-128 - 127 。

    when we usebyte b = 128;it will definitely report an error.

    But usingbyte b = 127+1;will not report an error.

    And the result of the operation is-128。

    We can think of the value range of a data type as a circle. Each additional data point moves forward by one. When the data reaches the maximum value, if we add 1 again, it becomes the minimum value. This is data overflow.

    byte value range

    In Java, byte occupies one byte. Why is its value range-128~127？（-2^7~2^7-1）

    Computers use binary to represent data. One byte is 8 bits, where the highest bit represents the sign bit (0 positive, 1 negative).

    Therefore, the value range of byte is1000 0000 到 0111 1111。

    In Java, data is represented using two's complement.

    The two's complement of a positive number is the same as its original code. The two's complement of a negative number is obtained by inverting each bit of the original code and then adding 1.

    1000 000 is a two's complement. Subtract 1 and then invert bitwise to get its original code 1000 0000. (Subtracting 1 gives 0111 1111, then inverting bitwise gives 1000 0000)

    Because it is a negative number, the minimum byte value is-2^7=-128。

    The decimal value of 0111 1111 is 2^7-1=127 (sum of a geometric sequence).

    byte is one byte, with 2^8=256 possible values, namely -128~127.

    The same applies to other primitive data types:

    char has no negative values and occupies two bytes, so its value range is0~2^16-1（65535）。

    The difference between throw and throws:

    throws is used to declare all exceptions that a method may produce; it does not handle them but passes them up, throwing them to whoever calls me.

    throw is used to throw a specific exception type.

    throws declares exceptions after the method, meaning you don't want to handle the exceptions yourself, but tell others about the possible exceptions and leave them to others to handle.

    throw means handling an exception yourself; there are two ways: either catch the exception yourselftry...catchin a code block, or throw an exception (throws an exception).
