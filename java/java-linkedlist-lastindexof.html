Java LinkedList lastIndexOf() Method Explained in Detail

Java LinkedList

lastIndexOf()The method is a practical method in JavaLinkedListprovided by the LinkedList class, used to find the index of the last occurrence of the specified element in the linked list. If the linked list does not contain the element, -1 is returned.

This method is inherited fromListinterface, and inLinkedListthe implementation searches elements from the tail of the linked list forward.

Method Syntax

public int lastIndexOf(Object o)

Parameter description

  • o: the element to be searched in the linked list
  • Return value: the index of the last occurrence of the element (counting from 0), or -1 if not found

Usage examples

Let's understand through several examples:lastIndexOf()the usage of the method:

Example 1: Basic Usage

Example

import java.util.LinkedList;

public class LastIndexOfExample {
    public static void main(String[] args) {
        // Create a LinkedList
        LinkedList<String> fruits = new LinkedList<>();
       
        // Add elements
        fruits.add("Apple");
        fruits.add("Banana");
        fruits.add("Orange");
        fruits.add("Banana");
        fruits.add("Mango");
       
        // Find the last occurrence position of "Banana"
        int lastIndex = fruits.lastIndexOf("Banana");
        System.out.println("Last position of Banana: " + lastIndex);
       
        // Find a non-existent element
        int notFound = fruits.lastIndexOf("Grape");
        System.out.println("Position of Grape: " + notFound);
    }
}

Output result:

Banana 最后一次出现的位置: 3
Grape 的位置: -1

Method Implementation Principle

LinkedListin thelastIndexOf()The implementation logic of the method is as follows:

  1. Traverse the linked list from the tail backwards
  2. For each element, useequals()the equals() method to compare with the target element
  3. After finding the first matching element, return its index
  4. If no matching element is found after traversing the entire linked list, return -1

Performance Considerations

  • lastIndexOf()The time complexity of the method is O(n), because it may need to traverse the entire linked list
  • For large linked lists, frequently calling this method may affect performance
  • If you need to frequently find element positions, consider usingArrayListArrayList or other data structures more suitable for random access
