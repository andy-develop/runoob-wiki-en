图论结构

In computer science, graphs are widely used to model social networks (users are nodes, friendships are edges), web links (web pages are nodes, hyperlinks are edges), communication networks, and even path planning problems.

图It's like a social network relationship graph:

  • Node (Vertex): Each person in the social network
  • 边: Relationships between people (friends, follows, etc.)
  • 权重: strength of the relationship (closeness, interaction frequency, etc.)

Imagine the transportation network in your city: various locations (such as home, school, shopping mall) are点, the roads connecting these locations are线. A graph (Graph) is the mathematical abstraction of the relationship between points and lines; it is used to representComplex relationships between entitiesa data structure.

Real-life examples:

  • 地图: cities are nodes, roads are edges, distances are weights
  • 电路: components are nodes, wires are edges, resistance is the weight
  • 互联网: websites are nodes, links are edges, traffic is the weight
  • 交通网络: stations are nodes, routes are edges, fares are weights

社交关系 Difficult to express complex relationships Naturally expresses many-to-many relationships
路径规划 Requires complex data structures Intuitively represents networks and paths
依赖关系 Difficult to represent circular dependencies Easily handles complex dependencies

Basic concepts of graphs

一个图GConsists of two sets:

  • 顶点集 V (Vertex Set): The set of all vertices in the graph.
  • 边集 E (Edge Set): the set of lines connecting these points. An edge is defined by the two vertices it connects(u, v)表示。

实例

# 一个简单的图示例：用字典表示社交网络好友关系
# 顶点： Alice, Bob, Charlie, Diana
# 边： 表示他们之间的好友关系

social_graph = {

    'Bob': ['Alice', 'Charlie', 'Diana'],

    'Diana': ['Bob']

print(f"顶点（用户）: {list(social_graph.keys())}")
print(f"Alice 的好友（边）: {social_graph['Alice']}")

输出：

顶点（用户）: ['Alice', 'Bob', 'Charlie', 'Diana']
Alice 的好友（边）: ['Bob', 'Charlie']

Graph classification and important concepts

Graphs can be divided into multiple types based on the properties of their edges; understanding these is the foundation of mastering graph theory.

Undirected graph vs directed graph

类型 Characteristics of edges (Edge) 生活类比 示例
无向图 Edges have no direction,(A, B)Represents that A and B are mutually connected. 双向友谊: if Alice is Bob's friend, then Bob must also be Alice's friend. Friendships in social networks, connections in circuits.
有向图 边有方向，A -> BRepresents a one-way connection from A to B. 微博关注: You can follow someone, but the other person may not follow you back. Web hyperlinks, task dependencies, one-way traffic roads.

权重图

In a weighted graph, each edge is assigned a numerical value (weight), which can represent distance, cost, time, or relationship strength.

实例

# 一个表示城市间距离的权重图（邻接表形式）
weighted_graph = {
    '北京': {('上海', 1200), ('天津', 100)},  # 北京到上海距离1200，到天津距离100
    '上海': {('北京', 1200), ('杭州', 200)},
    '天津': {('北京', 100)},
    '杭州': {('上海', 200)}
}

关键术语

  • 度 (Degree): the number of edges connected to a vertex. In a directed graph, it is divided into入度(number of edges pointing to the vertex) and出度(number of edges pointing out from the vertex).
  • 路径 (Path): a sequence of edges traversed from one vertex to another. For example,A -> B -> C。
  • 环/回路 (Cycle): a path whose starting point and ending point are the same vertex.
  • 连通图 (Connected Graph): in an undirected graph, there is a path between any two vertices.
  • 强连通图 (Strongly Connected Graph): in a directed graph, there is a path between any two vertices.双向路径。

Graph storage methods

How to represent a graph in a computer? There are mainly two mainstream methods.

邻接矩阵

Use a two-dimensional array (matrix)matrix来表示图。matrix[i][j]The value represents the vertexi到顶点jThe situation of edges.

  • For undirected graphs, the matrix is symmetric.
  • For a weighted graph, the matrix entries store weights (using special values such as0 或 ∞Represents no edge).
  • 优点: checking whether there is an edge between any two vertices is very fast (O(1)）。
  • 缺点: Takes up a lot of space (O(V^2)), but it wastes space for "sparse graphs" with few edges.

实例

# 使用邻接矩阵表示一个无向图
# 顶点： 0-A, 1-B, 2-C
# 边： A-B, A-C

V = 3  # 顶点数
adj_matrix = [[0] * V for _ in range(V)]

# 添加边 A-B (0-1)
adj_matrix[0][1] = 1
adj_matrix[1][0] = 1  # 无向图需要设置对称位置
# 添加边 A-C (0-2)
adj_matrix[0][2] = 1
adj_matrix[2][0] = 1

print("邻接矩阵：")
for row in adj_matrix:
    print(row)
# 输出：
# [0, 1, 1]
# [1, 0, 0]
# [1, 0, 0]

邻接表

Maintain a list (linked list, array, etc.) for each vertex, recording all vertices (and weights) directly connected to it.

  • 优点: High space efficiency (O(V + E)), especially suitable for sparse graphs. It can quickly find all neighbors of a vertex.
  • 缺点: checking whether there is an edge between any two vertices is slower (O(degree(V))）。

实例

# 使用邻接表（字典+列表）表示同一个无向图
adj_list = {
    'A': ['B', 'C'],  # A 连接着 B 和 C
    'B': ['A'],       # B 连接着 A
    'C': ['A']        # C 连接着 A
}

print("邻接表：")
for vertex, neighbors in adj_list.items():
    print(f"{vertex}: {neighbors}")

Graph traversal algorithms

Traversal is the foundation of graph algorithms; it means systematically visiting every vertex in the graph.

There are mainly two strategies:

Breadth-First Search

Breadth-first search (BFS) is like "water wave diffusion": starting from the starting point, it first visits all direct neighbors, then the neighbors' neighbors, and so on. It uses队列来实现。

算法步骤：

  1. Put the starting point into a queue and mark it as visited.
  2. When the queue is not empty: a. Dequeue the front vertexv。 b. 访问vall unvisited neighbors of it, put them into the queue and mark them as visited.
  3. Repeat step 2.

实例

from collections import deque

def bfs(graph, start):
    """使用 BFS 遍历图，返回访问顺序"""
    visited = set([start])  # 记录已访问顶点
    queue = deque([start])  # 初始化队列
    result = []             # 存储访问顺序

    while queue:
        vertex = queue.popleft()
        result.append(vertex)
        # 遍历当前顶点的邻居
        for neighbor in graph[vertex]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    return result

# 测试数据
test_graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E']
}

print("BFS 遍历顺序（从A开始）:", bfs(test_graph, 'A'))
# 输出可能是: ['A', 'B', 'C', 'D', 'E', 'F']

Depth-First Search

Depth-first search (DFS) is like "walking through a maze": it chooses one path, goes to the end, then backtracks and takes another path. It uses栈(or recursion) to implement.

Recursive algorithm steps：

  1. 从顶点vStart, mark as visited.
  2. 对于vevery unvisited neighbor ofu: a. Recursive callDFS(u)。

实例

def dfs_recursive(graph, vertex, visited=None, result=None):
    """使用递归实现 DFS"""
    if visited is None:
        visited = set()
    if result is None:
        result = []

    visited.add(vertex)
    result.append(vertex)

    for neighbor in graph[vertex]:
        if neighbor not in visited:
            dfs_recursive(graph, neighbor, visited, result)
    return result

print("DFS 遍历顺序（从A开始）:", dfs_recursive(test_graph, 'A'))
# 输出可能是: ['A', 'B', 'D', 'E', 'F', 'C']

Classic application scenarios and algorithm introduction

Once you have mastered graph representation and traversal, you can explore many classic problems:

  1. Shortest path problem: in map navigation, find the shortest driving distance between two points.

    • Dijkstra's algorithm：适用于权重非负的图。
    • Floyd's algorithm: compute the shortest paths between all pairs of vertices.

  2. 最小生成树: under the premise of keeping all vertices connected, select the edge set with the smallest total weight (for example, laying the lowest-cost fiber network for multiple villages).

    • 普里姆算法
    • Kruskal's algorithm

  3. 拓扑排序: linearly order the vertices of a directed acyclic graph (DAG) so that for any directed edgeu->v，uIn sorting, all are rankedvbefore (for example, arranging the learning order of courses).
