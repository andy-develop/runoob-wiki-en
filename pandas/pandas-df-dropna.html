df.dropna()is a function in Pandas used to delete rows or columns that contain missing values.

) is a common problem.NaN、None 或 NULLThe function provides a simple way to clean data. You can choose to delete rows or columns containing missing values, or filter data based on the proportion of missing values.dropna()Basic Syntax and Parameters

import pandas as pd
import numpy as np

# Has 2 missing values
data = {
    'A': [1, 2, np.nan, 4, 5],
    'B': [np.nan, 2, 3, 4, np.nan],  # No missing values
    'C': [1, 2, 3, 4, 5],  # Has 3 missing values
    'D': [np.nan, np.nan, np.nan, 4, 5]  "原始数据："
}
df = pd.DataFrame(data)

print(# Keep only rows with at least 3 non-missing values)
print(df)
print("=" * 50)

"保留至少3个非缺失值的行："
df_cleaned = df.dropna(thresh=3)

print(Expected output:)
print(df_cleaned)

import pandas as pd
import numpy as np

"原始数据："

Notes

  • dropna()By default, the original DataFrame is not modified. To modify it in place, useinplace=Trueparameter.
  • UsethreshWhen using the parameter, the value you set should be based on your requirements for data quality.
  • Before deleting data, it is recommended to first usedf.isnull().sum()to view the number of missing values in each column, so you can make more informed decisions.
  • For important datasets, use with cautiondropna(), because this may lead to a large amount of data loss. You may consider usingfillna()to fill missing values.
