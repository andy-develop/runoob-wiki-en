Eclipse Tutorial

Eclipse is an open-source, Java-based extensible development platform.

Eclipse is an integrated development environment (IDE) for Java; of course, Eclipse can also serve as an IDE for other development languages, such as C, C++, PHP, and Ruby.

Eclipse comes with a standard set of plugins, including the Java Development Kit (JDK).

License

The Eclipse platform and its plugins are released under the Eclipse Public License (EPL).

The Eclipse Public License (EPL for short) is an open-source software distribution license applied by the Eclipse Foundation to its integrated development environment Eclipse.

Release

Since 2006, the Eclipse Foundation has arranged a simultaneous release every year. To date, the simultaneous releases are mainly held in June, and SR1 and SR2 versions are released in the following September and February.
