安装 Lua

Lua 以 源代码is distributed in source form; you need to build it before using it. Building Lua is very simple, because Lua is implemented in pure ANSI C and can be compiled directly on all platforms that have an ANSI C compiler. Lua can also be compiled directly as C++. The build process on Unix-like platforms is described below. There is also其它系统构建介绍 与 配置选项 以作参考。

If you do not have the time or interest to compile Lua yourself, you can getLuaBinariescompiled binaries fromLuaDistor get a multi-platform distribution of Lua (batteries included) here.

Building Lua

On most Unix-like platforms, type "make" plus an appropriate platform name. The steps are:

  1. Open a console window and switch tolua-5.3.0directory. Under the directoryMakefileThe file contains the build and installation process.

  2. 运行 "make" and check whether your platform is listed. Currently supported platforms are:

    aix bsd c89 freebsd generic linux macosx mingw posix solaris

    If your platform is among them, run "make xxx" is enough, where xxx represents your platform name.

    If your platform is not among them, first try the most similar platform, then try in the order posix, generic, c89.

  3. The compilation process is very short, and finally insrcthe directory, three files are generated: lua (interpreter), luac (compiler), and liblua.a (static library).

  4. After the build is complete, you can run "make testto check whether it was successful. It will run the interpreter and print the version number.

If you are on Linux and get compilation errors, make sure you have installedreadline （也可能叫 libreadline-dev 或者 readline-devel) development package. After that, if there are still link errors, try "make linux MYLIBS=-ltermcap" 。

Installing Lua

Once you have built Lua, you may want to install it in the system default location, so run "make install" and that's it. The system default location and how to install are defined inMakefilein. This process may require relevant permissions.

运行 "make xxx install" can build and install in one step, where xxx refers to your platform name.

If you want to install Lua locally, run "make local. It will create ainstall 目录，内有 bin, include, lib, man, share, subdirectory, and install the following files in it.make install INSTALL_TOP=xxx, xxx refers to the directory you choose.src 以及 docproceed in the directory, so whenINSTALL_TOPbe careful when it is not an absolute path.

These are the directories needed for development. If you merely want to run some Lua programs, then you only needbin 和 man 下的文件。 include 和 libThe files under are used to embed Lua into C or C++ programs.

定制

There are three kinds of customization that can be done by editing files:

  • How to install Lua and where to install it — editMakefile。
  • How to build Lua — editingsrc/Makefile。
  • Lua features — editsrc/luaconf.h。

Actually you don't need to edit the Makefile; when running make, you can specify the relevant variables on the command line. Of course, editing and saving the Makefile can leave a record of the customization.

On the other hand, if you need to customize some Lua features, you need to edit before building and installing Luasrc/luaconf.h. The edited files must ensure consistency, that is, they are installed in only one place, so that all the programs you compile that use Lua use this single copy. Experts can customize more by editing the Lua source code.

在其它系统上构建 Lua

If you do not use the standard Unix tools, then the process of building Lua depends on the compiler you use. You need to create several projects to build the library, the interpreter, and the compiler, etc. Please add the following source files to the relevant projects:

解释器:

To use Lua as a library in your program, you need to know how to create libraries and use libraries with your compiler. For example, to use Lua as a dynamically loaded C library, you need to know how to create a dynamic library and make the Lua API functions visible in the dynamic library —不要link the Lua library into each dynamic library.src/MakefileThat is how the Lua interpreter is handled. On Windows, we recommend compiling the Lua library as a DLL. In any case, the compiler luac should be statically linked.

As mentioned above, you can edit before building Luasrc/luaconf.hto customize some features.

自 Lua 5.2 以来的变更

Here are the main changes introduced in Lua 5.3:参考手册 中列出了 不兼容的地方。

Main Changes

  • Integers (64-bit by default)
  • Official support for 32-bit integers
  • 位操作符
  • Basic utf-8 support
  • Functions for packing and unpacking values
These are other changes introduced in Lua 5.3:

Language

  • Userdata can be any Lua value
  • 整数除法
  • Some metamethods have more flexible rules

库

  • ipairsand the table library will also take metamethods into account
  • string.dumpadded more trimming options
  • The table library takes metamethods into account
  • 新函数 table.move
  • 新函数 string.pack
  • 新函数 string.unpack
  • 新函数 string.packsize

C API

  • Simplified the continuation-point API
  • lua_gettableas well as the value types of results returned by similar functions
  • lua_dumpadded trimming options
  • 新函数： lua_geti
  • 新函数： lua_seti
  • 新函数： lua_isyieldable
  • 新函数： lua_numbertointeger
  • 新函数： lua_rotate
  • 新函数： lua_stringtonumber

The Standalone Lua Interpreter

  • It can be used as a calculator; no leading '=' is needed.
  • argTables are available to all code
