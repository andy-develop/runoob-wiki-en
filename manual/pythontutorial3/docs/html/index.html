Python Getting Started Guide¶

Release:3.6.3
Date:Nov 26, 2017

Python is a simple, easy-to-learn yet powerful programming language. It has efficient high-level data structures and enables simple yet efficient object-oriented programming. Python's elegant syntax and dynamic typing, combined with its interpreted nature, make it an ideal language for scripting or developing applications in many fields on most platforms.

You can freely download from the official Python website: http://www.python.orgYou can obtain the Python interpreter and its standard extension libraries in source or binary form and freely distribute them. This site also provides a large number of third-party Python modules, programs, and tools, along with their additional documentation.

You can easily use C or C++ (or other languages callable through C) to extend the Python interpreter with new functions and data types. Python can also be used as an extension language for customized applications.

This manual informally introduces readers to the basic knowledge and concepts of the Python language and its related ecosystem. It is helpful to use the Python interpreter during learning and practice, but all examples are complete, so this manual can also be read offline.

For detailed information about related standard libraries or objects, please refer to Python Reference Documentation 。Python Reference Manual Provides more formal language-related specifications. If you want to write extensions in C or C++, please refer to Python Interpreter Extension and Integration Chapter And C API Reference Manual Of course, you can also read some books that introduce Python knowledge in depth.

This manual does not attempt to cover all of Python's knowledge and every feature, nor does it even cover all commonly used features. Instead, it introduces many of Python's most striking features and gives you an understanding of the language's characteristics and style. After reading it, you will be able to read and write Python modules or programs, and to use them later. Python Reference Manual Be prepared to continue learning many Python module libraries.
