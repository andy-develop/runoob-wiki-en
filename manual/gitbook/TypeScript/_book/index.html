TypeScript Handbook

TypeScript Handbook (Chinese Edition)

I used to hate languages that compile to JavaScript from the bottom of my heart, like CoffeeScript, Dart, etc. But around the Spring Festival of 2015, I fell in love with TypeScript. At the same time, my favorite frameworks, Dojo and AngularJS, also announced that they would use TypeScript for new version development. So what exactly is TypeScript? And what is its charm?

TypeScript is a registered trademark of Microsoft Corporation.

TypeScript has a type system and is a superset of JavaScript. It can be compiled into plain JavaScript code. TypeScript supports any browser, any environment, and any system, and it is open source.

TypeScript is still under active development and improvement, with new features constantly being added. Therefore, this handbook will closely follow every official commit, continuously adding new chapters and revising any inappropriate wording.

If you fall in love with TypeScript at first sight, you can subscribe toand starthis manual to stay up to date with the new native features in ECMAScript 2015 and 2016, and master how to use them in advance with the help of TypeScript!
