Property definition and usage instructions

The box-sizing property defines how to calculate an element's total width and total height, mainly setting whether padding and border need to be included.

For example, if you need to place two bordered boxes side by side, you can set box-sizing to "border-box". This allows the browser to render boxes with the specified width and height, and includes the border and padding inside the boxes.

By default, the width and height of an element are calculated as follows:

width(宽度) + padding(内边距) + border(边框) = 元素实际宽度
height(高度) + padding(内边距) + border(边框) = 元素实际高度
默认值: content-box
继承: no
版本: CSS3
JavaScript 语法: object.style.boxSizing="border-box"

语法

box-sizing: content-box|border-box|inherit:

值 说明
content-box Default value. If you set an element's width to 100px, then the element's content area will be 100px wide, and any border and padding widths will be added to the final rendered width of the element.
border-box Tells the browser: the border and padding values you set are included within the width. That is, if you set an element's width to 100px, then these 100px will include its border and padding, and the actual width of the content area is width minus (border + padding). In most cases, this makes it easier for us to set an element's width and height.
注：border-box 不包含 margin。
inherit Specifies that the value of the box-sizing property should be inherited from the parent element.

    This chapter doesn't highlight the key point! The main use of box-sizing is to specify the final size calculation method of a container element.

    If you create a <div> without setting the box-sizing property to border-box (if not set, the default value is content-box), and you also set width:100px; border:10px solid red; padding:10px;Then the final actual width of the div container is:

    100px(width)+2*10px*(padding)+2*10px(border)=140px

    So you will get a container larger than you expected (100px), which will break the webpage layout.

    注意Note: the size of margin will not be calculated into the final container width, because its definition is whitespace around the container, but it does not belong to the container itself.

    If we define a container's box-sizing property as border-box (the expression:br{box-sizing:border-box}), then when we create a <div> container with the same settings as in the previous paragraph, its final width will be 100px, so the effective width of its content part (content) becomes100px-2*10px-2*10px =60px;So you will get a box container of the expected size, but only the content part is compressed; however, this is quite beneficial for the overall layout.

    Therefore, you should make good use of this property; it is very important.

    The descriptions of content-box and border-box are too abstract, making them harder to understand.

    An intuitive and simple explanation is:

    content-box: Specifies the box model as the W3C standard model. Setting border and padding increases the element's width and height dimensions. That is, border and padding are equivalent to the element's "colonies"; the element's "land" and dimensions increase, extending outward.

    border-box: Specifies the box model as the IE model (quirks mode). Setting border and padding does not affect the element's width and height dimensions. That is, border and padding are converted from the element's already-allocated space. The space is still the same space; it just converts some unused areas into other space usages, which is an internal transformation.

    设置border与padding与被影响属性值的关系公式：

W3C标准盒模型（conten-box值）【width/height被改变，扩展】
width = content + border + padding;

// 其中，width 为浏览器视窗呈现尺寸，content 为在CSS中设置的元素的 width;

IE怪异盒模型（border-box值）【content被改变，压缩】
content = width - border - padding;

// 其中，width 为在CSS中设置的元素的width;


具体可用浏览器调试看看，多观察观察就懂了。

    总之：

    1. W3C standard box model (content-box): setting border and padding will break the element's width and height, requiring recalculation, which is very troublesome (except in IE browsers, where the default is the standard box model, so box-sizing can be used to convert);

    2. IE (quirks) box model (border-box): setting border and padding does not affect the element's width and height, which is very practical (and because the IE box model is not standard, there is the standard property box-sizing to set it and standardize it) [IE6/5 are quirks models, and IE7 onwards is the standard box model].

    Another little trick: [Line height calculation]

    /* 默认, W3C标准盒模型、 box-sizing: content-box */
<style type="text/css">
    .box {
      width: 200px;
      height: 200px;
      text-align: center;
      border: 10px solid black;
      padding: 15px;
    }
</style>
/* 此时的行高：line-height = height = 200px;*/
/* 【因为行高即内容的高，而内容在这里即元素的高（边框和填充是扩展外部空间的）】 */

/* - - - - - - 分割线 - - - - - - */

/* IE怪异盒模型、box-sizing: border-box; */
<style type="text/css">
    .box {
      width: 200px;
      height: 200px;
      text-align: center;
      border: 10px solid black;
      padding: 15px;
      box-sizing: border-box;
    }
</style>
/* 此时的行高：line-height = height - border*2 - padding*2 = 200px - 10px*2 - 15px*2 = 150px; */
/* 【因为此时，内容的其余空间被边框和填充占用，所以是元素的高减去边框和填充的空间，剩余即为内容空间】 */
