CSS 颜色

Color is formed by the display combination of red (RED), green (GREEN), and blue (BLUE) light.

颜色值

In CSS, colors are defined using hexadecimal (hex) notation as a combination of red, green, and blue color values. The lowest value can be 0 (hex 00) and the highest value is 255 (hex FF).

Written as three two-digit hexadecimal values, starting with the # symbol.

颜色实例

Color Color HEX Color RGB
  #000000 rgb(0,0,0)
  #FF0000 rgb(255,0,0)
  #00FF00 rgb(0,255,0)
  #0000FF rgb(0,0,255)
  #FFFF00 rgb(255,255,0)
  #00FFFF rgb(0,255,255)
  #FF00FF rgb(255,0,255)
  #C0C0C0 rgb(192,192,192)
  #FFFFFF rgb(255,255,255)

More than 16 million different colors

The combination of red, green, and blue values from 0 to 255 gives a total of over 16 million different colors (256 × 256 × 256).

Most modern monitors are capable of displaying at least 16,384 colors.

If you look at the color table below, you will see different red light colors from 0 to 255.

To see the red light change from 0 to 255 in a full color mix, click the hexadecimal or RGB value.

Network security color?

Several years ago, when computers supported a maximum of 256 different colors, a 216-color "web-safe colors" list was recommended as a Web standard, reserving 40 fixed system colors.

This is not very important now, because most computers can display millions of different colors, but the choice is left to you.
