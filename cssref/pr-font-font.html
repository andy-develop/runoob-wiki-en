Property definition and usage instructions

The font shorthand property sets all font properties in one declaration.

canSettingsofPropertyYes（pressSequence）： "font-style font-variant font-weight font-size/line-height font-family"

The values of font-size and font-family are required. If other values are missing, default values will be inserted, if there are default values.

Note:The line-height property sets the space between lines.

Default value: not specified
Inherited: yes
version: CSS1
JavaScript Syntax: object.style.font="italic small-caps bold 12px arial,sans-serif"
