CSS 选择器

CSS (Cascading Style Sheets) provides a variety of selectors for selecting HTML elements to apply styles to.

CSS selectors are patterns used to select the elements you want to style.

The "CSS" column in the table below indicates the CSS version in which the property is defined. CSS1, CSS2, and CSS3 are different versions of Cascading Style Sheets, each introducing new features and capabilities to improve the control and design of web page styles.

Common CSS selectors

The following are some common CSS selectors:

Element Selector:Selects HTML elements by element name.

如下代码，pThe selector will select all<p>元素:

p {
  color: blue;
}

类选择器（Class Selector）：Selects HTML elements with a specific class by class name.

类选择器以.starting with, followed by the class name.

如下代码，.highlightThe selector will select all elements with the class"highlight"的元素。

.highlight {
  background-color: yellow;
}

ID 选择器（ID Selector）：Selects HTML elements by the element's unique identifier (ID).

ID selectors start with#starting with, followed by the ID name.

如下代码，#runoobThe selector will select elements with the ID"runoob"的元素。

#runoob {
  width: 200px;
}

属性选择器（Attribute Selector）：Selects HTML elements by the element's attributes. Attribute selectors can select based on attribute names and attribute values.

如下代码，input[type="text"]The selector will select alltype属性为"text"the <input> element.

input[type="text"] {
  border: 1px solid gray;
}

后代选择器（Descendant Selector）：Selects HTML elements by specifying the descendant relationship of elements.

The descendant selector uses spaces to separate element names.

In the following code, the div p selector will select all <p> elements within <div> elements.

div p {
  font-weight: bold;
}

    CSS1、CSS2和CSS3

    CSS1, CSS2, and CSS3 are different versions of Cascading Style Sheets, each introducing new features and capabilities to improve the control and design of web page styles.

    • CSS1 (introduced in 1996):CSS1 is the first version of the CSS specification. It introduced a basic set of style properties and selectors, allowing developers to apply styles to HTML documents through style sheets. CSS1 provided control over basic styles such as fonts, colors, backgrounds, and borders. It laid some groundwork for web page layout and styling, but its functionality was relatively limited.

    • CSS2 (introduced in 1998):CSS2 is the second version of the CSS specification, introducing more features and selectors and enhancing the ability to control styles. It introduced features such as floats, positioning, and cascading, enabling developers to better control and lay out web page elements. CSS2 also introduced pseudo-class and pseudo-element selectors, allowing developers to apply styles based on the state or position of elements.

    • CSS3 (started in 2001, continuously evolving):CSS3 is the next-generation CSS specification, consisting of a series of modules, each introducing new features and capabilities. CSS3 introduced more selectors, box model properties, color and background properties, text effects, transitions and animations, multi-column layouts, and more. It also introduced Media Queries, allowing developers to apply different styles based on device attributes and characteristics, thereby enabling responsive design. The development of CSS3 is incremental, with new modules and features continuously being added and standardized.

    It should be noted that CSS3 is not a complete standard version, but rather a collection of multiple modules. The development and support levels of each module may vary. However, people generally refer to the new functions and features introduced since CSS3 collectively as CSS3, to distinguish them from earlier CSS versions. Developers can choose to use CSS3 features based on target browsers and requirements, and ensure compatibility across different browsers through feature detection and prefixes.
