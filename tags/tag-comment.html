HTML <!--...-->Comment Tag


Examples

HTML Comments:

<!--This is a comment. Comments are not displayed in the browser.--> <p>This is a paragraph.</p>

Try it Yourself »

Browser Support

All major browsers support the <!--...--> comment tag.

Tag Definition and Usage Instructions

The <!--...--> comment tag is used to insert comments in the source document. Comments are not displayed in the browser.

You can use comments to explain your code, which helps you edit the code at a later time. This is especially useful when you have a large amount of code.

You can also store program-specific information in the comment content. In this case, this information is invisible to users but available to programs. A good habit is to put script or style elements within comment text, so that old browsers that do not support scripts or styles will not display them as plain text.

<script type="text/javascript"> <!-- function displayMsg() { alert("Hello World!") } //--> </script>

Note:The two forward slashes (//) at the end of the line are JavaScript comment symbols. This ensures that JavaScript does not execute the --> tag.

In addition to their obvious role in the source document, many web servers also use comments to implement features specific to server-side software for documents. These servers can scan documents to find specific character sequences in traditional HTML/XHTML comments, and then take corresponding actions based on commands embedded in the comments. These actions may be as simple as including text from other files (i.e., so-called server-side includes, server-inside include), or as complex as executing other commands to dynamically generate the content of the document.

Differences between HTML 4.01 and HTML5

None.

Standard Attributes

The <!--...--> comment tag does not support any standard attributes.

For more information about HTML standard attributes, please visitStandard Attributes。

Event Attributes

The <!--...--> comment tag does not support any event attributes.

For more information about HTML event attributes, please visitEvent Attributes。

    What is the purpose of <!-- //--> in JavaScript?

    In HTML, the following syntax is often seen when using JavaScript:

    <script type="text/javascript">
<!--
XXXXXXXX内容略XXXXX
//-->
</script>

    This is to prevent some browsers that do not support JavaScript from displaying JavaScript code directly on the page, which would affect the appearance.

    Therefore, use HTML comments to enclose the JavaScript code. If the browser does not support JavaScript, it will be treated as a comment. Even if JavaScript is disabled, the source code will not be displayed on the page.

    (Some browsers may support JavaScript, but also provide users with a switch to disable JavaScript. If the user disables JavaScript, the same will happen.)

    If a tag is very long, how can you embed a comment within the tag? The comment tag cannot do this. The answer is to use the tag's style (inline style) attribute. The format is:

    style="/* 注释内容 */"

    Note the opening/*and the closing*/, they are CSS comment symbols. The style attribute is often used to change the appearance of an element, but here it only contains a comment, so it will not change any appearance.

    For example:

    <a style="/* 菜鸟教程官方网站 */" href="../index.html" target="_blank" rel="noopener">菜鸟教程</a>

    This way it can load normally.

    If the style attribute already exists (used to change appearance), you can add the comment at the beginning or the end. For example:

    <a style="font-style:italic;font-size:32px;/* 菜鸟教程官方网站 */" href="../index.html" target="_blank" rel="noopener">菜鸟教程</a>

    Or:

    <a style="/* 菜鸟教程官方网站 */font-style:italic;font-size:32px;" href="../index.html" target="_blank" rel="noopener">菜鸟教程</a>
