HTML ISO-8859-1Reference Manual

Character sets supported by modern browsers:

  • ASCII character set
  • Standard ISO character set
  • Mathematical symbols, Greek letters, and other symbols

ISO-8859-1

ISO-8859-1 is the default character set for most browsers.

The lower part of ISO-8859-1 (codes between 1 and 127) is the original ASCII character set (digits 0-9, uppercase and lowercase English alphabet, and some special characters).

The upper part of ISO-8859-1 (codes between 160 and 255) contains characters used in some Western European countries and some widely used special characters, all of which have entity names.

Most of these symbols can be used without entity references, but entity names or entity numbers provide a way to express symbols that are not easy to type via the keyboard.
