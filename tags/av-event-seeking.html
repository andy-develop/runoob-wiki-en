Definition and Usage

The seeking event is triggered when the user starts moving/jumping to a new audio/video playback position.

Tip:The opposite event of the seeking event isseekedEvent.

Tip:Use of Audio/Video objectscurrentTimeAttribute to get the playback position.

Browser Support

The numbers in the table represent the version number of the first browser that supports the event.

Events
seeking Yes 9.0 Yes Yes Yes

Syntax

In HTML:

<audio|video onseeking="myScript">Try it Yourself

In JavaScript:

audio|video.onseeking=function(){myScript};Try it Yourself

In JavaScript, using the addEventListener() method:

audio|video.addEventListener("seeking", myScript);Try it Yourself

Note:Internet Explorer 8 and earlier IE versions do not supportaddEventListener()method.

Technical Details
Supported HTML tags: <audio> and <video>
Supported JavaScript objects: Audio, Video

Example

When the user starts moving to a new position, use the currentTime property of the Video object to display the current playback position:

// Get the <video> element with id="myVideo"
var vid = document.getElementById("myVideo");

// Add seeking event to <video>, if seeking starts, execute the function
vid.addEventListener("seeking", myFunction);

function myFunction() {
// Display the playback position of <video> in the p element with id="demo"
    document.getElementById("demo").innerHTML = vid.currentTime;
}
