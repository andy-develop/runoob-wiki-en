Definition and Usage

The canPlayType() method detects whether the browser can play the specified audio/video type.

The canPlayType() method can return one of the following values:

  • "probably" - The browser most likely supports the audio/video type
  • "maybe" - The browser might support the audio/video type
  • "" - (empty string) The browser does not support the audio/video type

Browser Support

All major browsers support the canPlayType() method.

Note:Internet Explorer 8 and earlier versions do not support this method.

Syntax

audio|video.canPlayType(type))

Parameter

Value Description
type Specifies the audio/video type (and optional codecs) to be detected.

Common values:

  • video/ogg
  • video/mp4
  • video/webm
  • audio/mpeg
  • audio/ogg
  • audio/mp4

Common values, including codecs:

  • video/ogg; codecs="theora, vorbis"
  • video/mp4; codecs="avc1.4D401E, mp4a.40.2"
  • video/webm; codecs="vp8.0, vorbis"
  • audio/ogg; codecs="vorbis"
  • audio/mp4; codecs="mp4a.40.5"

Note:If a codec is included, the method can only return "probably".

Return Value

Type Description
String Indicates the level of support. Possible return values:
  • "probably" - most likely to support
  • "maybe" - may be supported
  • "" - (empty string) not supported
