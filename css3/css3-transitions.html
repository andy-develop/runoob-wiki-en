How does it work?

CSS3 transitions are effects that gradually change an element from one style to another.

To achieve this, two things must be specified:

  • Specify the CSS property to which you want to add the effect.
  • Specify the duration of the effect.

实例

A transition effect applied to the width property, with a duration of 2 seconds:

div { transition: width 2s; -webkit-transition: width 2s; /* Safari */ }

注意：If the duration is not specified, the transition will have no effect, because the default value is 0.

The effect changes when the value of the specified CSS property changes. A typical CSS property change occurs when the user's mouse hovers over an element:

实例

Specify when the mouse pointer hovers (:hover) over the <div> element:

div:hover { width:300px; }

注意：When the mouse cursor moves over the element, it gradually transitions from its original style.

多项改变

To add transition effects for multiple styles, add the properties separated by commas:

实例

Added width, height, and transform effects:

div { transition: width 2s, height 2s, transform 2s; -webkit-transition: width 2s, height 2s, -webkit-transform 2s; }

过渡属性

The following table lists all the transition properties:

属性 描述 CSS
transition Shorthand property, used to set four transition properties in one property. 3
transition-property Specifies the name of the CSS property to which the transition is applied. 3
transition-duration Defines the time spent on the transition effect. The default is 0. 3
transition-timing-function Specifies the timing curve of the transition effect. The default is "ease". 3
transition-delay Specifies when the transition effect will start. The default is 0. 3

The following two examples set all transition properties:

实例

Use all transition properties in one example:

div { transition-property: width; transition-duration: 1s; transition-timing-function: linear; transition-delay: 2s; /* Safari */ -webkit-transition-property:width; -webkit-transition-duration:1s; -webkit-transition-timing-function:linear; -webkit-transition-delay:2s; }

Same transition effect as the example above, but using the shorthand transition property:

    I have always wondered how to handle this effect before. I originally considered using JavaScript, but it is very complicated to write; if you also consider the color transition effect after the mouse moves over it, it is even more difficult. Now we can consider using CSS transitions to handle this.

    The common "black curtain" surface we see looks like this:

    The effect after moving the mouse is like this:

    So our design approach is as follows:

    1) The background color remains black;

    2) The font color is also black, and it gradually turns white only when the mouse hovers over it or it is selected.

    From this, we can design the following code:

    <p>这是测试<span class="mask">并且被掩盖的</span>文字！</p>

    color: #252525;

.mask:hover {

    <div class="left"></div>
<div class="right"></div>
<style>
.left{
    width:50%;
    height:50px;
    background:#C00;
    position:absolute;
    top:0;
    left:0;
    transition:0.6s;/*动画*/
    -moz-transition:0.6s; /* Firefox 4 */
    -webkit-transition:0.6s; /* Safari and Chrome */
    -o-transition:0.6s; /* Opera */
}
.right{
    width:50%;
    height:50px;
    background:#03C;
    position:absolute;
    top:0;
