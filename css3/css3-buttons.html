CSS 按钮

In this chapter, we introduce how to use CSS to create buttons.

Basic button style

实例

.button {
    background-color: #4CAF50; /* Green */
    border: none;
    color: white;
    padding: 15px 32px;
    text-align: center;
    text-decoration: none;
    display: inline-block;
    font-size: 16px;
}

按钮颜色

We can usebackground-colorAttribute to set button color:

实例

.button1 {background-color: #4CAF50;} /*绿色*/ .button2 {background-color: #008CBA;} /*蓝色*/ .button3 {background-color: #f44336;} /*红色*/ .button4 {background-color: #e7e7e7; color: black;} /*灰色*/ .button5 {background-color: #555555;} /*黑色*/

按钮大小

We can usefont-sizeAttribute to set button size:

实例

.button1 {font-size: 10px;} .button2 {font-size: 12px;} .button3 {font-size: 16px;} .button4 {font-size: 20px;} .button5 {font-size: 24px;}

We can useborder-radiusAttribute to set rounded button:

实例

.button1 {border-radius: 2px;} .button2 {border-radius: 4px;} .button3 {border-radius: 8px;} .button4 {border-radius: 12px;} .button5 {border-radius: 50%;}

Button border color

实例

Mouse hover button


We can use:hoverThe selector is used to modify the style when the mouse hovers over the button.

提示:We can usetransition-durationThe property sets the speed of the "hover" effect:

实例

.button { -webkit-transition-duration: 0.4s; /* Safari */ transition-duration: 0.4s; } .button:hover { background-color: #4CAF50; /* Green */ color: white; } ...

按钮阴影

We can usebox-shadowAttribute to add shadow to button:

实例

.button1 { box-shadow: 0 8px 16px 0 rgba(0,0,0,0.2), 0 6px 20px 0 rgba(0,0,0,0.19); } .button2:hover { box-shadow: 0 12px 16px 0 rgba(0,0,0,0.24), 0 17px 50px 0 rgba(0,0,0,0.19); }

尝试一下 »

禁用按钮

We can useopacityThe property adds transparency to the button (looks similar to the effect of the "disabled" attribute).

提示:We can addcursorThe property, set to "not-allowed", is used to set a disabled image:

实例

.disabled { opacity: 0.6; cursor: not-allowed; }

尝试一下 »

按钮宽度


By default, the size of the button is determined by the text content on the button (the length matches based on the text content). We can usewidthAttribute to set button width:

提示:If you want to set a fixed width, you can use pixels (px) as the unit; if you want to set a responsive button, you can set it as a percentage.

实例

.button1 {width: 250px;} .button2 {width: 50%;} .button3 {width: 100%;}

Remove outer margin and addfloat:leftto set up a button group:

实例
