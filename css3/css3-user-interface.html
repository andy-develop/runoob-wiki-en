CSS3 User Interface

In CSS3, some new user interface features have been added to adjust element size, box sizing, and outlines.

In this chapter, you will learn about the following user interface properties:

  • resize
  • box-sizing
  • outline-offset

CSS3 Resizing

In CSS3, the resize property specifies whether an element should be resized by the user.

这个 div 元素由用户调整大小。 (在 Firefox 4+, Chrome, 和 Safari中)

The CSS code is as follows:

实例

The user specifies the size of a div element:

div { resize:both; overflow:auto; }

CSS3 Box Sizing

The box-sizing property allows you to define specific content in an exact way to fit an area.

实例

Specify two side-by-side bordered boxes:

div { box-sizing:border-box; -moz-box-sizing:border-box; /* Firefox */ width:50%; float:left; }

CSS3 外形修饰（outline-offset ）

The outline-offset property offsets the outline and draws it beyond the border edge.

There are two differences between outlines and borders:

  • Outline takes up no space
  • Outlines may be non-rectangular
这个 div 在边框之外 15 像素处有一个轮廓。

The CSS code is as follows:

实例

Specifies an outline 15 pixels outside the border edge:

div { border:2px solid black; outline:2px solid red; outline-offset:15px; }

    The resize property specifies that the user can display overflow hidden content by stretching the element size. The effect is similar to the <textarea></textarea> textarea tag.

    It can be said that the <textarea> tag comes with resize: both; so you can prevent the <textarea> from being resized by setting resize: none;.

    However, it is worth noting the settings for overflow:

    1. When overflow: hidden;, regardless of whether the size is stretched, content that exceeds the size will be hidden and clipped;

    2. When overflow: scroll;, regardless of whether the size is stretched, the element always displays the scrollbar;

    3. When overflow: auto;, the scrollbar appears only when the size is smaller than the content display - it can be said that this is the most aesthetic setting (<textarea> also has this property by default);

    ----------------------------------------------------------------------------------------------------

    The outline-offset property is used to set the spacing, or "padding", between the outline (outer border) and the border (inner border). By default, the outline is flush with the border, so this property is needed to separate them.

    outline does not break the width and height of the element; similarly, the spacing set by outline-offset does not affect the width and height of the element.

    ----------------------------------------------------------------------------------------------------

    box-sizing is used to tell the browser which box model to use to render the document.

    content-box is the default box model, i.e., the W3C standard box model. Nowadays, all mainstream browsers support and use this model for layout rendering, including IE. But it brings a lot of trouble, because under this model, the settings of border and padding will break the element's size, causing the final layout to not match the desired effect. To achieve the desired effect, you need to calculate the width and height, which is very troublesome.

    (For other properties, the more standard the better, but this property actually goes in the opposite direction toward the IE standard)

    border-box refers to the IE box model, also called the "weird box model". Under this model, the border and padding do not affect the width and height of the element. It is equivalent to occupying the element's space as its own space; the overall size of the element remains unchanged, the content space becomes smaller, and the border and padding occupy the place that originally belonged to the content space. This is very comfortable when designing layouts, because after specifying the element size and setting this property value, the element size will not be broken and need to be recalculated.

    例子：

    <div class="clearfix">
  <h3>想要实现的效果</h3>
  <div class="container">
    <div class="box left"></div>
    <div class="box right"></div>
  </div>
</div>
<hr />
<div class="clearfix">
  <h3>默认标准盒模型，添加边框、填充后的效果</h3>
  <div class="container">
    <div class="box left content-box"></div>
    <div class="box right content-box"></div>
  </div>
  <!-- 实现效果则需改 width = 400px - 5px*2 - 10px*2 = 370px -->
</div>
<hr />
<div class="clearfix">
  <h3>设置border-box后，添加边框、填充后的效果</h3>
  <div class="container">
    <div class="box left border-box"></div>
    <div class="box right border-box"></div>
  </div>
</div>
