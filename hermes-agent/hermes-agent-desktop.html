Hermes Agent 桌面版

Hermes Desktop is the official desktop application, providing a graphical interface on top of the command-line tool—including a visual Dashboard, Profile manager, Skill browser, etc. When installing the desktop application, the command-line tool is also installed (hermescommand), and the two can be used together.

下载与安装

  • 访问官网hermes-agent.nousresearch.com
  • 点击Download For ...按钮
  • Run the downloaded installer and follow the prompts to complete the installation.

After downloading, just double-click to install:

After installation is complete,hermesThe command will be automatically added to the system PATH, so it can be used directly in the terminal.

The entire panel is as shown below:

左侧边栏

Divided into three parts:

  • Top action area (new session ⌘N, skill tools, messaging platforms, Artifacts entrance).
  • Center search bar.
  • Bottom session list, divided into two groups: PINNED (pinned) and SESSIONS (normal, showing total count).

标题栏

  • Centrally displays the current session name; click ∨ to rename or manage it.
  • The icons on the right are, in order: Voice mode, Keyboard shortcuts, Settings (opens the Settings panel).

对话区

  • Main chat area; user messages are displayed on the right, Agent replies on the left.
  • Before a reply, a Thinking status line is visible, indicating the model is reasoning (the currently used kimi-k2.5 supports chain-of-thought).

输入框

  • 左侧 + 可附加文件/图片。
  • Center placeholder text.
  • On the right, the following are displayed in order: current model name + reasoning intensity (Med), microphone (voice input), and send button.
  • 输入/Trigger slash command completion.

底部状态栏

  • Gateway ready: gateway online status.
  • Agents 子 Agent 管理。
  • Cron scheduled tasks.
  • On the right are the number of Tokens used in this session, session duration, and version number v0.17.0.

配置说明

Configuration panel menu function descriptions:

  • 模型: Select the AI large model called by the conversation, and configure model parameters.
  • 对话: Manage session history, context window, and conversation retention rules.
  • Appearance (current page)
    • Language: Switch the desktop client interface language; supports Simplified Chinese and other languages.
    • Light/dark mode: three display modes—Light / Dark / Follow System.
    • Theme colors: Built-in interface themes such as Nous, Midnight, and more; can also search the VS Code marketplace for additional themes.
  • 工作区: Divide project spaces to isolate sessions and configurations across different scenarios.
  • 安全: Configure access permissions, local data encryption, and privacy controls.
  • Memory and context: Configure long-term memory, context truncation, and historical message carrying policies.
  • 语音: Enable voice input / voice reading, choose microphone and TTS voice engine.
  • 高级: Debug logs, network proxy, local cache, and experimental feature toggles.
  • 通知: Control message pop-ups, background reminders, and message push notifications.
  • 提供方: Configure API keys for major model service providers (OpenAI, Anthropic, etc.).
  • 网关: Connect to a model relay gateway to centrally manage interface addresses.
  • 工具与密钥: Configure extended tools such as web search and code execution, and manage third-party keys.
  • MCP: Integrate with MCP protocol services to extend Agent capabilities.
  • 已归档对话: View archived historical session records.
  • 关于: View client version, license information, and update entry.
