Python3 OS File/Directory Methods

osThe module is an important module in the Python standard library, providing functions for interacting with the operating system.

Throughosthe module, you can perform tasks such as file operations, directory operations, environment variable management, and process management.

osThe module is cross-platform, which means you can use the same code on different operating systems (such as Windows, Linux, macOS).

Before usingosthe module, you need to import it first. ImportosThe code for the module is as follows:

import os

Common functions of the os module

1. Get the current working directory

os.getcwd()The function is used to get the path of the current working directory. The current working directory is the directory where the Python script is executed.

Example

current_directory = os.getcwd()
print("当前工作目录:", current_directory)

2. Change the current working directory

os.chdir(path)The function is used to change the current working directory.pathis the path to the directory you want to switch to.

Example

os.chdir("/path/to/new/directory")
print("新的工作目录:", os.getcwd())

3. List directory contents

os.listdir(path)The function is used to list all files and subdirectories in the specified directory. If not providedpathparameter, it lists the contents of the current working directory by default.

Example

files_and_dirs = os.listdir()
print("目录内容:", files_and_dirs)

4. Create a directory

os.mkdir(path)The function is used to create a new directory. If the directory already exists, it will raiseFileExistsErroran exception.

Example

os.mkdir("new_directory")

5. Delete a directory

os.rmdir(path)The function is used to delete an empty directory. If the directory is not empty, it will raiseOSErroran exception.

Example

os.rmdir("new_directory")

6. Delete a file

os.remove(path)The function is used to delete a file. If the file does not exist, it will raiseFileNotFoundErroran exception.

Example

os.remove("file_to_delete.txt")

7. Rename a file or directory

os.rename(src, dst)The function is used to rename a file or directory.srcis the original path,dstis the new path.

Example

os.rename("old_name.txt", "new_name.txt")

8. Get an environment variable

os.getenv(key)The function is used to get the value of the specified environment variable. If the environment variable does not exist, it returnsNone。

Example

home_directory = os.getenv("HOME")
print("HOME 目录:", home_directory)

9. Execute system commands

os.system(command)The function is used to execute commands in the operating system shell. After the command is executed, it returns the exit status of the command.

Example

os.system("ls -l")

def get_py(path,l):
    fileList = os.listdir(path)   #获取path目录下所有文件
    for filename in fileList:
        pathTmp = os.path.join(path,filename)   #获取path与filename组合后的路径
        if os.path.isdir(pathTmp):   #如果是目录
            get_py(pathTmp,l)        #则递归查找
        elif filename[-3:].upper()=='.PY':   #不是目录,则比较后缀名
            l.append(pathTmp)
path = input('请输入路径:').strip()
get_py(path,l)
print('在%s目录及其子目录下找到%d个py文件\n分别为：\n'%(path,len(l)))

    print(filepath+'\n')

    Batch rename files

    For batch-renaming files, Python uses the listdir method and the rename method in the os module.

    • os.listdir(dir): Get all subdirectories and file names under the specified directory.
    • os.rename(original file name, new file name): Rename a file or directory.

    Change messy file names into ordered file names:

    import os
path=input('请输入文件路径(结尾加上/)：')       

#获取该目录下所有文件，存入列表中
fileList=os.listdir(path)

n=0
for i in fileist:
    
    #设置旧文件名（就是路径+文件名）
    oldname=path+ os.sep + fileList[n]   # os.sep添加系统分隔符
    
    #设置新文件名
    newname=path + os.sep +'a'+str(n+1)+'.JPG'
    
    os.rename(oldname,newname)   #用os模块中的rename方法对文件改名
    print(oldname,'======>',newname)
    
    n+=1
