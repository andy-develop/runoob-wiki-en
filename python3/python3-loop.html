This chapter will introduce the use of Python loop statements.

The loop statements in Python are for and while.

while Loop Using else Statement

If the condition statement after while is false, the else statement block is executed.

The syntax format is as follows:

while <expr>:
    <statement(s)>
else:
    <additional_statement(s)>

If the expr condition is true, the statement(s) block is executed; if it is false, additional_statement(s) is executed.

Loop to output numbers and compare their sizes:

Example

#!/usr/bin/python3 count = 0 while count < 5: print (count, "less than 5") count = count + 1 else: print (count, "greater than or equal to 5")

for...else

In Python, the for...else statement is used to execute a block of code after the loop ends.

The syntax format is as follows:

for item in iterable:
    # 循环主体
else:
    # 循环结束后执行的代码

When the loop finishes executing (that is, after all elements in the iterable have been traversed), the code in the else clause will be executed. If a break statement is encountered during the loop, the loop will be interrupted, and the else clause will not be executed at this point.

Example

for x in range(6):
  print(x)
else:
  print("Finally finished!")

After executing the script, the output result is:

1

3
4
5
Finally finished!

range() Function

If you need to iterate over a sequence of numbers, you can use the built-in range() function. It will generate a sequence of numbers, for example:

Example

>>>for i in range(5): ... print(i) ... 0 1 2 3 4

You can also use range() to specify values in an interval:

Example

>>>for i in range(5,9) : print(i) 5 6 7 8 >>>

You can also make range() start at a specified number and specify a different increment (which can even be negative, sometimes also called 'step'):

Example

>>>for i in range(0, 10, 3) : print(i) 0 3 6 9 >>>

Negative numbers:

Example

>>>for i in range(-10, -100, -30) : print(i) -10 -40 -70 >>>

You can combine the range() and len() functions to iterate over the indices of a sequence, as shown below:

Example

>>>a = ['Google', 'Baidu', 'Runoob', 'Taobao', 'QQ'] >>> for i in range(len(a)): ... print(i, a[i]) ... 0 Google 1 Baidu 2 Runoob 3 Taobao 4 QQ >>>

You can also use the range() function to create a list:

Example

>>>list(range(5)) [0, 1, 2, 3, 4] >>>

For more on the usage of the range() function, refer to:https://www.runoob.com/python3/python3-func-range.html

    Bubble sort, Python version

    Explanation: This is a very classic sorting method. Starting from the 0th element in the array, compare it with the next element. If the previous element is greater than the next element, swap their positions. Loop until the end (i.e., after a0 is compared with a1, a1 is compared with a2, ...). The largest element is moved to the very end of the array. Exclude the last element and perform the above operation on the remaining array elements. In the end, the entire array is sorted from smallest to largest.

    # python 冒泡排序

def paixu(li) :
    max = 0
    for ad in range(len(li) - 1):
        for x in range(len(li) - 1 - ad):
            if li[x] > li[x + 1]:
                max = li[x]
                li[x] = li[x + 1]
                li[x + 1] = max
            else:
                max = li[x + 1]
    print(li)
paixu([41,23344,9353,5554,44,7557,6434,500,2000])

    Bubble sort, Python version - 20220411

    Explanation: This is a very classic sorting method. Starting from the 0th element in the array, compare it with the next element. If the previous element is greater than the next element, swap their positions. Loop until the end (i.e., after a0 is compared with a1, a1 is compared with a2, ...). The largest element is moved to the very end of the array. Exclude the last element and perform the above operation on the remaining array elements. In the end, the entire array is sorted from smallest to largest.

    # python 冒泡排序
def paixu(li) :
    mx = 0
    for ad in range(len(li) - 1):
        for x in range(len(li) - 1 - ad):
            mx = max(li[x],li[x+1])
            if li[x] > li[x + 1]:li[x],li[x + 1]=li[x + 1],li[x]
            
    print(li)

    The following is another sorting method: pick out the minimum value one by one, remove the minimum value from the original list, add the minimum value to the new list, and continue until the last value (the maximum value). Finally assign the new list to the original list, and the entire array is sorted from smallest to largest.

    # python 其他排序
list1=([4165,233454,44,5554,44,7557,6434,500,2000])
list2=[]
while len(list1):
    list2.append(min(list1))
    list1.remove(min(list1))
list1=list2
print(list1)
