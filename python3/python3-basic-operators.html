What is an operator?

This chapter mainly explains Python's operators.

Let's take a simple example:

4 + 5 = 9

  • Arithmetic operators
  • Comparison (relational) operators
  • Assignment operators
  • Logical operators
  • Bitwise operators
  • Membership operators
  • Identity operators
  • Operator precedence

In Python 3.8 and later, a new syntax feature called the "Walrus Operator" was introduced, which uses:=symbol. The main purpose of this operator is to perform assignment and return the assigned value simultaneously within an expression.

Using the walrus operator can simplify code in some cases, especially when you need to use the assignment result within an expression. This is useful for simplifying loop conditions or repeated calculations in expressions.

The following is a simple example demonstrating the use of the walrus operator:

Example

# Traditional approach
n = 10
if n > 5:
    print(n)

# Using the walrus operator
if (n := 10) > 5:
    print(n)
  • if (n := 10) > 5:: This is using the walrus operator (:=) syntax. The walrus operator performs an assignment operation within an expression.
    • (n := 10): Assigns the variablento 10 and returns the assignment result at the same time.
    • > 5: Checks whether the assignednis greater than 5. If the condition is true, execute the following code block.
  • print(n): If the condition is true, print the variablen's value (i.e., 10).

Advantages of the walrus operator:

  • The walrus operator (:=) allows assignment within an expression, which can reduce code duplication and improve code readability and conciseness.
  • In the above example, the traditional approach requires a separate line to assignn, and thenifstatement for condition checking. With the walrus operator, the code canifdirectly perform assignment and condition checking within the statement.

Python Bitwise Operators

Bitwise operators treat numbers as binary for calculation. The bitwise operation rules in Python are as follows:

In the table below, variable a is 60 and b is 13. The binary formats are as follows:

a = 0011 1100

b = 0000 1101

-----------------

a&b = 0000 1100

a|b = 0011 1101

a^b = 0011 0001

~a  = 1100 0011
OperatorDescriptionExample
&Bitwise AND operator: For the two values involved in the operation, if both corresponding bits are 1, the result bit is 1; otherwise, it is 0.(a & b) outputs 12. Binary explanation: 0000 1100
|Bitwise OR operator: As long as one of the two corresponding binary bits is 1, the result bit is 1.(a | b) outputs 61. Binary explanation: 0011 1101
^Bitwise XOR operator: When the two corresponding binary bits are different, the result is 1.(a ^ b) outputs 49. Binary explanation: 0011 0001
~Bitwise NOT operator: Inverts each binary bit of the data, turning 1 into 0 and 0 into 1.~xsimilar to-x-1 (~a ) outputs -61. Binary explanation: 1100 0011, in two's complement form for a signed binary number.
<<Left shift operator: All binary bits of the operand are shifted left by a specified number of places. The number on the right of "<<" specifies the number of places to shift. High-order bits are discarded, and low-order bits are filled with 0.a << 2 outputs 240. Binary explanation: 1111 0000
>>Right shift operator: All binary bits of the operand on the left of ">>" are shifted right by a specified number of places. The number on the right of ">>" specifies the number of places to shift.a >> 2 outputs 15. Binary explanation: 0000 1111

The following examples demonstrate the operations of all Python bitwise operators:

Example (Python 3.0+)

#!/usr/bin/python3 a = 60 # 60 = 0011 1100 b = 13 # 13 = 0000 1101 c = 0 c = a & b # 12 = 0000 1100 print ("1 - The value of c is:", c) c = a | b # 61 = 0011 1101 print ("2 - The value of c is:", c) c = a ^ b # 49 = 0011 0001 print ("3 - The value of c is:", c) c = ~a # -61 = 1100 0011 print ("4 - The value of c is:", c) c = a << 2 # 240 = 1111 0000 print ("5 - The value of c is:", c) c = a >> 2 # 15 = 0000 1111 print ("6 - The value of c is:", c)

    When I first started learning Python, I naturally used a++ for increment operation. But I found that the compiler doesn't recognize ++, so I searched online and found an excellent Q&A by a foreigner, which involved the design principles of the Python language.

    The question is simply that Python has no increment operator, so how is the increment operation implemented?

    In the answers, someone introduced the philosophical logic of Python not using ++ for increment operation: simplicity in compilation/parsing and simplicity of the language itself. I won't translate it in detail.

    Later, another foreigner gave an answer with a very brilliant example, pointing out some conceptual differences between Python and C. The description may not be entirely accurate, so let's go straight to the example:

    >>> b = 5  
>>> a = 5  
>>> id(a)  
162334512  
>>> id(b)  
162334512  
>>> a is b  
True

    It can be seen that in Python, variables are based on content rather than on variable names as in C. So as long as your numeric content is 5, no matter what name you give it, the ID of this variable is the same. This also explains that in Python, a variable can be accessed by multiple names.

    This design logic determines that numeric type values in Python are immutable, because if as in the above example, both a and b are 5, when you change a, b would also change, which is certainly not what we want.

    Therefore, the correct increment operation should be a = a + 1 or a += 1. After this a is incremented, you can see from id() that the id value has changed, meaning a is now the name of the new value.

    1.or

    In Python, for the logical operator or, x or y, if x is True it returns x, and if x is False it returns y. Because if x is True, the or operation no longer needs to be evaluated; since one true value makes the result true, it returns x. If x is false, then the result of the or operation depends on y, so it returns y.

    print(1 or 2)   # 1
print(3 or 2)   # 3
print(0 or 2)   # 2
print(0 or 100) # 100
print(0 or 0)

    2.and

    In Python, for the logical operator and, x and y, if x is True it returns y. If x is False it returns x. If x is True, the and operation does not end; it continues to evaluate y, so the result depends on y. Thus if x is true, it returns y. If x is false, the and operation ends, because if one operand is false, the and result is false, so it returns x.

    print(1 and 2)  # 2
print(3 and 0)  # 0
print(0 and 2)  # 0
print(3 and 2)  # 2
print(0 and 0)  # 0

    # -*- coding:utf-8 -*-
class Solution:
    # bin函数： bin返回一个整数的二进制字符串，以0b开头，
    # bin(10) '0b1010'  bin(-10)  '-0b1010'
    #
    # count函数 返回字符串当中非重叠的字符串的个数，可以传入start，end来表示对字符串切片的结果
    #
    #如果一个数为负数，那么2**32 + n 然后再用bin返回的就是它的补码形式。 补码+源码=2**32
    def NumberOf1(self, n):
        if n >= 0:
            return bin(n).count('1')
        else:
            return bin(2**32 + n).count('1')
 
if __name__ == '__main__':
    solution = Solution()
    print(solution.NumberOf1(10))
    print(solution.NumberOf1(-10))
