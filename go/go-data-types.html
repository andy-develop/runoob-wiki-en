Go language data types

In the Go programming language, data types are used to declare functions and variables.

Data types exist to divide data into categories with different memory size requirements. When programming, you only need to allocate large memory when large data is needed, thereby making full use of memory.

Go language has the following data types by category:

序号类型和描述
1布尔型
Boolean values can only be the constants true or false. A simple example: var b bool = true.
2数字类型
Integer type int and floating-point types float32 and float64. Go supports integer and floating-point numbers, and also supports complex numbers, where bit operations use two's complement.
3字符串类型:
A string is a character sequence formed by connecting a series of fixed-length characters. Go strings are made up of individual bytes. The bytes of Go strings use UTF-8 encoding to identify Unicode text.
4派生类型:
包括：
  • (a) Pointer type
  • (b) Array type
  • (c) Structured types (struct)
  • (d) Channel 类型
  • (e) Function type
  • (f) Slice type
  • (g) Interface type (interface)
  • (h) Map 类型

数字类型

Go also has architecture-based types, such as: int, uint, and uintptr.

序号类型和描述
1uint8
Unsigned 8-bit integer (0 to 255)
2uint16
Unsigned 16-bit integer (0 to 65535)
3uint32
Unsigned 32-bit integer (0 to 4294967295)
4uint64
无符号 64 位整型 (0 到 18446744073709551615)
5int8
Signed 8-bit integer (-128 to 127)
6int16
Signed 16-bit integer (-32768 to 32767)
7int32
有符号 32 位整型 (-2147483648 到 2147483647)
8int64
有符号 64 位整型 (-9223372036854775808 到 9223372036854775807)

浮点型

序号类型和描述
1float32
IEEE-754 32-bit floating-point number
2float64
IEEE-754 64-bit floating-point number
3complex64
32-bit real and imaginary numbers
4complex128
64-bit real and imaginary numbers

    Remove spaces and newline characters from a string

    package main  
  
import (  
    "fmt"  
    "strings"  
)  
  
func main() {  
    str := "这里是 www\n.runoob\n.com"  
    fmt.Println("-------- 原字符串 ----------")  
    fmt.Println(str)  
    // 去除空格  
    str = strings.Replace(str, " ", "", -1)  
    // 去除换行符  
    str = strings.Replace(str, "\n", "", -1)  
    fmt.Println("-------- 去除空格与换行后 ----------")  
    fmt.Println(str)  
}

    The output result is:

    -------- 原字符串 ----------
这里是 www
.runoob
.com
-------- 去除空格与换行后 ----------
这里是www.runoob.com
