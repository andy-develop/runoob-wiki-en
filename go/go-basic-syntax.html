Go Language Basic Syntax

In the previous chapter, we learned the basic composition and structure of the Go language. In this chapter, we will learn the basic syntax of the Go language.

Go 标记

A Go program can be composed of multiple tokens, which can be keywords, identifiers, constants, strings, and symbols. For example, the following Go statement consists of 6 tokens:

fmt.Println("Hello, World!")

6 tokens are (one per line):

1. fmt
2. .
3. Println
4. (
5. "Hello, World!"
6. )

行分隔符

In a Go program, a line represents the end of a statement. Each statement does not need to end with a semicolon ; like in other C-family languages, because these tasks are automatically completed by the Go compiler.

If you intend to write multiple statements on the same line, they must be manually separated with ;, but this practice is not encouraged in real development.

The following are two statements:

fmt.Println("Hello, World!")
fmt.Println("菜鸟教程：runoob.com")

注释

Comments are not compiled, and every package should have related comments.

Single-line comments are the most common form of comments. You can use single-line comments starting with // anywhere. Multi-line comments, also called block comments, all start with /* and end with */. For example:

// 单行注释
/*
 Author by 菜鸟教程
 我是多行注释
 */

标识符

Identifiers are used to name program entities such as variables and types. An identifier is actually a sequence composed of one or more letters (A~Z and a~z), digits (0~9), and underscores _, but the first character must be a letter or an underscore and cannot be a digit.

The following are valid identifiers:

mahesh   kumar   abc   move_name   a_123
myname50   _temp   j   a23b9   retVal

The following are invalid identifiers:

  • 1ab (starts with a digit)
  • case (a Go language keyword)
  • a+b (operators are not allowed)

字符串连接

String concatenation in Go can be done through+实现：

实例

package main
import "fmt"
func main() {
    fmt.Println("Google" + "Runoob")
}

The output of the above example is:

GoogleRunoob

A program is generally composed of keywords, constants, variables, operators, types, and functions.

The program may use these delimiters: parentheses (), square brackets [], and curly braces {}.

The program may use these punctuation marks:.、,、;、: 和 …。

Whitespace in Go

In the Go language, spaces are usually used to separate identifiers, keywords, operators, and expressions, improving the readability of the code.

In Go, variable declarations must be separated by spaces, for example:

var x int
const Pi float64 = 3.14159265358979323846

Using spaces between operators and operands can make the program easier to read:

无空格：

fruit=apples+oranges;

Adding spaces between variables and operators makes the program look more beautiful, for example:

fruit = apples + oranges;

Spaces should be used between keywords and expressions.

例如：

if x > 0 {
    // do something
}

When calling a function, spaces should be used between the function name and the equals sign on the left, and also between parameters.

例如：

result := add(2, 3)

Format string

In Go language, usefmt.Sprintf 或 fmt.PrintfFormat a string and assign it to a new string:

  • SprintfGenerate a formatted string according to the formatting parameters and return the string.
  • PrintfGenerate a formatted string according to the formatting parameters and write it to standard output.

Sprintf 实例

package main

import (
    "fmt"
)

func main() {
   // %d 表示整型数字，%s 表示字符串
    var stockcode=123
    var enddate="2020-12-31"
    var url="Code=%d&endDate=%s"
    var target_url=fmt.Sprintf(url,stockcode,enddate)
    fmt.Println(target_url)
}

The output result is:

Code=123&endDate=2020-12-31

    Golang fmt 包

    The Print() function converts each parameter in the parameter list a to a string and writes it to standard output.

    Spaces are added between non-string parameters, and it returns the number of bytes written.

    func Print(a ...interface{}) (n int, err error)

    The Println() function is similar to Print, except that a newline character is added at the end.

    Spaces are added between all parameters, and it returns the number of bytes written.

    func Println(a ...interface{}) (n int, err error)

    The Printf() function fills the parameters in the parameter list a into the placeholders of the format string format.

    The formatted result is written to standard output, and the number of bytes written is returned.

    func Printf(format string, a ...interface{}) (n int, err error)

    The following three functions have the same functionality as the above three functions, except that they write the converted result tow中。

    func Fprint(w io.Writer, a ...interface{}) (n int, err error)
func Fprintln(w io.Writer, a ...interface{}) (n int, err error)
func Fprintf(w io.Writer, format string, a ...interface{}) (n int, err error)

    The following three functions have the same functionality as the above three functions, except that they return the converted result as a string.

    func Sprint(a ...interface{}) string
func Sprintln(a ...interface{}) string
func Sprintf(format string, a ...interface{}) string

    The following function has the same functionality as the Sprintf() function, except that the resulting string is wrapped as an error type.

    func Errorf(format string, a ...interface{}) error

    实例：

    func main() {
    fmt.Print("a", "b", 1, 2, 3, "c", "d", "\n")
    fmt.Println("a", "b", 1, 2, 3, "c", "d")
    fmt.Printf("ab %d %d %d cd\n", 1, 2, 3)
    // ab1 2 3cd
    // a b 1 2 3 c d
    // ab 1 2 3 cd

    if err := percent(30, 70, 90, 160); err != nil {
        fmt.Println(err)
    }
    // 30%
    // 70%
    // 90%
    // 数值 160 超出范围（100）
}

func percent(i ...int) error {
    for _, n := range i {
        if n > 100 {
            return fmt.Errorf("数值 %d 超出范围（100）", n)
        }
        fmt.Print(n, "%\n")
    }
    return nil
}

    Formatter is implemented by custom types to implement the custom formatting process for that type.

    When a formatter needs to format a variable of that type, it calls its Format method.

    type Formatter interface {
    // f 用于获取占位符的旗标、宽度、精度等信息，也用于输出格式化的结果
    // c 是占位符中的动词
    Format(f State, c rune)
}

    Implemented by formatters (functions like Print) to provide information for custom formatting processes:

    type State interface {
    // Formatter 通过 Write 方法将格式化结果写入格式化器中，以便输出。
    Write(b []byte) (ret int, err error)
    // Formatter 通过 Width 方法获取占位符中的宽度信息及其是否被设置。
    Width() (wid int, ok bool)
    // Formatter 通过 Precision 方法获取占位符中的精度信息及其是否被设置。
    Precision() (prec int, ok bool)
    // Formatter 通过 Flag 方法获取占位符中的旗标[+- 0#]是否被设置。
    Flag(c int) bool
}

    Stringer is implemented by custom types to implement the custom formatting process for that type.

    When a formatter needs to output the string format of that type, it calls its String method.

    type Stringer interface {
    String() string
}

    Stringer is implemented by custom types to implement the custom formatting process for that type.

    When a formatter needs to output the Go syntax string of that type (%#v), it calls its String method.

    type GoStringer interface {
    GoString() string
}

    实例：

    type Ustr string

func (us Ustr) String() string {
    return strings.ToUpper(string(us))
}

func (us Ustr) GoString() string {
    return `"` + strings.ToUpper(string(us)) + `"`
}

func (u Ustr) Format(f fmt.State, c rune) {
    write := func(s string) {
        f.Write([]byte(s))
    }
    switch c {
    case 'm', 'M':
        write("旗标：[")
        for s := "+- 0#"; len(s) > 0; s = s[1:] {
            if f.Flag(int(s[0])) {
                write(s[:1])
            }
        }
        write("]")
        if v, ok := f.Width(); ok {
            write(" | 宽度：" + strconv.FormatInt(int64(v), 10))
        }
        if v, ok := f.Precision(); ok {
            write(" | 精度：" + strconv.FormatInt(int64(v), 10))
        }
    case 's', 'v': // 如果使用 Format 函数，则必须自己处理所有格式，包括 %#v
        if c == 'v' && f.Flag('#') {
            write(u.GoString())
        } else {
            write(u.String())
        }
    default: // 如果使用 Format 函数，则必须自己处理默认输出
        write("无效格式：" + string(c))
    }
}

func main() {
    u := Ustr("Hello World!")
    // "-" 标记和 "0" 标记不能同时存在
    fmt.Printf("%-+ 0#8.5m\n", u) // 旗标：[+- #] | 宽度：8 | 精度：5
    fmt.Printf("%+ 0#8.5M\n", u)  // 旗标：[+ 0#] | 宽度：8 | 精度：5
    fmt.Println(u)                // HELLO WORLD!
    fmt.Printf("%s\n", u)         // HELLO WORLD!
    fmt.Printf("%#v\n", u)        // "HELLO WORLD!"
    fmt.Printf("%d\n", u)         // 无效格式：d
}

    ScanRead data from standard input, split and parse the data using whitespace, then store it into the variables provided by a (newlines are treated as whitespace). The variables must be passed as pointers.

    Scanning stops when EOF is reached or all variables have been filled.

    返回成功解析的参数数量。
    func Scan(a ...interface{}) (n int, err error)

    Scanln 和 ScanSimilar, except that scanning stops when a newline is encountered.

    func Scanln(a ...interface{}) (n int, err error)

    Scanf reads data from standard input, parses the data according to the format string `format`, and stores the parsed results in the variables supplied by the parameter `a`; the variables must be passed as pointers.

    The newlines at the input side must correspond to the newlines in format (if the format string contains newlines, the corresponding newlines must be entered at the input side).

    The placeholder %c always matches the next character, including whitespace, such as spaces, tabs, and newlines.

    Returns the number of arguments successfully parsed.

    func Scanf(format string, a ...interface{}) (n int, err error)

    The following three functions have the same functionality as the above three functions, except that they read data from r.

    func Fscan(r io.Reader, a ...interface{}) (n int, err error)
func Fscanln(r io.Reader, a ...interface{}) (n int, err error)
func Fscanf(r io.Reader, format string, a ...interface{}) (n int, err error)

    The following three functions have the same functionality as the above three functions, except that they read data from str.

    func Sscan(str string, a ...interface{}) (n int, err error)
func Sscanln(str string, a ...interface{}) (n int, err error)
func Sscanf(str string, format string, a ...interface{}) (n int, err error)

    ScannerImplemented by custom types to implement the custom scanning process for that type.

    When a scanner needs to parse data of that type, it calls its Scan method.

    type Scanner interface {
    // state 用于获取占位符中的宽度信息，也用于从扫描器中读取数据进行解析。
    // verb 是占位符中的动词
    Scan(state ScanState, verb rune) error
}

    Implemented by scanners (functions like Scan) to provide data and information for the custom scanning process.

    type ScanState interface {
    // ReadRune 从扫描器中读取一个字符，如果用在 Scanln 类的扫描器中，
    // 则该方法会在读到第一个换行符之后或读到指定宽度之后返回 EOF。
    // 返回“读取的字符”和“字符编码所占用的字节数”
    ReadRune() (r rune, size int, err error)
    // UnreadRune 撤消最后一次的 ReadRune 操作，
    // 使下次的 ReadRune 操作得到与前一次 ReadRune 相同的结果。
    UnreadRune() error
    // SkipSpace 为 Scan 方法提供跳过开头空白的能力。
    // 根据扫描器的不同（Scan 或 Scanln）决定是否跳过换行符。
    SkipSpace()
    // Token 用于从扫描器中读取符合要求的字符串，
    // Token 从扫描器中读取连续的符合 f(c) 的字符 c，准备解析。
    // 如果 f 为 nil，则使用 !unicode.IsSpace(c) 代替 f(c)。
    // skipSpace：是否跳过开头的连续空白。返回读取到的数据。
    // 注意：token 指向共享的数据，下次的 Token 操作可能会覆盖本次的结果。
    Token(skipSpace bool, f func(rune) bool) (token []byte, err error)
    // Width 返回占位符中的宽度值以及宽度值是否被设置
    Width() (wid int, ok bool)
    // 因为上面实现了 ReadRune 方法，所以 Read 方法永远不应该被调用。
    // 一个好的 ScanState 应该让 Read 直接返回相应的错误信息。
    Read(buf []byte) (n int, err error)
}

    实例：

    type Ustr string

func (u *Ustr) Scan(state fmt.ScanState, verb rune) (err error) {
    var s []byte
    switch verb {
    case 'S':
        s, err = state.Token(true, func(c rune) bool { return 'A' <= c && c <= 'Z' })
        if err != nil {
            return
        }
    case 's', 'v':
        s, err = state.Token(true, func(c rune) bool { return 'a' <= c && c <= 'z' })
        if err != nil {
            return
        }
    default:
        return fmt.Errorf("无效格式：%c", verb)
    }
    *u = Ustr(s)
    return nil
}

func main() {
    var a, b, c, d, e Ustr
    n, err := fmt.Scanf("%3S%S%3s%2v%x", &a, &b, &c, &d, &e)
    fmt.Println(a, b, c, d, e)
    fmt.Println(n, err)
    // 在终端执行后，输入 ABCDEFGabcdefg 回车
    // 结果：
    // ABC DEFG abc de
    // 4 无效格式：x
}
