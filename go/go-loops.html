Go language loop statements

In many practical problems, there are many regular repetitive operations, so it is necessary to repeatedly execute certain statements in programs.

The following is a flowchart of loop programs in most programming languages:

The Go language provides the following types of loop handling statements:

循环类型 描述
for 循环 Repeatedly execute statement block
循环嵌套 Nest one or more for loops inside a for loop

Loop control statement

Loop control statements can control the execution process of statements within the loop body.

The Go language supports the following loop control statements:

控制语句 描述
break 语句 Often used to interrupt the current for loop or jump out of a switch statement
continue 语句 Skip the remaining statements of the current loop and then continue with the next round of the loop.
goto 语句 Transfer control to the labeled statement.

无限循环

If the condition statement in the loop is never false, an infinite loop will occur. We can execute an infinite loop by setting only one conditional expression in the for loop statement:

实例

package main

import "fmt"

func main() {
    for true  {
        fmt.Printf("这是无限循环。\n");
    }
}

    package main

import "fmt"

func main() {
   for i := 1; i <= 9; i++ { // i 控制行，以及计算的最大值
      for j := 1; j <= i; j++ { // j 控制每行的计算个数
         fmt.Printf("%d*%d=%d ", j, i, j*i)
      }
      fmt.Println("")
   }

    Another method to output prime numbers from 1 to 100:

    package main
import "fmt"

func main() {
    var a, b int
    for a = 2; a <= 100; a++ {
        for b = 2; b <= (a / b); b++ {
            if a%b == 0 {
                break
            }
        }
        if b > (a / b) {
            fmt.Printf("%d\t是素数\n", a)
        }
    }
}

    To find prime numbers within 100, let me also post a final version:

    // 打印100内的素数
// 素数定义：在大于1的自然数中，因数只有1和自身的数称为素数。
func t01_test2() {
    const RANGE = 100
    for num := 2; num <= RANGE; num++ {
        // 当前因数 factor 对应的另一个因数就是 num / factor。
        // 当前者大于后者时，可以认为所有因数已经分析完毕。
        for factor := 2; factor <= (num / factor); factor++ {
            //能除尽，则表示 factor 是 num 的一个因子。那么num就不是素数。
            if num%factor == 0 {
                goto NEXT_NUM
            }
        }
        fmt.Printf("%d\t是素数\n", num)
    NEXT_NUM:
    }
}
