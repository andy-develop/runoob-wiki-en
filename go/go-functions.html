Go Language Functions

Functions are basic code blocks used to perform a task.

Go language has at least one main() function.

You can divide different functions by using functions; logically each function executes a specified task.

The function declaration tells the compiler the function name, return type, and parameters.

The Go standard library provides various built-in functions that are available. For example, the len() function can accept arguments of different types and return the length of that type. If we pass a string, it returns the length of the string; if we pass an array, it returns the number of elements contained in the array.

函数定义

The format for defining functions in Go is as follows:

func function_name( [parameter list] ) [return_types] {
   函数体
}

Function Definition Analysis:

  • func: A function is declared starting with func.
  • function_name: The function name, parameter list, and return value type constitute the function signature.
  • parameter list: The parameter list. Parameters are like placeholders. When a function is called, you can pass values to the parameters, and these values are called actual parameters. The parameter list specifies the parameter types, order, and number of parameters. Parameters are optional, meaning a function may not contain parameters.
  • return_types: The return type. The function returns a list of values. return_types is the data type of that list of values. Some functions do not need a return value; in this case, return_types is not necessary.
  • Function body: the collection of code that defines the function.

实例

The following example is the code for the max() function, which takes two integer parameters num1 and num2 and returns the maximum of these two parameters:

实例

/* 函数返回两个数的最大值 */
func max(num1, num2 int) int {
   /* 声明局部变量 */
   var result int

   if (num1 > num2) {
      result = num1
   } else {
      result = num2
   }
   return result
}

函数调用

When you create a function, you define what the function needs to do, and the specified task is executed by calling the function.

Calling a function, passing arguments to the function, and returning values, for example:

实例

package main

import "fmt"

func main() {
   /* 定义局部变量 */
   var a int = 100
   var b int = 200
   var ret int

   /* 调用函数并返回最大值 */
   ret = max(a, b)

   fmt.Printf( "最大值是 : %d\n", ret )
}

/* 函数返回两个数的最大值 */
func max(num1, num2 int) int {
   /* 定义局部变量 */
   var result int

   if (num1 > num2) {
      result = num1
   } else {
      result = num2
   }
   return result
}

In the above example, the max() function is called in the main() function, and the execution result is:

最大值是 : 200

Functions Returning Multiple Values

Go functions can return multiple values, for example:

实例

package main

import "fmt"

func swap(x, y string) (string, string) {
   return y, x
}

func main() {
   a, b := swap("Google", "Runoob")
   fmt.Println(a, b)
}

The execution result of the above example is:

Runoob Google

函数参数

If a function uses parameters, those variables can be called the formal parameters of the function.

Formal parameters are like local variables defined inside the function body.

When calling a function, there are two ways to pass arguments:

传递类型 描述
值传递 Pass by value means copying the actual parameter and passing it to the function when calling the function, so that if the parameter is modified in the function, it will not affect the actual parameter.
引用传递 Passing by reference means passing the address of the actual parameter into the function when calling it. Modifications made to the parameter inside the function will then affect the actual parameter.

By default, the Go language uses value passing, which means the actual parameters will not be affected during the call.

    package main

import "fmt"

//行数
const LINES int = 10

// 杨辉三角
func ShowYangHuiTriangle() {
    nums := []int{}
    for i := 0; i < LINES; i++ {
        //补空白
        for j := 0; j < (LINES - i); j++ {
            fmt.Print(" ")
        }
        for j := 0; j < (i + 1); j++ {
            var length = len(nums)
            var value int
            if j == 0 || j == i {
                value = 1
            } else {
                value = nums[length-i] + nums[length-i-1]
            }
            nums = append(nums, value)
            fmt.Print(value, " ")
        }
        fmt.Println("")
    }
}

func main() {
    ShowYangHuiTriangle()

import "fmt"

func main() {
    // 长
    x := 9
    // 宽
    y := 9
    // 行数
    row := 1
    for row <= y {
        // 计算每行得星星数
        count := 0
        if row <= (y/2 + 1) {
            count = (2 * row - 1)
        } else {
            count = 2 * (y - row) + 1 
        }
        row++
        text := ""
        // 算出显示星星的范围
        star_min := ((x - count) / 2) + 1
        star_max := ((x - count) / 2) + count
        for index := 1;index <= x;index++ {
            if index >= star_min && index <= star_max {
                text += "*"
            } else {
                text += " "
            }
        } 
        fmt.Println(text)
    }
}

    All parameters are passed by value:slice, map, and channel give the illusion of pass by reference (for example, a slice corresponds to an array behind it; the slice itself is a data structure that contains a pointer to this array. Therefore, even when the structure is copied into the function in the case of pass by value, when operating on the array's values through the pointer, it is actually operating on the same memory space. In reality, the structure is copied, but the pointer contained in the structure points to the same array, which is why this illusion arises)
