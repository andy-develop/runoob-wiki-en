Go Language Environment Installation

Go language supports the following systems:

  • Linux
  • FreeBSD
  • Mac OS X（也称为 Darwin）
  • Windows

The download address for the installation package is:https://go.dev/dl/。

If it cannot be opened, you can use this address:https://golang.google.cn/dl/。

The package names corresponding to each system:

Installer package filename 适用系统 处理器架构 System version requirements 说明
go1.26.3.windows-amd64.msi Microsoft Windows x86-64 (Intel 64-bit) Windows 10 or later Windows 64-bit system graphical installer
go1.26.3.darwin-arm64.pkg Apple macOS ARM64 (Apple Silicon 64-bit) macOS 12 or later Installer package for M-series chip Macs (including your Mac mini 4)
go1.26.3.darwin-amd64.pkg Apple macOS x86-64 (Intel 64-bit) macOS 12 or later For older Macs with Intel processors
go1.26.3.linux-amd64.tar.gz Linux x86-64 (Intel 64-bit) Linux 3.2 or later Compressed archive for most 64-bit Linux systems
go1.26.3.src.tar.gz 任意系统 源码 - Go language source code package, requires compiling yourself

UNIX/Linux/Mac OS X, 和 FreeBSD 安装

The following describes how to install from source on UNIX/Linux/Mac OS X, and FreeBSD systems:

1、下载二进制包：go1.4.linux-amd64.tar.gz。

2. Extract the downloaded binary package to the /usr/local directory.

tar -C /usr/local -xzf go1.4.linux-amd64.tar.gz

3. Add the /usr/local/go/bin directory to the PATH environment variable:

export PATH=$PATH:/usr/local/go/bin

The above only temporarily adds PATH; it will be gone after closing the terminal and logging in next time.

We can edit ~/.bash_profile or /etc/profile, and add the following command to the end of the file, so it takes effect permanently:

export PATH=$PATH:/usr/local/go/bin

After adding, you need to execute:

source ~/.bash_profile
或
source /etc/profile

注意：On MAC systems you can use.pkgDouble-click the installation package ending with to complete the installation; the installation directory is at/usr/local/go/下。

Installation on Windows systems

On Windows, you can install using the package with the .msi suffix (you can find this file in the download list, such as go1.4.2.windows-amd64.msi).

默认情况下.msiFiles will be installed in thec:\Godirectory. You canc:\Go\bin目录添加到PathIn the environment variables. After adding it, you need to restart the command window for it to take effect.

    Red Hat-based Linux distributions can all use the yum command to install:

    sudo yum install golang

    To check the Go language version installed on the current system, you can use the following command:

    go version

    Next, still in the Home directory (for example, ~/workspace), create a workspace directory and define the GOPATH environment variable to point to that directory. This directory will be used by Go tools to save and edit binary files.

    mkdir ~/workspace
echo 'export GOPATH="$HOME/workspace"' >> ~/.bashrc
source ~/.bashrc

    Depending on different needs, we can use yum to install Go tools:

    yum search golang

    Environment variable configuration under DeepinOS or Ubuntu system (to solve the issue of environment variables becoming invalid after restarting the terminal)

    Terminal command:

    vim  ~/.bashrc

    或者：

    vim ~/profile

    注：bashrc applies to all system users, profile applies to the current user.

    There are three variables GOPATH, PATH, and GOROOT:

    • GOROOT is the installation path of Go;
    • GOPATH is the working directory of Go;
    • PATH is the bin directory under the Go installation path.

    After entering the command, press insert to input, and paste the following content into it (any blank space is fine, it is recommended at the beginning or end):

    export GOROOT="/usr/local/go"
export GOPATH="/go"
export PATH=$PATH:/usr/local/go/bin

    After entering, press ESC to exit, type :wq, and save.

    After saving, there is one more step, which is to make the changed environment variables take effect. Enter the following command in the terminal:

    source  ~/.bashrc

    或者：

    source ~/profile

    At this point, golang installation and configuration is complete, and can be checked with the following command:

    go version
