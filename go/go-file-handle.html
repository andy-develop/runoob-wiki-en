File Handling in Go

File handling is one of the most common operations in Go—reading configuration, writing logs, and data persistence all depend on it. Go's standard library provides a concise yet powerful set of file I/O interfaces, covering scenarios from one-shot reads/writes to streaming processing.

There are 5 core packages related to file handling, each with its own role:

版本提示：ioutilThe package was deprecated in Go 1.16, and its functionality has been moved toos（如os.ReadFile、os.WriteFile）和io（如io.ReadAll). New code should directly useos 和 io包。

1. File creation

os.CreateCreate a new file. If the file already exists,会被截断（清空内容）. The returned file object must be closed to release system resources:

实例

package main

import (
        "log"
        "os"
)

func main() {
        // os.Create 创建文件（已存在则清空）
        file, err := os.Create("test.txt")
        if err != nil {
                log.Fatal(err)
        }
        defer file.Close() // defer 确保函数结束时关闭文件

        // 写入内容验证创建成功
        file.WriteString("文件创建成功\n")
        log.Println("文件创建成功")
}

defer file.Close()is a best practice for Go file operations.deferensures that even if subsequent code panics, the file will be correctly closed, avoiding file descriptor leaks.

2. Opening and Closing Files

osThe package provides three ways to open files, suitable for different scenarios:

函数 模式 说明
os.Open(name) 只读 The simplest way is to open read-only
os.Create(name) 读写 + 创建/截断 Create a new file or clear an existing file
os.OpenFile(name, flag, perm) 自定义 You can specify flags such as read/write, append, create, etc.

实例

package main

import (
        "fmt"
        "os"
)

func main() {
        // 方式1：只读打开
        file, err := os.Open("example.txt")
        if err != nil {
                fmt.Println("打开失败:", err)
                return
        }
        defer file.Close()
        fmt.Println("文件打开成功")

        // 方式2：OpenFile 自定义模式
        // os.O_WRONLY  只写
        // os.O_CREATE  不存在则创建
        // os.O_APPEND  追加模式
        // os.O_TRUNC   存在则截断
        f, err := os.OpenFile("log.txt",
                os.O_WRONLY|os.O_CREATE|os.O_APPEND, 0644)
        if err != nil {
                fmt.Println("打开失败:", err)
                return
        }
        defer f.Close()
        f.WriteString("追加一行日志\n")
}

OpenFile Flag Descriptions

标志 说明
os.O_RDONLY Read-only (default)
os.O_WRONLY 只写
os.O_RDWR 读写
os.O_APPEND Append mode, writes content appended to the end of the file
os.O_CREATE Create if the file does not exist
os.O_TRUNC Clear the file content when opening
os.O_EXCL Used with CREATE, errors if the file already exists

3. File reading

Go provides three main ways to read files; choose based on file size and processing requirements:

3.1 One-time Read (Recommended for Small Files)

os.ReadFileis the simplest way—automatically open, read, and close the file in one step:

实例

package main

import (
        "fmt"
        "log"
        "os"
)

func main() {
        // 一次性读取整个文件（Go 1.16+）
        data, err := os.ReadFile("config.json")
        if err != nil {
                log.Fatal(err)
        }

        fmt.Println(string(data))
}

3.2 Reading line by line (recommended for large files)

For large files, usebufio.ScannerProcess line by line to avoid loading everything into memory at once:

实例

package main

import (
        "bufio"
        "fmt"
        "log"
        "os"
)

func main() {
        file, err := os.Open("large-file.log")
        if err != nil {
                log.Fatal(err)
        }
        defer file.Close()

        // 逐行扫描
        scanner := bufio.NewScanner(file)
        lineNum := 0
        for scanner.Scan() {
                lineNum++
                line := scanner.Text() // 获取当前行内容
                fmt.Printf("第 %d 行: %s\n", lineNum, line)
        }

        // 检查扫描过程中是否出错
        if err := scanner.Err(); err != nil {
                log.Fatal("读取错误:", err)
        }
}

注意：bufio.ScannerThe default maximum line length is 64KB. If the file contains overly long lines, you need to, when callingScan()前设置scanner.Buffer(make([]byte, 0), maxSize)to increase the buffer.

3.3 Reading with io.ReadAll

When you already have an openio.Reader(such as network responses, opened files), you can useio.ReadAll：

实例

package main

import (
        "fmt"
        "io"
        "log"
        "os"
)

func main() {
        file, err := os.Open("example.txt")
        if err != nil {
                log.Fatal(err)
        }
        defer file.Close()

        // 从 Reader 读取所有数据
        data, err := io.ReadAll(file)
        if err != nil {
                log.Fatal(err)
        }

        fmt.Println(string(data))
}

4. File writing

Go provides multiple ways to write, from simple one-shot writes to high-performance buffered writes:

4.1 One-time Write

os.WriteFileWrite data to the file in one shot (overwriting existing content):

实例

package main

import (
        "log"
        "os"
)

func main() {
        content := []byte("Hello, Go!\n这是第二行\n")

        // 0644: 所有者读写，其他用户只读
        err := os.WriteFile("output.txt", content, 0644)
        if err != nil {
                log.Fatal(err)
        }
        log.Println("写入成功")
}

4.2 Writing using the File object

Writing through the file object allows you to write content in multiple passes:

实例

package main

import (
        "fmt"
        "log"
        "os"
)

func main() {
        file, err := os.Create("output.txt")
        if err != nil {
                log.Fatal(err)
        }
        defer file.Close()

        // 方式1：写入字符串
        file.WriteString("直接写入字符串\n")

        // 方式2：写入字节切片
        data := []byte("写入字节切片\n")
        file.Write(data)

        // 方式3：格式化写入
        fmt.Fprintf(file, "格式化写入: %d + %d = %d\n", 3, 4, 7)
}

4.3 Buffered Writing (Recommended for Large Amounts of Data)

bufio.WriterIt first writes data to an in-memory buffer, then writes to disk in batches once enough has accumulated, significantly reducing the number of I/O operations.务必在结束前调用Flush()：

实例

package main

import (
        "bufio"
        "log"
        "os"
)

func main() {
        file, err := os.Create("buffered-output.txt")
        if err != nil {
                log.Fatal(err)
        }
        defer file.Close()

        // 创建带缓冲的写入器
        writer := bufio.NewWriter(file)

        // 写入多行（先进入缓冲区，不会立即写磁盘）
        for i := 0; i < 1000; i++ {
                writer.WriteString("这是第 " + itoa(i) + " 行\n")
        }

        // Flush 将缓冲区剩余数据写入文件
        if err := writer.Flush(); err != nil {
                log.Fatal("刷新缓冲区失败:", err)
        }
        log.Println("缓冲写入完成")
}

// 简单的 int 转 string 辅助函数
func itoa(n int) string {
        return fmt.Sprintf("%d", n)
}

5. Appending to Files

使用os.O_APPENDThe flag appends content at the end of the file without overwriting existing data:

实例

package main

import (
        "log"
        "os"
        "time"
)

func main() {
        // O_APPEND: 追加模式
        // O_CREATE: 不存在则创建
        // O_WRONLY: 只写
        file, err := os.OpenFile("app.log",
                os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0644)
        if err != nil {
                log.Fatal(err)
        }
        defer file.Close()

        // 每次运行都会追加，不会覆盖
        timestamp := time.Now().Format("2006-01-02 15:04:05")
        file.WriteString("[" + timestamp + "] 应用启动\n")
}

对比：os.CreateIt will clear the existing content;os.OpenFile配合O_APPENDIt will append the content. In logging scenarios, be sure to use append mode.

6. Deleting and Renaming Files

实例

package main

import (
        "log"
        "os"
)

func main() {
        // 重命名 / 移动文件
        err := os.Rename("old.txt", "new.txt")
        if err != nil {
                log.Fatal("重命名失败:", err)
        }
        log.Println("重命名成功")

        // 删除文件
        err = os.Remove("temp.txt")
        if err != nil {
                log.Fatal("删除失败:", err)
        }
        log.Println("删除成功")
}

7. File Information and Inspection

7.1 Getting File Information

实例

package main

import (
        "fmt"
        "log"
        "os"
)

func main() {
        info, err := os.Stat("test.txt")
        if err != nil {
                log.Fatal(err)
        }

        fmt.Println("文件名:    ", info.Name())
        fmt.Println("大小:      ", info.Size(), "字节")
        fmt.Println("权限:      ", info.Mode())
        fmt.Println("修改时间:  ", info.ModTime())
        fmt.Println("是目录吗:  ", info.IsDir())
}

7.2 Checking Whether a File Exists

Go does not have a dedicated "file exists" function; byos.Stat + os.IsNotExist判断：

实例

package main

import (
        "fmt"
        "os"
)

// fileExists 检查文件是否存在
func fileExists(path string) bool {
        _, err := os.Stat(path)
        return !os.IsNotExist(err)
}

func main() {
        if fileExists("test.txt") {
                fmt.Println("文件存在")
        } else {
                fmt.Println("文件不存在")
        }
}

8. Directory operations

实例

package main

import (
        "fmt"
        "log"
        "os"
)

func main() {
        // 创建单个目录
        err := os.Mkdir("newdir", 0755)
        if err != nil {
                log.Fatal(err)
        }

        // 递归创建多级目录（父目录不存在也会自动创建）
        err = os.MkdirAll("path/to/deep/dir", 0755)
        if err != nil {
                log.Fatal(err)
        }

        // 读取目录内容
        entries, err := os.ReadDir(".")
        if err != nil {
                log.Fatal(err)
        }
        for _, entry := range entries {
                mark := "&#x1f4c4;"
                if entry.IsDir() {
                        mark = "&#x1f4c1;"
                }
                fmt.Printf("%s %s\n", mark, entry.Name())
        }

        // 删除空目录
        os.Remove("newdir")

        // 递归删除目录及其所有内容（&#x26a0; 谨慎使用）
        os.RemoveAll("path")
}

9. Advanced operations

9.1 File copying

使用io.CopyEfficiently copy data between two files:

实例

package main

import (
        "io"
        "log"
        "os"
)

// copyFile 复制文件的通用函数
func copyFile(src, dst string) (int64, error) {
        srcFile, err := os.Open(src)
        if err != nil {
                return 0, err
        }
        defer srcFile.Close()

        dstFile, err := os.Create(dst)
        if err != nil {
                return 0, err
        }
        defer dstFile.Close()

        // io.Copy 自动管理缓冲区，高效复制
        return io.Copy(dstFile, srcFile)
}

func main() {
        n, err := copyFile("source.txt", "destination.txt")
        if err != nil {
                log.Fatal(err)
        }
        log.Printf("复制完成，共 %d 字节", n)
}

9.2 Temporary files and directories

实例

package main

import (
        "fmt"
        "log"
        "os"
)

func main() {
        // 创建临时文件（自动命名，前缀为 "app-"）
        tmpFile, err := os.CreateTemp("", "app-*.txt")
        if err != nil {
                log.Fatal(err)
        }
        defer os.Remove(tmpFile.Name()) // 用完后清理
        fmt.Println("临时文件:", tmpFile.Name())

        // 创建临时目录
        tmpDir, err := os.MkdirTemp("", "app-*")
        if err != nil {
                log.Fatal(err)
        }
        defer os.RemoveAll(tmpDir) // 用完后清理
        fmt.Println("临时目录:", tmpDir)
}

9.3 Recursively traversing directories

filepath.WalkYou can recursively traverse all files and subdirectories in the directory tree:

实例

package main

import (
        "fmt"
        "log"
        "os"
        "path/filepath"
)

func main() {
        root := "." // 从当前目录开始遍历

        err := filepath.Walk(root, func(path string, info os.FileInfo, err error) error {
                if err != nil {
                        return err // 遇到错误时可以选择跳过或返回
                }

                // 打印路径和大小
                size := ""
                if !info.IsDir() {
                        size = fmt.Sprintf(" (%d bytes)", info.Size())
                }
                fmt.Println(path + size)
                return nil
        })

        if err != nil {
                log.Fatal(err)
        }
}

9.4 Cross-platform Path Joining

永远不要用字符串拼接路径（如dir + "/" + file），使用filepath.JoinTo ensure cross-platform compatibility:

// 错误：Windows 上路径分隔符是 \
path := "dir" + "/" + "file.txt"

// 正确：自动适配当前操作系统
path := filepath.Join("dir", "file.txt")

写入小文件 os.WriteFile os.WriteFile("f.txt", data, 0644)
