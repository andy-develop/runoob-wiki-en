Go Pointer

Before we understand pointer arrays, let's look at an example that defines an integer array of length 3:

Example

package main

import "fmt"

const MAX int = 3

func main() {

   a := []int{10,100,200}
   var i int

   for i = 0; i < MAX; i++ {
      fmt.Printf("a[%d] = %d\n", i, a[i] )
   }
}

The output of the above code execution is:

a[0] = 10
a[1] = 100
a[2] = 200

There is a situation where we may need to save arrays, so we need to use pointers.

The following declares an integer pointer array:

var ptr [MAX]*int;

ptr is an integer pointer array. Therefore each element points to a value. The three integers in the following example will be stored in the pointer array:

Example

package main

import "fmt"

const MAX int = 3

func main() {
   a := []int{10,100,200}
   var i int
   var ptr [MAX]*int;

   for  i = 0; i < MAX; i++ {
      ptr[i] = &a[i] /* Assign integer addresses to pointer array */
   }

   for  i = 0; i < MAX; i++ {
      fmt.Printf("a[%d] = %d\n", i,*ptr[i] )
   }
}

The output of the above code execution is:

a[0] = 10
a[1] = 100
a[2] = 200

    When creating a pointer array, it is not suitable to userangeLoop.

    Error code:

    const max = 3

func main() {
    number := [max]int{5, 6, 7}
    var ptrs [max]*int //指针数组
    //将number数组的值的地址赋给ptrs
    for i, x := range &number {
        ptrs[i] = &x
    }
    for i, x := range ptrs {
        fmt.Printf("指针数组：索引:%d 值:%d 值的内存地址:%d\n", i, *x, x)
    }
}

    The output result is:

    指针数组：索引:0 值:7 值的内存地址:824634204304
指针数组：索引:1 值:7 值的内存地址:824634204304
指针数组：索引:2 值:7 值的内存地址:824634204304

    From the results, we find that the memory addresses are all the same, and the values are the same too. What's going on?

    This problem is caused by the implementation logic of the range loop. Unlike a for loop, the x variable in a range loop is a temporary variable. The range loop simply copies the value into the x variable. Therefore, the memory addresses are all the same.

    The correct code is as follows:

    const max = 3

func main() {
    number := [max]int{5, 6, 7}
    var ptrs [max]*int //指针数组
    //将number数组的值的地址赋给ptrs
    for i := 0; i < max; i++ {
        ptrs[i] = &number[i]
    }
    for i, x := range ptrs {
        fmt.Printf("指针数组：索引:%d 值:%d 值的内存地址:%d\n", i,*x, x)
    }
}

    The output result is:

    指针数组：索引:0 值:5 值的内存地址:824634212672
指针数组：索引:1 值:6 值的内存地址:824634212680
指针数组：索引:2 值:7 值的内存地址:824634212688

    From the results, we can see that the memory addresses are all different.

var parr [3]*int
for k, v := range arr {
    temp := v
    parr[k] = &temp;

// 输出地址比对
for i := 0; i < 3; i+=1 {
    fmt.Println(&arr[i], parr[i]);
