The + Operator Used on Strings

The + operator is used to add (concatenate) text values or string variables.

To concatenate two or more string variables, use the+operator.

Examples

To concatenate two or more string variables, use the+operator:

txt1="What a very"; txt2="nice day"; txt3=txt1+txt2;

txt3The result is as follows:

What a verynice day

    The Difference Between JavaScript == and ===

    1. For primitive types such as string and number, there is a difference between == and ===.

    • a) When comparing between different types, == compares "the values after being converted to the same type" to see if the "values" are equal; if the types are different, === returns unequal.
    • b) When comparing the same type, it directly compares "values", and the results of both are the same.

    2. For advanced types such as Array and Object, there is no difference between == and ===.

    They compare "pointer addresses".

    3. Between primitive types and advanced types, there is a difference between == and ===.

    • a) For ==, convert the advanced type to a primitive type and compare "values".
    • b) Because the types are different, === returns false.
