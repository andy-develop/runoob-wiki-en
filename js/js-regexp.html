JavaScript Regular Expressions

A regular expression (English: Regular Expression, often abbreviated as regex, regexp, or RE in code) uses a single string to describe and match a series of string search patterns that conform to a certain syntactic rule.

Search patterns can be used for text search and text replacement.

What is a Regular Expression?

A regular expression is a search pattern formed by a sequence of characters.

When you search for data in text, you can use a search pattern to describe what you are looking for.

A regular expression can be a simple character or a more complex pattern.

Regular expressions can be used in all text search and text replacement operations.

For more regular expression content, visit:Regular Expressions - Tutorial.

Syntax

/regex body/modifiers (optional)

The modifiers are optional.


Example:

var patt = /runoob/i

Example analysis:

/runoob/iis a regular expression.

runoobis aregular expression body(used for searching).

iis amodifier(search is case-insensitive).

Using String Methods

In JavaScript, regular expressions are usually used with two string methods: search() and replace().

search() The method is used to search for a specified substring in a string, or to search for a substring that matches a regular expression, and returns the starting position of the substring.

replace() The method is used to replace some strings with other strings in a string, or to replace a substring that matches a regular expression.

search() method using a regular expression

Example

Use a regular expression to search for the string "Runoob" without distinguishing case:

var str = "Visit Runoob!"; var n = str.search(/Runoob/i);

The output result is:

6

search() method using a string

The search method can use a string as an argument. The string argument will be converted to a regular expression:

Example

Search for the substring "Runoob" in the string:

var str = "Visit Runoob!"; var n = str.search("Runoob");

replace() method using a regular expression

Example

Use a regular expression without distinguishing case to replace Microsoft with Runoob in the string:

var str = document.getElementById("demo").innerHTML; var txt = str.replace(/microsoft/i,"Runoob");

The result output is:

Visit Runoob!

replace() method using a string

The replace() method will accept a string as an argument:

var str = document.getElementById("demo").innerHTML; var txt = str.replace("Microsoft","Runoob");

Did you notice?


Regular expression arguments can be used in the above methods (instead of string arguments).
Regular expressions make search functionality more powerful (e.g., case-insensitive search in the example).

Regular Expression Modifiers

ModifiersCan be used for case-insensitive global searches:

Modifier Description
i Perform a case-insensitive match.
g Perform a global match (find all matches rather than stopping after the first match).
m Perform a multiline match.

Regular Expression Patterns

Square brackets are used to find characters in a certain range:

Expression Description
[abc] Find any character between the square brackets.
[0-9] Find any digit from 0 to 9.
(x|y) Find any of the options separated by |.

Metacharacters are characters that have special meanings:

Metacharacter Description
\d Find a digit.
\s Find a whitespace character.
\b Match a word boundary.
\uxxxx Find a Unicode character specified by the hexadecimal number xxxx.

Quantifiers:

Quantifier Description
n+ Matches any string containing at least onen.
n* Matches any string containing zero or moren.
n? Matches any string containing zero or onen.

Using the RegExp Object

In JavaScript, the RegExp object is a regular expression object with predefined properties and methods.

Using test()

The test() method is a regular expression method.

The test() method is used to test whether a string matches a pattern. If the string contains matching text, it returns true; otherwise, it returns false.

The following example is used to search for the character "e" in a string:

Example

var patt = /e/;
patt.test("The best things in life are free!");

The string contains "e", so the output of this example is:

true

Try it Yourself »

You can avoid setting a regular expression variable; the above two lines of code can be combined into one line:

/e/.test("The best things in life are free!")

Using exec()

The exec() method is a regular expression method.

The exec() method is used to search for matches of a regular expression in a string.

This function returns an array containing the matching results. If no match is found, the return value is null.

The following example is used to search for the letter "e" in a string:

Example 1

/e/.exec("The best things in life are free!");

The string contains "e", so the output of this example is:

e

    match()、replace()、search()、split()In methods, a regular expression argument can also be replaced with a string. In this case, the string will be implicitly converted to a regular expression. For example:

    var str = "abcdeabc";
console.log(str.match("abc")); // 输出["abc"]
console.log(str.replace("abc", "xyz")); // 输出"xyzdeabc"
console.log(str.search("abc")); // 输出0
console.log(str.split("abc")); // 输出["", "de", ""]

    Here, the string"abc"is treated as a literal regular expression, and it matches the"abc"part.

    But note that different methods have different rules when converting a string argument to a regular expression:

    split()methods andreplace()methods treat all metacharacters in the string argument (such as *, +, ?, etc.) as ordinary characters, and prepend a backslash to escape them, in order to match the actual characters in the string.

    match()methods andsearch()methods, however, treat all metacharacters in the string argument as metacharacters themselves, preserving their original meanings, in order to match specific patterns in the string.

    For example:

    var str = "a*b*c";
console.log(str.split("*")); // 相当于str.split(/\*/)，表示匹配一个星号字符。输出['a', 'b', 'c']
console.log(str.match("*")); // 相当于str.match(/*/)，/*/是一个无效的正则表达式。报错
console.log(str.search("*")); // 相当于str.search(/*/)。报错
console.log(str.replace("*", "+")); // 相当于str.replace(/\*/, "+")。输出a+b*c

    Therefore, when callingmatch()method andsearch()when using the method, if you want to represent a special character in the regular expression parameter, you need to ensure that in the regular expression converted from the string, there is a backslash before the corresponding character to escape it. This means that in the string passed in, you need to use two backslashes for escaping. And when callingsplit()method andreplace()when using the method, due to its special conversion rules, strings cannot represent metacharacters in regular expressions. Whether you add a backslash before a metacharacter in the string or not, it is treated as an escape character in the regular expression.

    Note:split("\\")、replace("\\")、match("\\\\")、search("\\\\")means matching a backslash, equivalent to xxx(/\\/). Andsplit("\")、match("\")、match("\\")、match("\\\")etc. are all illegal. For example:

    var str = "a\\b\\c";
console.log(str.split("\\")); // 输出["a", "b", "c"]
console.log(str.replace("\\","+")); // 输出a+b\c
console.log(str.match("\\\\")); // 输出['\\', index: 1, input: 'a\\b\\c', groups: undefined]
console.log(str.search("\\\\")); // 输出1

    Also note that a string cannot specify flags for a regular expression, nor can it use or reference groups. If there is such a need, you must use the RegExp object.
