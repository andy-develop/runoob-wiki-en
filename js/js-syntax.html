JavaScript Data Types

JavaScript has several data types: numbers, strings, arrays, objects, etc.:

Concept of Data Types

In programming languages, data types are a very important concept.

In order to operate on variables, it is very important to understand the concept of data types.

How is 16 plus "Volvo" calculated? Will the above produce an error or output the following result?

"16Volvo"

    CamelCase naming convention:

    When a variable name or function name is a unique identifier formed by joining one or more words together, the first word starts with a lowercase letter; the first letter of the second word is capitalized, or the first letter of every word is capitalized, for example: myFirstName, myLastName. Such variable names look like camel humps rising one after another, hence the name.

    The CamelCase naming convention can be regarded as a convention, with no absolute or mandatory rules, for the purpose of increasing recognition and readability.

    Variable naming conventions:

    2. CamelCase naming:

    • (1) All lowercase: words are separated by underscores
