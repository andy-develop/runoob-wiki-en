HTML Plugin

The plugin is designed to extend the functionality of an HTML browser.

HTML helper (plugin)

Helper application (helper application) is a program that can be launched by the browser. Helper applications are also called plugins.

Helper application can be used to play audio and video (and other) and is loaded using the <object> tag.

One advantage of using helper applications to play video and audio is that you can allow users to control part or all of the playback settings.

Plugins can be added to a page using either the <object> tag or the <embed> tag.

Most helper applications allow manual (or programmatic) control of volume settings and playback functions (such as backward, pause, stop, and play) .

Note:

Most browsers no longer support Java applets and plugins.

Most modern browsers have disabled support for Flash.

The following SWF file instances cannot run in modern browsers.

We can use the <video> and <audio> tags to display video and audio

<object> element

All mainstream browsers support the <object> tag.

<object> element defines an object to be embedded in the HTML document.

This tag is used to insert objects (such as Java applets, PDF readers, Flash players) into a webpage.

Instance

<object width="400" height="50" data="bookmark.swf"></object>

Try it »

<object> element can also be used to include HTML files:

Instance

<object width="100%" height="500px" data="snippet.html"></object>

Try it »

Or insert an image:

Instance

<object data="audi.jpeg"></object>

Try it »

<embed> element

All mainstream browsers support the <embed> element.

<embed> element represents an HTML Embed object.

<embed> element has been around for a long time, but it was not detailed in HTML 5, and it will be validated on HTML 5 pages, but not on HTML 4 pages.

Instance

<embed width="400" height="50" src="bookmark.swf">

Try it »

Note: The <embed> element does not have a closing tag. It cannot be used with an alternative text.

<embed> element can also be used to include HTML files:

Instance

<embed width="100%" height="500px" src="snippet.html">

Try it »

Or insert an image:

Instance

<embed src="audi.jpeg">

Try it »
