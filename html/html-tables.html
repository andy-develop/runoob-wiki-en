HTML Table

HTML Table and by<table>The <table> tag defines it.

An HTML table is a markup language element used to display structured data.

Each table has several rows (defined by the <tr> tag), each row is divided into several cells (defined by the <td> tag), and a table can contain a header row (defined by the <th> tag) to define column titles.<tr>:tr stands for table row, representing a row in the table.<td>:td stands for table data, representing a data cell in the table.<th>:th stands for table header, representing a header cell in the table.

  • trData cells can contain text, images, lists, paragraphs, forms, horizontal lines, tables, etc.

<tbody> is used to define the table's body section:

  • In <tbody>, the <tr> element is used to define rows, and <td> elements are used to define cell data. In the example, there are two rows of data, each containing three cells.By using the <th> element to define column titles, they can be displayed in bold and separated from regular cells.

  • HTML tables can also have other parts such as <tfoot> (table footer) and <caption> (table title). <tfoot> is used to define summary, statistical information, etc. at the bottom of the table. <caption> is used to define a title for the entire table.HTML tables support merging cells and spanning rows/columns, as well as applying other styles and attributes to meet various needs.

We can also use CSS to further customize the style and appearance of the table.

    As in the above table: tr represents the number of rows, td represents the number of cells, and th represents the title nature of td.

    Determine the method to identify tr and td (th is the same as td):

    1. From top to bottom, the most detailed to how many rows is how many tr.

    2. As shown in the three basic cell forms. A is the basic cell, and the other variations are formed by merging the basic cells. B is formed by merging the upper and lower cells, and C is formed by merging the left and right cells. The merged B cell is counted as the first cell in the second row, and the merged C cell is counted as the first cell in the fourth row (according to the table from top to bottom and from left to right).

    3. The fourth variant cell is a combination of both horizontal and vertical merging. In this case, both rowspan and colspan (separated by a space) are used to indicate how many cells (counting itself) are merged.

    The principle of cell merging is left-up, meaning that the lower cell belongs to the upper cell, the right cell belongs to the left cell, and the cell closer to the top-left corner has priority.

    Table semantic tags of the table:

    • 1. <table>: Root element of the table.
    • 2. <thead>: Table header.
    • 3. <tbody>: Table body.
    • 4.<tfoot>:tfoot, generally can be ignored.
    • 5.<tr>:table row.

    Table content tags:

    • 1.<th>:header cell.
    • 2.<td>:body cell.

    Span across columns: colspan

    Span across rows: rowspan

    Padding inside the cell: cellpadding

    Padding outside the cell: cellspacing

    col and colgroup are used to conveniently define the style of specified columns in a table.
