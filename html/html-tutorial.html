    Difference between htm and html

    The former is the Hypertext Markup

    The latter is the Hypertext Markup Language

    One can say htm = html

    At the same time, both are the extensions of static web page files. The extensions can be changed without causing errors (this refers to opening, but for a link, if it points to a htm file and that htm file is changed to an html file, then the link cannot be found)

    Why are there two file formats?

    htm comes from the old 8.3 file format, DOS operating system can only support suffixes of three characters, so it is htm, but in Windows, it doesn't matter whether it is HTM or HTML, HTML is named for the format of long file names. So htm exists to be compatible with the past DOS naming format, with no difference in effect. Previously, htm and html were different hyper text files on different servers, but now they are generally used.

    What is the 8.3 file format? This is a short file name file format of the old 16-bit Win95 or Win98 file system, the suffix is limited to three characters, and the file name is limited to eight characters. If you need to interact with the 16-bit system, for example, to pass a path to a 16-bit program, you cannot use a long file name, but must convert it. For example, convert "C : /MyLongestPath/MyLongerPath/MyFilename.txt" to "C : /Mylong~1/MyLong~2/Myfile~1.txt"

    What use is there in knowing this? In the DOS environment of the FAT disk format, only the 8.3 file format is supported. If you want to do applications in this environment, you should pay attention to this file format issue. In NTFS, by default, it can be compatible with this file format and also supports long file names, you can also adjust the registry to cancel the support for the 8.3 file format.

    What suffix to choose: use htm or use html?

    Recommended to use long suffixeshtml 。

    Naming should follow the principle of clarity, simplicity, and consistency. Clarity means seeing the name and knowing the meaning, for example, the htm (hypertext markup) and html (hypertext markup language) here both use the initial letters of the English word, the meaning is clear. Simplicity requires that variable names be as short as possible, for example, here the suffix uses initial letters instead of the full word. The principle of consistency requires that the same rules be followed for a large number of variables in the same environment, for example, some friends who are used to the Linux folder naming rules, when using the Windows system, still refuse to use spaces in the new folder names, which causes the new folder name to be inconsistent with the old folder name naming rules.

    The principle of consistency is often more important. For example, in collaborative development, one cannot each stick to their own ways, artificially increasing the difficulty of development.

    From the notes of all wind dust, we learned that htm is the legacy naming method of the 8.3 character limit, but now we do not name according to the 8.3 rule when naming. Therefore, when choosing between htm and html, we should also choose the naming method with unlimited length, html.
