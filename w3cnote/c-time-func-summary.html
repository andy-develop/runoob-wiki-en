Summary of time functions in C language

Category

In programming, functions for time expression and conversion are often used. They are all defined in the time.h library. Here is a summary for convenient reference and use later.

Several time concepts:

1：Coordinated Universal Time(UTC)：

Coordinated Universal Time, also known as Universal Time Coordinated, that is, Greenwich Mean Time (GMT). The time difference between mainland China and UTC is +8, that is, UTC+8; the US is UTC-5.

2：Calendar Time：

Calendar time is the time represented by "the number of seconds elapsed from a standard time point to the present". The standard time point may differ for different compilers, but for a compilation system, the standard time is constant. It is generally the number of seconds from UTC time 1970-01-01 00:00:00.

3：epoch：

Time point. In standard C/C++, it is an integer, represented by the number of seconds between the current time and the standard time point (i.e., calendar time).

4：clock tick：

Clock tick (not called clock tick count). The length of a clock tick is controlled by the CPU. A clock tick is not a CPU clock cycle, but a basic timing unit in C/C++.

Definition of time.h

The time.h header file defines four variable types, two macros, and various functions for manipulating dates and times.

4 variables

size_t It is an unsigned integer type, which is the result of the sizeof keyword.
clock_t This is a type suitable for storing processor time, of type unsigned long.
time_t This is a type suitable for storing calendar time.
struct tm This is a structure used to store time and date.

The definition of the tm structure is as follows:

struct tm
{
   int tm_sec;         /* Seconds, range from 0 to 59 */
   int tm_min;         /* Minutes, range from 0 to 59 */
   int tm_hour;        /* Hours, range from 0 to 23 */
   int tm_mday;        /* Day of the month, range from 1 to 31 */
   int tm_mon;         /* Month, range from 0 to 11 (note) */
   int tm_year;        /* Years since 1900 */
   int tm_wday;        /* Day of the week, range from 0 to 6 */
   int tm_yday;        /* Day of the year, range from 0 to 365 */
   int tm_isdst;       /* Daylight saving time */
};

Two macros

NULL This macro is the value of a null pointer constant.
CLOCKS_PER_SEC This macro represents the number of processor clocks per second. It is used to convert the result of the clock() function into a quantity in seconds. The specific value of this quantity is operating system dependent and is usually 1000.

Library functions

1: clock function

Function prototype:clock_t clock(void)

Function return: Returns the processor clock time used since the start of the clock function execution (usually the beginning of the program).

Function functionality: Used to calculate the execution time of a program or a certain section of a program.

Example

#include<stdio.h>
#include<time.h>

int main()
{
    clock_t start_t,finish_t;
    double total_t = 0;
    int i = 0;
    start_t = clock();
    for(;i<100000;++i)
    {
        //do someting;
    }
    finish_t = clock();
    total_t = (double)(finish_t - start_t) / CLOCKS_PER_SEC;//Convert time to seconds

    printf("Total CPU time: %f\n", total_t);
    return 0;
}

2: time function

Function prototype: time_t time(time_t *timer)

Parameter description: When timer=NULL, the current calendar time is obtained (the number of seconds from 1970-01-01 00:00:00 to now). When timer is a time value, it is used to set the calendar time. time_t is an unsigned long type. If timer is not empty, the return value is also stored in the variable timer.

Function functionality: Get the current calendar time or set the calendar time.

Function return: Current calendar time

Example

#include <stdio.h>
#include <time.h>

int main ()
{
  time_t seconds;

  seconds = time(NULL);
  printf("Hours since 1970-01-01 = %ld\n", seconds/3600);

  return(0);
}

3: asctime function

Function prototype: char* asctime(struct tm * ptr)

Function functionality: Represent the time represented by the structure struct tm * ptr as a string.

Function return: The returned time string format is: weekday, month, day, hour:minute:second, year

Parameter description: The structure pointer ptr should be obtained via the functions localtime() or gmtime().

Example

#include <stdio.h>
#include <time.h>

int main()
{
   struct tm t;//In more cases, the tm structure is obtained through the localtime function and gmtime function

   t.tm_sec    = 10;
   t.tm_min    = 10;
   t.tm_hour   = 6;
   t.tm_mday   = 25;
   t.tm_mon    = 2;
   t.tm_year   = 89;
   t.tm_wday   = 6;

   printf("%s\n",asctime(&t));

   return(0);
}

4: localtime function

Function prototype: struct tm *localtime(const time_t *timer)

Function functionality: Use the value of timer to fill the tm structure. The value of timer is decomposed into a tm structure and expressed in the local time zone.

Function return: The time expressed as a tm structure.

Example

#include <stdio.h>
#include <time.h>

int main ()
{
   time_t timer;
   struct tm *Now;

   time( &timer );
   Now = localtime( &timer );
   printf("Current local time and date: %s, asctime(Now));

   return(0);
}

5: ctime function

Function prototype: char *ctime(const time_t * timer)

Function functionality: Convert the calendar time parameter timer into a string representing the current local time.

Function return: Returns the string format: weekday, month, day, hour:minute:second, year

Parameter description: The timer parameter should be obtained by the function time. It is equivalent to astime( localtime(timer) ).

Example

#include <stdio.h>
#include <time.h>

int main ()
{
   time_t curtime;
   time(&curtime);
   printf("Current time = %s, ctime(&curtime));

   return(0);
}

6: difftime function

Function prototype: double difftime(time_t time2, time_t time1)

Function functionality: Get the difference between two machine times, in seconds.

Function return: The time difference, in seconds.

Parameter description: time1 and time2 represent two different machine times respectively. These parameters should be obtained using the time function.

Example

#include <time.h>  
#include <stdio.h>  
int main()  
{  
    time_t first,second;  
    time(&first);  
    sleep(2000);  
    time(&second);
    printf("The difference is: %f seconds",difftime(second,first));  

    return 0;  
}  

7: gmtime function

Function prototype: struct tm *gmtime(time_t *timer)

Function functionality: Obtain time information represented by the structure tm, expressed in Greenwich Mean Time.

Function return: A pointer to time information represented by the structure tm.

Parameter description: timer is the time information obtained by the function time().

Example

#include <stdio.h>
#include <time.h>

#define BST (+1)
#define CCT (+8)

int main ()
{

   time_t rawtime;
   struct tm *info;

   time(&rawtime);
   /* Get GMT time */
   info = gmtime(&rawtime );

   printf("Current world clock:\n");
   printf("London: %2d:%02d\n", (info->tm_hour+BST)%24, info->tm_min);
   printf("China: %2d:%02d\n", (info->tm_hour+CCT)%24, info->tm_min);

   return(0);
}

8: mktime function

Function prototype: time_t mktime(struct tm *timeptr)

Function functionality: Convert the structure pointed to by timeptr into a time_t value based on the local time zone.

Function return: This function returns a time_t value corresponding to the calendar time passed as a parameter. If an error occurs, it returns a value of -1.

Example

#include <stdio.h>
#include <time.h>

int main ()
{
   int ret;
   struct tm info;
   char buffer[80];

   info.tm_year = 2001 - 1900;
   info.tm_mon = 7 - 1;
   info.tm_mday = 4;
   info.tm_hour = 0;
   info.tm_min = 0;
   info.tm_sec = 1;
   info.tm_isdst = -1;

   ret = mktime(&info);
   if( ret == -1 )
   {
       printf("Error: Cannot use mktime to convert the time.\n");
   }
   else
   {
      strftime(buffer, sizeof(buffer), "%c", &info );
      print(buffer);
   }

   return(0);
}

9: strftime function

Function prototype: size_t strftime( char *strDest, size_t maxsize, const char *format, const struct tm *timeptr);

Function functionality: According to the format commands in the string pointed to by format, place the time information stored in timeptr into the string pointed to by strDest, storing at most maxsize characters into strDest.

Parameter description: The conversion result is stored in s, and at most maxsize characters are written to s.

Function return: This function returns the number of characters placed into the string pointed to by strDest (excluding '\0'). If the number of characters exceeds maxsize, the function returns 0.

Example

/*format is as follows: They are case-sensitive.
%a Abbreviated weekday name
%A Full weekday name

#include <stdio.h>
#include <time.h>

int main ()
{
   time_t rawtime;
   struct tm *info;
   char buffer[80];

   time( &rawtime );

   info = localtime( &rawtime );

   strftime(buffer,80,"%Y%m%e_%H%M%S", info);// Represent the current time in the format of year-month-day_hour-minute-second
   printf("%s\n", buffer );

   return(0);
}
