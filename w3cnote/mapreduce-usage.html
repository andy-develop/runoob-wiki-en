6.0 MapReduce Usage

Categories Hadoop Tutorial

After learning the previous MapReduce concepts, we should already know what Map and Reduce are, and understand how they work.

This chapter will teach how to use MapReduce.

Word Count

Word Count means "word counting", and it is one of the most classic MapReduce programs. Its main task is to summarize and count the words in a text file, calculating the total number of occurrences for each word that appears.

Hadoop includes many classic MapReduce example programs, among which is Word Count.

Note:This example can still run even when HDFS is not running, so let's first test it in standalone mode.

First, start a new container from the previously built hadoop_proto image:

docker run -d --name=word_count hadoop_proto

Enter the container:

docker exec -it word_count bash

Go to the HOME directory:

cd ~

Now let's prepare a text file input.txt:

I love runoob
I like runoob
I love hadoop
I like hadoop

Save the above content with a text editor.

Execute MapReduce:

hadoop jar $HADOOP_HOME/share/hadoop/mapreduce/hadoop-mapreduce-examples-3.1.4.jar wordcount input.txt output

Let's explain the meaning:

hadoop jar executes a MapReduce task from a jar file, followed by the path to the example program package.

wordcount means executing the Word Count program in the example program package, followed by two parameters: the first is the input file, and the second is the output directory name (because the output result consists of multiple files).

After execution, a folder named output should be generated. This folder contains two files: _SUCCESS and part-r-00000.

Among them, _SUCCESS is just an empty file indicating successful execution, while part-r-00000 is the processing result. When we display its content:

cat ~/output/part-r-00000

You should see the following information:

I       4
hadoop  2
like    2
love    2
runoob  2

Cluster Mode

Now let's run MapReduce in cluster mode.

Start the cluster containers configured in the previous chapter:

docker start nn dn1 dn2

Enter the NameNode container:

docker exec -it nn su hadoop

Go to HOME:

cd ~

Edit input.txt:

I love runoob
I like runoob
I love hadoop
I like hadoop

Start HDFS:

start-dfs.sh

Create a directory:

hadoop fs -mkdir /wordcount
hadoop fs -mkdir /wordcount/input

Upload input.txt

hadoop fs -put input.txt /wordcount/input/

Execute Word Count:

hadoop jar $HADOOP_HOME/share/hadoop/mapreduce/hadoop-mapreduce-examples-3.1.4.jar wordcount /wordcount/input /wordcount/output

View the execution result:

hadoop fs -cat /wordcount/output/part-r-00000

If everything is normal, the following result will be displayed:

I       4
hadoop  2
like    2
love    2
runoob  2
