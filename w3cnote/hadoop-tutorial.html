1.0 Hadoop Tutorial

Categories Hadoop Tutorial

Hadoop is an open-source distributed computing and storage framework developed and maintained by the Apache Foundation.

Hadoop provides reliable, scalable application-layer computing and storage support for large computer clusters. It allows the distributed processing of large data sets across computer clusters using a simple programming model, and supports scaling from a single computer to thousands of computers.

Hadoop is developed in Java, so it can be deployed and used on computers with various hardware platforms. Its core components include the distributed file system (Hadoop DFS, HDFS) and MapReduce.

Hadoop History

In 2003 and 2004, Google successively published two famous papers, GFS and MapReduce.

These two papers, together with BigTable published in 2006, became the now-famous "Google's Three Major Papers".

Doug Cutting began developing Hadoop after being influenced by these theories.

Hadoop contains two core components. In Google's paper, GFS is a distributed file system running in a large computer cluster; in Hadoop, HDFS implements its functions. MapReduce is a distributed computing method, and Hadoop implements its functions with the MapReduce framework of the same name. We will introduce it in detail in the MapReduce chapter later. Since 2008, Hadoop has existed as an Apache top-level project. It and its many subprojects are widely used in large Internet service enterprises such as Yahoo, Alibaba, and Tencent, and are listed as supported targets by platform companies such as IBM, Intel, and Microsoft.

The Role of Hadoop

The role of Hadoop is very simple: it creates a unified and stable storage and computing environment in a multi-computer cluster environment, and can provide platform support for other distributed application services.

In other words, Hadoop organizes multiple computers into one computer (doing the same thing) to some extent. HDFS is equivalent to the hard disk of this computer, and MapReduce is the CPU controller of this computer.
