1.7 Heapsort

Category Algorithm

Heapsort refers to a sorting algorithm designed using the heap data structure. A heap is a structure that approximates a complete binary tree, and simultaneously satisfies the heap property: the key value or index of a child node is always less than (or greater than) its parent node. Heapsort can be said to be a selection sort that uses the concept of a heap to sort. It is divided into two methods:

  1. Max heap: each node's value is greater than or equal to the values of its child nodes, used for ascending order in the heapsort algorithm;
  2. Min heap: each node's value is less than or equal to the values of its child nodes, used for descending order in the heapsort algorithm;

The average time complexity of heapsort is Ο(n log n).

1. Algorithm steps

  1. Create a heap H[0...n-1];

  2. Swap the top of the heap (maximum value) with the tail of the heap;

  3. Reduce the heap size by 1, and call shift_down(0), in order to adjust the new array top data to the corresponding position;

  4. Repeat step 2 until the heap size is 1.

2. Animation demonstration

Suppose there is a list to be sorted [4, 10, 3, 5, 1], the heapsort process is as follows:

  1. Build max heap：

    • Initial list:[4, 10, 3, 5, 1]。

    • Starting from the last non-leaf node, adjust the heap step by step:

      • Adjust the node5：[4, 10, 3, 5, 1](No adjustment needed).

      • Adjust the node10：[4, 10, 3, 5, 1](No adjustment needed).

      • Adjust the node4：[10, 5, 3, 4, 1]。

    • Final max heap:[10, 5, 3, 4, 1]。

  2. Swap the top element：

    • Move the top element10with the last element1swap, the list becomes[1, 5, 3, 4, 10]。

    • The heap size decreases by 1, the sorted part is[10]。

  3. Adjust the heap：

    • For the new top element1perform the sift-down operation:

      • Compare1with its child nodes5、3, then1and5swap.

      • The list becomes[5, 1, 3, 4, 10]。

      • Continue comparing1with its child nodes4, then1and4swap.

      • The list becomes[5, 4, 3, 1, 10]。

    • Adjusted heap:[5, 4, 3, 1]。

  4. Repeat steps：

    • Move the top element5with the last element1swap, the list becomes[1, 4, 3, 5, 10]。

    • The heap size decreases by 1, the sorted part is[5, 10]。

    • For the new top element1perform the sift-down operation:

      • Compare1with its child nodes4、3, then1and4swap.

      • The list becomes[4, 1, 3, 5, 10]。

    • Adjusted heap:[4, 1, 3]。

  5. Continue repeating：

    • Move the top element4with the last element3swap, the list becomes[3, 1, 4, 5, 10]。

    • The heap size decreases by 1, the sorted part is[4, 5, 10]。

    • For the new top element3perform the sift-down operation:

      • Compare3with its child nodes1, no swap needed.

    • Adjusted heap:[3, 1]。

  6. Final step：

    • Move the top element3with the last element1swap, the list becomes[1, 3, 4, 5, 10]。

    • The heap size decreases by 1, the sorted part is[3, 4, 5, 10]。

    • The heap size is 1, sorting is complete.

Example

def heapify(arr, n, i):
    # Find the maximum value among the current node, left child node, and right child node
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2

    if left < n and arr[left] > arr[largest]:
        largest = left
    if right < n and arr[right] > arr[largest]:
        largest = right

    # If the maximum value is not the current node, swap and continue adjusting
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)

def heap_sort(arr):
    n = len(arr)

    # Build max heap
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)

    # Take out the top element one by one and adjust the heap
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]  # Swap the top element and the last element
        heapify(arr, i, 0)  # Adjust the heap

    return arr

# Example
arr = [4, 10, 3, 5, 1]
sorted_arr = heap_sort(arr)
print(sorted_arr)  # Output: [1, 3, 4, 5, 10]

Time complexity

  • Building the max heap：O(n)。

  • Adjusting the heap each time: O(log n), a total of n-1 adjustments are needed.

  • Total time complexity：O(n log n)。

Space complexity

  • O(1). Heapsort is an in-place sorting algorithm and does not require extra storage space.

Pros and cons

  • Advantages：

    • The time complexity is stable at O(n log n), suitable for large-scale data.

    • In-place sorting, no extra storage space needed.

  • Disadvantages：

    • Unstable sorting algorithm (may change the relative order of equal elements).

    • For small-scale data, performance may not be as good as simple algorithms such as insertion sort.

Applicable scenarios

  • Sorting large-scale data sets.

  • Scenarios with high performance requirements.

  • Suitable for in-memory sorting (not suitable for external sorting).

JavaScript

Example

var len;    // Because multiple declared functions need the data length, set len as a global variable

function buildMaxHeap(arr) {   // Build max heap
    len = arr.length;
    for (var i = Math.floor(len/2); i >= 0; i--) {
        heapify(arr, i);
    }
}

function heapify(arr, i) {     // Heap adjustment
    var left = 2 * i + 1,
        right = 2 * i + 2,
        largest = i;

    if (left < len && arr[left] > arr[largest]) {
        largest = left;
    }

    if (right < len && arr[right] > arr[largest]) {
        largest = right;
    }

    if (largest != i) {
        swap(arr, i, largest);
        heapify(arr, largest);
    }
}

function swap(arr, i, j) {
    var temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}

function heapSort(arr) {
    buildMaxHeap(arr);

    for (var i = arr.length-1; i > 0; i--) {
        swap(arr, 0, i);
        len--;
        heapify(arr, 0);
    }
    return arr;
}

public class HeapSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // Copy arr, do not change the parameter content
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        int len = arr.length;

        buildMaxHeap(arr, len);

        for (int i = len - 1; i > 0; i--) {
            swap(arr, 0, i);
            len--;
            heapify(arr, 0, len);
        }
        return arr;
    }

    private void buildMaxHeap(int[] arr, int len) {
        for (int i = (int) Math.floor(len / 2); i >= 0; i--) {
            heapify(arr, i, len);
        }
    }

    private void heapify(int[] arr, int i, int len) {
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        int largest = i;

        if (left < len && arr[left] > arr[largest]) {
            largest = left;
        }

        if (right < len && arr[right] > arr[largest]) {
            largest = right;
        }

        if (largest != i) {

            heapify(arr, largest, len);
        }
    }

        int temp = arr[i];

C

Example

#include <stdio.h>
#include <stdlib.h>

void swap(int *a, int *b) {
    int temp = *b;
    *b = *a;
    *a = temp;
}

void max_heapify(int arr[], int start, int end) {
    // Set up parent node index and child node index
    int dad = start;
    int son = dad * 2 + 1;
    while (son <= end) { // Only compare if the child node index is within range
        if (son + 1 <= end && arr[son] < arr[son + 1]) // First compare the sizes of the two child nodes, choose the largest
            son++;
        if (arr[dad] > arr[son]) // If the parent node is greater than the child node, the adjustment is complete, exit the function directly
            return;
        else { // Otherwise, swap the parent-child contents and continue comparing child nodes with grandchild nodes
            swap(&arr[dad], &arr[son]);
            dad = son;
            son = dad * 2 + 1;
        }
    }
}

void heap_sort(int arr[], int len) {
    int i;
    // Initialization, i starts adjusting from the last parent node
    for (i = len / 2 - 1; i >= 0; i--)
        max_heapify(arr, i, len - 1);
    // First swap the first element with the element before the sorted elements, then adjust again, until sorting is complete
    for (i = len - 1; i > 0; i--) {
        swap(&arr[0], &arr[i]);
        max_heapify(arr, 0, i - 1);
    }
}

int main() {
    int arr[] = { 3, 5, 3, 0, 8, 6, 1, 5, 8, 6, 2, 4, 9, 4, 7, 0, 1, 8, 9, 7, 3, 1, 2, 5, 9, 7, 4, 0, 2, 6 };
    int len = (int) sizeof(arr) / sizeof(*arr);
    heap_sort(arr, len);
    int i;
    for (i = 0; i < len; i++)
        printf("%d ", arr[i]);
    printf("\n");
    return 0;
}
