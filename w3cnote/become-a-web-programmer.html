How to Become a Web Developer

Category Programming Technology

1. What knowledge points does a Web programmer need to know?

Web applications mainly run in browsers. The web pages we usually open are Web programs. Common Web technologies include:

  • HTTP
  • FTP
  • POP3
  • SMTP
  • TCP
  • IP protocols
  • HTML
  • XML
  • Coldfusion
  • ASP
  • JSP
  • PHP
  • ASP.NET

2. Browse various kinds of websites

In browsers we commonly use, such as Chrome and Firefox, you can press the F12 key (or right-click the mouse => View Source) to view the source code of a web page.

Website types include: corporate sites, portal sites, personal blogs, information encyclopedias, social networking, etc.

3. Learn to use a flowchart software

It can be: MS Visio or Xmind.

4. Familiarize yourself with website structure

Be familiar with the tree structure, site map, navigation settings, etc. of a website.

5. You can learn an image processing software

6. Learn basic Internet fundamentals

  • Basic Web service protocols (HTTP, FTP, SMTP, and POP3 or IMAP4)
  • Web server software (Apache, Tomcat, Nginx, etc.)
  • Browsers (Chrome, Firefox, etc.)
  • Email server and client software

7. Learn HTML and CSS

If a website is compared to a house, HTML is like the brick structure of a web page, and CSS is the material for decorating the house.

You can directly go to the Runoob Tutorial website to learn.

8. Learn XML, JSON, and related technologies

Again, Runoob Tutorial.

9. Use HTML to create a simple static page

10. Learn client-side scripting languages

Client-side scripting languages can be understood as the various switches in the house: lights, water heaters, etc.

The languages include: JavaScript, VBScript, Java Applet (deprecated). It is recommended to directly learn JavaScript.

JavaScript is a client-side scripting language. It is very important, study it well.

Say it again: Runoob Tutorial has it.

11. Learn a backend language

It can be PHP, JSP, ASP.Net, etc. These languages are mainly used for interaction with backend data, involving operations such as adding, deleting, modifying, and viewing data.

12. Try writing a small project yourself

It can be a personal blog system, shopping cart, etc...

13. Participate in the development of a Web project

Learning is just the beginning; the most important growth still comes in project development...
