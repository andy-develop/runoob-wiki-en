MySQL 5.6 Installation and Configuration Illustrated Tutorial on Windows 8

Category Programming Technology

I. Preparation Before Installation

1. Download the installation package from the MySQL official websitewww.mysql.comDownload, as shown in the figure:

The downloaded installation file is shown in the figure:

II. Installation

1. Double-click the downloaded installation file. The MySQL version installed in this blog post is 5.6.10.1, and the page shown in the figure appears:

2. Click "Install MySQL Products" to enter the page shown in Figure 1-4:

3. Check "I accept the license

terms", then click "Next". The page for checking the latest product updates appears as shown in the figure. If you don't like updates, you can select "Skip the check for updates (not recommended)" below, then click "Next" to continue:

4. Choose the installation type that suits you according to the installation type description on the right, as shown in the figure. Be sure to modify the installation path to avoid having to reinstall MySQL after reinstalling the system:

5. Depending on the installation type you selected, some frameworks need to be installed. Click "Execute" to install the required frameworks, as shown in the figure:

6. The page during framework installation, as shown in the figure:

7. The prompt after the framework installation succeeds, as shown in the figure:

8. After all required frameworks are installed successfully, as shown in the figure, click "Next":

9. Start the installation. As shown in Figure 1-11, click "Execute". The interface during installation is shown in the figure:

10. Confirm the configuration information, as shown in the figure, click "Next":

11. Server configuration type selection, Developer

Machine - The installed MySQL server is part of a development machine; among the three type options, it uses the least memory. Server Machine - The installed MySQL server is part of a server machine; its memory usage is in the middle among the three types. Dedicated MySQL Server Machine - Installs a dedicated MySQL database server, using all available memory of the machine. No changes need to be made; the default port 3306 and other settings can also remain unchanged, click "Next":

12. Set the administrator password. As shown in the figure, select "Add User". You can also create users at the same time, but from a security perspective, it is best not to create users:

13. In the interface shown in the figure, you can set the system server name and whether to automatically start the MySQL database server when the system starts. You can use the default options, click "Next":

14. Confirm the installation is complete. Check "Start MySQL Workbench after Setup" to test whether the installation was successful, then click "Finish":

III. Installation Successful

1. The Workbench GUI page appears, as shown in the figure. The installation is successful:
