How to add Python to PATH on Windows

Category Programming Technology

When you see'python' is not recognized as an internal or external commandthis error, it means Windows cannot find the Python executable in the PATH environment variable.

By adding the correct directory to PATH, you can run Python and pip in any terminal without full paths.

Before you start, make sure you have the following:

Prerequisites Description
Python installed from python.org or Microsoft Store on Windows 11
Administrator privileges Required for modifying system-level variables; user-level modifications do not require administrator privileges
Restart terminal Any PATH change requires reopening a new terminal session to take effect

For detailed guidance on PATH, installer options, and Python Launcher, see the "Using Python on Windows" chapter in the official Python documentation (docs.python.org).

Method 1: Use the official installer to add PATH (recommended)

The installer from python.org can set PATH for you directly, avoiding manual entry errors, and it also adds the Scripts folder needed for pip.

The same installer can also be used with theModifyoption to add PATH to an existing installation without reinstalling.

Method 2: Manually add Python to PATH (user level)

If you did not enable the PATH option when installing Python, or you need to adjust only the current user's environment variables without affecting system variables, you can edit PATH manually.

Steps

Notes and common pitfalls

Common mistakes Correct approach
Trailing backslash in path Should useC:\Path\To\Python311, notC:\Path\To\Python311\
Extra spaces before path Each entry should be a clean path line without leading or trailing spaces
Old entries pointing to invalid folders Delete or fix non-existent paths to avoid path resolution confusion
Terminal not restarted after modification Completely close all terminal windows and reopen; in some cases, log off or restart

Method 3: Fix "App execution aliases" for Microsoft Store installations

If you installed Python from the Microsoft Store, it relies on "App execution aliases" and the WindowsApps directory to resolve the python command, rather than traditional PATH editing.

If enteringpythonopens Microsoft Store instead of running Python, the alias is pointing to the Store. Turn off the alias for the corresponding version, install the python.org version instead, or use the Python Launcher (py command) described below.

Method 4: Use Python Launcher instead of editing PATH

Python Launcher（py.exe) is installed with python.org builds and can automatically locate installed Python versions based on labels, completely avoiding PATH conflicts.

This is the officially recommended multi-version management solution — you can pin a specific Python version for each project without modifying PATH.

Steps

Check the Launcher version:

py --version

Explicitly run the desired Python version:

py -3
py -3.11
py -3.10 -m pip --version

Use the Launcher to create and use virtual environments:

# 使用指定版本创建虚拟环境
py -3.11 -m venv venv

# 激活虚拟环境
venv\Scripts\activate

# 在虚拟环境中确认 Python 版本
python --version

Additional notes

Command Purpose
py --list List all detected Python runtime versions
py -3.11 Start the interactive interpreter of the specified Python version
py -3.11 -m pip install 包名 Install third-party packages for the specified Python version

When using the py Launcher, you can completely skip manual PATH editing. The Launcher automatically discovers all installed Python versions and lets you choose as needed — this is especially convenient for developers who need both Python 3.10 and 3.12.

Summary

Once PATH is set correctly—or you start using Python Launcher—you can run Python and pip from anywhere without typing the full path.

For multi-version environments, it is strongly recommended to use Python Launcher to precisely select versions, combined with virtual environments to maintain dependency isolation for each project.
