Solving the Problem of Slow NPM in China

Category Programming Technology

NPM is a package management tool installed along with NodeJS. We often use it to download third-party packages to our local machine.

But as many people who have used NPM probably know, downloading third-party packages in China is extremely slow.

Today I recommend using the Taobao NPM mirror. It is a complete npmjs.org mirror. You can use it to replace the official version (read-only). The synchronization frequency is currently once every 10 minutes to ensure synchronization with the official service as much as possible.

Taobao NPM mirror address:https://npm.taobao.org/

Usage Instructions

You can use the cnpm command-line tool customized by the Taobao NPM mirror (with gzip compression support) to replace the default npm:

npm install -g cnpm --registry=https://registry.npmmirror.com

In this way, you can use the cnpm command to install modules:

$ cnpm install [name]

Examples

Install the Express development framework:

$ cnpm install express
