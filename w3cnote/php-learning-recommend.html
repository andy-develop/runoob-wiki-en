Learning path and suggestions for PHP beginners

Category Programming Technology

Let's first look at the learning path for PHP beginners:

  • (1) Familiarize yourself with basic web elements such as HTML/CSS/JS. By the end of this stage, you can create simple web pages on your own and be relatively familiar with element attributes.
  • (2) Understand the concepts and operating mechanisms of dynamic languages, and become familiar with basic PHP syntax.
  • (3) Learn how to combine PHP with HTML to complete simple dynamic pages.
  • (4) Start learning MySQL and begin designing databases.
  • (5) Continuously consolidate PHP syntax, become familiar with most common PHP functions, understand object-oriented programming, MySQL optimization, as well as some templates and frameworks.
  • (6) Finally complete a fully functional dynamic website.

  • Beginners should not look at the summary above and think that learning PHP is very simple. Programming requires serious thinking and continuous practice. The following explains the PHP learning path in detail. First, any website is composed of web pages. In other words, to complete a website, you must first learn to make web pages. Mastering the techniques of creating static web pages is a prerequisite for learning website development. Therefore, we need to learn HTML to lay a foundation for building websites in the future. When learning HTML, you should learn by doing. You should personally practice every element in HTML. Only by understanding what effect each element produces can you remember it deeply; reading books all the time won't work.

  • Assuming you can already complete a static page, it's time to start learning about dynamic languages. As soon as you are exposed to dynamic languages, many people may have many doubts. Code is not output directly, but has to be processed. HTML goes through an HTML parser, and PHP also goes through a PHP parser. Just like learning HTML, if you want any parser to work, you must use its dedicated syntax structure.

  • When learning PHP, you should feel lucky, because if you have learned other languages, you will find that PHP is relatively simple. At this stage, you need to clarify the concepts of HTML and PHP. You can now let PHP calculate what one plus one equals for you, and then output it in the browser. Don't think it's childish. Although this is a very small piece of code, it is a big step for your programming journey. However, right now, you are still a beginner.

  • Next, it's time to learn databases. MySQL can be said to be PHP's golden partner. We need to conquer this database. After you understand the concept of databases, you should try to connect to a database through PHP, and then successfully insert, delete, and update data using PHP.

  • At this point, you might be in this state: Do you know HTML? Yes, I can code several web pages with table layouts! Do you know PHP? Yes, I can write the one-plus-one calculation in a function and then call it! Do you know MySQL? Yes, I can insert and delete data in the database!

  • So what should you do next? Try to make a small guestbook. This is also a hurdle that beginners face. After spending some time, you finally learn to insert form data into the database and then display it. It can be said that the prototype of a program has been born. However, you may see others writing a forum or developing a CMS, and wonder when you can write one. Don't worry. Consolidate your knowledge again. After becoming familiar with the key points of PHP and MySQL development, look back at the guestbook you wrote. You may doubt whether it was really written by you. At this time, you can improve the guestbook you wrote. The guestbook should add registration and pagination functions. If possible, the UI can also be enhanced.

  • Does this mean you've learned it? NO, NO, NO, it's still early. You haven't touched OOP yet, have you? What about templates and frameworks? You still need to continue learning! A PHP framework provides a basic framework for building web applications, thereby simplifying the process of writing web applications in PHP. It can save development time and help build more stable applications. Therefore, a PHP framework is a tool that can save time and strengthen your code. When you first choose a PHP framework, it is recommended to try several. Each framework has its own strengths and weaknesses. For example, the Zend framework has been popular for a long time due to its diverse functions and extensive support system. CakePHP is a PHP framework that came after Zend and has fewer support systems, but it is more convenient and easier to use.

  • After understanding object-oriented programming and frameworks, you should get in touch with XML. All in all, you will never find that you have learned everything. There is no end to learning! When learning something, never expect that there is such a thing as a quick fix. No matter how many skills you have, without effort, it is useless. One thing is guaranteed: if you have learned PHP, then learning other languages will definitely be quick. Conversely, if you have learned other languages before, learning PHP will definitely be fast.

  • Learn more from others' successful code; it is absolutely beneficial and harmless. Therefore, reading more classic code that has been tempered and refined through countless trials is the best way to improve. In addition, it should be emphasized that you may encounter difficulties and feel confused during the process of learning a technology. Perhaps you are halfway through learning PHP and start thinking about C#, or someone says Java is great. At this time, you must not waver. You should persevere to the end and learn it thoroughly. Wish you success in learning PHP and developing the website you want.
