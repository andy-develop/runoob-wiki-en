1.5 Merge Sort

Category Algorithm

Merge sort is an efficient sorting algorithm based on the merge operation. It is a very typical application of the divide and conquer approach.

As a typical algorithmic application of the divide and conquer idea, merge sort can be implemented in two ways:

  • Top-down recursion (all recursive methods can be rewritten with iteration, hence the second method);
  • Bottom-up iteration;

Like selection sort, merge sort's performance is not affected by the input data, but it performs much better than selection sort because it always has a time complexity of O(nlogn). The cost is that it requires extra memory space.

The core idea of merge sort is to break a big problem down into several smaller problems, solve these smaller problems separately, then merge the results to finally obtain the solution to the whole problem. Specifically for the sorting problem, the steps of merge sort are as follows:

  1. Divide: Split the array to be sorted into two subarrays, each containing about half of the elements.
  2. Conquer: Recursively sort each subarray.
  3. Combine: Merge the two sorted subarrays into one ordered array.

Through continuous dividing and merging, the entire array will eventually be sorted.

2. Algorithm Steps

  1. Allocate space whose size is the sum of the two already sorted sequences; this space is used to store the merged sequence;

  2. Set two pointers, initially positioned at the starting positions of the two sorted sequences;

  3. Compare the elements pointed to by the two pointers, select the relatively smaller element to put into the merge space, and move the pointer to the next position;

  4. Repeat step 3 until one pointer reaches the end of its sequence;

  5. Directly copy all remaining elements of the other sequence to the end of the merged sequence.

3. Animated Demo

Suppose there is a list to be sorted [38, 27, 43, 3, 9, 82, 10]. The process of merge sort is as follows:

  1. Divide：

    • Split the list in half:[38, 27, 43, 3]and[9, 82, 10]。

    • Continue dividing:

      • [38, 27, 43, 3]Split into[38, 27]and[43, 3]。

      • [9, 82, 10]Split into[9]and[82, 10]。

    • Continue dividing:

      • [38, 27]Split into[38]and[27]。

      • [43, 3]Split into[43]and[3]。

      • [82, 10]Split into[82]and[10]。

    • Finally divided into sublists of single elements.

  2. Merge：

    • Merge[38]and[27]Obtain[27, 38]。

    • Merge[43]and[3]Obtain[3, 43]。

    • Merge[27, 38]and[3, 43]Obtain[3, 27, 38, 43]。

    • Merge[9]and[10, 82]Obtain[9, 10, 82]。

    • Merge[3, 27, 38, 43]and[9, 10, 82]Obtain the final sorted list[3, 9, 10, 27, 38, 43, 82]。

Example

def merge_sort(arr):
    if len(arr) <= 1:
        return arr

    # Divide: split the list in half
    mid = len(arr) // 2
    left_half = merge_sort(arr[:mid])  # Recursively sort the left half
    right_half = merge_sort(arr[mid:])  # Recursively sort the right half

    # Merge: merge two sorted sublists
    return merge(left_half, right_half)

def merge(left, right):
    sorted_arr = []
    i = j = 0

    # Compare the elements of the two sublists and merge them in order
    while i < len(left) and j < len(right):
        if left[i] < right[j]:
            sorted_arr.append(left[i])
            i += 1
        else:
            sorted_arr.append(right[j])
            j += 1

    # Add the remaining elements to the result
    sorted_arr.extend(left[i:])
    sorted_arr.extend(right[j:])
    return sorted_arr

# Example
arr = [38, 27, 43, 3, 9, 82, 10]
sorted_arr = merge_sort(arr)
print(sorted_arr)  # Output: [3, 9, 10, 27, 38, 43, 82]

Time Complexity

  • Divide: Each time the list is split in half, requiring O(log n) levels of recursion.

  • Merge: Each level of recursion requires O(n) time to merge sublists.

  • Total time complexity：O(n log n)。

Space Complexity

  • O(n). Merge sort requires extra space to store temporary lists.

Advantages and Disadvantages

  • Advantages：

    • The time complexity is consistently O(n log n), suitable for large-scale data.

    • Stable sorting algorithm (the relative order of equal elements does not change).

    • Suitable for external sorting (such as sorting disk files).

  • Disadvantages：

    • Requires extra storage space, with a space complexity of O(n).

    • For small-scale data, performance may not be as good as simple algorithms like insertion sort.

JavaScript

Example

function mergeSort(arr) {  // Using the top-down recursive method
    var len = arr.length;
    if(len < 2) {
        return arr;
    }
    var middle = Math.floor(len / 2),
        left = arr.slice(0, middle),
        right = arr.slice(middle);
    return merge(mergeSort(left), mergeSort(right));
}

function merge(left, right)
{
    var result = [];

    while (left.length && right.length) {
        if (left[0] <= right[0]) {
            result.push(left.shift());
        } else {
            result.push(right.shift());
        }
    }

    while (left.length)
        result.push(left.shift());

    while (right.length)
        result.push(right.shift());

    return result;
}

func merge(left []int, right []int) []int {
        var result []int
        for len(left) != 0 && len(right) != 0 {
                if left[0] <= right[0] {

Example

public class MergeSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // Make a copy of arr, without changing the parameter content
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        if (arr.length < 2) {
            return arr;
        }
        int middle = (int) Math.floor(arr.length / 2);

        int[] left = Arrays.copyOfRange(arr, 0, middle);
        int[] right = Arrays.copyOfRange(arr, middle, arr.length);

        return merge(sort(left), sort(right));
    }

    protected int[] merge(int[] left, int[] right) {
        int[] result = new int[left.length + right.length];
        int i = 0;
        while (left.length > 0 && right.length > 0) {
            if (left[0] <= right[0]) {
                result[i++] = left[0];
                left = Arrays.copyOfRange(left, 1, left.length);
            } else {
                result[i++] = right[0];
                right = Arrays.copyOfRange(right, 1, right.length);
            }
        }

        while (left.length > 0) {
            result[i++] = left[0];
            left = Arrays.copyOfRange(left, 1, left.length);
        }

        while (right.length > 0) {
            result[i++] = right[0];
            right = Arrays.copyOfRange(right, 1, right.length);
        }

        return result;
    }

}

void merge_sort_recursive(int arr[], int reg[], int start, int end) {
    if (start >= end)
        return;
    int len = end - start, mid = (len >> 1) + start;
    int start1 = start, end1 = mid;
    int start2 = mid + 1, end2 = end;
    merge_sort_recursive(arr, reg, start1, end1);
    merge_sort_recursive(arr, reg, start2, end2);
    int k = start;
    while (start1 <= end1 && start2 <= end2)
        reg[k++] = arr[start1] < arr[start2] ? arr[start1++] : arr[start2++];
    while (start1 <= end1)
        reg[k++] = arr[start1++];
    while (start2 <= end2)
        reg[k++] = arr[start2++];
    for (k = start; k <= end; k++)
        arr[k] = reg[k];
}

void merge_sort(int arr[], const int len) {
    int reg[len];
    merge_sort_recursive(arr, reg, 0, len - 1);
}

void Merge(vector<int> &Array, int front, int mid, int end) {
    // preconditions:
    // Array[front...mid] is sorted
    // Array[mid+1 ... end] is sorted
    // Copy Array[front ... mid] to LeftSubArray
    // Copy Array[mid+1 ... end] to RightSubArray
    vector<int> LeftSubArray(Array.begin() + front, Array.begin() + mid + 1);
    vector<int> RightSubArray(Array.begin() + mid + 1, Array.begin() + end + 1);
    int idxLeft = 0, idxRight = 0;
    LeftSubArray.insert(LeftSubArray.end(), numeric_limits<int>::max());
    RightSubArray.insert(RightSubArray.end(), numeric_limits<int>::max());
    // Pick min of LeftSubArray[idxLeft] and RightSubArray[idxRight], and put into Array[i]
    for (int i = front; i <= end; i++) {
        if (LeftSubArray[idxLeft] < RightSubArray[idxRight]) {
            Array[i] = LeftSubArray[idxLeft];
            idxLeft++;
        } else {
            Array[i] = RightSubArray[idxRight];
            idxRight++;
        }
    }
}

void MergeSort(vector<int> &Array, int front, int end) {
    if (front >= end)
        return;
    int mid = (front + end) / 2;
    MergeSort(Array, front, mid);
    MergeSort(Array, mid + 1, end);
    Merge(Array, front, mid, end);
}

public static List<int> sort(List<int> lst) {
    if (lst.Count <= 1)
        return lst;
    int mid = lst.Count / 2;
    List<int> left = new List<int>();  // Define the left list
    List<int> right = new List<int>(); // Define the right list
    // The following two loops divide lst into left and right lists
    for (int i = 0; i < mid; i++)
        left.Add(lst[i]);
    for (int j = mid; j < lst.Count; j++)
        right.Add(lst[j]);
    left = sort(left);
    right = sort(right);
    return merge(left, right);
}
/// <summary>
/// Merge two already sorted lists
/// </summary>
/// <param name="left">Left List</param>
/// <param name="right">Right List</param>
/// <returns></returns>
static List<int> merge(List<int> left, List<int> right) {
    List<int> temp = new List<int>();
    while (left.Count > 0 && right.Count > 0) {
        if (left[0] <= right[0]) {
            temp.Add(left[0]);
            left.RemoveAt(0);
        } else {
            temp.Add(right[0]);
            right.RemoveAt(0);
        }
    }
    if (left.Count > 0) {
        for (int i = 0; i < left.Count; i++)
            temp.Add(left[i]);
    }
    if (right.Count > 0) {
        for (int i = 0; i < right.Count; i++)
            temp.Add(right[i]);
    }
    return temp;
}
