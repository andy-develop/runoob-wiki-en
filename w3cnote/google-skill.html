How to use Google and other search engines well

Category Internet

It is probably blocked by the firewall, and we have also provided everyone withGoogle global IP address database, you can directly access Google via the above IP. Today, Rookie Notes introduces everyone to a complete guide to commands for Google and other search engines such as Baidu.

Complete guide to search engine commands!

1. Double quotes

Putting the search terms in double quotes represents an exact match search. That is, the pages returned by the search results contain all the words in the double quotes, and the order must also match exactly.

Both Baidu and Google support this command. For example, search: "菜鸟教程".

2. Minus sign

The minus sign means to search for pages that do not contain the word after the minus sign. When using this command, there must be a space before the minus sign, and no space after the minus sign; the word to be excluded immediately follows.

Both Google and Baidu support this command.

For example: search - engine.

The returned results contain the word "搜索" but not the word "引擎".

3. Asterisk

The asterisk * is a commonly used wildcard and can also be used in searches. Baidu does not support the * search command.

For example, in Google search: 搜索*擎. The * here represents any text.

The returned results not only include "搜索引擎", but also "搜索收擎", "搜索巨擎", and so on.

4、inurl

The inurl: command is used to search for pages where the query term appears in the URL.

Both Baidu and Google support the inurl command. The inurl command supports both Chinese and English.

For example, search: inurl:搜索引擎优化 The returned results are all pages whose URL contains "搜索引擎优化". Since keywords appearing in the URL have a certain impact on ranking, using inurl: can find competitors more accurately.

5、inanchor

The inanchor: command returns pages whose inbound link anchor text contains the search term. Baidu does not support inanchor.

For example, search in Google: inanchor:点击这里 The returned result pages themselves do not necessarily contain the four characters "点击这里", but the anchor text of links pointing to these pages contains "点击这里".

It can be used to find competitors for a keyword, and these competitors are often those who have done SEO. By studying what external links competitor pages have, you can find many link resources.

6、intitle

The intitle: command returns pages whose page title contains the keyword. Both Google and Baidu support the intitle command.

Pages found with the intitle command are more accurate competitor pages. If the keyword only appears in the visible text of the page but not in the title, in most cases the page has not been optimized for the keyword, so it is not a strong competitor.

7、allintitle

allintitle: search returns pages whose page titles contain multiple sets of keywords.

For example: allintitle:SEO 搜索引擎优化, is equivalent to: intitle:SEO intitle:搜索引擎优化, returning pages whose titles contain both "SEO" and "搜索引擎优化".

8、allinurl

Similar to allintitle:.

allinurl:SEO 搜索引擎优化, is equivalent to: inurl:SEO inurl:搜索引擎优化

9、filetype

Used for searching specific file formats. Both Google and Baidu support the filetype command.

For example, search filetype:pdf SEO, and the results will be all PDF files containing the keyword SEO.

10、site

site: is the most familiar advanced search command for SEO, used to search all files under a certain domain.

11、linkdomain

The linkdomain: command only applies to Yahoo, and returns the backlinks of a certain domain. Yahoo's backlink data is still relatively accurate, and it is one of the important tools for SEO professionals to study competitors' external link situations.

For example, search: linkdomain:http://cnseotool.com -site:http://cnseotool.com, What you get is the external links of the Dianshi website, because -site:http://cnseotool.com has excluded Dianshi's own pages, i.e., internal links, leaving only external links.

12、related

The related: command only applies to Google, and returns pages related to a certain website. For example, search related:http://cnseotool.com

We can then get other pages that Google considers related to the Dianshi website. What exactly this relationship means, Google has not explicitly stated; it is generally believed to refer to websites that share common external links.

The several advanced search commands introduced above can find many resources when used alone, or can locate competitors more precisely. Mixing these commands together makes them even more powerful.

Google search examples

inurl:gov 减肥

What is returned are pages whose URL contains gov and whose page contains the word "减肥". Many SEO professionals believe that government (gov) and school websites have higher authority; finding relevant government and school websites means finding the best link resources.

inurl:.edu.cn intitle:link exchange link exchange

The above command returns pages from CERNET (China Education and Research Network) (edu.cn), i.e., on school domains, that contain the word "交换链接".

From this, SEO professionals can find school websites willing to exchange links.

Or use a more precise search:

inurl:.edu.cn intitle:交换链接

What is returned are pages from the China Education and Research Network (CERNET) domain whose titles contain the four characters "交换链接". Most of the returned results should be school websites willing to exchange links.

Another example is the following command:

inurl:.edu.cn*register

The returned results are pages on the China Education and Research Network (CERNET) domain whose URL contains the two words "forum" and "register", i.e., registration pages of school forums. Finding these forums also gives you many opportunities to leave signatures on high-authority domains.

The following command returns pages related to weight loss and whose URL contains the word "links":

减肥 inurl:links

Many webmasters name their link exchange pages links.html, etc. So this command returns link exchange pages related to the weight loss topic.

The following command returns pages whose URL contains http://gov.cn and links, i.e., link exchange pages on government (gov) domains:

allinurl:gov.cn+links

The last example: search this command on Yahoo:

linkdomain:http://cnseotool.com -linkdomain:http://cnseotool.com

What is returned are websites that link to the Dianshi website but not to my blog. Using this command, you can find many pages that link to your competitors or other websites in the same industry but not to your website. These websites are the best link resources.

Advanced search commands can be combined in many varied and powerful ways. A qualified SEO must be proficient in the meanings and combination methods of these common commands in order to find more competitors and link resources more efficiently.

When looking for external links, you can use these command combinations, for example site:.com inurl:blog "post a comment" -"comments closed" -"you must be logged in" "输入你的关键词"

site:.com means to only show .com websites. If you want .org links, change it to site:.org; inurl:blog means blogs. "post a comment" -"comments closed" -"you must be logged in" means: "those that allow commenting" minus "those with comments closed" minus "those that require login to comment".
