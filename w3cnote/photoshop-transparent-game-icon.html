PS beginner tutorial, teaching you to draw transparent textured buttons

Category Miscellaneous

Making a button is not difficult. First establish the specific shape, then use layer styles to add effects, and finally strengthen the texture by giving some highlights to the bottom and top, then add text and it is done. Next, let's learn this button tutorial together!

1. Analyze Layers

Even complex graphic effects are built up layer by layer. To recreate the effect, you must analyze the composition of each layer. Only then can you create better design works. First, we break down the entire button and observe that it consists of four parts. The "bottom layer" is completed with a single layer, not multiple layers stacked together. The other three layers are relatively simple. Next, we'll create them layer by layer.

2. Create Background

Create a new RGB canvas of 600px*600px at 72 dpi. Then use the gradient tool (G) to make a radial gradient layer with the color values as follows. After that, fill a texture layer on top and appropriately reduce the opacity to increase the background texture.

3. Create the "Bottom Layer" of the Button

Create a new layer named "Bottom Layer". Use the rounded rectangle tool to draw a rounded rectangle on the canvas. Feel free to experiment with the corner radius to achieve the effect you want. If you are using the CC version, it is very convenient because you can adjust it in the live shape properties. Then double-click to open the layer style and make the following settings (values are for reference only).

4. Create the "Reflection" of the Button

The "reflection" can give the button a further textured effect. Create a new layer, use the ellipse tool (U) to draw an elliptical selection below the button, then feather it appropriately and fill with white. Finally, change the layer mode to "Overlay" and appropriately reduce the opacity.

5. Add Texture to the Button

Adding texture to the button makes it more beautiful and gives it more texture. The method is simple: create a new layer above the button layer and name it "Texture" (remember to name your layers, otherwise it will be messy!). Then hold the Ctrl key and click the button layer to bring up its selection. Fill the pattern on the texture layer. Finally, change the layer mode to Soft Light and appropriately reduce the opacity.

6. Add Highlights to the Button

Highlights on four sides: Use the pen tool to outline white lines along the edge of the button. Be sure to check "Simulate Pressure" so that both ends appear thin, then appropriately reduce the opacity. Semicircular highlight: First create an elliptical selection, then subtract the selection outside the button shape. What remains is the effect shown in the figure.

7. Add Text Effects

Now the entire button is complete, but it still lacks the iconic text.

Here I want to make it a "Start Game" button, so I added the text "START". To make it blend into the entire button, I also added inner shadow, color overlay, and drop shadow. The method is relatively simple, so I won't demonstrate it here.

Tutorial Summary

  1. It is recommended that you collect more texture patterns, as they can bring very nice effects to your graphics.
  2. As for layer styles, there is nothing to say—just practice more.
  3. Ctrl+Shift+Alt is the shortcut for intersecting with a selection. For details, you can search on Baidu yourself.
  4. Pay attention to fine pixels; they will add brilliance to your work.
