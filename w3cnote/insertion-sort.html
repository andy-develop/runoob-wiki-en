1.3 Insertion Sort

Category Algorithm

Insertion Sort is a simple and intuitive sorting algorithm. Its working principle is similar to arranging playing cards.

Insertion Sort works by building an ordered sequence. For unsorted data, it scans from back to front in the sorted sequence, finds the corresponding position, and inserts it.

Although the code implementation of Insertion Sort is not as simple and crude as Bubble Sort and Selection Sort, its principle should be the easiest to understand, because anyone who has played cards should be able to understand it instantly.

Like Bubble Sort, Insertion Sort also has an optimized algorithm, called Binary Insertion.

1. Algorithm Steps

  1. Initialization: Divide the list into a sorted part and an unsorted part. Initially, the sorted part contains only the first element, and the unsorted part contains the remaining elements.

  2. Select Element: Take the first element from the unsorted part.

  3. Insert into the Sorted Part: Compare this element with the elements in the sorted part one by one from back to front, and find the appropriate position to insert.

  4. Repeat Steps: Repeat the above steps until the unsorted part is empty and the list is completely sorted.

2. Animated Demo

Suppose there is a list to be sorted, [5, 2, 4, 6, 1, 3]. The process of Insertion Sort is as follows:

  1. Initial State：

    • Sorted part:[5]。

    • Unsorted part:[2, 4, 6, 1, 3]。

  2. First Round：

    • Take the first element of the unsorted part2。

    • will2compare it with the sorted part's5;2 < 5insert it before5.

    • The list becomes[2, 5, 4, 6, 1, 3]。

    • Sorted part:[2, 5], unsorted part:[4, 6, 1, 3]。

  3. Second Round：

    • Take the first element of the unsorted part4。

    • will4compare it with the sorted part's5;4 < 5continue comparing with2;4 > 2insert it between2and5.

    • The list becomes[2, 4, 5, 6, 1, 3]。

    • Sorted part:[2, 4, 5], unsorted part:[6, 1, 3]。

  4. Third Round：

    • Take the first element of the unsorted part6。

    • will6compare it with the sorted part's5;6 > 5, insert it directly at the end.

    • The list becomes[2, 4, 5, 6, 1, 3]。

    • Sorted part:[2, 4, 5, 6], unsorted part:[1, 3]。

  5. Fourth Round：

    • Take the first element of the unsorted part1。

    • will1compare it with the sorted part's6;1 < 6continue comparing with5、4、2;1it is the smallest, insert it at the very front.

    • The list becomes[1, 2, 4, 5, 6, 3]。

    • Sorted part:[1, 2, 4, 5, 6], unsorted part:[3]。

  6. Fifth Round：

    • Take the first element of the unsorted part3。

    • will3compare it with the sorted part's6;3 < 6continue comparing with5、4、2;3 > 2insert it between2and4.

    • The list becomes[1, 2, 3, 4, 5, 6]。

    • Sorted part:[1, 2, 3, 4, 5, 6], and the unsorted part is empty.

Example

def insertion_sort(arr):
    n = len(arr)
    for i in range(1, n):
        key = arr[i]  # Take the first element of the unsorted part
        j = i - 1
        # Insert key into the correct position in the sorted part
        while j >= 0 and key < arr[j]:
            arr[j + 1] = arr[j]  # Move elements backward
            j -= 1
        arr[j + 1] = key  # Insert key
    return arr

# Example
arr = [5, 2, 4, 6, 1, 3]
sorted_arr = insertion_sort(arr)
print(sorted_arr)  # Output: [1, 2, 3, 4, 5, 6]

Time Complexity

  • Worst Case: O(n²). When the list is in reverse order, each insertion requires moving all sorted elements.

  • Best Case: O(n). When the list is already sorted, it only needs to traverse the list once.

  • Average Case：O(n²)。

Space Complexity

  • O(1). Insertion Sort is an in-place sorting algorithm and does not require additional storage space.

Advantages and Disadvantages

  • Advantages：

    • Simple to implement, and the code is easy to understand.

    • High efficiency for small-scale data or nearly sorted data.

    • In-place sorting, no additional storage space required.

    • Stable sorting algorithm (the relative order of equal elements will not change).

  • Disadvantages：

    • High time complexity, not suitable for large-scale datasets.

Applicable Scenarios

  • Scenarios where the data volume is small or the data is nearly sorted.

  • Scenarios requiring a stable sorting algorithm.

  • Used as an auxiliary algorithm for more complex sorting algorithms (such as Quick Sort and Merge Sort).

Code Implementation

JavaScript

Example

function insertionSort(arr) {
    var len = arr.length;
    var preIndex, current;
    for (var i = 1; i < len; i++) {
        preIndex = i - 1;
        current = arr[i];
        while(preIndex >= 0 && arr[preIndex] > current) {
            arr[preIndex+1] = arr[preIndex];
            preIndex--;
        }
        arr[preIndex+1] = current;
    }
    return arr;
}

Java

Example

public class InsertSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // Copy arr without modifying the parameter content
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        // Start from the element at index 1 to select the appropriate position for insertion, because there is only one element at index 0, which is sorted by default
        for (int i = 1; i < arr.length; i++) {

            // Record the data to be inserted
            int tmp = arr[i];

            // Start comparing from the rightmost of the sorted sequence to find a number smaller than it
            int j = i;
            while (j > 0 && tmp < arr[j - 1]) {
                arr[j] = arr[j - 1];
                j--;
            }

            // If a smaller number exists, insert
            if (j != i) {
                arr[j] = tmp;
            }

        }
        return arr;
    }
}

public static void InsertSort(int[] array)
{
    for(int i = 1;i < array.length;i++)
    {
        int temp = array[i];
        for(int j = i - 1;j >= 0;j--)
        {
            if(array[j] > temp)
            {
                array[j + 1] = array[j];
                array[j] = temp;
            }
            else
                break;
        }
    }
}
