Recommended search resource websites

Categories Programming Technology

In the process of learning technology, we often need to use search engines to retrieve information. The one commonly used domestically is Baidu.

Of course, if conditions permit, Google is still the first recommended search engine. If you cannot use it, you can use the following as backups:

Bing

Bing International:https://cn.bing.com/

It is better than Baidu. It was even suspended for a few days before, but it has been available recently.

DuckDuckGo

DuckDuckGo：https://duckduckgo.com/

According to the introduction on the official website, this search engine does not collect user information and has no ads.

Stack Overflow

Stack Overflow：https://stackoverflow.com/

If we often use Google, many answers to technical questions are on this website. If you cannot use Google, you can simply search directly on this website.

Gitlogs

Gitlogs：https://www.gitlogs.com/

Gitlogs is a search engine specifically for GitHub projects. Through it, we can quickly find the projects we want.

jiumo search

Document search engine jiumo search (Jiumo Book Search):https://www.jiumodiary.com/。

It can be used to find technical documentation manuals, many of which are on Baidu Netdisk.

Ebooke

Ebooke：https://ebookee.org/

Ebookee is an internet-based search engine website that provides free e-book downloads.

Iconfinder

Icon search:https://www.iconfinder.com/

Used to find logo images.

TinEye

TinEye：https://www.tineye.com

Use images to search for images. We can upload an image or enter the URL of an image to search.

SemanticScholar

SemanticScholar：https://www.semanticscholar.org/

SemanticScholar is a free academic search engine; its search results come from journals, academic conference materials, or documents from academic institutions.

LibreStock

LibreStock：https://librestock.com/

On LibreStock, you can search for some high-quality HD images.

CC Search

CC Search：https://ccsearch.creativecommons.org/

The image resources found on CC Search are all copyright-free, and we can use them for free.

The App Store

The App Store：https://theappstore.org/

The App Store is an application search tool for iPhone, iPad, and Mac devices.
