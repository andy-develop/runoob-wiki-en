Website Tip Button Creation

Category Programming Technology

This article introduces how to add a tip button to your website, supporting Alipay and WeChat.

The following functional code is implemented based on jQuery.

Remember to change the payment QR codes in the code to your own.

Complete HTML download:dashang.html.zip

HTML Code

<div class="content"> <p><a href="javascript:void(0)" onclick="dashangToggle()" class="dashang" title="Tip, show your support">Tip</a></p> <div class="hide_box"></div> <div class="shang_box"> <a class="shang_close" href="javascript:void(0)" onclick="dashangToggle()" title="Close"><img src="https://static.jyshare.com/images/dashang/close.jpg" alt="Cancel" /></a> <div class="shang_tit"> <p>Thank you for your support, I will continue to work hard!</p> </div> <div class="shang_payimg"> <img src="https://static.jyshare.com/images/dashang/alipayimg.png" alt="Scan to support" title="Scan" /> </div> <div class="pay_explain">Scan to tip, the amount is up to you</div> <div class="shang_payselect"> <div class="pay_item checked" data-id="alipay"> <span class="radiobox"></span> <span class="pay_logo"><img src="https://static.jyshare.com/images/dashang/alipay.jpg" alt="Alipay" /></span> </div> <div class="pay_item" data-id="weipay"> <span class="radiobox"></span> <span class="pay_logo"><img src="https://static.jyshare.com/images/dashang/wechat.jpg" alt="WeChat" /></span> </div> </div> <div class="shang_info"> <p>Open<span id="shang_pay_txt">Alipay</span>Scan the QR code to make a tip</p> <p>Powered by <a href="http://www.runoob.com" target="_blank" title="Runoob" rel="noopener">RUNOOB.COM</a>, what you learn is not only technology, but also dreams!!!</p> </div> </div> </div>

JavaScript Code

$(function(){ $(".pay_item").click(function(){ $(this).addClass('checked').siblings('.pay_item').removeClass('checked'); var dataid=$(this).attr('data-id'); $(".shang_payimg img").attr("src","https://static.jyshare.com/images/dashang/"+dataid+"img.png"); $("#shang_pay_txt").text(dataid=="alipay"?"Alipay":"WeChat"); }); }); function dashangToggle(){ $(".hide_box").fadeToggle(); $(".shang_box").fadeToggle(); }
