Dart Operators

Operators are symbols that perform calculations, comparisons, and logical judgments in programs.

This chapter systematically introduces various operators in Dart, including arithmetic, relational, logical, assignment, conditional operators, and type checking.

算术运算符

Arithmetic operators are used to perform basic mathematical operations.

实例

void main() {
  int a = 10;
  int b = 3;

  print('a = $a, b = $b');
  print('加法 a + b = ${a + b}');    // 13
  print('减法 a - b = ${a - b}');    // 7
  print('乘法 a * b = ${a * b}');    // 30
  print('除法 a / b = ${a / b}');    // 3.333... (结果是 double)
  print('整除 a ~/ b = ${a ~/ b}');  // 3 (取整，舍去小数)
  print('取余 a % b = ${a % b}');    // 1 (取模运算)
  print('取反 -a = ${-a}');          // -10 (一元负号)
}
a = 10, b = 3
加法 a + b = 13
减法 a - b = 7
乘法 a * b = 30
除法 a / b = 3.3333333333333335
整除 a ~/ b = 3
取余 a % b = 1
取反 -a = -10

Note: The / operator always returns a double type, even when both operands are int and evenly divisible. If you only need an integer result, use the ~/ integer division operator.

Increment and Decrement Operators

Like most C-family languages, Dart supports ++ (increment) and -- (decrement).

实例

void main() {
  int count = 0;

  // 前置 ++：先自增，再使用
  print('前置 ++: ${++count}');  // 1

  // 后置 ++：先使用，再自增
  print('后置 ++: ${count++}');  // 1（此时 count 还是 1）
  print('现在 count = $count');   // 2

  // 自减同理
  print('前置 --: ${--count}');  // 1
  print('后置 --: ${count--}');  // 1
  print('现在 count = $count');   // 0
}
前置 ++: 1
后置 ++: 1
现在 count = 2
前置 --: 1
后置 --: 1
现在 count = 0

Prefix and postfix increment/decrement have the same effect when used alone, but behave differently within expressions. Beginners are advised to avoid using them in expressions as much as possible; writing them on a separate line is clearer.

关系运算符

Relational operators are used to compare two values, and the result is a bool value.

运算符含义示例结果
==等于5 == 5true
!=不等于5 != 3true
>大于5 > 3true
<小于5 < 3false
>=大于等于5 >= 5true
<=小于等于3 <= 5true

实例

void main() {
  int runoobScore = 95;
  int passLine = 60;

  print('分数: $runoobScore, 及格线: $passLine');
  print('及格了吗? ${runoobScore >= passLine}');
  print('满分了吗? ${runoobScore == 100}');

  // 字符串也可以比较
  String a = 'apple';
  String b = 'banana';
  print("'$a' == '$b'? ${a == b}");

  // == 判断的是值是否相等
  String c = 'RUNOOB';
  String d = 'RUNOOB';
  print("'$c' == '$d'? ${c == d}");  // true（内容相同）
}
分数: 95, 及格线: 60
及格了吗? true
满分了吗? false
'apple' == 'banana'? false
'RUNOOB' == 'RUNOOB'? true

In Dart, == compares whether the values of two objects are equal, not their reference addresses. This differs from Java—in Dart, you don't need to use the equals() method to compare strings.

逻辑运算符

Logical operators are used to combine multiple bool expressions, usually for conditional judgments.

运算符含义说明
&&逻辑与Returns true only if both sides are true.
||逻辑或Returns true if either side is true.
!逻辑非取反，true 变 false，false 变 true

实例

void main() {
  bool isLoggedIn = true;
  bool isAdmin = false;

  // && 与：两者都为 true
  print('登录且是管理员: ${isLoggedIn && isAdmin}');  // false

  // || 或：至少一个为 true
  print('登录或是管理员: ${isLoggedIn || isAdmin}');  // true

  // ! 非：取反
  print('未登录: ${!isLoggedIn}');  // false

  // 短路求值：如果左边已经能确定结果，右边不会执行
  int age = 20;
  // age > 18 已经是 true，但还需要看右边
  print('成年且有权限: ${age >= 18 && isAdmin}');

  // age < 18 已经是 false，&& 右边直接跳过
  print('未成年且有权限: ${age < 18 && isAdmin}');
}
登录且是管理员: false
登录或是管理员: true
未登录: false
成年且有权限: false
未成年且有权限: false

Dart 使用短路求值（Short-circuit Evaluation）For &&, if the left side is false, the right side is not evaluated; for ||, if the left side is true, the right side is not evaluated.

This feature can be used to avoid null pointer issues.

实例

Practical applications of short-circuit evaluation:

void main() {
  String? username;

  // 安全判断：username 不为 null 且长度大于 3
  // 如果 username 为 null，&& 右边不会执行，避免了空指针错误
  if (username != null && username.length > 3) {
    print('有效用户名');
  } else {
    print('用户名无效或太短');
  }
}
Username is invalid or too short.

赋值运算符

You are already familiar with the basic assignment operator =.

Dart also provides compound assignment operators to simplify common "compute then assign" operations.

运算符等价写法Example (when a=10)
+=a = a + ba += 3 → 13
-=a = a - ba -= 3 → 7
*=a = a * ba *= 3 → 30
/=a = a / ba /= 2 → 5.0
~/=a = a ~/ ba ~/= 3 → 3
%=a = a % ba %= 3 → 1

实例

void main() {
  int score = 0;

  // 每次答对加 10 分
  score += 10;
  print('答对第1题: $score');

  score += 10;
  print('答对第2题: $score');

  // 答错扣 5 分
  score -= 5;
  print('答错1题: $score');

  // 得分翻倍
  score *= 2;
  print('奖励翻倍: $score');

  print('RUNOOB 最终得分: $score');
}
答对第1题: 10
答对第2题: 20
答错1题: 15
奖励翻倍: 30
RUNOOB 最终得分: 30

Conditional operators: ?? and ??=

These two operators are specifically designed for handling null values and are an important part of Dart's null safety system.

?? null coalescing operator

If the left expression is not null, return its value; otherwise, return the right value.

??= null-aware assignment operator

If the variable is currently null, assign it the value on the right; otherwise, leave it unchanged.

实例

void main() {
  // ?? 空值合并
  String? nickname;
  String displayName = nickname ?? 'RUNOOB 用户';
  print(displayName);  // RUNOOB 用户

  nickname = '小R';
  displayName = nickname ?? 'RUNOOB 用户';
  print(displayName);  // 小R

  // 链式 ?? 也可以
  String? a;
  String? b;
  String result = a ?? b ?? '默认值';
  print(result);  // 默认值

  // ??= 空值赋值
  int? count;
  count ??= 0;  // count 为 null，赋值为 0
  print(count);  // 0

  count ??= 100;  // count 已经是 0（非 null），不赋值
  print(count);  // 0（不变）
}
RUNOOB 用户
小R
默认值
0
0

Ternary conditional operator ? :

This is Dart's only three-operand operator, a concise version of if-else.

实例

void main() {
  int score = 75;

  // 语法：条件 ? 为真时的值 : 为假时的值
  String result = score >= 60 ? '及格' : '不及格';
  print('RUNOOB 考试结果: $result');

  // 可以嵌套使用（但不建议超过两层，可读性会变差）
  String grade = score >= 90 ? '优秀' : score >= 60 ? '及格' : '不及格';
  print('评级: $grade');
}
RUNOOB 考试结果: 及格
评级: 及格

Type checking operators: is and as

is is used to check whether an object belongs to a type, as is used for type casting.

实例

void main() {
  // is：类型检查
  var name = 'RUNOOB';
  print('name 是 String 吗? ${name is String}');   // true
  print('name 是 int 吗? ${name is int}');         // false

  // is!：不是某类型
  print('name 不是 int 吗? ${name is! int}');      // true

  // as：类型转换
  Object obj = 'Hello, Dart!';
  // 将 Object 类型转换为 String，以便使用 String 的方法
  String str = obj as String;
  print(str.toUpperCase());

  // 安全的类型判断 + 转换
  Object maybeString = 42;
  if (maybeString is String) {
    // 在 is 判断为 true 的分支中，变量自动"提升"为该类型
    print(maybeString.length);  // 不需要 as 转换
  } else {
    print('不是字符串，值是: $maybeString');
  }
}
name 是 String 吗? true
name 是 int 吗? false
name 不是 int 吗? true
HELLO, DART!
不是字符串，值是: 42

Prefer using is for type checking. In a condition branch where is evaluates to true, Dart automatically promotes the variable to the target type (Type Promotion), so there is no need to use as for casting. Use as only when you are certain of the type but the compiler cannot infer it.

Operator precedence overview

When an expression contains multiple operators, Dart evaluates them in order of precedence from highest to lowest.

If you are unsure about precedence, the safest practice is to使用括号明确计算顺序。

优先级运算符说明
最高() [] . ?.Parentheses, subscripts, member access
! ~ - ++ --一元运算符
* / % ~/乘除取余
+ -加减
< <= > >=关系比较
== !=相等判断
&&逻辑与
||逻辑或
??空值合并
? :三元条件
= += -= *= 等Assignment (lowest precedence)

实例

void main() {
  // 不依赖优先级——用括号明确表达意图
  int result = ((10 + 5) * 2) - (8 ~/ 3);
  print('计算结果: $result');  // 28

  // 如果不加括号，结果可能完全不同
  // 10 + 5 * 2 - 8 ~/ 3 的结果会是 18（先乘除后加减）
  int result2 = 10 + 5 * 2 - 8 ~/ 3;
  print('不加括号: $result2');  // 18
}
计算结果: 28
不加括号: 18
