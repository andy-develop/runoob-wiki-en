The first Dart program

Learning a programming language—the best way is not to memorize grammar rules first, but to get a program running, and then ask line by line what it means.

In this chapter, we will start from the simplest program and gradually expand it into a slightly more complete small program, going through the most basic concepts of Dart along the way.

Dart language standard file suffix.dart，比如hello.dart。

The simplest program: Hello, Dart!

打开 DartPadhttps://dartpad.dev(or create a hello.dart file in a local editor), enter the following code:

实例

void main() {
  print('Hello, Dart!');
}

Click run, output:

Hello, Dart!

Command to run in local environment:

dart hello.dart

Just these 3 lines of code. Now let's understand every character.

逐行解析

void main() {

This is the entry function declaration of the program. Dart programs always start executing from main().

拆开来看：

部分含义
voidReturn type. void means "this function returns nothing after execution."
mainFunction name. This is the Dart-conventional entry function name; it cannot be changed to anything else.
()Parameter list. It is empty here, meaning the main function accepts no parameters.
{The beginning of the function body. It pairs with the } on the last line and wraps all the code of the function.

main() is the only entry point of Dart. No matter how many files or classes your program has, execution always starts from the first line of main().

print('Hello, Dart!');

This is a statement that outputs the content inside the parentheses to the console.

拆开来看：

部分含义
printBuilt-in function name, used to output a line of text to the console.
(...)Parameter list of a function call
'Hello, Dart!'A string literal, enclosed in single quotes '.
;Statement terminator. Every statement must end with a semicolon.
The leading two spacesIndentation, indicating that this line of code belongs inside the main() function. Dart convention uses 2 spaces for indentation.

}

The closing marker of the main() function body, paired with the opening {.

整体结构图

void main() {          ← 函数签名（返回类型 + 函数名 + 参数）
  print('Hello,        ← 函数体：调用 print 函数
         Dart!');      ← 传入字符串参数，以 ; 结尾
}                      ← 函数体结束

Two ways to write strings

In Dart, strings can be wrapped in either single quotes or double quotes; they are completely equivalent.

实例

void main() {
  print('Hello, Dart!');   // 单引号
  print("Hello, Dart!");   // 双引号，效果相同
}
Hello, Dart!
Hello, Dart!

When should you use which type of quote? You can refer to the following scenarios:

场景推荐示例
一般情况Single quotes (Dart community convention)'Hello'
String contains single quotes双引号"It's a beautiful day!"
String contains double quotes单引号'He said: "Hello"'

When the string content itself contains single quotes, wrapping it in double quotes is more convenient and avoids escaping. The Dart community convention prefers single quotes, and this tutorial will mainly use single quotes going forward.

注释

Comments are explanatory text written for humans; the Dart compiler completely ignores them.

实例

void main() {
  // 这是单行注释，从 // 开始到行尾
  print('Hello, Dart!'); // 也可以写在语句后面

  /*
这是多行注释。
可以跨越多行，
常用于临时注释掉一大段代码。
  */

  /// 这是文档注释，用于描述函数、类或变量的作用。
  /// IDE 会将文档注释显示为悬浮提示。
}
注释类型语法用途
单行注释// 内容Explain a line of code
多行注释/* 内容 */Comment out a block of code, or write a longer explanation
文档注释/// 内容For describing APIs and generating documentation

Good comments explain "why," not "what was done." The code itself already shows "what was done"; comments should supplement the reason or intent behind it.

Variables: naming data

A program cannot only output fixed text; we need variables to store and use data.

实例

void main() {
  String name = 'RUNOOB';
  int age = 25;
  double height = 1.68;
  bool isStudent = true;

  print(name);
  print(age);
  print(height);
  print(isStudent);
}
RUNOOB
25
1.68
true

Variable declaration format

类型名  变量名  =  初始值  ;
 │       │         │    └─ 语句结束符
 │       │         └─ 赋值运算符
 │       └─ 你给这个数据起的名字
 └─ 告诉 Dart 这个变量存储什么类型的数据

Quick overview of basic data types

类型说明示例
String文本字符串'RUNOOB'、"hello"
int整数25、-10、0
doubleDecimals (floating-point numbers)1.68、3.14
bool布尔值（真/假）true、false

The details of data types will be covered in later chapters; here we just get a preliminary impression.

Use var to automatically infer the type

It's a bit tedious to write the type name every time.

Dart supports using the var keyword to automatically infer the variable type—the compiler determines the type based on the value you assign.

实例

void main() {
  var name = 'RUNOOB';    // 推断为 String
  var age = 25;           // 推断为 int
  var height = 1.68;      // 推断为 double
  var isStudent = true;   // 推断为 bool

  print(name);
  print(age);
}
RUNOOB
25

The type inferred by var is determined at compile time; after that, you cannot assign a value of a different type to it.

实例

void main() {
  var name = 'RUNOOB';
  name = 'Bob';    // 可以，仍然是 String
  // name = 123;   // 错误：不能把 int 赋给 String 类型的变量
}

When should you use var, and when should you explicitly write the type?

场景推荐原因
Local variables, the type is obvious at a glancevar更简洁
Function parameters, class fields, and return types.写明类型Code is clearer and self-documenting

String interpolation: embedding variables into strings

If you want to embed a variable's value into a string, Dart provides very concise string interpolation syntax—use $variableName or ${expression}.

实例

void main() {
  var name = 'RUNOOB';
  var age = 25;

  print('我叫 $name，今年 $age 岁。');
  print('明年我将 ${age + 1} 岁。');
}
我叫 RUNOOB，今年 25 岁。
明年我将 26 岁。
语法用途示例
$变量名Directly embed variable values, concise$name
${expression}Embed any expression (calculation, method call, etc.).${age + 1}、${name.toUpperCase()}

Compared to string concatenation like print('我叫 ' + name + '，今年 ' + age.toString() + ' 岁。'), interpolation syntax is clearer, safer, and the idiomatic style in Dart.

A slightly more complete small program

Now let's combine what we've learned earlier and write a slightly more realistic program: a simple self-introduction generator.

  var city = '上海';

  var hobby = 'Dart 编程';

  var occupation = isStudent ? '学生' : '职场人';

  print('       个人简介');
  print('=============================');
  print('姓名：$name');

  print('城市：$city');

  print('今年 $age 岁，是一名$occupation。');
  print('我的爱好是${hobby}，很高兴认识大家！');
  print('=============================');
}

New syntax: ternary operator

实例

var occupation = isStudent ? '学生' : '职场人';

This is Dart's ternary operator, formatted as:

condition ? value when the condition is true : value when the condition is false

Equivalent to the following if/else form:

实例

String occupation;
if (isStudent) {
  occupation = '学生';
} else {
  occupation = '职场人';
}

The ternary operator is very concise when a value has only two possibilities. Later chapters will introduce the full usage of if/else in detail.

Code style: Dart writing conventions.

Good code style makes code more readable and professional.

Dart has an official recommended style guide; at the beginner stage, mastering the following points is enough.

Use 2 spaces for indentation

实例

// 正确：2 个空格
void main() {
  print('Hello');
}

// 不推荐：4 个空格（其他语言常见，但 Dart 社区偏好 2 格）

Variable and function names use lowerCamelCase (lowerCamelCase).

实例

var firstName = 'RUNOOB';     // 小驼峰：正确
// var first_name = 'RUNOOB'; // 下划线风格：非 Dart 惯例
// var FirstName = 'RUNOOB';  // 大驼峰：保留给类名

Class names use UpperCamelCase.

实例

class UserProfile { }   // 正确
// class user_profile { }  // 错误
// class userProfile { }   // 错误

Constants use lower camel case (not all uppercase)

实例

const maxRetries = 3;       // Dart 惯例：正确
// const MAX_RETRIES = 3;   // 这是 C/Java 风格，Dart 不推荐

Use dart format to automatically format.

You don't have to memorize the rules; just run in the project directory:

$ dart format .

Dart's official formatting tool automatically adjusts code to the standard style; in VS Code, you can also configure automatic formatting on save.

Common errors and explanations

Beginners often encounter the following errors when writing their first program; let's get familiar with them.

Error 1: Forgetting the semicolon

实例

void main() {
  print('Hello, Dart!')  // 缺少 ;
}

报错信息：

Error: Expected ';' after this.

Solution: add ; at the end of the statement.

Error 2: Mismatched parentheses

实例

void main() {
  print('Hello, Dart!'   // 缺少右括号 )
}

报错信息：

Error: Expected ')' before this.

Solution: carefully check that every ( has a corresponding ). VS Code will highlight mismatched brackets.

Error 3: Mismatched string quotes

void main() {
  print('Hello, Dart!");  // 一个单引号、一个双引号
}

报错信息：

Error: Unterminated string literal.

Solution: make sure both ends of the string use the same type of quote.

Error 4: main misspelled

实例

void Main() {  // M 大写了
  print('Hello, Dart!');
}

Dart is case-sensitive; Main and main are completely different names.

The program compiles, but it will report an error at runtime:

Error: No 'main' method found.

Solution: the entry function must be lowercase main.

Error 5: Variable used before being assigned

实例

void main() {
  String name;
  print(name);  // name 未初始化
}

Dart null-safety error:

Error: Non-nullable variable 'name' must be assigned before it can be used.

Solution: assign an initial value when declaring the variable, or declare it as a nullable type String? name (detailed in later chapters).
