Dart 简介

Dart is a modern programming language developed by Google, designed for building high-performance, cross-platform applications.

This chapter introduces you to Dart's origins, design philosophy, and its broad application scenarios in frontend, mobile, and backend development.

The History and Design Goals of Dart

Dart was born in 2011, with the initial goal of replacing JavaScript as the browser's native scripting language.

Although this goal was not achieved, Dart hit a critical turning point in 2017—the release of the Flutter framework brought Dart back into developers' view.

Dart's design goals are very clear:

设计目标说明
高性能Supports AOT (Ahead-of-Time) and JIT (Just-in-Time) compilation, enabling rapid development while generating native code.
强类型Supports type inference, balancing type safety with development efficiency.
跨平台A single codebase can be compiled to ARM, x64 machine code, or JavaScript.
易学习Syntax borrowed from mainstream languages such as Java, JavaScript, and C#, reducing the learning cost.
空安全Built-in Null Safety mechanism, avoiding null pointer exceptions at the language level.

Dart 2.0 was released in 2018, marking the language's maturity. Dart 3.0 was released in 2023, further strengthening features such as the type system and pattern matching.

Application Scenarios of Dart

Dart's application scenarios are very broad, covering full-stack development needs from mobile to backend.

Mobile Development (Flutter)

This is Dart's most core application scenario at present.

Through the Flutter framework, Dart can build native applications for both iOS and Android platforms, with a single codebase running on both.

Web 开发

Dart can be compiled to JavaScript for building web frontend applications.

AngularDart is Google's maintained Dart version of the Angular framework, suitable for large-scale web projects.

服务端开发

With the dart:io library and frameworks such as Shelf, Dart can also be used to write high-performance server-side applications.

Multiple server-side projects inside Google are written in Dart.

命令行工具

Dart can be compiled into standalone executable files, making it well-suited for writing cross-platform CLI tools.

Dart 与 JavaScript 对比

Both Dart and JavaScript are object-oriented languages, but Dart is more rigorous in language design.

Below is a comparison of their differences across several dimensions:

对比维度DartJavaScript
类型系统Strong typing, supports type inferenceWeak typing, dynamic typing
空安全内置 Null SafetyNone (requires TypeScript or manual checking)
入口函数Must have a main() functionDirect script execution
类与继承Class-based OOP, single inheritance基于原型链
编译方式AOT + JIT dual modeJIT 为主
并发模型Isolate (message passing)Worker threads / event loop
包管理pub.dev (unified official repository)npm (community repository)

If you have a JavaScript background, learning Dart will be very easy—their async syntax (async/await) is almost identical.

However, Dart's type system and null safety mechanism will give you a greater sense of security in large projects.

实例

A comparison of how the same functionality is written in the two languages:

// JavaScript 版本
function greet(name) {
  if (name === null || name === undefined) {
    return 'Hello, stranger!';
  }
  return `Hello, ${name}!`;
}

console.log(greet('runoob'));
console.log(greet(null));
// Dart 版本——空安全让类型更明确
String greet(String? name) {
  // name 可能为 null，需要显式处理
  if (name == null) {
    return 'Hello, stranger!';
  }
  return 'Hello, $name!';
}

void main() {
  print(greet('runoob'));
  print(greet(null));
}
Hello, runoob!
Hello, stranger!

The relationship between Dart and Flutter

Many people first encounter Dart because of Flutter.

In fact, Flutter is Dart's "killer app," but Dart itself is an independent general-purpose programming language.

The reasons Flutter chose Dart are as follows:

  • JIT 编译Supports Hot Reload—seeing results in sub-seconds after modifying code, greatly improving development efficiency.
  • AOT 编译Generates native machine code, apps start fast and run smoothly, without the performance overhead of a JavaScript Bridge
  • Dart 的声明式 UINaturally fits with Flutter's Widget tree structure
  • 统一技术栈Google maintains both the language and the framework simultaneously, ensuring good version compatibility.

Before learning Flutter, it is recommended to first master the basics of Dart. After understanding the language features, the learning curve for Flutter will be much smoother. This tutorial is prepared for this purpose.
