Linux lspci Command

Linux Command Reference

What is the lspci Command

lspciIt is a utility command in Linux systems used to list information about all PCI devices. PCI (Peripheral Component Interconnect) is a computer bus standard used to connect the motherboard with various hardware devices.

With this command,lspcisystem administrators and developers can:

  • View all PCI devices installed in the system
  • Obtain detailed device information, including vendor ID, device ID, etc.
  • Diagnose hardware compatibility issues
  • Check whether drivers are loaded correctly

Basic Syntax

lspciThe basic syntax format of the command is as follows:

lspci [选项]

If no options are provided,lspciit will display a brief list of information for all PCI devices in the system.

Common Options

Display detailed information

Example

lspci -v      # Display detailed information (verbose)
lspci -vv     # Display more detailed information (very verbose)
lspci -vvv    # Display the most detailed information (very very verbose)

Query a specific device

Example

lspci -s <Bus>:<Device>.<Function>  # View information for a specific device

For example:

Example

lspci -s 00:02.0  # View the device on bus 00, device 02, function 0

Other common options

Example

lspci -n      # Display vendor and device IDs in numeric form
lspci -nn     # Display both numeric IDs and device names
lspci -k      # Display kernel driver module information
lspci -t      # Display the device hierarchy as a tree diagram
lspci -mm     # Output in machine-readable format
lspci -D      # Display the full domain name (including domain number)

A typicallspcioutput is as follows:

00:01.0 PCI bridge: Intel Corporation 440BX/ZX/DX - 82443BX/ZX/DX AGP bridge (rev 01)
00:07.0 ISA bridge: Intel Corporation 82371AB/EB/MB PIIX4 ISA (rev 08)
00:07.1 IDE interface: Intel Corporation 82371AB/EB/MB PIIX4 IDE (rev 01)
00:07.2 USB controller: Intel Corporation 82371AB/EB/MB PIIX4 USB (rev 01)
00:07.3 Bridge: Intel Corporation 82371AB/EB/MB PIIX4 ACPI (rev 08)

Output format description:

  • First part：00:00.0is the device address, formatted asBus:Device.Function

  • Third part: device vendor and specific model

Common Problem Solutions

1. Command not found

If the system promptslspci: command not found, it means you need to install thepciutilspackage:

Example

# Debian/Ubuntu
sudo apt-get install pciutils

# CentOS/RHEL
sudo yum install pciutils

2. Insufficient permissions

When a normal user executeslspci, they may not be able to obtain complete information. You can usesudo：

Example

sudo lspci -v

3. Device recognition issues

If some devices are not recognized, you can try updating the PCI ID database:

Example

sudo update-pciids

Advanced Tips

1. Combine grep to filter specific devices

Example

lspci | grep -i ethernet  # Find network card
lspci | grep -i audio     # Find sound card

2. Export device information to a file

Example

lspci -vvv > pci_info.txt

3. View the complete configuration space of a device

Example

lspci -xxxx  # Display configuration space in hexadecimal
