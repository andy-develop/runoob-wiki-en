Linux efax command

Linux Command Reference

The Linux efax command is used to send and receive faxes.

Supports Class 1 and Class 2 modems to send and receive faxes.

Syntax

efax [-sw][-a<AT指令>][-c<调制解调器属性>][-d<驱动程序>][-f<字体文件>][-g<指令>][-h<传真标题字符串>][-i<AT指令>][-j<AT指令>][-k<AT指令>][-l<识别码>][-o<选项>][-q<错误次数>][-r<文件名>][-v<信息类型>][-x<UUCP锁定文件>][-t<电话号码><传真文件>]

Parameter Description：

  • -a<AT command> Use the specified AT command to answer the phone.
  • -c<modem properties> Set the local modem properties.
  • -d<driver> Specify the modem driver.
  • -f<font file> Use the specified font file to create the fax header.
  • -g<command> If the incoming call is data, execute the specified command.
  • -h<fax header string> Specify the string as the title at the top of each page.
  • -i<AT command> Send the AT command to the modem before the modem enters fax mode.
  • -j<AT command> Send the AT command to the modem after the modem enters fax mode.
  • -k<AT command> Send the AT command to the modem before the modem exits fax mode.
  • -l<identification code> Set the local modem's identification code.
  • -o<option> Set related options when using a non-standard modem.
  • -q<error count> When receiving a fax, if the number of errors per page exceeds the specified count, request the other party to resend.
  • -r<file name> When receiving a fax, save each page as a separate file.
  • -v<message type> Select the type of information to print.
  • -w Do not answer the phone; wait for the OK or CONNECT signal.
  • -x<UUCP lock file> Use a UUCP-format lock file to lock the modem.
  • -t<phone number><fax file> Dial the number in <phone number> and fax out the <fax file>.
