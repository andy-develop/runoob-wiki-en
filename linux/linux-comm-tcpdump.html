Linux tcpdump command

Linux Command Encyclopedia

The Linux tcpdump command is used to dump network transmission data.

Executing the tcpdump command lists the packet headers passing through the specified network interface. In the Linux operating system, you must be a system administrator.

Syntax

tcpdump [-adeflnNOpqStvx][-c<数据包数目>][-dd][-ddd][-F<表达文件>][-i<网络界面>][-r<数据包文件>][-s<数据包大小>][-tt][-T<数据包类型>][-vv][-w<数据包文件>][输出数据栏位]

Parameter description：

  • -a Attempt to convert network and broadcast addresses to names.
  • -c<number of packets> Stop the dump operation after receiving the specified number of packets.
  • -d Convert the compiled packet encoding into a readable format and dump it to standard output.
  • -dd Convert the compiled packet encoding into C language format and dump it to standard output.
  • -ddd Convert the compiled packet encoding into decimal number format and dump it to standard output.
  • -e Display the link-level header on each column of dumped data.
  • -f Display internet addresses numerically.
  • -F<expression file> Specify a file containing expressions.
  • -i<network interface> Use the specified network interface to send packets.
  • -l Use the standard output column buffer.
  • -n Do not convert host network addresses to names.
  • -N Do not list domain names.
  • -O Do not optimize the packet encoding.
  • -p Do not put the network interface into promiscuous mode.
  • -q Quick output, only listing a small amount of transmission protocol information.
  • -r<packet file> Read packet data from the specified file.
  • -s<packet size> Set the size of each packet.
  • -S List TCP association numbers using absolute rather than relative values.
  • -t Do not display timestamps on each column of dumped data.
  • -tt Display unformatted timestamps on each column of dumped data.
  • -T<packet type> Force the packets specified by the expression to be translated into the set packet type.
  • -v Display the command execution process in detail.
  • -vv Display the command execution process in more detail.
  • -x List packet data in hexadecimal code.
  • -w<packet file> Write packet data to the specified file.
