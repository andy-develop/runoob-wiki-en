Selenium Installation

Before you start using Selenium, you need to install it first. The following are the detailed steps for installing Selenium.

Selenium supports multiple programming languages, but this tutorial series will use Python as an example.

If you have not installed Python yet, you can install it by following the steps below:

  1. VisitPython official website。
  2. Download the Python installer suitable for your operating system.
  3. Run the installer and make sure to check the "Add Python to PATH" option during installation.
  4. After installation, open the command line (Command Prompt or PowerShell on Windows, Terminal on macOS and Linux) and enterpython --version 或 python3 --version, and check whether Python was installed successfully.

You can also refer to the following for Python content:Python Tutorial

to install Selenium.pipis Python's package management tool, used to install and manage Python libraries.pipOpen the command line and enter the following command to install Selenium:

If you are using Python 3, you may need to use

pip install selenium

After installation, you can check whether Selenium was installed successfully with the following command:pip3：

pip3 install selenium

If the Selenium version information is displayed, the installation was successful.

pip show selenium

Starting from Selenium 4, there has been a change in the way browser drivers are managed: Selenium 4 attempts to automatically detect the browser version installed on the system and download the corresponding driver.
