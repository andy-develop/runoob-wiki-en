C++ 指针

Learning C++ pointers is both simple and fun. Through pointers, some C++ programming tasks can be simplified, and some tasks, such as dynamic memory allocation, cannot be performed without pointers. Therefore, to become a good C++ programmer, it is necessary to learn pointers.

As you know, every variable has a memory location, and every memory location defines an address that can be accessed using the ampersand (&) operator, which represents an address in memory. See the following example, which will output the addresses of the defined variables:

实例

#include <iostream> using namespace std; int main () { int var1; char var2[10]; cout << "var1 变量的地址："; cout << &var1 << endl; cout << "var2 变量的地址："; cout << &var2 << endl; return 0; }

When the above code is compiled and executed, it produces the following results:

var1 变量的地址： 0xbfebd5c0
var2 变量的地址： 0xbfebd5b6

Through the above example, we have learned what a memory address is and how to access it. Next, let's take a look at what a pointer is.

What is a pointer?

指针It is a variable whose value is the address of another variable, that is, the direct address of a memory location. Just like other variables or constants, you must declare a pointer before using it to store the address of another variable. The general form of a pointer variable declaration is:

type *var-name;

在这里，typeIt is the base type of the pointer, and it must be a valid C++ data type.var-name. The first represents an array whose elements are int pointers. The second represents a pointer to an int array. When encountering such problems, read from the inside out.

int    *ip;    /* 一个整型的指针 */
double *dp;    /* 一个 double 型的指针 */
float  *fp;    /* 一个浮点型的指针 */
char   *ch;    /* 一个字符型的指针 */

The actual data type of the value of all pointers, whether integer, floating-point, character, or other data types, is the same: a long hexadecimal number representing a memory address. The only difference between pointers of different data types is the data type of the variable or constant to which the pointer points.

Using Pointers in C++

When using pointers, the following operations are frequently performed: defining a pointer variable, assigning a variable address to the pointer, and accessing the value at the address available in the pointer variable. These are accomplished by using the unary operator*to return the value of the variable located at the address specified by the operand. The following example involves these operations:

实例

#include <iostream> using namespace std; int main () { int var = 20; // 实际变量的声明 int *ip; // 指针变量的声明 ip = &var; // 在指针变量中存储 var 的地址 cout << "Value of var variable: "; cout << var << endl; // 输出在指针变量中存储的地址 cout << "Address stored in ip variable: "; cout << ip << endl; // 访问指针中地址的值 cout << "Value of *ip variable: "; cout << *ip << endl; return 0; }

When the above code is compiled and executed, it produces the following results:

Value of var variable: 20
Address stored in ip variable: 0xbfc601ac
Value of *ip variable: 20

C++ Pointers in Detail

In C++, there are many pointer-related concepts. These concepts are simple, but they are all very important. Listed below are some important pointer-related concepts that C++ programmers must clearly understand:

概念描述
C++ Null 指针C++ supports null pointers. A NULL pointer is a constant defined in the standard library with a value of zero.
C++ 指针的算术运算Four arithmetic operations can be performed on pointers: ++, --, +, -
C++ 指针 vs 数组There is a close relationship between pointers and arrays.
C++ 指针数组Arrays can be defined to store pointers.
C++ 指向指针的指针C++ allows pointers to pointers.
C++ 传递指针给函数Passing parameters by reference or by address makes the passed parameters changed in the calling function.
C++ 从函数返回指针C++ allows functions to return pointers to local variables, static variables, and dynamically allocated memory.

    There are still misunderstandings regarding value passing, pointer passing, and reference passing.

    值传递：

    A formal parameter is a copy of an actual parameter; changing the value of the formal parameter does not affect the value of the external actual parameter. From the perspective of the called function, value passing is one-way (actual parameter -> formal parameter); the parameter value can only be passed in, not out. When the function needs to modify the parameter internally, but this change is not intended to affect the caller, value passing is used.

    指针传递：

    The formal parameter is a pointer to the address of the actual parameter. When an operation is performed on the formal parameter through dereferencing, it is equivalent to operating on the actual parameter itself.

    引用传递：

    The formal parameter is equivalent to an "alias" of the actual parameter. An operation on the formal parameter is actually an operation on the actual parameter. During reference passing, although the called function's formal parameter also opens up memory space on the stack as a local variable, what is stored there is the address of the actual parameter variable passed in by the calling function. Any operation by the called function on the formal parameter is handled as indirect addressing, that is, accessing the actual parameter variable in the calling function through the address stored in the stack. For this reason, any operation performed by the called function on the formal parameter affects the actual parameter variable in the calling function.

    cout<<"值传递--函数操作地址"<<&n<<endl;         //显示的是拷贝的地址而不是源地址  6   n++;
 }

     return true;

    C++ allows declaring pointers to functions, which are called function pointers.

    The declaration of a function pointer is similar to the declaration of a function, except that the function name becomes(*指针名), and the definition method is as follows:

    data_types (*func_pointer)( data_types arg1, data_types arg2, ...,data_types argn);

    例如：

    int (*fp)(int a);

    Here, a pointer fp to a function (whose parameter is only an int type and whose return value is int type) is defined.

    After declaration, a function pointer can be pointed to a function that meets the conditions, for example:

    int a(int b);
{
    cout<<b;
    return ++b;
}

int(*p)(int);
p=a;

    After this, we can call the function through the function pointer:

    (*p)(5);

    The difference between array names and pointers:

    The string literal on the right side of char p[]= and char *p= is used differently.

    The former declares an array, and the string literal is used to initialize the array. The lifetime and scope of the array are related to the way it is declared. Moreover, if the array does not have the const qualifier, the contents of the string can be modified. The first address of this array cannot be returned from a function unless the declaration uses static.

    The latter declares a pointer. The string literal itself becomes an array of static storage duration, which is then implicitly converted into a pointer to initialize the declared pointer. This string is not modifiable (modifying it leads to undefined behavior; the array itself may be placed in read-only memory). Its first address can be returned from a function.

    Type casting of C++ pointer types

    The value of the pointer and the value at the address pointed to by the pointer correspond to the address of the data and the value of the data stored at that address. Therefore, according to the endianness of the CPU, when continuing operations after casting the pointer to a different type, attention should be paid to endianness.

    #include <cstdlib>
#include <iostream>

using namespace std;

int main()
{
    char str1[4] = {0x12,0x34,0x56,0x78};
    char * ptr = str1;
    cout << "value of *ptr " << hex << (int)(*ptr) << endl;//hex输出必须对应int类型，否则输出ASCII码
    cout << "value of *ptr " << hex << (int)(*(int*)ptr) << endl;//hex输出必须对应int类型，否则输出ASCII码
    return 0;
}

    编译输出：

    E:\CppTest\VScodeTest\pointer_t> g++ .\pointer_t.cpp -o pointer_t        
E:\CppTest\VScodeTest\pointer_t> .\pointer_t.exe

value of *ptr 78563412
E:\CppTest\VScodeTest\pointer_t>
