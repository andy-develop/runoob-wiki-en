C++ this 指针

C++ 类 & 对象

在 C++ 中，thisThe this pointer is a special pointer that points to the instance of the current object.

In C++, every object can, throughthisThe this pointer is used to access its own address.

thisa hidden pointer, which can be used in a class's member functions, and it can be used to point to the calling object.

When a member function of an object is called, the compiler implicitly passes the address of that object as the this pointer.

Friend functions do not havethispointer, because a friend is not a member of the class; only member functions have it.this指针。

The following example helps to better understand the concept of the this pointer:

实例

#include <iostream> class MyClass { private: int value; public: void setValue(int value) { this->value = value; } void printValue() { std::cout << "Value: " << this->value << std::endl; } }; int main() { MyClass obj; obj.setValue(42); obj.printValue(); return 0; }

The output result of the above code execution is:

Value: 42

实例解析：

  • In the above example, we defined a class named MyClass, which has a private member variable value.

  • The setValue() function in the class is used to set the value of value, while the printValue() function is used to print the value of value.

  • In the setValue() function, we use the this pointer to refer to the current object's member variable value, and assign the passed-in value to it. This clearly tells the compiler that we want to access the current object's member variable, rather than a function parameter or local variable.

  • In the printValue() function, we likewise use the this pointer to refer to the current object's member variable value and print it out.

  • In the main() function, we create an object obj of MyClass, then use the setValue() function to set value to 42, and print it out via the printValue() function.

  • By using the this pointer, we can access the current object's member variables in member functions even if they have the same names as function parameters or local variables. This avoids naming conflicts and ensures we access the correct variable.

#include <iostream> using namespace std; class Box { public: // 构造函数定义 Box(double l=2.0, double b=2.0, double h=2.0) { cout <<"调用构造函数。" << endl; length = l; breadth = b; height = h; } double Volume() { return length * breadth * height; } int compare(Box box) { return this->Volume() > box.Volume(); } private: double length; // 宽度 double breadth; // 长度 double height; // 高度 }; int main(void) { Box Box1(3.3, 1.2, 1.5); // 声明 box1 Box Box2(8.5, 6.0, 2.0); // 声明 box2 if(Box1.compare(Box2)) { cout << "Box2 的体积比 Box1 小" <<endl; } else { cout << "Box2 的体积大于或等于 Box1" <<endl; } return 0; }

    引入 this：

    When we call a member function, we are actually calling it on behalf of some object.

    Member functions access the object on which they are called through an extra implicit parameter named this. When we call a member function, this is initialized with the address of the object on which the function is requested. For example, if we call total.isbn(), the compiler is responsible for passing the address of total to isbn's implicit parameter this. Equivalently, we can think of the compiler rewriting the call into the following form:

    //伪代码，用于说明调用成员函数的实际执行过程
Sales_data::isbn(&total)

    Here, when calling the isbn member of Sales_data, the address of total is passed in.

    Inside a member function, we can directly use the members of the object on which the function was called, without having to use the member access operator to do so, because this refers exactly to that object. Any direct access to a class member is treated as an implicit reference to this. That is, when isbn uses bookNo, it implicitly uses the member pointed to by this, just as if we had writtenthis->bookNo一样。

    For us, the this parameter is implicitly defined. In fact, any attempt to define a parameter or variable named this is illegal. We can use this inside the body of a member function, so although it is not necessary, we can still define isbn in the following form:

    std::string isbn() const { return this->bookNo; }

    Because the purpose of this is always to point to "this" object, this is a const pointer (see Section 2.4.2, page 56); we are not allowed to change the address stored in this.
