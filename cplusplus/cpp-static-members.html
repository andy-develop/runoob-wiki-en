C++ 类的静态成员

C++ 类 & 对象

We can usestaticThe keyword is used to define class members as static. When we declare a class member as static, it means that no matter how many objects of the class are created, there is only one copy of the static member.

Static members are shared among all objects of the class. If no other initialization statements exist, all static data will be initialized to zero when the first object is created. We cannot place the initialization of static members inside the class definition, but we can do it outside the class using the scope resolution operator.::To re-declare the static variable in order to initialize it, as shown in the following example.

The following example helps to better understand the concept of static member data:

实例

#include <iostream> using namespace std; class Box { public: static int objectCount; // 构造函数定义 Box(double l=2.0, double b=2.0, double h=2.0) { cout <<"Constructor called." << endl; length = l; breadth = b; height = h; // 每次创建对象时增加 1 objectCount++; } double Volume() { return length * breadth * height; } private: double length; // 长度 double breadth; // 宽度 double height; // 高度 }; // 初始化类 Box 的静态成员 int Box::objectCount = 0; int main(void) { Box Box1(3.3, 1.2, 1.5); // 声明 box1 Box Box2(8.5, 6.0, 2.0); // 声明 box2 // 输出对象的总数 cout << "Total objects: " << Box::objectCount << endl; return 0; }

When the above code is compiled and executed, it produces the following results:

Constructor called.
Constructor called.
Total objects: 2

static member functions

If a function member is declared as static, the function can be made independent of any particular object of the class. Static member functions can be called even when no class object exists,静态函数Simply use the class name plus the scope resolution operator::then we can access it.

Static member functions can only access static member data, other static member functions, and other functions outside the class.

Static member functions have class scope; they cannot access the this pointer of the class. You can use static member functions to determine whether certain objects of the class have been created.

Differences between static member functions and ordinary member functions:

  • Static member functions do not have a this pointer and can only access static members (including static member variables and static member functions).
  • Ordinary member functions have a this pointer and can access any member of the class; static member functions do not have a this pointer.

The following example helps to better understand the concept of static member functions:

实例

#include <iostream> using namespace std; class Box { public: static int objectCount; // 构造函数定义 Box(double l=2.0, double b=2.0, double h=2.0) { cout <<"Constructor called." << endl; length = l; breadth = b; height = h; // 每次创建对象时增加 1 objectCount++; } double Volume() { return length * breadth * height; } static int getCount() { return objectCount; } private: double length; // 长度 double breadth; // 宽度 double height; // 高度 }; // 初始化类 Box 的静态成员 int Box::objectCount = 0; int main(void) { // 在创建对象之前输出对象的总数 cout << "Inital Stage Count: " << Box::getCount() << endl; Box Box1(3.3, 1.2, 1.5); // 声明 box1 Box Box2(8.5, 6.0, 2.0); // 声明 box2 // 在创建对象之后输出对象的总数 cout << "Final Stage Count: " << Box::getCount() << endl; return 0; }

When the above code is compiled and executed, it produces the following results:

Inital Stage Count: 0
Constructor called.
Constructor called.
Final Stage Count: 2

    Static member variables are only declared, not defined, in the class; therefore they must be defined outside the class, which actually allocates memory for the static member variable. If no definition is added, an error will be reported. Initialization is assigning an initial value, while definition is allocating memory.

    #include <iostream>
 
using namespace std;

class Box
{
   public:
      static int objectCount;
      // 构造函数定义
      Box(double l=2.0, double b=2.0, double h=2.0)
      {
         cout <<"Constructor called." << endl;
         length = l;
         breadth = b;
         height = h;
         // 每次创建对象时增加 1
         objectCount++;
      }
      double Volume()
      {
         return length * breadth * height;
      }
   private:
      double length;     // 长度
      double breadth;    // 宽度
      double height;     // 高度
};

// 初始化类 Box 的静态成员   其实是定义并初始化的过程
int Box::objectCount = 0;
//也可这样 定义却不初始化
//int Box::objectCount;
int main(void)
{
   Box Box1(3.3, 1.2, 1.5);    // 声明 box1
   Box Box2(8.5, 6.0, 2.0);    // 声明 box2

   // 输出对象的总数
   cout << "Total objects: " << Box::objectCount << endl;

   return 0;
}

    输出结果：

    Constructor called.
Constructor called.
Total objects: 2

    You can use static member variables to clearly understand the invocation of constructors and destructors.

    #include <iostream>
using namespace std;

class Cpoint{
    public:
        static int value;
        static int num;
    Cpoint(int x,int y){
        xp=x;yp=y;
        value++;
        cout << "调用构造:" << value << endl;
    }

    ~Cpoint(){num++; cout << "调用析构:" << num << endl;}

    private:
    int xp,yp;
};

int Cpoint::value=0;
int Cpoint::num=0;
class CRect{
    public:
        CRect(int x1,int x2):mpt1(x1,x2),mpt2(x1,x2) {cout << "调用构造\n";}
        ~CRect(){cout << "调用析构\n";}
    private:
        Cpoint mpt1,mpt2;
};

int main()
{
    CRect p(10,20);
    cout << "Hello, world!" << endl;
    return 0;
}
    运行结果：
    调用构造:1
调用构造:2
调用构造
Hello, world!
调用析构
调用析构:1
调用析构:2

    The initialization of static variables in a class is always confusing. Here I will summarize and share.

    类中特殊成员变量的初始化问题：

    • Constant variables: must be initialized through the constructor parameter list.
    • Reference variables: must be initialized through the constructor parameter list.
    • Ordinary static variables: must be initialized outside the class using '::'.
    • Static integer constants: can be initialized directly at the time of definition.
    • Static non-integer constants: cannot be initialized directly at the time of definition. They must be initialized outside the class using '::'.
