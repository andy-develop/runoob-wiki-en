C++ 继承

In object-oriented programming, one of the most important concepts is inheritance. Inheritance allows us to define a class based on another class, which makes creating and maintaining an application easier. In doing so, it also achieves the effect of reusing code functionality and improving execution efficiency.

When creating a class, you do not need to rewrite new data members and member functions; you only need to specify that the newly created class inherits the members of an existing class. This existing class is called基类, the newly created class is called派生类。

继承代表了is arelationship. For example, mammals are animals, dogs are mammals, therefore, dogs are animals, and so on.

代码如下：

// 基类
class Animal {
    // eat() 函数
    // sleep() 函数
};


//派生类
class Dog : public Animal {
    // bark() 函数
};

Base class & Derived class

A class can be derived from multiple classes, which means it can inherit data and functions from multiple base classes. To define a derived class, we use a class derivation list to specify the base classes. The class derivation list names one or more base classes, in the following form:

class derived-class: access-specifier base-class

Here, the access modifier access-specifier ispublic、protected 或 privateAmong them, base-class is the name of a class previously defined. If no access modifier access-specifier is used, it defaults to private.

Suppose there is a base classShape，Rectangleis its derived class, as shown below:

实例

#include <iostream> using namespace std; // 基类 class Shape { public: void setWidth(int w) { width = w; } void setHeight(int h) { height = h; } protected: int width; int height; }; // 派生类 class Rectangle: public Shape { public: int getArea() { return (width * height); } }; int main(void) { Rectangle Rect; Rect.setWidth(5); Rect.setHeight(7); // 输出对象的面积 cout << "Total area: " << Rect.getArea() << endl; return 0; }

When the above code is compiled and executed, it produces the following results:

Total area: 35

Access control and inheritance

A derived class can access all non-private members of the base class. Therefore, if a base class member is not intended to be accessed by member functions of the derived class, it should be declared private in the base class.

We can summarize the different access types according to access permissions, as follows:

访问publicprotectedprivate
同一个类yesyesyes
派生类yesyesno
外部的类yesnono

A derived class inherits all base class methods, except for the following cases:

  • The base class's constructor, destructor, and copy constructor.
  • Overloaded operators of the base class.
  • Friend functions of the base class.

继承类型

When a class is derived from a base class, the base class can be inherited aspublic、protected 或 privateseveral types. The inheritance type is specified by the access modifier access-specifier explained above.

We rarely useprotected 或 privateinheritance, usually usingpublicInheritance. When using different types of inheritance, follow the following rules:

  • 公有继承（public）：When a class is derived from公有a base class, the base class's公有Members also belong to the derived class.公有members, the base class's保护Members also belong to the derived class.保护members, the base class's私有Members cannot be directly accessed by the derived class, but they can be accessed by calling the base class's公有和保护members to access.
  • 保护继承（protected）：When a class is derived from保护a base class, the base class's公有和保护Members will become members of the derived class.保护成员。
  • 私有继承（private）：When a class is derived from私有a base class, the base class's公有和保护Members will become members of the derived class.私有成员。

多继承

Multiple inheritance means that a subclass can have multiple parent classes, and it inherits the characteristics of multiple parent classes.

C++ classes can inherit members from multiple classes, with the syntax as follows:

class <派生类名>:<继承方式1><基类名1>,<继承方式2><基类名2>,…
{
<派生类类体>
};

where the access modifier inheritance method ispublic、protected 或 privateOne of them is used to modify each base class, and the base classes are separated by commas, as shown above. Now let's look at the following example together:

实例

#include <iostream> using namespace std; // 基类 Shape class Shape { public: void setWidth(int w) { width = w; } void setHeight(int h) { height = h; } protected: int width; int height; }; // 基类 PaintCost class PaintCost { public: int getCost(int area) { return area * 70; } }; // 派生类 class Rectangle: public Shape, public PaintCost { public: int getArea() { return (width * height); } }; int main(void) { Rectangle Rect; int area; Rect.setWidth(5); Rect.setHeight(7); area = Rect.getArea(); // 输出对象的面积 cout << "Total area: " << Rect.getArea() << endl; // 输出总花费 cout << "Total paint cost: $" << Rect.getCost(area) << endl; return 0; }

When the above code is compiled and executed, it produces the following results:

Total area: 35
Total paint cost: $2450

    In addition, multiple inheritance (cyclic inheritance), A->D, B->D, C->(A, B), for example:

    class D{......};
class B: public D{......};
class A: public D{......};
class C: public B, public A{.....};

    This inheritance will cause D to create two objects. To solve the above problem, use virtual inheritance format.

    格式：class 类名: virtual 继承方式 父类名

    class D{......};
class B: virtual public D{......};
class A: virtual public D{......};
class C: public B, public A{.....};

    Virtual inheritance -- (a virtual table is created when creating an object) when creating the parent class object

    A:virtual public D
B:virtual public D

    实例：

    #include <iostream>

using namespace std;
//基类

class D
{
public:
    D(){cout<<"D()"<<endl;}
    ~D(){cout<<"~D()"<<endl;}
protected:
    int d;

    Why does the base class constructor appear in the initialization list of the derived class's constructor? The reason lies in the limitations on what the derived class can inherit from the base class.

    We know that a derived class inherits all base class methods, except for the following cases:

    • The base class's constructor, destructor, and copy constructor.
    • Overloaded operators of the base class.
    • Friend functions of the base class.

    Therefore, we cannot call the base class constructor in the body of the derived class's member functions to initialize member variables. For example, the following is not allowed.

    #include <iostream>
 
using namespace std;
 
// 基类
class Shape 
{
   public:
      Shape(int w,int h)
      {
        width=w;
        height=h;
      }
   protected:
      int width;
      int height;
};
 
// 派生类
class Rectangle: public Shape
{
   public:
      Rectangle(int a,int b)
      {
        Shape(a,b);
      }

     
};

    But we can put the base class constructor in the initialization list of the derived class constructor, thereby calling the base class constructor to initialize the member variables that the derived class inherits from the base class.

    #include <iostream>
 
using namespace std;
 
// 基类
class Shape 
{
   public:
      Shape(int w,int h)
      {
        width=w;
        height=h;
      }
   protected:
      int width;
      int height;
};
 
// 派生类
class Rectangle: public Shape
{
   public:
      Rectangle(int a,int b):Shape(a,b)
      {
        
      }
};

    When a derived class inherits the base class's member variables, it allocates a separate block of memory to store the base class's member variables. Therefore, even if the derived class's own member variables have the same names as the base class's member variables, it will not cause conflicts. As in the following code:

    #include <iostream>
using namespace std;

//基类
class A
{
public:
   A(){n = 0;};
   ~A(){};
   int getA(){ return n;};
   void setA(int t){ n = t;};

private:
   int n;
};

//派生类
class B :public A
{
public:
   B(){ n = 0;};
   ~B(){};
   int getB(){ return n;};
   void setB(int t){ n = t;};

private:
  int n;
};

int main(int argc, char * argv[])
{
   B b;
   b.setA(10); //设置基类的成员变量n

   cout<<"A::n "<<b.getA()<<endl;                                                                       
   cout<<"B::n "<<b.getB()<<endl;                                                                                                                                                         
   b.setB(9);  //设置派生类的成员变量n                                                                                                                     
   cout<<"A::n "<<b.getA()<<endl;                                                                       
   cout<<"B::n "<<b.getB()<<endl;                                                                                                                            
   return 0;                                                                                 
}

    To supplement the statement from the second floor, a derived class does inherit the parent class's constructors, but there are some precautions when inheriting constructors. This is supported in C++11 and later standards. The specific situation depends on whether the derived class defines its own constructors and the accessibility of the parent class's constructors.

    #define _CRT_SECURE_NO_WARNINGS

#include <iostream>

using namespace std;

class Base {
public:
    Base() {
        num = 5;
        cout << "BaseConstructorCall:" << protectedMember << endl;
    }
    Base(int n) {
        num = n;
        cout << "BaseConstructorCallnum:" << protectedMember << endl;
    }
    ~Base() {
        cout << "BaseDestructorCall:" << protectedMember << endl;
    }
protected:
    int protectedMember = 0;
    int num;
};

class Derived1 : public Base {
public:
    using Base::Base; // 这行声明继承父类的构造方法
    void modifyMember(int newValue) {
        protectedMember = newValue; // 修改父类的成员
        cout << "Derived1:" << num << endl;
    }
};

class Derived2 : public Base {
public:
    void modifyMember(int newValue) {
        protectedMember = newValue; // 修改同一个父类的成员
        cout << "Derived2:" << num << endl;
    }
};

int main() {
    Derived1 d1(88);
    Derived2 d2;

    d1.modifyMember(10);
    d2.modifyMember(20);

    return 0;
}

    Accessing the base class's private member variables by calling the base class's public member functions:

    #include <iostream>
using namespace std;

class Base {
private:
    int privateVar;
public:
    Base() : privateVar(10) {}
    void accessPrivateVar() {
        cout << "Base privateVar: " << privateVar << endl;
    }
};

class Derived : public Base {
public:
    void accessBasePrivateVar() {
        // 通过调用基类的公有成员函数来访问基类的私有成员变量
        accessPrivateVar();
    }
};

int main() {
    Derived d;
    d.accessBasePrivateVar(); // 输出 Base privateVar: 10
    return 0;
}
