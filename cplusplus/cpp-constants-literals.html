C++ 常量

Constants are fixed values that do not change during program execution. These fixed values are also called字面量。

Constants can be of any basic data type and can be divided into integer numbers, floating-point numbers, characters, strings, and boolean values.

Constants are like regular variables, except that the value of a constant cannot be modified after definition.

整数常量

Integer constants can be decimal, octal, or hexadecimal constants. The prefix specifies the base: 0x or 0X indicates hexadecimal, 0 indicates octal, and no prefix means decimal by default.

Integer constants can also have a suffix, which is a combination of U and L. U means unsigned integer, and L means long integer. The suffix can be uppercase or lowercase, and the order of U and L is arbitrary.

The following are some examples of integer constants:

212 // 合法的 215u // 合法的 0xFeeL // 合法的 078 // 非法的：8 不是八进制的数字 032UU // 非法的：不能重复后缀

The following are examples of integer constants of various types:

85 // 十进制 0213 // 八进制 0x4b // 十六进制 30 // 整数 30u // 无符号整数 30l // 长整数 30ul // 无符号长整数

浮点常量

Floating-point constants consist of an integer part, a decimal point, a fractional part, and an exponent part. You can use decimal form or exponential form to represent floating-point constants.

When using decimal form, you must include the integer part, the fractional part, or both. When using exponential form, you must include the decimal point, the exponent, or both. A signed exponent is introduced by e or E.

The following are some examples of floating-point constants:

3.14159 // 合法的 314159E-5L // 合法的 510E // 非法的：不完整的指数 210f // 非法的：没有小数或指数 .e55 // 非法的：缺少整数或分数

布尔常量

There are two boolean constants, both of which are standard C++ keywords:

  • true值代表真。
  • false值代表假。

We should not regard the value of true as 1 or the value of false as 0.

字符常量

Character constants are enclosed in single quotes. If a constant begins with L (only when uppercase), it indicates that it is a wide-character constant (e.g., L'x'), and it must be stored inwchar_ta variable of type. Otherwise, it is a narrow-character constant (e.g., 'x'), and it can be stored incharin a simple variable of that type.

A character constant can be an ordinary character (e.g., 'x'), an escape sequence (e.g., '\t'), or a universal character (e.g., '\u02C0').

In C++, certain specific characters have special meanings when preceded by a backslash, and are used to represent things like newline (\n) or tab (\t). The following table lists some of these escape sequence codes:

定义常量

In C++, there are two simple ways to define constants:

  • 使用#define预处理器。
  • 使用const关键字。

#define preprocessor

The following is the form of defining a constant using the #define preprocessor:

#define identifier value

See the examples below for details:

实例

#include <iostream> using namespace std; #define LENGTH 10 #define WIDTH 5 #define NEWLINE '\n' int main() { int area; area = LENGTH * WIDTH; cout << area; cout << NEWLINE; return 0; }

When the above code is compiled and executed, it produces the following results:

50

const keyword

您可以使用constThe prefix declaration specifies a constant of a specific type, as shown below:

const type variable = value;

See the examples below for details:

实例

#include <iostream> using namespace std; int main() { const int LENGTH = 10; const int WIDTH = 5; const char NEWLINE = '\n'; int area; area = LENGTH * WIDTH; cout << area; cout << NEWLINE; return 0; }

When the above code is compiled and executed, it produces the following results:

50

Please note that defining constants in uppercase letters is a good programming practice.

    The difference between the macro definition #define and the constant const

    Type and safety checks differ

    A macro definition is character substitution, with no distinction of data types. At the same time, this substitution has no type-safety check and may cause errors such as side effects;

    A const constant is a declaration of a constant, has type distinction, and needs type checking at the compilation stage.

    Different handling by compilers

    A macro definition is a 'compile-time' concept, expanded in the preprocessing stage. Macro definitions cannot be debugged, and their lifetime ends at the compilation period;

    A const constant is a "runtime" concept, used during program execution, similar to read-only data.

    Different storage methods

    A macro definition is direct substitution, does not allocate memory, and is stored in the code segment of the program;

    A const constant requires memory allocation and is stored in the data segment of the program.

    定义域不同

    void f1 ()
{
    #define N 12
    const int n 12;
}
void f2 ()
{
    cout<<N <<endl; //正确，N已经定义过，不受定义域限制
    cout<<n <<endl; //错误，n定义域只在f1函数中
}

    Whether it can be canceled after definition

    A macro definition can be invalidated by #undef.

    After a const constant is defined, it remains valid permanently within its scope.

    void f1()
{
  #define N 12
  const int n = 12;

  #undef N //取消宏定义后，即使在f1函数中，N也无效了
  #define N 21//取消后可以重新定义
}

    Whether it can be used as a function parameter

    Macro definitions cannot be passed as parameters to functions

    A const constant can appear in a function's parameter list.

    const keyword

    const是constantAn abbreviation for 'constant'. As long as a variable is prefixed with const, it means that the data in the variable can be accessed but not modified. In other words, const means read-only.

    Rule: const modifies whatever it is closest to; that thing cannot be modified.

    When const modifies a variable, that variable must be given an initial value. If it is not initialized, it cannot be initialized later.

    Essence: whatever follows const cannot be modified. If const is at the very front, move it one position to the right; the two are equivalent.

    The role of the const keyword

    • To convey very useful information to those reading your code, declaring a parameter as a constant is to tell users the intended purpose of this parameter;
    • By giving the optimizer some additional information, the keyword const may enable the generation of more compact code;
    • Using the keyword const reasonably can make the compiler naturally protect those parameters that are not intended to be modified, preventing accidental code modifications and reducing the occurrence of bugs;

    Application of the const keyword

    • To prevent a variable from being changed, you can use const. When defining such a const variable, you must initialize it first; after that there is no chance to change it.
    • For pointers, you can specify the pointer itself as const, specify the data pointed to by the pointer as const, or specify both as const;
    • In a function declaration, const can modify a formal parameter to indicate that it is an input parameter, and its value cannot be changed inside the function;
    • For class member functions, sometimes they must be specified as const type, indicating that they are constant functions and cannot modify the member variables of the class;
    • For class member functions, sometimes their return value must be specified as const type, so that the return value is not an 'lvalue'.

    角度1As far as defining constants is concerned, a constant defined by const is a variable and also has a type, while a constant defined by #define is just a constant without a type.

    角度2: As far as the stage at which they take effect is concerned, #define takes effect during the preprocessing stage of compilation, while const takes effect during compilation and runtime.

    角度3As far as the way they work, #define is just simple string substitution with no type checking. Whereas const has a corresponding data type, which is checked, and can avoid some low-level errors. Precisely because define is just simple string substitution, it can lead to side effects. For a specific example, refer to the code below:

    #define N 2+3     // 我们预想的 N 值是 5，我们这样使用 
Ndouble a = N/2;  // 我们预想的  a 的值是 2.5，可实际上 a 的值是 3.5

    角度4: In terms of space occupation, for example:

    #define PI 3.14     //预处理后 占用代码段空间
const float PI=3.14;    // 本质上还是一个 float，占用数据段空间

    角度5From the convenience of code debugging, const constants can be debugged, while #define cannot be debugged, because it is already replaced during the preprocessing stage.

    角度6From the perspective of whether they can be redefined, const's inadequacy is inherent: const cannot be redefined, whereas #define can cancel the definition of a symbol via #undef and then redefine it.

    修饰指针

    There are quite a few cases of modifying pointers; the main cases are as follows:

    1、const 修饰*pThe pointed-to object is read-only, and the pointer's pointing can change:

    int a = 9;
int b = 10;
const int *p = &a;//p是一个指向int类型的const值,与int const *p等价
*p = 11;    //编译错误，指向的对象是只读的，不可通过p进行改变
p = &b;     //合法，改变了p的指向

    Here, for ease of understanding, you can consider that const modifies *p, and it is usually used*to access the object by dereferencing the pointer; therefore, the object is read-only.

    2. const modifies p: the pointed-to object can change, but the pointer's pointing cannot change:

    int a = 9;
int b = 10;
int * const p = &a;//p是一个const指针
*p = 11;    //合法，
p = &b;     //编译错误，p是一个const指针，只读，不可变

    3. The pointer cannot change its pointing, and the pointed-to content also cannot be changed.

    int a = 9;
int b = 10;
const int * const p = &a;//p既是一个const指针，同时也指向了int类型的const值
*p = 11;    //编译错误，指向的对象是只读的，不可通过p进行改变
p = &b;     //编译错误，p是一个const指针，只读，不可变

    After seeing the above cases, do you feel confused and find them hard to remember? Let us summarize in one sentence:

    If const is placed anywhere to the left of *, it limits the object pointed to by the pointer to be read-only; if const is placed to the right of *, it limits the pointer itself to be read-only, that is, immutable.

    If it is still not easy to understand, we can look at it this way: remove the type specifier and inspect what const modifies. After removing the type specifier int in the above three cases, it is as follows:

    const *p; //修饰*p，指针指向的对象不可变
* const p; //修饰p，指针不可变
const * const p; //第一个修饰了*p，第二个修饰了p，两者都不可变

    Whatever const modifies on its right side is immutable. The above statement is only to help with understanding and memory. With this understanding, you will find the following equivalent cases:

    const int NUM = 10; //与int const NUM等价
int a = 9;
const int *p  = &a;//与int const *p等价
const int arr[] = {0,0,2,3,4}; //与int const arr[]等价

    When the const keyword appears to the left of *, the content pointed to by the pointer cannot be modified. This is called a pointer to a constant, and it is also referred to as low-level const.

    When the const keyword appears to the right of *, the pointer itself cannot be modified. This is called a constant pointer, and it is also referred to as top-level const,

    The `const` keyword appears on both sides of `*`: both the content pointed to by the pointer and the pointer itself cannot be modified. At this point, both low-level and top-level `const` are present.

    几点注意：

    (1) The content pointed to by a low-level pointer is not unmodifiable; it simply cannot be modified through that pointer. In other words, a low-level pointer "flatters itself" by believing the content it points to is unmodifiable, but in reality, the content it points to can be changed through assignment or other means.

    (2) In practice, top-level `const` is only used to qualify pointers and cannot qualify references (because references are not variables); whereas low-level `const` can qualify both pointers and references, and its meaning is that the pointed-to or referenced content is a constant. Simply remember: low-level `const` restricts the pointed-to or referenced object to be a constant, and places no restriction on the pointer or reference itself; top-level `const` restricts the pointer to be a constant, and places no restriction on the content it points to.

    (3) Low-level `const` imposes a restriction on a variable. When performing copy operations, an object without low-level `const` cannot be assigned to a variable that has low-level `const`.

    int main()
{
    int a = 1;
    const int *p1 = &a;         //底层const, 也可以用int const *p1 = &a;.
    *p1 = 2;                    //非法, 无法通过p1更改a的值.
    p1++;                       //合法, p1的值(指向的地址)是可以更改的.
    a = 2;                      //合法, 只是无法通过p1解引用的方式更改a的值, 其他方式可以.

    int *const p2 = &a;         //顶层const, p2是常量.
    *p2 = 3;                    //合法, p2指向地址的内容可以更改.
    p2++;                       //非法, p2的值(指向的地址)无法更改.
    a = 4;                      //合法, p2指向地址的内容可以更改.
    const int *const p3 = &a;   //同时具有底层和顶层const, p3的值(指向的地址)无法修改, 且无法通过p3解引用进行更改.
    int *p4 = p1;               //非法, p1是const *int(底层const), 无法给普通int*赋值.
    int *p5 = p2;               //合法, p2是*const int(顶层const), 赋值时没有限制.
    const int *p6 = p1;         //合法, p6也是const *int(底层const), 可以获得p1的赋值.
}
