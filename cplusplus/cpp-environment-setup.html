C++ Environment Setup

If you want to set up a C++ language environment, you need to make sure you have the following two software programs available on your computer: a text editor and a C++ compiler.

Text Editor

Files created through an editor are usually called source files, and source files contain the program's source code.

Source files for C++ programs usually use the extension.cpp、.cpor.c。

Before you start programming, make sure you have a text editor and enough experience to write a computer program, then save it in a file, compile it, and execute it.

  • Visual Studio Code: Although it is a general-purpose text editor, it has many plugins that support C/C++ development, making it a popular choice. By installing C/C++ plugins and adjusting settings, you can turn it into a great C language development environment.

    Download URL:https://code.visualstudio.com/

  • Eclipse: Eclipse is another powerful integrated development environment. Although it was originally designed for Java development, it can support C language development by installing C/C++ plugins.

C++ compiler

The source code written in a source file is human-readable source. It needs to be "compiled" into machine language so that the CPU can execute the program according to the given instructions.

The C++ compiler is used to compile source code into a final executable program.

Most C++ compilers do not care about the extension of the source file, but if you do not specify an extension, the default is used.cpp。

The most commonly used freely available compiler is the GNU C/C++ compiler. If you are using HP or Solaris, you can use the compiler on your respective operating system.

The following sections will guide you on how to install the GNU C/C++ compiler on different operating systems. C/C++ is mentioned together here mainly because the GNU gcc compiler is suitable for both C and C++ programming languages.

g++ Application Notes

The program g++ is a special version of gcc that sets the default language to C++. When linking, it automatically uses the C++ standard library instead of the C standard library. By following the source code naming conventions and specifying the corresponding library names, it is possible to compile and link C++ programs with gcc, as shown in the following example:

$ gcc main.cpp -lstdc++ -o main

Below is the code of a simple C++ program saved in the file helloworld.cpp:

#include <iostream>
using namespace std;
int main()
{
    cout << "Hello, world!" << endl;
    return 0;
}

The simplest way to compile:

$ g++ helloworld.cpp

Since the executable file name was not specified in the command line, the compiler uses the default a.out. The program can be run like this:

$ ./a.out
Hello, world!

Usually we use-oThe option specifies the executable file name. The following example generates an executable file named helloworld:

$ g++ helloworld.cpp -o helloworld

Run helloworld:

$ ./helloworld
Hello, world!

If there are multiple C++ code files, such as runoob1.cpp and runoob2.cpp, the compilation command is as follows:

$ g++ runoob1.cpp runoob2.cpp -o runoob

Generate a runoob executable file.

Some systems default to C++98 for g++, and we can specify C++11 to compile the main.cpp file:

g++ -g -Wall -std=c++11 main.cpp

OptionsExplanation
-ansiOnly supports C syntax conforming to the ANSI standard. This option will disable certain features of GNU C, such as the asm or typeof keywords.
-c Compile only and generate object files.
-DMACRO Define the MACRO macro as the string "1".
-DMACRO=DEFNDefine the MACRO macro with the string "DEFN".
-E Only run the C preprocessor.
-g Generate debugging information. The GNU debugger can use this information.
-IDIRECTORY Specify additional header file search path DIRECTORY.
-LDIRECTORYSpecify additional library search path DIRECTORY.
-lLIBRARYSearch the specified library LIBRARY when linking.
-m486 Optimize code for 486.
-oFILE generates the specified output file. Used when generating executable files.
-O0Do not perform optimization.
-O Or -O1 to optimize generated code.
-O2Further optimization.
-O3Further optimization beyond -O2, including inline functions.
-sharedGenerate a shared object file. Usually used when building shared libraries.
-staticDisable shared linking.
-UMACRO Undefine the MACRO macro.
-wDo not generate any warning messages.
-Wall Generate all warning messages.
