C++ 环境设置

If you want to set up a C++ language environment, you need to make sure you have the following two software programs available on your computer: a text editor and a C++ compiler.

文本编辑器

Files created through an editor are usually called source files, and source files contain the program's source code.

Source files for C++ programs usually use the extension.cpp、.cp 或 .c。

Before you start programming, make sure you have a text editor and enough experience to write a computer program, then save it in a file, compile it, and execute it.

  • Visual Studio Code: Although it is a general-purpose text editor, it has many plugins that support C/C++ development, making it a popular choice. By installing C/C++ plugins and adjusting settings, you can turn it into a great C language development environment.

    安装教程：https://www.runoob.com/w3cnote/vscode-tutorial.html

    下载地址：https://code.visualstudio.com/

  • Visual Studio: A comprehensive Windows IDE for .NET and C++ developers, which can be used to build web, cloud, desktop, mobile apps, services, and games.

    下载地址：https://visualstudio.microsoft.com/zh-hans/downloads/。

  • Vim 和 Emacs: These are two traditional text editors. They have powerful editing features and a high degree of customizability. They are very powerful for skilled users, and there are many plugins and configurations that can support C language development.

  • Eclipse: Eclipse is another powerful integrated development environment. Although it was originally designed for Java development, it can support C language development by installing C/C++ plugins.

More related tools

C++ compiler

The source code written in a source file is human-readable source. It needs to be "compiled" into machine language so that the CPU can execute the program according to the given instructions.

The C++ compiler is used to compile source code into a final executable program.

Most C++ compilers do not care about the extension of the source file, but if you do not specify an extension, the default is used.cpp。

The most commonly used freely available compiler is the GNU C/C++ compiler. If you are using HP or Solaris, you can use the compiler on your respective operating system.

The following sections will guide you on how to install the GNU C/C++ compiler on different operating systems. C/C++ is mentioned together here mainly because the GNU gcc compiler is suitable for both C and C++ programming languages.

g++ Application Notes

The program g++ is a special version of gcc that sets the default language to C++. When linking, it automatically uses the C++ standard library instead of the C standard library. By following the source code naming conventions and specifying the corresponding library names, it is possible to compile and link C++ programs with gcc, as shown in the following example:

$ gcc main.cpp -lstdc++ -o main

Below is the code of a simple C++ program saved in the file helloworld.cpp:

#include <iostream>
using namespace std;
int main()
{
    cout << "Hello, world!" << endl;
    return 0;
}

The simplest way to compile:

$ g++ helloworld.cpp

Since the executable file name was not specified in the command line, the compiler uses the default a.out. The program can be run like this:

$ ./a.out
Hello, world!

Usually we use-oThe option specifies the executable file name. The following example generates an executable file named helloworld:

$ g++ helloworld.cpp -o helloworld

执行 helloworld:

$ ./helloworld
Hello, world!

If there are multiple C++ code files, such as runoob1.cpp and runoob2.cpp, the compilation command is as follows:

$ g++ runoob1.cpp runoob2.cpp -o runoob

Generate a runoob executable file.

Some systems default to C++98 for g++, and we can specify C++11 to compile the main.cpp file:

g++ -g -Wall -std=c++11 main.cpp

    Regarding the window that flashes by above, as someone with 3 years of C++ coding experience, let me point out the problem and the solution.

    The flashing-by happens because your program has no input, only fixed output. The program exits when it reaches the return statement.

    Let me explain the three solutions given earlier one by one:

    第一种：

    cin.clear();  // 清空缓存
cin.sync();   // 清空缓存
cin.get();    // 接收键盘输入
// From:本帖，"但对于太突然"

    This method uses an input approach to prevent the program from terminating. It will exit the program after reading in data (cin.get).

    #include <stdio.h>
int main()
{
  getchar();
  return 0;
}
// From:本帖，"xuezy"

    This method also uses an input approach, but unlike the previous one, this time it uses the getchar function to obtain a char type, but does not store the read data in any variable.

    #include <stdlib.h>
int main()
{
  system("pause"); //注意：“system("pause")”;语句会显示“请按任意键继续……”
  return 0;
}
// From:本帖，"xuezy"

    This method uses the pause command in the system() function to pause the program.

    About GNU and GCC:

    After the Unix system was invented, everyone found it very enjoyable to use. But later it began to be commercialized, closed-source, and charged for. A guy named RMS was unhappy about this, so he initiated the GNU project, imitating Unix's interface and usage, to create an open-source version from scratch. Then he himself made the editor Emacs and the compiler GCC.

    Then many people did a lot of work and projects under the GNU Project, basically realizing the original plan. Including the core gcc and glibc. But the GNU system lacked an operating system kernel. The originally planned kernel was called HURD, which was never completed. At the same time, BSD (a UNIX distribution) was embroiled in copyright disputes, and x86 platform development was suspended. Then a student named Linus, in order to run Unix on a PC, developed Linux inspired by Minix. Note that Linux is just a system kernel; after the system boots, it still uses software such as gcc and bash. When Linus released Linux, he chose GPL, so it conforms to the GNU philosophy.

    Finally, everyone suddenly realized that this thing was exactly what the GNU project was missing. So they bundled it together and released it as GNU/Linux. Then as people kept saying it, they dropped the first part, and it became the Linux system. In reality, the kernel in Linux distributions such as Debian and RedHat only takes up a very small portion of the capacity.
