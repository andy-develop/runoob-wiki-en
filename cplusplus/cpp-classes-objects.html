C++ 类 & 对象

C++ adds object-oriented programming on the basis of C. C++ supports object-oriented programming. Classes are a core feature of C++ and are often called user-defined types.

Classes are used to specify the form of objects. They are user-defined data types that encapsulate a combination of data and functions. The data in a class is called member variables, and the functions are called member functions. A class can be viewed as a template that can be used to create multiple objects with the same properties and behaviors.

C++ class definition

To define a class, you need to use the keywordclassThen specify the name of the class, and the class body is enclosed in a pair of curly braces. The body contains the member variables and member functions of the class.

Defining a class is essentially defining a blueprint for a data type. It defines what objects of the class include and what operations can be performed on that object.

In the following example, we use the keywordclassDefine the Box data type, containing three member variables: length, breadth, and height:

class Box { public: double length; // 盒子的长度 double breadth; // 盒子的宽度 double height; // 盒子的高度 };

关键字publicIt determines the access attributes of class members. Within the scope of a class object, public members are accessible from outside the class. You can also specify class members as...private 或 protected, which we will explain later.

Defining C++ Objects

Classes provide the blueprint for objects, so basically, objects are created based on classes. Declaring an object of a class is like declaring a variable of a basic type. The following statements declare two objects of the Box class:

Box Box1; // 声明 Box1，类型为 Box Box Box2; // 声明 Box2，类型为 Box

The objects Box1 and Box2 each have their own data members.

access data members

The public data members of a class object can be accessed using the direct member access operator..来访问。

To better understand these concepts, let's try the following example:

实例

It should be noted that private members and protected members cannot be accessed directly using the direct member access operator (.). We will learn how to access private and protected members in later tutorials.

    The struct in C++ is an extension of the struct in C. It is no longer just a data structure containing different data types; it has acquired too many features.

    Can struct contain member functions? Yes!

    Can struct inherit? Yes it can!!

    Can struct implement polymorphism? Yes!!!

    Since it can do all of these, what difference can there still be between it and class?

    The most essential difference is the default access control, which is reflected in two aspects:

    1) Default inheritance access permission. struct is public, class is private.

    You can write the following code:

    struct A
{
    char a;
};
struct B : A
{
    char b;
};

    At this point, B is publicly inheriting A.

    If both of the above structs are changed to class, then B privately inherits A. This is the default inheritance access permission.

    Therefore, when we normally write class inheritance, we usually write it like this:

    struct B : public A

    This is to specify public inheritance, rather than using the default private inheritance.

    Of course, whether the default is public inheritance or private inheritance depends on the derived class, not the base class.

    What I mean is, a struct can inherit from a class, and likewise a class can inherit from a struct. In that case, the default inheritance access permission depends on whether the derived class uses struct or class. As follows:

    struct A{}; 
class B : A{}; //private继承
struct C : B{}; //public继承

    2) As an implementation of a data structure, struct's default data access control is public, while as an implementation of an object, class's default member variable access control is private.

    Note my wording above. I still emphasize that struct is an implementation of a data structure, although it can be used just like class. I still call the variables in struct "data" and the variables in class "members," although there is no difference between them.

    In fact, whether to use struct or class is entirely a matter of personal preference. You can replace all the class keywords in your program with struct, and it will still run normally. But my best advice is: if you think what you are doing is more like a data structure, then use struct; if it is more like an object, then use class.

    Of course, I also want to emphasize one point here: for access control, you should explicitly specify it in the program rather than rely on defaults. This is a good habit and also makes your code more readable.

    At this point, many knowledgeable people might think this topic can be concluded, because they know the "only" difference between struct and class is access control. Indeed, many documents mention only this one difference.

    But I did not use "only" above; instead, I said "most essential." That is because they really do have another difference, although we may rarely encounter it in normal work. That is: the keyword "class" is also used to define template parameters, just like "typename." But the keyword "struct" is not used to define template parameters. This point is explained in Inside the C++ Object Model written by Stanley B. Lippman.

    The discussion here should basically be concluded. But someone once said he had found other "differences." So let's take a look at whether this is really another difference. As mentioned above, struct in C++ is an extension of struct in C. Since it is an extension, it must be compatible with all the features that struct in C should have. For example, you can write like this:

    struct A //定义一个struct
{
    char c1;
    int n2;
    double db3;
};
A a={'p',7,3.1415926}; //定义时直接赋值

    That is to say, struct can be initialized with {} at the time of definition. Then the question arises: can class do it? Change the struct above to class and try. Error! Oh, so that person jumps out and says he has found another difference. Let's look carefully: is this really another difference?

    Try adding a constructor (or virtual function) to the struct above. What do you find?

    Right, struct also can no longer be initialized with {}.

    Indeed, initializing with {} is just using an initializer list to initialize data in order. For example, if above you write A a={'p',7}; then c1 and n2 are initialized, but db3 is not. Such a simple copy operation can only occur on simple data structures, and should not be applied to objects. Adding a constructor or a virtual function makes struct more reflect the characteristics of an object, and this {} operation is no longer valid.

    In fact, it is because adding such functions changes the internal structure of the class. What about adding a normal member function? You will find that {} remains usable. In fact, you can understand a normal function as an algorithm on the data structure, which does not break its data structure characteristics.

    So, seeing this, we find that even for struct to use {} for initialization, it must satisfy many constraints. These conditions actually make struct reflect the characteristics of a data structure rather than a class.

    Then why is it that when we simply change struct to class above, {} can no longer be used?

    Actually, the problem happens to be what we talked about earlier—access control! Look, what did we forget? Right, when changing struct to class, access control changes from public to private, so of course {} can no longer be used for initialization. Add a public, and you will find that class can also use {}, with no difference from struct at all!!!

    To summarize, from the differences above, we can see that struct is more suitable to be regarded as an implementation of a data structure, and class is more suitable to be regarded as an implementation of an object.

    Outside the class, you can actually also use pointers to access private members inside the class, for example:

    #include <iostream>
using namespace std;

class a    // 定义了类a
{
    long a0;   // 定义私有成员 a0
    public:
    a(long b)
    {
        a0=b;
    }
    void geta()
    {
        cout<<a0<<endl;
    }
};
int main()
{
    a b(5);          // 定义对象b，并给 b 中的 a0 赋初值
    long *p;
    p=(long*)&b;     // 令指针 p 指向 b 中前 4 个字节，在这里相当于指向 a0
    b.geta();        // 用内部函数访问 a0
    cout<<*p<<endl;  // 在外部直接访问 a0
    *p=8;            // 在外部改变 a0 的值
    b.geta();        // 输出改变后的结果
    cout<<*p<<endl;
    return 0;
}

    It should be noted that although this method can be used in some program development based on the class polymorphism principle, it violates the class encapsulation principle and is also extremely unsafe in classes that use pointers, so it is not recommended.

    What happens when one object is assigned to another object?

    Box Box1;        // 创建 Box1，执行后Box1已存在
Box Box2;        // 创建 Box2，执行后Box2已存在
Box2 = Box1;     // 这时是把Box1的成员变量值复制给了Box2，Box2还是原来的对象，并没有被销毁，对象地址还是原来的  地址。
Box &Box3 = Box1; // 创建Box1的引用变量Box3.

    其中Box &Box3 = Box1, similar to JavaBox3 = Box1。

    Difference from Java: A reference in C++ must be initialized when created, and after creation it cannot point to another object, whereas in Java, an object name can point to another object of the same type at any time.

    The above conclusion is drawn from the following example:

    #include <iostream>
 
using namespace std;
 
class Box
{
   public:
      double length;   // 长度
      double breadth;  // 宽度
      double height;   // 高度
      // 成员函数声明
      double get(void);
      void set( double len, double bre, double hei );
};
// 成员函数定义
double Box::get(void)
{
    return length * breadth * height;
}
 
void Box::set( double len, double bre, double hei)
{
    length = len;
    breadth = bre;
    height = hei;
}
int main( )
{
   Box Box1;        // 声明 Box1，类型为 Box
   Box Box2;        // 声明 Box2，类型为 Box
   double volume = 0.0;     // 用于存储体积
 
   // box 1 详述
   Box1.height = 5.0; 
   Box1.length = 6.0; 
   Box1.breadth = 7.0;
    
 
   // box 1 的体积
   volume = Box1.height * Box1.length * Box1.breadth;
   cout << "Box1 的地址：" << &Box1 <<endl;
   cout << "Box1 的体积：" << volume <<endl;
 
   // box 2 详述
   volume = Box2.get(); 
   cout << "Box2 的地址：" << &Box2 <<endl;
   cout << "Box2 的体积：" << volume <<endl;
    
   Box2 = Box1;
   volume = Box2.get();
   cout << "Box2 的地址：" << &Box2 <<endl;
   cout << "Box2 的体积：" << volume <<endl;
   return 0;
}

    This way of understanding is more intuitive; otherwise, beginners simply cannot understand it.

    // 1. 基础准备
#include <iostream>   // 引入输入输出库
using namespace std;  // 使用标准命名空间（简化代码书写）

// 2. 盒子类的声明
class Box {
public:               // 公有访问权限（初学者先记住这是必要结构）
    // 成员变量（物体的三维属性）
    double length;    // 长
    double breadth;   // 宽
    double height;    // 高
    
    // 成员函数声明（能力说明）
    double get();     // 获取体积
    void set(double l, double b, double h); // 设置尺寸
};

// 3. 成员函数具体实现
double Box::get() {   // 双冒号表示属于Box类的函数
    return length * breadth * height; // 体积计算公式
}

void Box::set(double l, double b, double h) {
    length = l;      // 将参数值赋给成员变量
    breadth = b;
    height = h;
}

// 4. 主程序（使用案例）
int main() {
    // 创建三个不同的盒子对象
    Box Box1, Box2, Box3; 
    double volume = 0;  // 临时存储计算结果

    /* 操作方式对比 */
    // 方式一：直接操作成员变量（公开访问）
    Box1.height = 5;    // ▢ 直接设置高度
    Box1.length = 6;    // ▢ 直接设置长度
    Box1.breadth = 7;   // ▢ 直接设置宽度
    volume = Box1.height * Box1.length * Box1.breadth;
    cout << "Box1体积：" << volume << endl; // 输出结果

    // 方式二：通过方法操作（推荐方式）
    Box3.set(16, 8, 12);        //  一键设置所有尺寸
    volume = Box3.get();        //  自动计算体积
    cout << "Box3体积：" << volume << endl;

    return 0;
}
