C++ provides the following two types of string representations:

  • C-style string
  • The string class type introduced by C++

C-style string

C-style strings originated in the C language and continue to be supported in C++. A string is actually a one-dimensional character array,null字符\0terminated by a null character. Therefore, a null-terminated string contains the characters that make up the string.

The following declaration and initialization creates aRUNOOBstring. Since a null character is stored at the end of the array, the size of the character array is larger than the wordRUNOOBIt has one more character.

According to the array initialization rules, you can write the above statement as the following:

char site[] = "RUNOOB";

    The string class provides a series of operations for strings, such as:

    • 1. append() -- append characters to the end of the string
    • 2. find() -- find a string within a string
    • 4. insert() -- insert characters
    • 5. length() -- returns the length of the string
    • 6. replace() -- replaces the string
    • 7. substr() -- returns a substring
    • 8. ...

    The following is an example of the string class:

    #include <iostream>
#include <string>
using namespace std;

int main()
{
    //定义一个string类对象
    string http = "www.runoob.com";

   //打印字符串长度
   cout<<http.length()<<endl;

    //拼接
    http.append("/C++");
    cout<<http<<endl; //打印结果为：www.runoob.com/C++

    //删除
    int pos = http.find("/C++"); //查找"C++"在字符串中的位置
    cout<<pos<<endl;
    http.replace(pos, 4, "");   //从位置pos开始，之后的4个字符替换为空，即删除
    cout<<http<<endl;

    //找子串runoob
    int first = http.find_first_of("."); //从头开始寻找字符'.'的位置
    int last = http.find_last_of(".");   //从尾开始寻找字符'.'的位置
    cout<<http.substr(first+1, last-first-1)<<endl; //提取"runoob"子串并打印

    return 0;
}

    I have always been confused about how to distinguish sizeof from strlen; recently I looked up some information:

    1. The result type of the sizeof operator is size_t, which is typedef'd as unsigned int in the header file. This type is guaranteed to accommodate the byte size of the largest object created by the implementation.

    2. sizeof is an operator, and strlen is a function.

    3. sizeof can take a type as a parameter,strlen只能用char*as a parameter, and must be\0结尾的。

    sizeof can also take a function as a parameter, for example:

    short f();
printf("%d\n", sizeof(f()));

    The output result is sizeof(short), which is 2.

    4、数组做sizeofThe parameter does not decay, and is passed tostrlenit decays into a pointer.

    5. Most compilers, at compile time, willsizeofhave already calculated it; it is the length of a type or variable. This issizeof(x)the reason why it can be used to define the dimensions of an array.

    char str[20]="0123456789";
int a=strlen(str); // a=10;
int b=sizeof(str); // 而 b=20;

    6. The result of strlen can only be calculated at runtime; it is used to calculate the length of a string, not the amount of memory occupied by a type.

    7. After sizeof, if it is a type, parentheses must be added; if it is a variable name, parentheses can be omitted. This is becausesizeofis an operator, not a function.

    8. When applied to a structure type or variable, sizeof returns the actual size; when applied to a statically allocated array, sizeof returns the size of the entire array; the sizeof operator cannot return the size of dynamically allocated arrays or external arrays.

    When an array is passed as a parameter to a function, what is passed is a pointer rather than the array; the address of the first element of the array is passed, for example:

    fun(char [8])
fun(char [])

    都等价于

    fun(char *)

    In C++, when passing an array as a parameter, it is always a pointer to the first element of the array that is passed; the compiler does not know the size of the array.

    If you want to know the size of the array inside the function, you need to do this:

    After entering the function, use memcpy to copy it out, and the length is passed in through another formal parameter.

    fun(unsiged char *p1, int len)
{
    unsigned char* buf = new unsigned char[len+1]
    memcpy(buf, p1, len);
}

    After reading the detailed explanation above, I found that there are still differences in the use of the two; this can be clearly seen from this example:

    char str[20]="0123456789";

    The above is the result of processing a static array; if it were a pointer, the result would be different.

sizeof(ss) 结果 4 ＝＝＝》ss 是指向字符串常量的字符指针，sizeof 获得的是一个指针的之所占的空间,应该是长整型的，所以是 4。
sizeof(*ss) 结果 1 ＝＝＝》*ss 是第一个字符 其实就是获得了字符串的第一位 '0' 所占的内存空间，是 char 类型的，占了 1 位

    Regarding why a character array can use the array name with cout to output the array contents, while an ordinary array cannot.

    先上范例：

    int a[10] = {1,2,3,6,7};
char b[6] = {'h','a','p','p','y','\0'};
char c[] = "happy";
cout<<a<<endl;
cout<<b<<endl;
cout<<c<<endl;

    The output result is:

    0x22fe6c
happy
happy

    From the above examples, it can be seen that outputting an ordinary array by its array name with cout only gives a string of addresses; with a character array, the contents of the array are output.

    So why is that?

    答案：因为charEach element in a `char`-type array is one byte, so the addresses between each character are +1 and consecutive. Therefore, when cout outputs and reads [the null character] in the character array\0it stops output. But in an int array, each element occupies 4 bytes, so the address interval between each element in the array is 4. In fact, it is also continuous; garbled characters appear because the terminator is not found.

    There is a point on the Runoob tutorial that has not been clearly explained, namely the use of the strcmp(s1, s2) function in C-style strings. The Runoob tutorial describes it as follows:

    strcmp(s1, s2);

    If s1 and s2 are identical, return 0; if s1<s2, the return value is less than 0; if s1>s2, the return value is greater than 0.

    However, to be more accurate, it actually returns a value less than 0 only if the two strings do not match and the first character of the first string is less than the first character of the second string; otherwise, it returns a value greater than 0.
