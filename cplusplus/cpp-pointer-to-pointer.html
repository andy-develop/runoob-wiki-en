C++ 指针

A pointer to a pointer is a form of multiple indirection, or a chain of pointers.

A pointer to a pointer is storing the address of a pointer inside another pointer.

Usually, a pointer contains the address of a variable. When we define a pointer to a pointer, the first pointer contains the address of the second pointer, and the second pointer points to the location that holds the actual value.

A pointer-to-pointer variable must be declared as follows, that is, placing two asterisks before the variable name. For example, the following declares a pointer to a pointer of int type:

int **var;

When a target value is indirectly pointed to by a pointer to another pointer, accessing that value requires the use of two asterisk operators, as shown in the following example:

实例

#include <iostream> using namespace std; int main () { int var; int *ptr; int **pptr; var = 3000; // 获取 var 的地址 ptr = &var; // 使用运算符 & 获取 ptr 的地址 pptr = &ptr; // 使用 pptr 获取值 cout << "var 值为 :" << var << endl; cout << "*ptr 值为:" << *ptr << endl; cout << "**pptr 值为:" << **pptr << endl; return 0; }

When the above code is compiled and executed, it produces the following results:

var 值为 :3000
*ptr 值为:3000
**pptr 值为:3000

    By examining the addresses of var, ptr, and *pptr, you can understand the addressing process of multi-level indirect addressing more clearly. From the results, you can see that the addresses of these three are all the same.

    #include <iostream>
 
using namespace std;

int main ()
{
    int var;
    int *ptr;
    int **pptr;
    var = 3000;

    // 获取 var 的地址
    ptr = &var;

    // 使用运算符 & 获取 ptr 的地址
    pptr = &ptr;

    // 使用 pptr 获取值
    cout << "var 值为 :" << var << endl;
    cout << "*ptr 值为:" << *ptr << endl;
    cout << "**pptr 值为:" << **pptr << endl;
    cout << "var 地址为 :" << &var << endl;
    cout << "ptr=&var 值为var的地址:" << ptr << endl;
    cout << "ptr地址为:" << &ptr << endl;
    cout << "*pptr=ptr=&var  值为var的地址:" << *pptr << endl;
    cout << "pptr 地址为:" << &pptr << endl;
    return 0;
}

    The calculation result is:

    var 值为 :3000
*ptr 值为:3000
**pptr 值为:3000
var 地址为 :0x7ffeec7a65e8
ptr=&var 值为var的地址:0x7ffeec7a65e8
ptr地址为:0x7ffeec7a65e0
*pptr=ptr=&var  值为var的地址:0x7ffeec7a65e8
pptr 地址为:0x7ffeec7a65d8

    Among these, if you understand what p, *p, and &p actually are for a pointer type *p, then you can also understand second-level pointers.

    My method is to view it piece by piece, where * is the dereference operator and & is the address-of operator; then just treat p as an ordinary variable.

    My personal understanding is not to view *p as a whole; it is easier to understand it as *(p). Treat p as an ordinary variable name, so p here represents the value of that variable;

    #include <iostream>

    int  var;

    Treating what is inside *p as an ordinary variable may be a bit hard to understand; here is an example:

    For example, an ordinary variable int a; we can understand it as a box that can hold 32 bits. This box can only contain integers, and the data value inside it might be 300, so a is an alias for 300, so we can say a is the integer 300. Similarly, looking at p alone, in a 32-bit computer, there is a box of 32 bits (4 bytes) that can only hold addresses. The address inside it might be 0x61ff18, so p is an alias for 0x61ff18. Therefore, both a and p actually represent the value inside the box.

    ptr = &var
*ptr = *(&var) = var
 
pptr = &ptr
*pptr = *(&ptr) = ptr = &var
**pptr = *(*pptr) = *(&var) = var

    A pointer array is used to store multiple pointers, that is, addresses. Addresses can be regarded as a special kind of value.

    The array name of a pointer array (that is, the first address of the pointer array) is equivalent to a pointer to a pointer.

    A function that returns a pointer array should be declared and defined as a pointer-to-pointer function.

    即:

    type ** muyFunction(){

}

   int b = 200;
   int **c;
   cout << "交换前，a 的值：" << a << endl;
   cout << "交换前，b 的值：" << b << endl;
