C++ Variable Scope

Generally speaking, there are three places where variables can be defined:

  • Variables declared inside a function or a code block are calledLocal variables。

  • Variables declared in the definition of function parameters are calledFormal parameters。

  • Variables declared outside all functions are calledGlobal variables。

Scope is an area of a program. The scope of variables can be divided into the following types:

  • Local Scope: Variables declared inside a function have local scope; they can only be accessed inside the function. Local variables are created each time the function is called and destroyed after the function finishes execution.

  • Global Scope: Variables declared outside all functions and code blocks have global scope; they can be accessed by any function in the program. Global variables are created when the program starts and destroyed when the program ends.

  • Block Scope: Variables declared inside a code block have block scope; they can only be accessed inside the code block. Block-scope variables are created each time the code block is executed and destroyed after the code block finishes execution.

  • Class Scope: Variables declared inside a class have class scope; they can be accessed by all member functions of the class. The lifetime of class-scope variables is the same as the lifetime of the class.

Note:If a variable declared in an inner scope has the same name as a variable in an outer scope, the variable in the inner scope will override the variable in the outer scope.

Local variables

Variables declared inside a function or a code block are called local variables. They can only be used by statements inside the function or code block. The following example uses local variables:

Example

#include <iostream> using namespace std; int main () { // Local variable declaration int a, b; int c; // actual initialization a = 10; b = 20; c = a + b; cout << c; return 0; }

Global variables

Variables defined outside all functions (usually at the head of the program) are called global variables. The values of global variables are valid throughout the entire lifetime of the program.

Global variables can be accessed by any function. That is, once a global variable is declared, it is available throughout the entire program. The following example uses global variables and local variables:

Example

#include <iostream> using namespace std; // global variable declaration int g; int main () { // Local variable declaration int a, b; // actual initialization a = 10; b = 20; g = a + b; cout << g; return 0; }

In a program, local variables and global variables can have the same name, but within a function, the value of the local variable will override the value of the global variable. Here is an example:

Example

#include <iostream> using namespace std; // global variable declaration int g = 20; int main () { // Local variable declaration int g = 10; cout << g; return 0; }

When the above code is compiled and executed, it produces the following results:

10

Initializing local variables and global variables

When a local variable is defined, the system does not initialize it; you must initialize it yourself. When a global variable is defined, the system automatically initializes it to the following values:

Data typesInitialize default values
int 0
char '\0'
float 0
double 0
pointer NULL

Correctly initializing variables is a good programming practice; otherwise, the program may produce unexpected results in some cases.

Block scope refers to variables declared inside a code block:

Example

#include <iostream>

int main() {
    int a = 10;
    {
        int a = 20;  // block scope variable
        std::cout << "Block variable: " << a << std::endl;
    }
    std::cout << "External variable: " << a << std::endl;
    return 0;
}

In the above example, a variable named a is declared in the inner code block, which has the same name as the variable a in the outer scope. The variable a in the inner scope will override the variable a in the outer scope. When accessing a in the inner scope, it outputs 20, while when accessing a in the outer scope, it outputs 10.

When the above code is compiled and executed, it produces the following results:

块变量: 20
外部变量: 10

Class Scope

Class scope refers to variables declared inside a class:

Example

#include <iostream>

class MyClass {
public:
    static int class_var;  // class scope variable
};

int MyClass::class_var = 30;

int main() {
    std::cout << "Class variable: " << MyClass::class_var << std::endl;
    return 0;
}

In the above example, a class-scoped variable named class_var is declared in the MyClass class. You can use the class name and the scope resolution operator::to access this variable. When accessing class_var in the main() function, 30 is output.

类变量: 30

    Variables with the same name can exist in a function body, provided that their scopes are different.

    #include <iostream>
using namespace std;

int main()
{
    int b = 2;
    {
        int b = 1;
        cout << "b = " << b << endl;
    }
    cout << "b = " << b << endl;
}

    The output is:

    b = 1
b = 2

    When variables have the same name, the smaller scope shields the larger scope. Therefore, the first cout above outputs b's value as 1. However, since the variable declared inside the block has a scope limited to the current block, the variable is automatically released after leaving this block, so the second cout outputs b's value as 2.

    Static Variable

    Variables stored in the static data area are initialized when the program first starts running, and this is the only initialization. There are two types of variables stored in the static storage area: global variables and static variables. However, compared with global variables, static can control the visibility scope of a variable. In the final analysis, static is still used for hiding. Although this usage is not common.

    PS: If a static local variable is defined inside a function, its lifetime is the entire source program, but its scope is still the same as an automatic variable; it can only be used within the function that defines it. After exiting the function, although the variable continues to exist, it cannot be used.

    #include <iostream>
using namespace std;

int count = 1; //全局变量

int fun()
{
    static int count = 10; // 在第一次进入这个函数的时候，变量 count 被初始化为 10！并接着自减 1，以后每次进入该函数，count 的值是上一次函数运行之后的值
    return count--;        // 就不会被再次初始化了，仅进行自减 1 的操作；在 static 发明前，要达到同样的功能，则只能使用全局变量
}
 
//int count = 1; //全局变量
 
int main()
{
     cout<<"global  "<<"local staic"<<endl;
     for(; count <= 10; ++count)
        cout<<count<<"        "<<fun()<<endl;
     return 0;
}

    Moreover, it can be seen from this that the scopes of the global variable and the local static variable count are different.

    Differences among C++ global variables, local variables, static global variables, and static local variables

    C++ variables have different scopes depending on their position of definition and lifetime. Scopes can be divided into 6 types:Global Scope，Local Scope，Statement Scope，Class Scope，Namespace scope and file scope。

    From the scope perspective:

    Global variables have global scope. A global variable only needs to be defined in one source file and can then act on all source files. Of course, other source files that do not contain the definition of this global variable need to declare this global variable again with the extern keyword.

    Static local variables have local scope. They are initialized only once, and they exist from the first initialization until the end of program execution. The difference between them and global variables is that global variables are visible to all functions, while static local variables are always visible only to the function body that defines them.

    Local variables also have local scope. They are automatic objects (auto). They do not exist throughout program execution, but only during function execution. When a function call ends, the variable is destroyed and the memory it occupies is reclaimed.

    Static global variables also have global scope. The difference from global variables is that if the program contains multiple files, it acts within the file where it is defined and cannot act on other files. That is, variables modified by the static keyword have file scope. Thus, even if two different source files both define static global variables with the same name, they are different variables.

    From the perspective of memory space allocation:

    Global variables, static local variables, and static global variables are allocated space in the static storage area, while local variables are allocated space on the stack.

    Global variables themselves are static storage; static global variables are of course also static storage. There is no difference in storage mode between the two. The difference is that non-static global variables have a scope of the entire source program. When a source program consists of multiple source files, non-static global variables are valid in every source file. Static global variables, however, limit their scope, that is, they are only valid within the source file that defines them and cannot be used in other source files of the same source program. Because the scope of a static global variable is limited to one source file and can only be shared by functions within that source file, it can avoid causing errors in other source files.

    • 1) Static variables are placed in the program's static data storage area (data segment) (globally visible), so that the original assigned value can be maintained at the next call. This is the difference between them and stack variables and heap variables.
    • 2) The variable uses static to tell the compiler that it is only visible within the scope of the variable. This is the difference between it and global variables.

    From the above analysis, it can be seen that changing a local variable into a static variable changes its storage mode, i.e., changes its lifetime. Changing a global variable into a static variable changes its scope and limits its range of use. Therefore, the static specifier plays different roles in different places. Attention should be paid to this.

    Tips:

    • A. If a global variable is only accessed in a single C file, this variable can be changed to a static global variable to reduce coupling between modules.
    • B. If a global variable is only accessed by a single function, this variable can be changed to a static local variable of that function to reduce coupling between modules.
    • C. When designing and using functions that access dynamic global variables, static global variables, and static local variables, reentrancy issues need to be considered because they are all placed in the static data storage area and are globally visible.
    • D. If we need a reentrant function, we must avoid using static variables in the function (such a function is called a function with "internal memory" functionality).
    • E. Cases where static variables must be used in a function: for example, when the return type of a function is a pointer type, the address of a static local variable must be used as the return value. If it is an auto type, a wrong pointer is returned.

    -----------------------------------------------------------------------------------------------------------

    static global variables: changes the scope, does not change the storage location

    static local variables: changes the storage location, does not change the scope

    Static Functions: Adding the static keyword before the return type of a function defines the function as a static function. A static function is different from an ordinary function in that it is only visible in the file where it is declared and cannot be used by other files.

    If a function defined in one source file can only be called by functions in this file, and cannot be called by functions in other files of the same program, this kind of function is also called an internal function. To define an internal function, simply add a "static" keyword before the function type.

    The difference between the character '0', '\0', and the integer 0

    A character variable is used to store a single character. In C language, it is represented by char, where each character variable occupies 1 byte (8 binary bits).

    An integer int occupies four bytes (32 binary bits) in memory.

    Character '0':char c = '0';Its ASCII code is actually 48; in memory it is stored as: 00110000.

    Character '\0': ASCII code is 0, indicating the end of a string. This is an escape character (treated as a whole character). Since storing a character in memory still stores the character encoding of the corresponding character set, its representation in memory is 00000000.

    Integer 0:In memory it is represented as 00000000 00000000 00000000 00000000. Although they are all 0, its storage length is different from the character '\0' above.
