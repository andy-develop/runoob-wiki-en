C++ 从函数返回数组

C++ 数组

C++ does not allow returning a complete array as a function argument. However, you can return a pointer to an array by specifying the array name without an index.

If you want to return a one-dimensional array from a function, you must declare a function that returns a pointer, as follows:

int * myFunction() { //. . . }

如下实例：

实例

int* myFunction()
{
   int myArray[3] = {1, 2, 3};
   return myArray;
}

注意：You cannot simply return a pointer to a local array, because when the function ends, the local array will be destroyed, and the pointer to it will become invalid.

C++ does not support returning the address of a local variable outside the function, unless the local variable is defined asstatic变量。

To avoid the above situation, you can use a static array or a dynamically allocated array.

Using a static array requires creating a static array inside the function and returning its address, for example:

int* myFunction()
{
   static int myArray[3] = {1, 2, 3};
   return myArray;
}

实例

Using a dynamically allocated array requires using the new operator inside the function to allocate an array, and using the delete operator to release the array when the function ends, for example:

实例

int* myFunction()
{
   int* myArray = new int[3];
   myArray[0] = 1;
   myArray[1] = 2;
   myArray[2] = 3;
   return myArray;
}

int main()
{
   int* result = myFunction();
   // 使用 result
   delete[] result;
   return 0;
}

The following is a simple application example that demonstrates how to return an array from a function:

实例

#include <iostream>
using namespace std;

int* createArray(int size) {
    int* arr = new int[size];
    for (int i = 0; i < size; i++) {
        arr[i] = i + 1;
    }
    return arr;
}

int main() {
    int* myArray = createArray(5);
    for (int i = 0; i < 5; i++) {
        cout << myArray[i] << " ";
    }
    cout << endl;
    delete[] myArray; // 释放内存
    return 0;
}

In the above example, we declared a function named createArray, which accepts an integer parameter size and returns an integer array filled with integers. We used the new operator to dynamically allocate an array on the heap and filled the array inside the function. Finally, the function returned a pointer to the array.

In the main function, we called the createArray function and stored the returned array pointer in myArray. Then we iterated over the array and printed the value of each element. Finally, we used the delete[] operator to release the memory occupied by myArray to avoid memory leakage.

When the above code is compiled and executed, it produces the following results:

1 2 3 4 5

注意：When using a dynamically allocated array, the code that calls the function is responsible for releasing the returned array. This is because the array allocated inside the function is not automatically released when the function ends.

    In C++, a function cannot directly return an array, but an array is actually a pointer, so you can have the function return a pointer to achieve this:

     #include <iostream>
 
 using namespace std;
 
 void MultMatrix(float M[4], float A[4], float B[4])
 {
     M[0] = A[0]*B[0] + A[1]*B[2];
     M[1] = A[0]*B[1] + A[1]*B[3];
     M[2] = A[2]*B[0] + A[3]*B[2];
     M[3] = A[2]*B[1] + A[3]*B[3];
 
     cout << M[0] << " " << M[1] << endl;
     cout << M[2] << " " << M[3] << endl;
 }
 
 int main()
 {
     float A[4] = { 1.75, 0.66, 0, 1.75 };
     float B[4] = {1, 1, 0, 0};
 
     float *M = new float[4];
     MultMatrix(M, A, B);
 
     cout << M[0] << " " << M[1] << endl;
     cout << M[2] << " " << M[3] << endl;
     delete[] M;
 
     return 0;
 }

    srand seeds with a time point as the parameter. When few random numbers are executed, the time does not change, and the generated random numbers are the same. In the example below, with many inputs, the first dozens of random numbers are all the same. When the time increases by one unit, the generated random numbers become different and will increment. Therefore, the srand function should be placed outside the rand loop to avoid the same random numbers being generated in each loop.

    # include<stdlib.h>
# include<iostream>
# include<time.h>
int main(){
//    srand((unsigned)time(NULL));    
for (int i = 0; i < 100000; ++i) {
       srand((unsigned)time(NULL));       
       int a=rand();       
       std::cout<<a<<std::endl;   
   }
}

    By using pointers, there is no need to declare static variables or a fixed array size to return an array.

    #include <iostream>
using namespace std;
 
int * addn(int a[], int b[], int size)   // 声明一个返回指针的函数
{
  int *s;                                //指针变量s    （相比以上，不需要static）
  s = new int[size];                     //new 动态内存分配 数组，长度为size（相比以上，不需要确定数组长度）
  for (int i = 0; i < size; i++)         
  {
    s[i] = a[i] + b[i];
    cout << s[i] << endl;
  }
return s;                               //返回数组首个地址
delete s;                               //释放动态分配的内存空间
}

int main()
{
  int a[3] = {1,2,3};
  int b[3] = {1,2,3};
  int * p ;                             //一个指向整数的指针
  p = addn(a,b,3);                      //返回数组赋值
  cout << p;                            //输出指针地址（数组首个地址）
}
