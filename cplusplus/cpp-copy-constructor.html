C++ 拷贝构造函数

C++ 类 & 对象

拷贝构造函数It is a special constructor that, when creating an object, uses a previously created object of the same class to initialize the newly created object. The copy constructor is usually used for:

  • By using another object of the same type to initialize the newly created object.

  • Copy the object and pass it as a parameter to the function.

  • Copy the object and return the object from the function.

If a copy constructor is not defined in the class, the compiler will define one itself. If the class has pointer variables and dynamic memory allocation, then it must have a copy constructor. The most common form of the copy constructor is as follows:

classname (const classname &obj) { // 构造函数的主体 }

在这里，objIt is an object reference, and this object is used to initialize another object.

实例

#include <iostream> using namespace std; class Line { public: int getLength( void ); Line( int len ); // 简单的构造函数 Line( const Line &obj); // 拷贝构造函数 ~Line(); // 析构函数 private: int *ptr; }; // 成员函数定义，包括构造函数 Line::Line(int len) { cout << "调用构造函数" << endl; // 为指针分配内存 ptr = new int; *ptr = len; } Line::Line(const Line &obj) { cout << "调用拷贝构造函数并为指针 ptr 分配内存" << endl; ptr = new int; *ptr = *obj.ptr; // 拷贝值 } Line::~Line(void) { cout << "释放内存" << endl; delete ptr; } int Line::getLength( void ) { return *ptr; } void display(Line obj) { cout << "line 大小 :" << obj.getLength() <<endl; } // 程序的主函数 int main( ) { Line line(10); display(line); return 0; }

    When the copy constructor is called.

    In C++, the following three kinds of objects need to call the copy constructor!

    1. The object is passed into a function parameter by value.

    class CExample 
{
private:
 int a;

public:
 //构造函数
 CExample(int b)
 { 
  a = b;
  cout<<"creat: "<<a<<endl;
 }

 //拷贝构造
 CExample(const CExample& C)
 {
  a = C.a;
  cout<<"copy"<<endl;
 }
 
 //析构函数
 ~CExample()
 {
  cout<< "delete: "<<a<<endl;
 }

     void Show ()
 {
         cout<<a<<endl;
     }
};

//全局函数，传入的是对象
void g_Fun(CExample C)
{
 cout<<"test"<<endl;
}

int main()
{
 CExample test(1);
 //传入对象
 g_Fun(test);

 return 0;
}

    When calling g_Fun(), the following important steps occur:

    • (1). When the test object is passed into the formal parameter, a temporary variable is first created; let's call it C.
    • (2). Then the copy constructor is called to give the value of test to C. These two steps together are somewhat like: CExample C(test);
    • (3). After g_Fun() has finished executing, the C object is destructed.

    Copy constructor

    几个原则：

    C++ primer p406: The copy constructor is a special constructor with a single formal parameter, which (usually modified by const) is a reference to the class type. When a new object is defined and initialized with an object of the same type, the copy constructor is explicitly used. When an object of this type is passed to a function or returned from a function, the copy constructor is implicitly called.

    C++ supports two forms of initialization:

    拷贝初始化int a = 5;and direct initializationint a(5);For other types there is no difference. For class types, direct initialization directly calls the constructor matching the arguments; copy initialization always calls the copy constructor. That is to say:

    A x(2);　　//直接初始化，调用构造函数
A y = x;　　//拷贝初始化，调用拷贝构造函数

    Cases where the copy constructor must be defined:

    For classes that contain only class-type members or built-in type members (but not pointer types), copying can be done without explicitly defining a copy constructor; some classes have a data member that is a pointer, or have members that represent other resources allocated in the constructor; in both cases, a copy constructor must be defined.

    In what cases is the copy constructor used?

    When an object of a class needs to be copied, the copy constructor will be called. The copy constructor is called in the following situations:

    • (1) An object is passed into a function body by value.
    • (2) An object is returned from a function by value.
    • (3) An object needs to be initialized by another object.

    As for why, when a class member contains a pointer-type member and memory needs to be allocated for it, there must be a custom-defined copy constructor?

    The default copy constructor can only perform a shallow copy, that is, it directly copies the data member values of the original object to the corresponding data members of the new object one by one, without allocating additional memory resources for the new object.

    In this way, if the object's data member is a pointer, the two pointer objects actually point to the same block of memory space.

    In some cases, shallow copy can bring hidden dangers in terms of data security.

    When the data members of a class include pointer types, we must define a specific copy constructor. This copy constructor can not only copy the data members between the original object and the new object, but also allocate separate memory resources for the new object. This is the deep copy constructor.

    How to prevent default copying from occurring.

    Declare a private copy constructor. In this way, because the copy constructor is private, if the user tries to pass or return an object of this class by value, the compiler will report an error, thus avoiding passing or returning objects by value.

    总结：

    When an assignment with an equal sign occurs for a class, the copy function is called. If an explicit copy constructor is not defined, the system will call the default copy function—that is, a shallow copy—which can perform member-by-member copying. When there are no pointers among the data members, shallow copy is feasible. However, when there are pointers among the data members, if a simple shallow copy is used, the two pointers in the two objects will point to the same address. When the objects are about to be destroyed, the destructor will be called twice, resulting in a dangling pointer. Therefore, in this case, a deep copy must be used.

    The difference between deep copy and shallow copy is that deep copy will additionally allocate space in heap memory to store data, thus solving the problem of dangling pointers. In short, when there are pointers among the data members, deep copy must be used.

    #include <iostream>
using namespace std;
 
class Line
{
   public:
      int getLength( void );
      Line( int len, string name); // 简单的构造函数
      Line( const Line &obj);      // 拷贝构造函数
      ~Line();                     // 析构函数
      string name;
   private:
      int *ptr;
};
 
// 成员函数定义，包括构造函数
Line::Line(int len, string n)
{
    // 为指针分配内存
    ptr = new int;
    *ptr = len;
    name = n;
    cout << "调用构造函数 " << name << endl;
}
 
Line::Line(const Line &obj)
{
    cout << "调用拷贝构造函数 " << obj.name << endl;
    ptr = new int;
    *ptr = *obj.ptr; // 拷贝值
    name = "~" + obj.name;
}
 
Line::~Line(void)
{
    cout << "释放内存 " << name << endl;
    delete ptr;
}
int Line::getLength( void )
{
    return *ptr;
}
 
void display(Line obj)
{
   cout << "line 大小 : " << obj.getLength() <<endl;
}
 
Line newline(double len)
{
    Line temp_line(len, "temp_line");
    return temp_line;
}
// 程序的主函数
int main( )
{
   Line line1(10, "direct_line1");   // 直接初始化，调用构造函数
   cout << endl;
   Line line2 = line1;  // 拷贝初始化，调用拷贝构造函数
   line2.name = "copy_line2";
   cout << endl;
   display(line1);      // 一个对象以值传递的方式传入函数体
   cout << endl;
   line1 = newline(8);  // 一个对象以值传递的方式从函数返回
   cout << line1.name << endl;
   line1.name = "modified_line1";
   cout << endl;
   display(line2);
   cout << endl;
   return 0;
}
