C++ 修饰符类型

C++ allows inchar、int 和 doublePlace modifiers before the data type.

Modifiers are keywords used to change the behavior of variable types, better meeting the needs of various situations.

The data type modifiers are listed below:

  • signed: Indicates that the variable can store negative numbers. For integer variables, signed can be omitted because integer variables are signed by default.

  • unsigned: Indicates that the variable cannot store negative numbers. For integer variables, unsigned can double the range of the variable.

  • short: Indicates that the variable has a smaller range than int. short int can be abbreviated as short.

  • long: Indicates that the variable has a larger range than int. long int can be abbreviated as long.

  • long long: Indicates that the variable has a larger range than long. A data type modifier added in C++11.

  • float: Represents a single-precision floating-point number.

  • double: Represents a double-precision floating-point number.

  • bool: Represents the boolean type, which has only two values: true and false.

  • char: Indicates a character type.

  • wchar_t: Represents the wide character type, which can store Unicode characters.

修饰符signed、unsigned、long 和 shortCan be applied to integer types,signed 和 unsignedCan be applied to character types,longCan be applied to double-precision types.

These modifiers can also be used in combination. Modifierssigned 和 unsigned也可以作为long 或 shortThe prefix of the modifier. For example:unsigned long int。

C++ allows the use of shorthand notation to declare无符号短整数或无符号长整数. You can omit int and just write the wordunsigned、short 或 long，intis implied. For example, the following two statements both declare unsigned integer variables.

signed int num1 = -10; // 定义有符号整型变量 num1，初始值为 -10
unsigned int num2 = 20; // 定义无符号整型变量 num2，初始值为 20

short int num1 = 10; // 定义短整型变量 num1，初始值为 10
long int num2 = 100000; // 定义长整型变量 num2，初始值为 100000

long long int num1 = 10000000000; // 定义长长整型变量 num1，初始值为 10000000000

float num1 = 3.14f; // 定义单精度浮点数变量 num1，初始值为 3.14
double num2 = 2.71828; // 定义双精度浮点数变量 num2，初始值为 2.71828

bool flag = true; // 定义布尔类型变量 flag，初始值为 true

char ch1 = 'a'; // 定义字符类型变量 ch1，初始值为 'a'
wchar_t ch2 = L'你'; // 定义宽字符类型变量 ch2，初始值为 '你'

To understand the difference between signed integer and unsigned integer modifiers as interpreted by C++, let's run the following short program:

实例

#include <iostream> using namespace std; /** 这个程序演示了有符号整数和无符号整数之间的差别*/ int main() { short int i; // 有符号短整数 short unsigned int j; // 无符号短整数 j = 50000; i = j; cout << i << " " << j; return 0; }

When the above program runs, it will output the following results:

-15536 50000

In the above results, the bit pattern of the unsigned short integer 50,000 is interpreted as the signed short integer -15,536.

Type qualifiers in C++

Type qualifiers provide additional information about variables; they are keywords used to change the default behavior of variables or functions when defining them.

限定符含义
constconstDefines a constant, indicating that the value of the variable cannot be modified.
volatile修饰符volatileTells that the value of the variable may be changed by factors outside the program, such as hardware or other threads.
restrict由 restrictA pointer so modified is the only way to access the object it points to. Only C99 added the new type qualifier restrict.
mutable mutable is used to modify member variables of a class. Member variables modified by mutable can be modified even if the object they belong to is const.
static Used to define static variables, indicating that the scope of the variable is limited to the current file or the current function and cannot be accessed by other files or functions.
register Used to define register variables, indicating that the variable is frequently used and can be stored in CPU registers to improve the running efficiency of the program.

Marked as deprecated in C++11, officially removed in C++17.

const 实例

const int NUM = 10; // 定义常量 NUM，其值不可修改
const int* ptr = &NUM; // 定义指向常量的指针，指针所指的值不可修改
int const* ptr2 = &NUM; // 和上面一行等价

volatile 实例

volatile int num = 20; // 定义变量 num，其值可能会在未知的时间被改变

mutable 实例

class Example {
public:
    int get_value() const {
        return value_; // const 关键字表示该成员函数不会修改对象中的数据成员
    }
    void set_value(int value) const {
        value_ = value; // mutable 关键字允许在 const 成员函数中修改成员变量
    }
private:
    mutable int value_;
};

static 实例

void example_function() {
    static int count = 0; // static 关键字使变量 count 存储在程序生命周期内都存在
    count++;
}

register 实例

void example_function(register int num) {
    // register 关键字建议编译器将变量 num 存储在寄存器中
    // 以提高程序执行速度
    // 但是实际上是否会存储在寄存器中由编译器决定
}

C++11 后 register 的变化：

  • Marked as deprecated in C++11.
  • Officially removed in C++17
  • Reserved as a keyword (possibly for compatibility or future use)

    C++ provides the keyword explicit, which can prevent implicit conversions that should not be allowed through converting constructors. Constructors declared explicit cannot be used in implicit conversions.

    In C++, a constructor with one parameter (or a multi-parameter constructor where all parameters except the first have default values) plays two roles. 1. It is a constructor; 2. It is a default and implicit type conversion operator.

    So, sometimes when we write code such as AAA = XXX, and the type of XXX happens to be the parameter type of AAA's single-parameter constructor, the compiler automatically calls this constructor to create an AAA object.

    This may seem cool and convenient. But in some cases (see the authoritative example below), it goes against our (the programmer's) original intention. At this point, you need to add the explicit modifier before this constructor, specifying that this constructor can only be called/used explicitly and cannot be implicitly used as a type conversion operator.

    The role of the explicit constructor

    解析：

    The explicit constructor is used to prevent implicit conversions. Look at the following code:

    class Test1
{
public:
    Test1(int n)
    {
        num=n;
    }//普通构造函数
private:
    int num;
};
class Test2
{
public:
    explicit Test2(int n)
    {
        num=n;
    }//explicit(显式)构造函数
private:
    int num;
};
int main()
{
    Test1 t1=12;//隐式调用其构造函数,成功
    Test2 t2=12;//编译错误,不能隐式调用其构造函数
    Test2 t2(12);//显式调用成功
    return 0;
}

    Test1's constructor takes an int parameter. Line 23 of the code will implicitly convert to calling this constructor of Test1. However, Test2's constructor is declared explicit, which means this constructor cannot be called through implicit conversion; therefore, line 24 of the code will cause a compilation error.

    Ordinary constructors can be called implicitly. However, explicit constructors can only be called explicitly.

    volatile is often used for multi-threading modification, for example:

    volatile boolean isNext = false;

Thread A（） {
    // 第一个工作
    // isNext = true;
}

Thread B （）{
    if (isNext) {
        // 第二个工作
    }
}

    Here volatile is used to mark isNext, to ensure that thread B re-reads the value of isNext from memory every time, and the second job must be performed after the first job.

    But note that ordering cannot be guaranteed here, because the compiler may reorder the two statements during compilation. Therefore, doing the first job and assigning to isNext may not execute in the order of your code.

    In the case of a 16-bit integer (short integer), decimal50000就是二进制11000011 01010000But in the signed case, the leftmost binary1, represents that the entire number is negative, but the computer represents numbers in two's complement form. To obtain the original number, first take the entire binary number- 11100001101010000 - 1 = ‭1100001101001111‬Then, take the one's complement of the answer.not ‭1100001101001111‬ = ‭0011110010110000Then convert the final answer to decimal, which is15536So, the initial binary number11000011 01010000in the signed case, it represents-15536。
