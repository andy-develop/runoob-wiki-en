C++ 循环

Sometimes, it may be necessary to execute the same block of code multiple times. In general, statements are executed sequentially: the first statement in a function executes first, then the second, and so on.

Programming languages provide various control structures that allow more complex execution paths.

Loop statements allow us to execute a statement or a group of statements multiple times. The following is the general form of a loop statement in most programming languages:

循环类型

The C++ programming language provides the following types of loops. Click the links to view details of each type.

循环类型描述
while 循环Repeats a statement or group of statements while a given condition is true. It tests the condition before executing the loop body.
for 循环Executes a sequence of statements multiple times, and simplifies the code that manages the loop variable.
do...while 循环Similar to a while statement, except that it tests the condition at the end of the loop body.
嵌套循环You can use one or more loops inside a while, for, or do..while loop.

Loop control statements

Loop control statements change the normal sequence of execution. When execution leaves a scope, all automatic objects created in that scope are destroyed.

C++ provides the following control statements. Click the links to view details of each statement.

控制语句描述
break 语句终止loop 或 switchThe statement causes program flow to continue with the next statement immediately following the loop or switch.
continue 语句Causes the loop to skip the remainder of its body and immediately retest its condition.
goto 语句Transfers control to a labeled statement. However, the use of the goto statement is not recommended in programs.

无限循环

If the condition is never false, the loop becomes an infinite loop.forA loop can be used to implement an infinite loop in the traditional sense. Since none of the three expressions that make up the loop is required, you can leave certain condition expressions blank to form an infinite loop.

实例

#include <iostream> using namespace std; int main () { for( ; ; ) { printf("This loop will run forever.\n"); } return 0; }

When the condition expression is absent, it is assumed to be true. You may also set an initial value and an increment expression, but in general, C++ programmers prefer to use the for(;;) construct to represent an infinite loop.

注意：You can terminate an infinite loop by pressing Ctrl + C.

    The following example uses nested for loops to output a diamond shape:

    #include <iostream>
#include <math.h>
#include <vector>
#include <algorithm>
using namespace std;

int main()
{
    //外层循环控制行、换行
    //内层循环控制列、列的图形
    //中分的三角菱形
    //定义半菱形高度，即定义了菱形的大小
    int n ;
    cout<<"请输入半菱形高度"<<endl;
    cin >> n; 
    //上半部分居中正三角n行
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < n - i -1; j++)
        {
            cout<<" ";
        }
        for (int j = 0; j <= 2 * i; j++)
        {
            //每行第一个和最后一个外打印星号，其余打印空格，做成空心效果，下半部分相同
            if (j == 0 or j == 2 * i)
                cout<<"*";
            else
                cout<<" ";
        }
        cout<<endl;
    }

    //下半部分居中倒三角n-1行
    for (int i = 0; i < n - 1; i++)
    {
        for (int j = 0; j <= i; j++)
        {
            cout<<" ";
        }
        for (int j = 0; j <= 2 * ( n - i - 2 ); j++)
        {
            if (j == 0 or j == 2 * ( n - i - 2 ))
                cout<<"*";
            else
                cout<<" ";
        }
        cout<<endl;
    }
    return 0;
}

    The above method for outputting a diamond is too troublesome; please just use this directly:

    #include <iostream>
#include <math.h>
using namespace std;
int main() {
    cout << "请输入半菱形高度n" << endl;
    int n = 0;
    cin >> n;
    for (int i = 0; i < 2 * n + 1; i++) {
        for (int j = 0; j < 2 * n + 1; j++) {
            if (abs(i - n) + abs(j - n) == n) {
                cout << "*";
            } else {
                cout << " ";
            }
        }
        cout << endl;
    }
}
