C++ STL 教程

The C++ Standard Template Library (STL) is a powerful collection of C++ template classes and functions that provides a series of generic, reusable algorithms and data structures.

STL's design is based on generic programming, which means that templates can be used to write code independent of any specific data type.

STL is divided into multiple components, including Containers, Iterators, Algorithms, Function Objects, and Adapters, etc.

Benefits of using STL:

  • 代码复用: STL provides a large number of generic data structures and algorithms, reducing the work of writing repetitive code.
  • 性能优化: The algorithms and data structures in STL are optimized to provide the best performance.
  • 泛型编程: Using templates, STL supports generic programming, allowing algorithms and data structures to apply to any data type.
  • 易于维护: STL's design makes code more modular and easier to read and maintain.

The core of the C++ Standard Template Library includes the following important components:

组件 描述
容器（Containers）

Containers are one of the most basic components in STL. They provide various data structures, including vector, list, queue, stack, set, map, and so on. These containers have different characteristics and uses, so you can choose the appropriate container based on actual needs.
算法（Algorithms） STL provides a large number of algorithms for performing various operations on elements in containers, including sorting, searching, copying, moving, transforming, etc. When using these algorithms, there is no need to care about the specific type of container; you only need to specify the range to be operated on.
Iterators Iterators are used to traverse the elements in containers, allowing elements to be accessed in a unified way without worrying about the internal implementation details of the container. STL provides many types of iterators, including random access iterators, bidirectional iterators, forward iterators, and input/output iterators, among others.
函数对象（Function Objects） Function objects are objects that can be called like functions and can be used for various operations in algorithms. STL provides a variety of function objects, including unary function objects, binary function objects, predicates, and more, to meet different needs.
Adapters Adapters are used to adapt one container or iterator into another container or iterator to meet specific requirements. STL provides a variety of adapters, including stack adapter, queue adapter, and priority queue adapter, among others.

These components all come with a rich set of predefined functions, helping us handle complex tasks in a simple way.

容器

Containers are sequences used to store data, and they provide different storage methods and access modes.

Containers in STL can be divided into three categories:

1. Sequence containers: store sequences of elements and allow bidirectional traversal.

  • std::vector: dynamic array, supports fast random access.
  • std::deque: double-ended queue, supports fast insertion and deletion.
  • std::list: linked list, supports fast insertion and deletion, but does not support random access.

2. Associative containers: store key-value pairs. Each element has a key and a value, and elements are organized by keys.

  • std::set: set, duplicate elements are not allowed.
  • std::multiset: multiset, allows multiple elements to have the same key.
  • std::map: map, each key maps to a value.
  • std::multimap: multimap, stores key-value pairs (pair), where keys are not unique and values can be repeated, allowing one key to map to multiple values.

3. Unordered containers (introduced in C++11): hash tables, support fast lookup, insertion, and deletion.

  • std::unordered_set：无序集合。
  • std::unordered_multiset：无序多重集合。
  • std::unordered_map：无序映射。
  • std::unordered_multimap：无序多重映射。

The following program demonstrates the vector container (a C++ standard template), which is very similar to an array. The only difference is that when the vector needs to expand its size, it automatically handles its own storage requirements:

实例

#include <iostream> #include <vector> using namespace std; int main() { // 创建一个向量存储 int vector<int> vec; int i; // 显示 vec 的原始大小 cout << "vector size = " << vec.size() << endl; // 推入 5 个值到向量中 for(i = 0; i < 5; i++){ vec.push_back(i); } // 显示 vec 扩展后的大小 cout << "extended vector size = " << vec.size() << endl; // 访问向量中的 5 个值 for(i = 0; i < 5; i++){ cout << "value of vec [" << i << "] = " << vec[i] << endl; } // 使用迭代器 iterator 访问值 vector<int>::iterator v = vec.begin(); while( v != vec.end()) { cout << "value of v = " << *v << endl; v++; } return 0; }

When the above code is compiled and executed, it produces the following results:

vector size = 0
extended vector size = 5
value of vec [0] = 0
value of vec [1] = 1
value of vec [2] = 2
value of vec [3] = 3
value of vec [4] = 4
value of v = 0
value of v = 1
value of v = 2
value of v = 3
value of v = 4

Regarding the various functions used in the above example, there are a few points to note:

  • The push_back( ) member function inserts a value at the end of the vector, expanding the vector's size if necessary.
  • The size( ) function displays the size of the vector.
  • The begin( ) function returns an iterator pointing to the beginning of the vector.
  • The end( ) function returns an iterator pointing to the end of the vector.

STL is an indispensable part of C++ programming. It greatly expands the functionality of C++, allowing programmers to write more efficient and more readable code.

Mastering the use of STL is very important for any C++ programmer.

    C++ STL 之 vector 的 capacity 和 size 属性区别

    sizeis the actual size occupied by the current vector container, that is, how many elements the container currently holds.

    capacityis the maximum number of elements allowed before a realloc occurs, that is, the pre-allocated memory space.

    Of course, these two properties correspond to two methods respectively:resize() 和 reserve()。

    使用resize()The memory space of the objects inside the container actually exists.

    使用reserve()It only modifies the value of capacity; the objects inside the container do not have real memory space (the space is "wild").

    Be sure to use at this point[]Using the operator to access objects in the container may likely cause array out-of-bounds problems.

    The following examples are used for illustration:

    #include <iostream>
#include <vector>

using std::vector;
int main(void)
{
    vector<int> v;
    std::cout<<"v.size() == " << v.size() << " v.capacity() = " << v.capacity() << std::endl;
    v.reserve(10);
    std::cout<<"v.size() == " << v.size() << " v.capacity() = " << v.capacity() << std::endl;
    v.resize(10);
    v.push_back(0);
    std::cout<<"v.size() == " << v.size() << " v.capacity() = " << v.capacity() << std::endl;

    return 0;
}

    The running result is: (win 10 + VS2010)

    注：对于reserve(10)Then use it directly afterward[]Accessing out of bounds causes an error (the memory is wild). You can add a line of code to try it; I didn't include it here.

    这里直接用[]For access, vector degenerates into an array and does not perform out-of-bounds checks. In this case, it is recommended to use at(), which performs out-of-bounds checking first.

    相关引申：

    Regarding the capacity property, other containers in STL, such as list, map, set, and deque, do not have the similar realloc() call situation because their memory is distributed in a scattered way. Therefore, we can consider that the capacity property is meaningless for these containers, so these containers do not have this property by design.

    In STL, the only containers that have the capacity property are vector and string.

    vector is actually a dynamic array. It does not have a fixed size; its size is dynamically allocated. If you are unsure about the size or want to save memory, vector is a good choice.

    #include <iostream>
#include <vector>  // 使用vector的头文件
using namespace std;

int main() {
    vector<int> v;  // 定义一个整型动态数组v

    v.push_back(1);  // 存入1
    v.push_back(2);  // 存入2
    v.push_back(5);  // 存入5

    cout << "size: " << v.size() << endl;

    // 使用auto和迭代器遍历vector
    for (auto i = v.begin(); i != v.end(); ++i) {
        cout << *i << " ";
    }

    return 0;
}
