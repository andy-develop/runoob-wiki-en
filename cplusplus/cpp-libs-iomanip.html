C++ Standard Library <iomanip>

<iomanip>It is a header file in the C++ standard library that provides formatted operations for input/output streams.

iomanipThe functions in the library allow developers to control output formatting, such as setting the number of digits after the decimal point, setting width, alignment, and so on.

iomanipIt is the abbreviation for Input/Output Manipulators, which provides a set of operators for controlling the formatting of input/output streams in the C++ standard library, applicable to the following scenarios:

  • Handling of floating-point formats in scientific computing;
  • Data alignment and beautification;
  • Display numeric values in a specific base or format.

Example

1. Set width

UsagesetwCan set the width of the output. If the number of characters in the output content is less than the set width, the remaining part will be filled with spaces.

Example

#include <iostream>
#include <iomanip>

int main() {
    std::cout << std::setw(10) << "Hello" << std::endl;
    return 0;
}

Output:

Hello

2. Set precision

UsagesetprecisionCan set the number of significant digits for floating-point numbers.

Example

#include <iostream>
#include <iomanip>

int main() {
    double pi = 3.141592653589793;
    std::cout << "Default: " << pi << "\n";
    std::cout << "Set precision (3): " << std::setprecision(3) << pi << "\n";
    std::cout << "Set precision (7): " << std::setprecision(7) << pi << "\n";
    return 0;
}

Output:

Default: 3.14159
Set precision (3): 3.14
Set precision (7): 3.141593

3. Fixed-point and scientific notation

fixedandscientificCan control the output format of floating-point numbers.

Example

#include <iostream>
#include <iomanip>

int main() {
    double num = 123456789.0;
    std::cout << "Fixed: " << std::fixed << num << std::endl;
    std::cout << "Scientific: " << std::scientific << num << std::endl;
    return 0;
}

Output:

Fixed: 123456789.000000
Scientific: 1.23456789e+08

4. Setting the fill character

UsagesetfillCan set the fill character, usually withsetwUsed together.

Example

#include <iostream>
#include <iomanip>

int main() {
    std::cout << std::setfill('*') << std::setw(10) << "World" << std::endl;
    return 0;
}

Output:

*****World

5. Setting and resetting format flags

setiosflagsandresetiosflagsCan set or reset the stream's format flags.

Example

#include <iostream>
#include <iomanip>

int main() {
    std::cout << std::setiosflags(std::ios::uppercase) << std::hex << 255 << std::endl;
    std::cout << std::resetiosflags(std::ios::uppercase) << std::hex << 255 << std::endl;
    return 0;
}

Output:

FF
