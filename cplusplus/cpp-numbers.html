C++ 数字

Usually, when we need to use numbers, we use primitive data types such as int, short, long, float, and double, etc. We have already discussed the possible values and ranges of these data types for numbers in the C++ Data Types chapter.

C++ Defining Numbers

We have already defined numbers in various examples in previous chapters. Below is a comprehensive example of defining various types of numbers in C++:

实例

#include <iostream> using namespace std; int main () { // 数字定义 short s; int i; long l; float f; double d; // 数字赋值 s = 10; i = 1000; l = 1000000; f = 230.47; d = 30949.374; // 数字输出 cout << "short s :" << s << endl; cout << "int i :" << i << endl; cout << "long l :" << l << endl; cout << "float f :" << f << endl; cout << "double d :" << d << endl; return 0; }

When the above code is compiled and executed, it produces the following results:

short  s :10
int    i :1000
long   l :1000000
float  f :230.47
double d :30949.4

C++ Math Operations

In C++, in addition to creating various functions, it also includes various useful functions for you to use. These functions are written in the standard C and C++ libraries, called内置functions. You can reference these functions in your program.

C++ has built-in rich mathematical functions that can operate on various numbers. The following table lists some useful built-in mathematical functions in C++.

To utilize these functions, you need to include the math header file<cmath>。

序号Function & Description

This function returns the cosine of a radian angle (double type).

This function returns the sine of a radian angle (double type).

This function returns the tangent of a radian angle (double type).

This function returns the natural logarithm of the argument.

Assuming the first argument is x and the second argument is y, this function returns x raised to the power of y.

Although earlier versions of C++ did not directly provide these constants, starting from C++20, the standard library introduced several commonly used mathematical constants and provided a more efficient and unified way to access them.

    The srand function is the initialization function of the random number generator.

    原型： void srand(unsigned seed);

    用法：It needs to provide a seed, which corresponds to a random number. If the same seed is used, the subsequent rand() function will produce the same random number. For example:srand(1);Directly use 1 to initialize the seed. However, to prevent random numbers from repeating each time, it is common to use system time to initialize, that is, use the time function to obtain the system time. Its return value is the number of seconds elapsed from 00:00:00 GMT, January 1, 1970 to the present. Then convert the time_t type data to (unsigned) type and pass it to the srand function, i.e.: srand((unsigned) time(&t)); There is also a common usage that does not require defining a time_t variable t, i.e.: srand((unsigned) time(NULL)); directly pass a null pointer, because your program often does not need the t data obtained through the parameter.

    例子：

    #include <stdlib.h>
#include <stdio.h>
#include <time.h> /*用到了time函数，所以要有这个头文件*/
#define MAX 10
 
int main( void)
{
    int number[MAX] = {0};
    int i;
    srand((unsigned) time(NULL)); /*播种子*/
    for(i = 0; i < MAX; i++)
    {
        number[i] = rand() % 100; /*产生100以内的随机整数*/
        printf("%d ", number[i]);
    }
    printf("\n");
    return 0;
}

    srand((int)time(0));//部署随机种子

    };

    window下的RAND_MAX为：0x7fff=2^15-1=32767

    linxu下的RAND_MAX为：2^31-1=2147483647

    Let's just explain under Windows:

    The Rand function returns a (pseudo) random integer in the range from 0 to RAND_MAX (32767).

    It is not recommended to use the "modulo+addition" method to obtain (pseudo) random numbers in a specified interval,

    For example: if you use this method to get a random number within 0-10000, the code would be written as:

    srand( (unsigned)time( NULL ) );
int n = rand()%10000;

    Then the probability of each number between 0-2767 appearing is 4/32676, while the probability of numbers between 2768-9999 appearing is 3/32676, which is different from the former. However, since rand() produces pseudo-random numbers, this doesn't matter, haha.

    建议采用如下方式：

    int u = (double)rand() / (RAND_MAX + 1) * (range_max - range_min)+ range_min

    The following is an example from the VS development documentation:

    // crt_rand.c
// This program seeds the random-number generator
// with the time, then exercises the rand function.
//

#include <stdlib.h>
#include <stdio.h>
#include <time.h>

void SimpleRandDemo( int n )
{
   // Print n random numbers.
   int i;
   for( i = 0; i < n; i++ )
      printf( "  %6d\n", rand() );
}

void RangedRandDemo( int range_min, int range_max, int n )
{
   // Generate random numbers in the half-closed interval
   // [range_min, range_max). In other words,
   // range_min <= random number < range_max
   int i;
   for ( i = 0; i < n; i++ )
   {
      int u = (double)rand() / (RAND_MAX + 1) * (range_max - range_min)
            + range_min;
      printf( "  %6d\n", u);
   }
}

int main( void )
{
   // Seed the random-number generator with the current time so that
   // the numbers will be different every time we run.
   srand( (unsigned)time( NULL ) );

   SimpleRandDemo( 10 );
   printf("\n");
   RangedRandDemo( -100, 100, 10 );
}
