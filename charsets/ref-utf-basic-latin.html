UTF-8 C1 Controls and Latin-1 Supplement

UTF-8 C0 Controls and Basic Latin (Latin alphabet)

Range: Decimal 0-127, Hexadecimal 0020-007F.

The character set is the same as the original ASCII character set.

If you want to display a special character in HTML, you can use the HTML entities in the table below.

If a character has no HTML entity, you can use a decimal or hexadecimal reference.

Examples

<p>My name is Johnny &quot;Bang&quot; Johnson<p>
<p>My name is Johnny &#34;Bang&#34; Johnson<p>

The results are as follows:

My name is Johnny "Bang" Johnson

My name is Johnny "Bang" Johnson

C0 Controls

Control characters were originally designed to control hardware devices such as printers and tape drives.

Control characters (other than horizontal tab, line feed, and carriage return) have no effect in HTML documents.
