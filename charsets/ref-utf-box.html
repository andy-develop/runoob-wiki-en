UTF-8 Box Drawings

Range: Decimal 9472-9599, Hexadecimal 2500-257F.

If you want to display these characters in HTML, you can use the HTML entities in the table below.

If a character does not have an HTML entity, you can use decimal or hexadecimal references.

Example

<p>I will display &#9487;<p>
<p>I will display &#x250F;<p>
