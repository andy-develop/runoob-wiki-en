OpenClaw (Clawdbot) Tutorial

OpenClaw (formerly Clawdbot, transitional name Moltbot) is an open-source personal AI assistant project that suddenly went viral in January 2026, developed by Peter Steinberger (founder of PSPDFKit).

OpenClaw is an agent that can execute tasks. When we give instructions, it not only answers but also proactively operates the system, visits web pages, processes emails, organizes files, sets reminders, and even writes code automatically.

OpenClaw is alocal computing power + large model Agent automationdeveloper productivity tool taken to the extreme.

OpenClaw's goal is to make AI not just give advice, but directly complete full engineering tasks.

Because Anthropic sent a lawyer's letter on January 27 stating that Clawd / Clawdbot was too similar to Claude, the project was urgently renamed to Moltbot (meaning molting lobster, with the mascot being little lobster Molty 🦞) that same day, but the functionality remains exactly the same, and the old command clawdbot is still compatible.

Moltbot is a transitional name thought up by the project team to address infringement risks; OpenClaw is the current final official name.

  • OpenClaw official website:https://openclaw.ai/

  • Chinese documentation:https://docs.openclaw.ai/zh-CN

  • GitHub address:https://github.com/openclaw/openclaw

  • OpenClaw Skills Collection:https://github.com/VoltAgent/awesome-openclaw-skills

Clawbot, Moltbot, and OpenClaw are actually the same open-source project. The name evolution sequence is:

Clawdbot → Moltbot → OpenClaw
Name Timeline Background/Reason Essential Relationship
Clawdbot / Clawbot Late 2025 to early January 2026 Initial project name; inspired byClaude 和 clawthe (lobster claw) meme Original name; the earliest identity on GitHub
Moltbot January 27, 2026 Required to be renamed due to Anthropic trademark concerns Intermediate transitional name; functionality and code identical to Clawdbot
OpenClaw After January 30, 2026 Dropped copyright conflicts, emphasized open-source nature/long-term branding Current official name; also the unified identifier for future documentation, repositories, etc.

Installation Methods

OpenClaw's installation is designed to be extremely user-friendly, allowing even non-developers to get started quickly.

System Requirements (not necessarily Mac mini):

  • Hardware: very low; 2GB RAM is sufficient to run.
  • Environment: Supports Mac, Windows, Linux; requires Node.js (pnpm) or Docker.

1. Recommended installation (one-click script):

Run the following command directly in the terminal.

macOS/Linux systems:

curl -fsSL https://openclaw.ai/install.sh | bash

Windows systems:

#PowerShell
iwr -useb https://openclaw.ai/install.ps1 | iex

#CMD
curl -fsSL https://openclaw.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

This will automatically install Node.js (≥22) and complete basic configuration.

2. Manual installation

You needNode.js ≥22and complete basic configuration:

Using npm:

npm i -g openclaw

# 如果速度慢可以指定国内镜像
npm i -g openclaw --registry=https://registry.npmmirror.com

Or using pnpm:

pnpm add -g openclaw

After installation, initialize and install the background service (launchd / systemd user service):

openclaw onboard

3. Install from source (development mode)

git clone https://github.com/openclaw/openclaw.git
cd openclaw

pnpm install

pnpm ui:build   # 首次运行会自动安装 UI 相关依赖并构建前端界面
pnpm build      # 构建整个项目（包含后端与相关模块）

# 初始化 OpenClaw 并安装为系统后台服务（开机自动运行）
pnpm openclaw onboard --install-daemon

# 开发模式：监听 TypeScript 代码变更并自动重载网关服务
pnpm gateway:watch

We recommend installing using the one-click script.

macOS/Linux systems:

curl -fsSL https://openclaw.ai/install.sh | bash

#PowerShell

It will perform environment detection, install necessary dependencies, and launch the onboarding (setup wizard) process.

To re-enter the setup wizard later, run the following command:

openclaw onboard --install-daemon

Then, it will remind you that this lobster is very powerful, and of course, the risk is also high. We selectyes(no means it won't be installed) and that's it:

Then there will be an option to choose a chat tool. If you don't have overseas ones, you can select the last one:

Other configurations, such as port settingsGateway Port, just use the default 18789. For example, for Skills and package manager, choose npm or others; you can keep pressing Yes all the way.

Uninstall

Use the built-in uninstaller:

openclaw uninstall

Non-interactive (automation / npx):

openclaw uninstall --all --yes --non-interactive
npx -y openclaw uninstall --all --yes --non-interactive

Using Skills

Skills are standalone folders containing a SKILL.md file. If you want to extend new features for the OpenClaw agent, ClawHub is the best choice for finding and installing skills.

ClawHub skill repository address:https://clawhub.ai/

ClawHub China mirror:https://skillhub.tencent.com/

Install ClawHub tool:

# 推荐方式（npx 无需全局安装）
npx clawhub@latest --version

# 或全局安装（方便以后直接用 clawhub 命令）
npm install -g clawhub
# 或者用 pnpm
pnpm add -g clawhub

Log in:

clawhub login

Search skills:

clawhub search "postgres backups"

Download and install new skills:

clawhub install my-skill-pack

Batch update installed skills:

clawhub update --all

Plugin Management

Plugins are lightweight code modules that can extend additional functionality for OpenClaw by adding commands, tools, and Gateway RPC capabilities.

View loaded plugins:

openclaw plugins list

Install official plugins (e.g., voice call plugin):

openclaw plugins install @openclaw/voice-call

Restart the gateway after plugin installation for changes to take effect:

openclaw gateway restart

  • WhatsApp：openclaw channels login(or scan QR)
  • Telegram：openclaw channels add --channel telegram(requires Bot Token)
  • Discord：openclaw channels add --channel discord(requires Bot Token)
  • iMessage: native macOS bridge
  • Slack：openclaw channels add --channel slack(requires Bot Token)

Workspace Structure (Workspace Anatomy)

  • AGENTS.md: instruction description
  • USER.md: preference settings
  • MEMORY.md: long-term memory
  • HEARTBEAT.md: checklist
  • SOUL.md: personality/tone
  • IDENTITY.md: name/topic
  • BOOT.md: startup configuration
  • 根目录：~/.openclaw/workspace

In-Chat Slash Commands

  • /status: Health + Context
  • /context list: Context Contributors
  • /model <m>: Switch Model
  • /compact: Free Window Space
  • /new: New Conversation
  • /stop: Abort Current Run
  • /tts on|off: Switch Voice
  • /think: Toggle Reasoning Mode

Key Path Mapping (Essential Path Map)

  • Main Configuration:~/.openclaw/openclaw.json
  • Default Workspace:~/.openclaw/workspace/
  • Agent State Directory:~/.openclaw/agents/<cid>/
  • OAuth & API Keys:~/.openclaw/agents/<agentId>/agent/auth-profiles.json, if it is in the older version~/.openclaw/credentials/
  • Vector Index Storage:~/.openclaw/memory/<cid>.sqlite
  • Global Shared Skills:~/.openclaw/skills/
  • Gateway File Logs:/tmp/openclaw/*.log

Voice and TTS

  • Paid: OpenAI / ElevenLabs
  • Free: Edge TTS (No API Key Required)
  • Automatic TTS:messages.tts.auto: "always"

Memory and Models

  • Vector Search:memory search "X"

  • Authentication Settings:models auth setup
  • Logs:memory/YYYY-MM-DD.md

Hooks and Skills

Troubleshooting

Why Is It So Popular Recently?

  • It truly achieves "like JARVIS": can read/write files, run terminal commands, operate browsers, send/receive emails, calendar, write code, book flights, clear inbox...
  • Local-first + long-term memory: all conversations share context across platforms, and the USER.md and memory/ directories get smarter with use
  • Supports almost all major models: Claude, Gemini, OpenAI, Ollama local models, Pi, etc.
  • Community skills ecosystem explosion: ClawdHub already has 500+ community skills (Slack, Discord, GitHub, browser control, macOS UI automation...)
  • Installation is as simple as npm install, but the actual capabilities are quite spicy (developer's words)

Its core capabilities include:

  • Break down natural language goals into executable steps
  • Automatically invoke terminal commands
  • Create and modify project files
  • Run code and check results
  • Automatically fix based on error messages

Compared to code completion tools like Claude Code/OpenCode, OpenClaw is closer to an engineering agent with execution permissions.

  • Claude Code and OpenCode excel in code quality and understanding
  • OpenClaw excels in automatically completing the entire engineering process
