Django 安装

Before installing Django, the system needs to have a Python development environment installed.

If you haven't installed Python yet, please go to the Python official website first.https://www.python.org/Download and install the latest version of Python.

Installing Django is also simple, just use the package management tool pip:

pip install Django

After installation is complete, you can verify whether Django was installed successfully by running the following command:

python3 -m django --version

If everything goes smoothly, you will see the installed Django version number, such as:4.2.7。

Recommended development environment:

  • 1、VS Code 开发工具
  • 2、PyCharm 开发工具
  • 3、阿里 Qoder
  • 4、Trae 开发工具

Windows 下安装 Django

Next, let's take a closer look at installing Django on different systems.

If you haven't installed the Python environment yet, you need to download the Python installation package first.

1. Python download address:https://www.python.org/downloads/

2. Django download address:https://www.djangoproject.com/download/

注意：Currently, Django 1.6.x and above versions are fully compatible with Python 3.x.

Python installation (skip if already installed)

To install Python, you just need to download the python-x.x.x.msi file, then keep clicking the "Next" button.

After installation, you need to set the Python environment variable. Right-click Computer -> Properties -> Advanced -> Environment Variables -> modify the system variable path, add the Python installation address. The example in this article uses C:\Python33; you need to install according to your actual situation.

Django 安装

Download the Django compressed package, extract it and place it in the same root directory as the Python installation directory. Enter the Django directory, execute python setup.py install, then the installation begins. Django will be installed to site-packages under Python's Lib.

Then configure environment variables by adding these directories to the system environment variables: C:\Python33\Lib\site-packages\django;C:\Python33\Scripts. After adding them, you can use Django's django-admin.py command to create a new project.

Check whether the installation was successful.

Enter the following command to check:

>>> import django
>>> django.get_version()

If the Django version number is output, the installation is correct.

Linux 上安装 Django

yum installation method

The following installation is performed in a CentOS Linux environment. If your Linux system is Ubuntu, please use the apt-get command.

By default, the Linux environment already supports Python. You can enter the Python command in the terminal to check whether it is installed.

Python 3.7.4 (default, Aug  1 2012, 05:14:39) 
[GCC 4.6.3] on linux2
Type "help", "copyright", "credits" or "license" for more information.
>>>

安装 setuptools

命令：

# Python3 安装
yum install python3-setuptools
# Python2 安装
yum install python2-setuptools

After that, you can use the easy_install command to install Django.

easy_install django

Then we enter the following code in the Python interpreter:

[root@solar django]# python
Python 3.7.4 (default, May 15 2014, 14:49:08)
[GCC 4.8.0] on linux2
Type "help", "copyright", "credits" or "license" for more information.
>>> import django
>>> django.VERSION
(3, 0, 6, 'final', 0)

We can see the Django version number is output, indicating that the installation was successful.

pip command installation method

If you haven't installed the pip tool yet, please refer to:Python pip 安装与使用。

sudo pip3 install Django -i https://pypi.tuna.tsinghua.edu.cn/simple

-i https://pypi.tuna.tsinghua.edu.cn/simpleSpecify the Tsinghua mirror source for faster download speed.

Specify the Django download version (3.0.6 can be changed to the version you want):

sudo pip3 install Django==3.0.6 -i https://pypi.tuna.tsinghua.edu.cn/simple

If pip < 1.4, the installation method is as follows:

pip install https://www.djangoproject.com/download/1.11a1/tarball/

Installing from source

Download the source package:https://www.djangoproject.com/download/

Enter the following command and install:

tar xzvf Django-X.Y.tar.gz    # 解压下载包
cd Django-X.Y                 # 进入 Django 目录
python setup.py install       # 执行安装命令

After a successful installation, Django is located in the site-packages directory under the Python installation directory.

Installation on Mac

下载

从这里Download the latest stable version: DJango-3.x.y.tar.gz, download it from the list on the right side of the page, as shown below:

Remember to use the latest official version. Among themx.y是版本号。进入你下载该文件的文件夹目录，执行如下命令:（Mac下默认是/Users/xxx/Downloads，xxx是你的用户名）

$ tar zxvf Django-3.x.y.tar.gz

You can also download the latest version from Github, address:https://github.com/django/django：

git clone https://github.com/django/django.git

安装

Enter the extracted directory:

cd Django-3.x.y
sudo python setup.py install

After a successful installation, the following information will be output:

……
Processing dependencies for Django==3.x.y
Finished processing dependencies for Django==3.x.y

Then enter our site directory and create a Django project:

$ django-admin.py startproject testdj

启动服务：

cd testdj # 切换到我们创建的项目
$ python manage.py runserver
……
Starting development server at http://127.0.0.1:8000/
Quit the server with CONTROL-C.

The above information indicates that the project has been started, and the access address is http://127.0.0.1:8000/.

    pycharm 安装 Django

    file ---> settings ----> project 解释器 ---> 点击+ ----> 输入Django ---> install(如果选择版本时,选择 CheckBox ,选择指定版本)

    创建项目

    Create a project using the command line

    django-admin startproject 项目名称

    Creating a project with Pycharm

    file ---> new project ---- 选择Django ---> 配置路径和项目名称 ---> 配置环境(默认用系统环境) ----> 点击create(完成创建)

    Project directory overview

    |---mysite # 项目的/目录 
  |---mysite # 项目目录 
      |---__init__.py 
      |---settings.py # 配置文件 
      |---urls.py # 路由系统 ===> url与视图的对应关系 
      |---wsgi.py # runserver命令就使用wsgiref模块做简单的web server 
|---manage.py # 管理文件

    创建应用

    Create an application using command line mode

    Enter in Terminalpython manage.py startapp应用名:

    Creating an application with Pycharm

    注意：Applications created using the command line must be placed insettings.py-->INSTALLED_APPSAdd your application name to register. Applications created with Pycharm do not need this. Understanding the application structure.

    运行项目

    Run the project using the command line:

    python3 manage.py runserver 
manage.py runserver 80      # 指定端口

    注意：You need to execute the command in the same directory as manage.py.

    Pycharm start project

    Click the green triangle button in the upper right corner.

    If you need to change the configuration information, please pull down to select edit configurations to configure.

    After configuring the above information, press Ctrl+shift+F10 directly to run the manage.py file.

    If the following result appears, the configuration was successful.
