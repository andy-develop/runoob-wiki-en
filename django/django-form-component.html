Django Form component

Django Form components are used to initialize pages, generate HTML tags, and also validate data submitted by users (displaying error messages).

Error message display order:

  • First display the error messages from field attributes, then display the error messages from local hooks.
  • If the error messages from field attributes are displayed, the error messages from local hooks will not be displayed.
  • If there are global hooks, the global hooks will start validation only after all data has been validated, and the error messages from global hooks will definitely be displayed.

To use Form components, you need to import forms first:

from django import forms

Next, we create a My_forms.py file in the app01 directory:

app01/My_forms.py

from django import forms
from django.core.exceptions import ValidationError
from app01 import models

class EmpForm(forms.Form):
    name = forms.CharField(min_length=4, label="Name", error_messages={"min_length": "You are too short.", "required": "This field cannot be empty!"})
    age = forms.IntegerField(label="Age")
    salary = forms.DecimalField(label="Salary")

Field attributes:

  • label: The text information in front of the input box.
  • error_message: Customize the displayed error messages. The attribute value is a dictionary, where `required` is the key for setting the error message displayed when the field cannot be empty.

Local hooks and global hooks

Define the Form class:

app01/My_forms.py

from django import forms
from django.core.exceptions import ValidationError
from app01 import models
class EmpForm(forms.Form):
    name = forms.CharField(min_length=5, label="Name", error_messages={"required": "This field cannot be empty!",
                                                                     "min_length": "Username is too short."})
    age = forms.IntegerField(label="Age")
    salary = forms.DecimalField(max_digits=5, decimal_places=2, label="Salary")
    r_salary = forms.DecimalField(max_digits=5, decimal_places=2, label="Please enter the salary again.")


    def clean_name(self):  # Local Hook
        val = self.cleaned_data.get("name")


        if val.isdigit():
            raise ValidationError("Username cannot be pure numbers")
        elif models.Emp.objects.filter(name=val):
            raise ValidationError("Username already exists!")
        else:
            return val

    def clean(self):  # Global hook to confirm whether the two entered wages are consistent.
        val = self.cleaned_data.get("salary")
        r_val = self.cleaned_data.get("r_salary")


        if val == r_val:
            return self.cleaned_data
        else:
            raise ValidationError("Please confirm whether the salary is consistent.")

views.py file code:

app01/views.py

def add_emp(request):
    if request.method == "GET":
        form = EmpForm()  # Initialize form object
        return render(request, "add_emp.html", {"form":form})
    else:
        form = EmpForm(request.POST)  # Pass data to the form object
        if form.is_valid():  # Perform Validation
            data = form.cleaned_data
            data.pop("r_salary")
            models.Emp.objects.create(**data)
            return redirect("/index/")
        else:  # Validation Failed
            clear_errors = form.errors.get("__all__")  # Get global hook error information
            return render(request, "add_emp.html", {"form": form, "clear_errors": clear_errors})
