Django creates the first project

In this chapter, we will introduce the Django management tool and how to use Django to create projects. For the first project, we name it HelloWorld.

  • Django 4.2.7

Creating the first project

Use django-admin to create the HelloWorld project:

django-admin startproject HelloWorld

After creation, we can view the project directory structure:

$ cd HelloWorld/
$ tree
HelloWorld/                  # 项目根目录
├── manage.py                # 项目管理脚本
├── db.sqlite3               # SQLite 数据库文件
├── __pycache__/             # Python 字节码缓存
└── HelloWorld/              # 项目配置目录（与项目同名）
    ├── __init__.py          # 包标识文件
    ├── settings.py          # 项目设置
    ├── urls.py             # 主路由配置
    ├── asgi.py             # ASGI 配置
    └── wsgi.py             # WSGI 配置

Project root directory (HelloWorld/):

文件/目录作用
manage.pyDjango command-line tool entry point, used for running the development server, database migrations, and other operations.
db.sqlite3SQLite database file (default database, used in development environment).
__pycache__/Python bytecode cache directory (automatically generated, no manual modification needed).

Main project configuration directory (HelloWorld/HelloWorld/):

文件/目录作用
__init__.pyEmpty file, tells Python that this directory is a package.
settings.pyCore configuration file，包含：
- Database settings (DATABASES)
- Static file paths (STATIC_URL)
- App registration (INSTALLED_APPS)
- Debug mode (DEBUG=True/False)
urls.pyMain route configuration file, defines the mapping relationship between URL paths and views.
asgi.pyASGI server configuration (used for asynchronous web servers, such as Daphne).
wsgi.pyWSGI server configuration (for traditional web servers, such as Gunicorn, uWSGI).

Next, we enter the HelloWorld directory and run the following command to start the server:

python3 manage.py runserver 0.0.0.0:8000

0.0.0.0 allows other computers to connect to the development server, and 8000 is the port number. If not specified, the port number defaults to 8000.

Enter your server's IP in the browser (here we enter the local IP address:127.0.0.1:8000) and port number. If it starts normally, the output is as follows:

Detailed explanation of key files

1. settings.py (core configuration)

实例

# HelloWorld/settings.py 示例片段

# 安全警告：生产环境必须关闭 DEBUG！
DEBUG = True

# 允许访问的域名（DEBUG=False 时需配置）
ALLOWED_HOSTS = []

# 注册的 Django 应用
INSTALLED_APPS = [
    'django.contrib.admin',  # 管理员后台
    'django.contrib.auth',   # 认证系统
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',  # 静态文件处理
]

# 数据库配置（默认 SQLite）
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',  # 数据库文件路径
    }
}

# 静态文件 URL（CSS/JS/图片）
STATIC_URL = 'static/'

2. urls.py (routing configuration)

实例

# HelloWorld/urls.py 示例

from django.contrib import admin
from django.urls import path

urlpatterns = [
    path('admin/', admin.site.urls),  # 后台管理路由
    # 可在此添加自定义路由，如：
    # path('blog/', include('blog.urls')),
]

3. manage.py (project management script)

实例

#!/usr/bin/env python
import os
import sys

if __name__ == "__main__":
    os.environ.setdefault("DJANGO_SETTINGS_MODULE", "HelloWorld.settings")
    from django.core.management import execute_from_command_line
    execute_from_command_line(sys.argv)

Views and URL configuration

In the HelloWorld directory created earlier, create a new views.py file inside the HelloWorld directory and enter the code:

HelloWorld/HelloWorld/views.py 文件代码：

from django.http import HttpResponse def hello(request): return HttpResponse("Hello world ! ")

Next, bind the URL to the view function. Open the urls.py file, delete the original code, and copy and paste the following code into the urls.py file:

HelloWorld/HelloWorld/urls.py 文件代码：

from django.urls import path from . import views urlpatterns = [ path("", views.hello, name="hello"), ]

path() 函数

Django path() can accept four parameters: two required parameters: route, view, and two optional parameters: kwargs, name.

语法格式：
path(route, view, kwargs=None, name=None)

  • route：A string defining the path portion of the URL. It can contain variables, for example<int:my_variable>, to capture parameters from the URL and pass them to the view function.

  • view：View function, handles requests matching the given route. It can be a function or a class-based view.

  • kwargs（可选）：A dictionary containing additional keyword arguments passed to the view function.

  • name（可选）：Specifies a unique name for the URL route so that it can be referenced elsewhere in the code. This is very useful for generating URLs in templates or performing redirects in code.

In Django 2.0, the re_path() method can be used to be compatible with theurl()method, and some regular expression rules can also be implemented through re_path().

from django.urls import include, re_path

urlpatterns = [
    re_path(r'^index/$', views.index, name='index'),
    re_path(r'^bio/(?P<username>\w+)/$', views.bio, name='bio'),
    re_path(r'^weblog/', include('blog.urls')),
    ...
]

    如果是 Django >= 2.0 的版本，urls.py 的 django.conf.urls 已经被 django.urls 取代。

    The usage of django.urls is as follows:

    from django.urls import path
from . import view

urlpatterns = [
    path('', view.hello),
    path('world/', view.world)
]

    The biggest changes are as follows:

    import url变成了import path

    如果是路径，则须在路径后加个/

    Old version of Django usage:

    from django.conf.urls import url
 
from . import view
 
urlpatterns = [
    url(r'^hello$', view.hello),
]

    New version reference approach:

    from django.urls import path
from . import view

urlpatterns = [
    path('hello/', view.hello),
]
