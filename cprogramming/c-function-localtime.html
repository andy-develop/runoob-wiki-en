C library functions -localtime()

C 标准库 - <time.h>

描述

C 库函数struct tm *localtime(const time_t *timer)Use the value of timer to filltm结构。timerthe value is decomposed intotmthe structure, and represent it in the local time zone.

声明

Below is the declaration of the localtime() function.

struct tm *localtime(const time_t *timer)

参数

  • timer-- This is a pointer to a time_t value representing calendar time.

返回值

this function returns a pointer totmA pointer to a structure that carries the filled time information. Below are the details of the tm structure:

struct tm { int tm_sec; /*秒，范围从 0 到 59*/ int tm_min; /*分，范围从 0 到 59*/ int tm_hour; /*小时，范围从 0 到 23*/ int tm_mday; /*一月中的第几天，范围从 1 到 31*/ int tm_mon; /*月份，范围从 0 到 11*/ int tm_year; /*自 1900 起的年数*/ int tm_wday; /*一周中的第几天，范围从 0 到 6*/ int tm_yday; /*一年中的第几天，范围从 0 到 365*/ int tm_isdst; /*夏令时*/ };

实例

The following example demonstrates the usage of the localtime() function.

实例

#include <stdio.h> #include <time.h> int main () { time_t rawtime; struct tm *info; char buffer[80]; time( &rawtime ); info = localtime( &rawtime ); printf("当前的本地时间和日期：%s", asctime(info)); return(0); }

Let us compile and run the above program, which will produce the following results:

当前的本地时间和日期：Thu Aug 23 09:12:05 2012

    In Visual Studio 2015, using the localtime function reports error C4996 indicating that the localtime function is unsafe, and recommends using localtime_s instead.

    Visual Studio 2010 and later versions have added a secure function, changed to localtime_s(), and the syntax format has also changed:

    errno_t localtime_s(
   struct tm* _tm,
   const time_t *time 
);

    其中：

    _tm
指向要填充的时间结构的指针。
time
指针，指向存储的时间。
如果成功，返回值则为零。 如果失败，返回值将是错误代码。 错误代码是在 Errno.h 中定义的。

结构类型的字段 tm 存储下面的值，其中每个为 int。

tm_sec
分钟后的几秒 (0-59)。
tm_min
小时后的分钟 (0-59)。
tm_hour
午夜后经过的小时 (0-23)。
tm_mday
月 (1-31) 天。
tm_mon
月 (0 – 11;年 1 月 = 0）。
tm_year
年份 （当前年份减去 1900年）。
tm_wday
星期几 (0 – 6;星期日 = 0）。
tm_yday
每年的一天 (0-365;1 月 1 日 = 0)。
tm_isdst
如果夏令时有效，则为，正值夏时制不起作用; 如果为 0如果夏时制的状态是未知的负值。 如果 TZ 设置环境变量，C 运行库会假定规则适用于美国境内用于实现夏令时 (DST) 计算。

    The following is an example in Visual Studio 2015 to output the local date and time:

    #include <iostream>
#include <ctime>

using namespace std;

int main(void)
{
    struct tm t;  //tm结构指针
    time_t now;  //声明time_t类型变量
    time(&now);  //获取系统日期和时间
    localtime_s(&t, &now);  //获取当地日期和时间
        
    //格式化输出本地时间
    printf("年：%d\n", t.tm_year + 1900);
    printf("月：%d\n", t.tm_mon + 1);
    printf("日：%d\n", t.tm_mday);
    printf("星期：%d\n", t.tm_wday);
    printf("一年中：%d\n", t.tm_yday);
    printf("时：%d\n", t.tm_hour);
    printf("分：%d\n", t.tm_min);
    printf("秒：%d\n", t.tm_sec);
    printf("夏令时：%d\n", t.tm_isdst);
    system("pause");
    return 0;
}
