C 指针

Learning pointers in C is both simple and interesting. Through pointers, you can simplify the execution of some C programming tasks, and some tasks, such as dynamic memory allocation, cannot be performed without pointers. Therefore, to become a good C programmer, it is necessary to learn pointers.

As you know, every variable has a memory location, and every memory location defines a usable&address accessed by the operator, which represents an address in memory.

Please look at the following example, which will output the address of the defined variable:

实例

#include <stdio.h> int main () { int var_runoob = 10; int *p; // 定义指针变量 p = &var_runoob; printf("var_runoob 变量的地址： %p\n", p); return 0; }

When the above code is compiled and executed, it will produce the following results:

var_runoob 变量的地址： 0x7ffeeaae08d8

Through the above example, we understand what a memory address is and how to access it. Next, let's look at what a pointer is.

What is a pointer?

A pointer is a memory address, and a pointer variable is a variable used to store memory addresses. Like other variables or constants, you must declare a pointer before using it to store the address of another variable. The general form of a pointer variable declaration is:

type *var_name;

在这里，typeis the base type of the pointer, which must be a valid C data type,var_nameis the name of the pointer variable. The asterisk used to declare a pointer*is the same as the asterisk used in multiplication. However, in this statement, the asterisk is used to specify that a variable is a pointer. The following are valid pointer declarations:

int *ip; /*一个整型的指针*/ double *dp; /*一个 double 型的指针*/ float *fp; /*一个浮点型的指针*/ char *ch; /*一个字符型的指针*/

For all actual data types, whether integer, floating-point, character, or other data types, the type of the value of the corresponding pointer is the same: it is a long hexadecimal number representing a memory address.

The only difference between pointers of different data types is the data type of the variable or constant that the pointer points to.

How to use pointers?

When using pointers, the following operations are frequently performed: defining a pointer variable, assigning the address of a variable to the pointer, and accessing the value at the available address in the pointer variable. These are done using the unary operator*to return the value of the variable located at the address specified by the operand. The following example involves these operations:

实例

#include <stdio.h> int main () { int var = 20; /*实际变量的声明*/ int *ip; /*指针变量的声明*/ ip = &var; /*在指针变量中存储 var 的地址*/ printf("var 变量的地址: %p\n", &var ); /*在指针变量中存储的地址*/ printf("ip 变量存储的地址: %p\n", ip ); /*使用指针访问值*/ printf("*ip 变量的值: %d\n", *ip ); return 0; }

When the above code is compiled and executed, it will produce the following results:

var 变量的地址: 0x7ffeeef168d8
ip 变量存储的地址: 0x7ffeeef168d8
*ip 变量的值: 20

NULL pointers in C

When declaring a variable, if there is no exact address to assign, assigning a NULL value to the pointer variable is a good programming practice. A pointer assigned a NULL value is called a空指针。

NULL pointer is a constant with a value of zero defined in the standard library. Consider the following program:

实例

#include <stdio.h> int main () { int *ptr = NULL; printf("ptr 的地址是 %p\n", ptr ); return 0; }

When the above code is compiled and executed, it will produce the following results:

ptr 的地址是 0x0

On most operating systems, programs are not allowed to access memory at address 0 because that memory is reserved by the operating system. However, memory address 0 has special significance: it indicates that the pointer does not point to an accessible memory location. But by convention, if a pointer contains a null value (zero), it is assumed to point to nothing.

To check for a null pointer, you can use an if statement, as shown below:

if(ptr) /*如果 p 非空，则完成*/ if(!ptr) /*如果 p 为空，则完成*/

Detailed explanation of C pointers

In C, there are many pointer-related concepts. These concepts are all simple, but they are all important. The following lists some important pointer-related concepts that C programmers must be clear about:

概念描述
指针的算术运算Four arithmetic operations can be performed on pointers: ++, --, +, -
指针数组You can define an array used to store pointers.
指向指针的指针C allows pointers to pointers.
传递指针给函数Passing parameters by reference or address enables the passed parameters to be modified in the called function.
从函数返回指针C allows functions to return pointers to local variables, static variables, and dynamically allocated memory.

    A pointer is a variable whose value is the address of another variable, i.e., the direct address of a memory location. Like other variables or constants, you must declare a pointer before using it to store the address of another variable.

    To understand pointers, you must first understand computer memory. Computer memory is divided into memory units numbered in sequence. Each variable is stored in a memory unit, called an address.

    #include <stdio.h>

int main ()
{
    int var = 20;   /* 实际变量的声明 此时的 VAR 这个变量是存在某个地址的，地址对应某个内存单元，该单元中存储了数据20 */
    int *ip;         /* 指针变量的声明 定义了一个指针 即一个内存单元的地址变量 */

    ip = &var;      /* 在指针变量中存储 var 的地址 就是将地址值赋值给指针这个变量*/

    /* 在指针变量中存储的地址 利用&符号直接输出了var所存储的数据的内存单元的地址*/
    printf("Address of var variable: %p\n", &var );
    
    /* 在指针变量中存储的地址 ip代表的是这个赋值到的地址的值 所以输出的是地址值 */
    printf("Address stored in ip variable: %p\n", ip );
    
    /* 使用指针访问值 *ip代表的是定义到这个内存单元之后，内存单元中所存储的数据的值也就是将20赋值给var中20这个值 */
    printf("Value of *ip variable: %d\n", *ip );

    return 0;
}

    Some complex descriptions of pointers:

    • int p;-- This is an ordinary integer variable
    • int *p;-- First, starting from p, it first combines with *, so p is a pointer; then it combines with int, indicating that the type of the content pointed to by the pointer is int. Therefore, p is a pointer to integer data.
    • int p[3]-- First, starting from p, it combines with [] first, indicating that p is an array; then it combines with int, indicating that the elements in the array are integer. So p is an array composed of integer data.
    • int *p[3];-- First, starting from p, it combines with [] first, because its precedence is higher than *, so p is an array; then it combines with *, indicating that the elements in the array are pointer types; then it combines with int, indicating that the content pointed to by the pointers is integer. So p is an array composed of pointers to integer data.
    • int (*p)[3];-- First, starting from p, it combines with * first, indicating that p is a pointer; then it combines with [] (the "()" step can be ignored, it is only to change precedence), indicating that the content pointed to by the pointer is an array; then it combines with int, indicating that the elements in the array are integer. Therefore, p is a pointer to an array composed of integer data.
    • int **p;-- First, starting from p, it combines with * first, meaning p is a pointer; then it combines with another *, indicating that the element pointed to by the pointer is a pointer; then it combines with int, indicating that the element pointed to by that pointer is integer data. Since two-level pointers and higher-level pointers are rarely used in complex types, we will not consider multi-level pointers for the more complex types later; at most we will only consider one-level pointers.
    • int p(int);-- Starting from p, it combines with () first, indicating that p is a function; then entering () for analysis, it indicates that the function has an integer variable parameter; then it combines with the outer int, indicating that the return value of the function is an integer data.
    • int (*p)(int);-- Starting from p, it combines with the pointer first, indicating that p is a pointer; then it combines with (), indicating that the pointer points to a function; then it combines with the int inside (), indicating that the function has an int parameter; then it combines with the outermost int, indicating that the return type of the function is integer. Therefore, p is a pointer to a function that has an integer parameter and whose return type is integer.
    • int *(*p(int))[3];-- You can skip this type for now; it is too complex. Starting from p, it combines with () first, indicating that p is a function; then entering (), it combines with int, indicating that the function has an integer variable parameter; then it combines with the outer *, indicating that the function returns a pointer; then at the outermost layer, it combines with [] first, indicating that the returned pointer points to an array; then it combines with *, indicating that the elements in the array are pointers; then it combines with int, indicating that the content pointed to by the pointers is integer data. Therefore, p is a function whose parameter is an integer and which returns a pointer variable pointing to an array composed of integer pointer variables.

    Pointer to a function

    Code and data are the same; both need to occupy a certain amount of memory, and of course they also have a base address. So we can define a pointer to point to this base address; this is the so-called function pointer.

    Suppose there is a function:

    double func(int a,char c);
double (*p)(int a,char c);
p=&func;

    That is, you can define a function pointer.

    调用函数

    double s1=func(100,'x');
double s2=(*p)(100,'x');

    The above two statements are equivalent.

    #include <stdio.h>

void func1(int *a, int **b);

void func1(int *a, int **b)
{
   (*a)++;
   (*b)++;//这里虽然传进来的是指针的形式，但其实是指针c的地址，
          //可以认为这里本质还是值传递，只不过这个值是地址值
}

int main()
{
    int a[2] = {10, 20};
    int *b = &a[0];
    int *c = a+1;
    int **d = &c;
    
    func1(b, d);
    printf("a[0] = %d   a[1] = %d\n", a[0], a[1]);

    return 0;
}

    执行结果：a[0] = 11 a[1] = 20

    From the above, we can see that although parameters are passed in the form of pointers, sometimes it turns out that it is still value passing, i.e., passing of address values. This is especially likely to occur when multi-dimensional arrays are passed as parameters.

    I started learning C in 2016, and at that time I simply couldn't understand it! Especially pointers. Now, more than two years later, I have a bit of understanding. Looking back, whenever pointers are mentioned, the concept of addresses comes up. Therefore, concepts related to pointers can be better understood in combination with C's memory management. Below I will talk about how to better understand pointers.

    Why is it called a pointer? A pointer is actually a very vivid metaphor. Below is my personal understanding.

    An int variable stores an int value, a char variable stores a char value, and a pointer is a special variable that stores a memory address. Following this template, it can be understood as:A "memory address variable" stores a "memory address", which is equivalent to: a "pointer variable" stores a "memory address".

    When the operating system performs resource scheduling, it will request and use the memory region represented by that address according to the addresses stored in these variables, as if the address stored in the variable points to a certain piece of memory. People use "pointer" to collectively refer to the so-called "memory address variable".

    因此，Any concept related to pointers can be understood by associating it with memory addresses.There must be a connection between the two; arrays and pointers, functions and pointers, are all like this.

    • Memory is linear.Memory is presented to us in the form of an address space, so it can be said that the so-called address space is also linear. A pointer stores a memory address, so you can perform operations such as ++ or -- on the address.
    • Not assigning NULL to two pointers is a bad habit.
    • Initializing a pointer without assigning NULL, because such a pointer points to an unknown area. Such a pointer is not a null pointer, but it points to a memory area with restricted access, and you cannot use it. In this situation, the industry has given it a vivid name: "wild pointer". Moreover, it is hard to debug. In many compilers, single-step debugging may produce strange errors, but the frequently seen error is something like "Segmentation Fault". In practice, when the code is large, this is a very annoying error. A wild pointer is one of the causes. So when you see such an error, first think about whether some pointer was not initialized.
    • Pointer not set to NULL after free(), after allocating memory to a pointer, the pointer can point to a legal and usable memory area. But when you use free() to release that memory, the pointer still stores the address of that memory area, that is, it still points to that memory, but this memory has already been released and cannot be accessed. If you accidentally use this pointer, a memory error will occur, and again there will be strange bugs. With a few hundred lines of code, it becomes hard to debug. The industry also has a general name for such pointers: "dangling pointer". To avoid this annoying situation, after releasing memory, you must assign NULL to all pointers pointing to this memory. From this, you can also see that free() releasing memory has nothing to do with the pointer pointing to this memory; it won't take care of the pointer along with it!Cherish life, stay away from "wild pointers" and "dangling pointers"!
    • 多级指针, a pointer to a pointer is sometimes also called a multi-level pointer. Since a pointer variable is a variable, a pointer variable can store the memory address of a variable.

    Just as int * stores the address of an int variable and char * stores the address of a char variable, a pointer can naturally store the address of a pointer variable.

    For example, int ** stores the address of an int *, and int *** stores the address of an int **.

    This is a two-level pointer storing the address of a one-level pointer, and a three-level pointer storing the address of a two-level pointer. People call this process a pointer to a pointer, but in fact it is just a higher-level pointer storing the address of a lower-level pointer.

    Therefore, as mentioned above, if you store its address, you are pointing to it. So:

    • A two-level pointer stores the address of a one-level pointer, so it can be said that the two-level pointer points to the one-level pointer.
    • A three-level pointer stores the address of a two-level pointer, so it can be said that the two-level pointer points to the one-level pointer.
    • Multi-level pointers have many uses; I won't go into detailed examples here for now.

    Personally, I think pointers can be said to be C's greatest feature. Through such a model, you can vividly manage part of the memory!
