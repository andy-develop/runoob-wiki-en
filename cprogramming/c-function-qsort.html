C Library Functions -qsort()

C 标准库 - <stdlib.h>

描述

qsortis a function provided in the C standard library, used for quicksorting arrays. It is in<stdlib.h>Defined in the header file.qsortIt uses the quicksort algorithm, which is an efficient sorting algorithm with an average time complexity of O(n log n).

C 库函数void qsort(void *base, size_t nitems, size_t size, int (*compar)(const void *, const void*)) Sort the array.

声明

The following is the declaration of the qsort() function.

void qsort(void *base, size_t nitems, size_t size, int (*compar)(const void *, const void *));

参数

  • base: Pointer to the first element of the array to be sorted.
  • nitems: The number of elements in the array.
  • size: Size of each element in the array (in bytes).
  • compar: A pointer to a comparison function used to compare two elements. The comparison function should return an integer indicating the result of the comparison:
    • Less than zero: indicates that the first element is smaller than the second element.
    • Equal to zero: indicates that the two elements are equal.
    • Greater than zero: indicates that the first element is larger than the second element.

返回值

This function does not return any value.

实例

The following example demonstrates the usage of the qsort() function.

实例

#include <stdio.h>
#include <stdlib.h>

// 定义一个包含五个整数的数组
int values[] = { 88, 56, 100, 2, 25 };

// 比较函数，用于比较两个整数
int cmpfunc (const void * a, const void * b)
{
   return ( *(int*)a - *(int*)b );
}

int main()
{
   int n;

   // 输出排序之前的数组内容
   printf("排序之前的列表：\n");
   for( n = 0 ; n < 5; n++ ) {
      printf("%d ", values[n]);
   }

   // 使用 qsort 函数对数组进行排序
   qsort(values, 5, sizeof(int), cmpfunc);

   // 输出排序之后的数组内容
   printf("\n排序之后的列表：\n");
   for( n = 0 ; n < 5; n++ ) {
      printf("%d ", values[n]);
   }
 
   return 0;
}

Let us compile and run the above program, which will produce the following result:

排序之前的列表：
88 56 100 2 25 
排序之后的列表：
2 25 56 88 100

Note that both formal parameters must be ofconst void *type, and when calling the compar function (compar is essentially a function pointer; the function it points to is also called compar here), the actual arguments passed must also be converted toconst void *type.     For comparing int-sized values, the cmpfunc implementation given in the example is unsafe and may cause overflow.

    int cmpfunc (const void * a, const void * b)
{
   return ( *(int*)a - *(int*)b );
}

    Consider the following case (assume int is 4 bytes long):

    int small_negative_val = (int)(0x80000000); // -2147483648
int big_positive_val = 0x7fffffff; // 2147483647
printf("%d", cmpfunc(&small_negative_val, &big_positive_val));
// 输出1。负数减正数却得出了正数，代表结果已经溢出，不再可靠。

    如果变量apoints to a smaller negative integer, b points to a larger positive integer,(*(int*)a - *(int*)b)The expression will evaluate to a positive number, which is the wrong result.

    Therefore, we cannot use subtraction to compare the sizes of ints, because this can cause overflow. Instead, we can use the greater-than and less-than operators to compare, which will not cause overflow:

    int cmpfunc (const void * a, const void * b)
{
    const int *aa = a;
    const int *bb = b;
    if (*aa < *bb)
        return -1;
    else if (*aa > *bb)
        return 1;
    else 
        return 0;
}

    A more concise way to write it is as follows:

    int cmpfunc(const void *a, const void *b) {
    const int *aa = a;
    const int *bb = b;
    return (*aa > *bb) - (*aa < *bb);
}

    Note that both methods preserve the const attribute of the memory pointed to by the pointers when performing type casts. This emphasizes that the memory pointed to by aa and bb cannot be modified, making it a more canonical style.

    compar - The comparison function.

    If the first parameter is less than the second, return a negative integer value; if the first parameter is greater than the second, return a positive integer value; if the two parameters are equivalent, return zero.

    The signature of the comparison function should be equivalent to the following form:

    int compar(const void *a, const void *b);

    The function must not modify the objects passed to it, and must return consistent results when comparing the same objects, regardless of their positions in the array.

    The style used above:

    return (*(int*)a) > (*(int*)b) ? 1 : -1;//升序排序
return (*(int*)a) > (*(int*)b) ? -1 : 1;//降序排序

    Not only does it fail to conform to the C language standard, but when the array contains a large number of equal elements, the time consumption increases significantly, and the time complexity advantage of qsort will no longer exist.return (*(int*)a - *(int*)b);It is indeed higher performance, but unsafe; the naiveif-elseThe performance of this approach is not much worse.

    if-elseIt can be compressed into one line:

    return *(int *)a < *(int *)b ? -1 : *(int *)a > *(int *)b;
