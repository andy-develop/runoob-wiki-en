C 数据类型

In C language, data types refer to a broad system used to declare variables or functions of different types. The type of a variable determines the space it occupies in storage and how the stored bit pattern is interpreted.

Types in C can be divided into the following categories:

序号类型与描述
1基本数据类型
They are arithmetic types, including integer (int), character (char), floating-point (float), and double-precision floating-point (double).
2枚举类型：
They are also arithmetic types, used to define variables that can only be assigned certain discrete integer values in a program.
3void 类型：
类型说明符voidA data type representing no value, usually used for function return values.
4派生类型：
Including array types, pointer types, and structure types.

Array types and structure types are collectively called aggregate types. The type of a function refers to the type of the function's return value. In the following part of this chapter, we will introduce basic types; the other types will be explained in later chapters.

void 类型

The void type specifies that no value is available. It is usually used in the following three situations:

序号类型与描述
1函数返回为空
In C, various functions do not return a value, or you can say they return nothing. The return type of a function that does not return a value is void. For example:void exit (int status);
2函数参数为空
In C, various functions do not accept any parameters. A function without parameters can accept a void. For example:int rand(void);
3指针指向 void
A pointer of type void * represents the address of an object, rather than a type. For example, the memory allocation functionvoid *malloc( size_t size );returns a pointer to void, which can be cast to any data type.

If you still cannot fully understand the void type now, don't worry too much; we will explain these concepts in detail in later chapters.

类型转换

Type casting is converting a value of one data type to a value of another data type.

There are two types of type conversion in C:

  • Implicit type conversion:Implicit type conversion occurs automatically in expressions without any explicit instruction or function call. It usually automatically converts a smaller type to a larger type, for example, converting int to long or float to double. Implicit type conversion may also cause loss of data precision or data truncation.

  • Explicit type conversion:Explicit type conversion requires the use of the type casting operator, which can force a value of one data type to be converted to a value of another data type. Force casting allows programmers to control data types more precisely when necessary, but it may also cause data loss or truncation.

Implicit type conversion example:

实例

int i = 10;
float f = 3.14;
double d = i + f; // 隐式将int类型转换为double类型

Explicit type conversion example:

实例

double d = 3.14159;
int i = (int)d; // 显式将double类型转换为int类型

    Automatic type conversion rules:

    • 1. If the types of operands involved in an operation are different, they are first converted to the same type, and then the operation is performed.

    • 2. Conversion is performed in the direction of increasing data length to ensure precision is not reduced. For example, when int and long are operated on, the int quantity is first converted to long before the operation.

      a. If the two types have different byte sizes, convert to the type with the higher number of bytes.

      b. If the two types have the same byte size, and one is signed and the other unsigned, convert to the unsigned type.

    • 3. All floating-point operations are performed in double precision. Even expressions containing only float single-precision quantities must first be converted to double before the operation.
    • 4. When char and short (in environments such as Visual C++) participate in operations, they must first be converted to int.
    • 5. In an assignment operation, when the data types on both sides of the assignment sign are different, the type of the value on the right side of the assignment sign is converted to the type of the left side. If the data type length on the right side is longer than that on the left side, some data will be lost, which reduces precision; the lost part is directly discarded.

    例如：

    • 1. When performing arithmetic operations, a low type (short bytes) can be converted to a high type (long bytes); for example: int converted to double, char converted to int, etc.;
    • 2. In an assignment expression, the type of the value of the expression on the right side of the equal sign is automatically and implicitly converted to the type of the variable on the left side, and then assigned to it;
    • 3. In a function call, when the value of an actual argument is passed to a formal parameter, the system first automatically and implicitly converts the type of the actual argument's value to the type of the formal parameter, and then assigns it to the formal parameter;
    • 4. When a function has a return value, the system first automatically and implicitly converts the type of the returned expression's value to the function's return type, and then assigns it to the calling function's return;

    How to use the Boolean (bool) type in C

    In C, the Boolean type is not a built-in data type. By default, C treats 0 as false and 1 as true. However, starting from C99, the _Bool type was added and the standard library file stdbool.h was introduced, allowing the bool data type to be directly used in C code.

    stdbool.h actually has only a few lines of code:

    #ifndef _STDBOOL
#define _STDBOOL
#define __bool_true_false_are_defined 1
#ifndef __cplusplus
#define bool _Bool
#define false 0
#define true 1
#endif // __cplusplus
#endif // _STDBOOL

    Its function is:

    • 定义 __bool_true_false_are_defined 为 1
    • Define bool as the C99 built-in type _Bool
    • Define true and false as 1 and 0 respectively
    • For the _Bool type, you can assign any value to it; any non-zero assignment will return 1 when this variable is used.

    The following is a code example using stdbool.h:

    #include <stdbool.h>
#include <stdio.h>

int main()
{
    printf("true = %d\n", true);
    printf("false = %d\n", false);
    bool a = 0;
    bool b = 'b';
    bool c = "Hello world";
    printf("bool a = %d\n", a);
    printf("bool b = %d\n", b);
    printf("bool c = %d\n", c);
    return 0;
}

    运行结果：

    true = 1
false = 0
bool a = 0
bool b = 1
bool c = 1
