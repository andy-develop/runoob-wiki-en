A pointer array stores a set of pointers, and each pointer can point to a different data object.

Pointer arrays are commonly used to handle multiple data objects, such as string arrays or arrays of other complex data structures.

Let's look at an example that uses an array of 3 integers:

实例

#include <stdio.h> const int MAX = 3; int main () { int var[] = {10, 100, 200}; int i; for (i = 0; i < MAX; i++) { printf("Value of var[%d] = %d\n", i, var[i] ); } return 0; }

When the above code is compiled and executed, it produces the following results:

Value of var[0] = 10
Value of var[1] = 100
Value of var[2] = 200

There may be a situation where we want an array to store pointers to int, char, or other data types.

The following is a declaration of a pointer array pointing to integers:

int *ptr[MAX];

在这里，把ptrDeclared as an array consisting of MAX integer pointers. Therefore, each element in ptr is a pointer to an int value. The following example uses three integers, which will be stored in an array of pointers, as shown below:

实例

#include <stdio.h> const int MAX = 3; int main () { int var[] = {10, 100, 200}; int i, *ptr[MAX]; for ( i = 0; i < MAX; i++) { ptr[i] = &var[i]; /*赋值为整数的地址*/ } for ( i = 0; i < MAX; i++) { printf("Value of var[%d] = %d\n", i, *ptr[i] ); } return 0; }

When the above code is compiled and executed, it produces the following results:

Value of var[0] = 10
Value of var[1] = 100
Value of var[2] = 200

You can also use a pointer array pointing to characters to store a list of strings, as follows:

实例

#include <stdio.h> const int MAX = 4; int main () { const char *names[] = { "Zara Ali", "Hina Ali", "Nuha Ali", "Sara Ali", }; int i = 0; for ( i = 0; i < MAX; i++) { printf("Value of names[%d] = %s\n", i, names[i] ); } return 0; }

When the above code is compiled and executed, it produces the following results:

Value of names[0] = Zara Ali
Value of names[1] = Hina Ali
Value of names[2] = Nuha Ali
Value of names[3] = Sara Ali

Let's look at another simple example. We first declare a pointer array ptrArray containing three integer pointers. Then, we point these pointers to different integer variables num1, num2, and num3 respectively. Finally, we use the pointer array to access the values of these integer variables.

实例

#include <stdio.h> int main() { int num1 = 10, num2 = 20, num3 = 30; // 声明一个整数指针数组，包含三个指针 int *ptrArray[3]; // 将指针指向不同的整数变量 ptrArray[0] = &num1; ptrArray[1] = &num2; ptrArray[2] = &num3; // 使用指针数组访问这些整数变量的值 printf("Value at index 0: %d\n", *ptrArray[0]); printf("Value at index 1: %d\n", *ptrArray[1]); printf("Value at index 2: %d\n", *ptrArray[2]); return 0; }

When the above code is compiled and executed, it produces the following results:

Value at index 0: 10
Value at index 1: 20
Value at index 2: 30

Pointer arrays are very useful in C, especially when dealing with data structures with an indeterminate number of elements, such as dynamically allocated string arrays or dynamically created struct arrays.

    The difference between a pointer array and an array pointer

    指针数组

    Pointer array: A pointer array can be described as an "array of pointers"; first, this variable is an array.

    Second, "pointer" modifies this array, meaning that all elements of this array are of pointer type.

    In a 32-bit system, a pointer occupies four bytes.

    数组指针

    Array pointer: An array pointer can be described as a "pointer to an array"; first, this variable is a pointer.

    Second, "array" modifies this pointer, meaning that this pointer stores the first address of an array, or that this pointer points to the first address of an array.

    根

    Based on the above explanation, one can understand the difference between a pointer array and an array pointer, because the two are fundamentally different types of variables.

    指针数组: An array of pointers is actually an array; its length is determined by the array itself. All elements of this array are of pointer type, and all store addresses.

    int *prt[ 10 ] ; *prt[ 1 ],*prt[ 2 ],*prt[ 3 ]......Each element in the array points to an address.

    数组指针: A pointer to an array is actually a pointer; its length is fixed (occupies 4 bytes in a 32-bit system). This pointer points to an array, but the number of bytes occupied by the pointed-to array is uncertain.

    int  a[5]={ 1,2,3,4,5 };    //定义一个一维数组 a
int  (*prt)[5];      // 步长为 5 的数组指针，即 prt 指向的数组里有 5 个元素  
prt=&a;    // 把数组 a 的地址付给 prt，则 prt 为数组 a 的地址，*prt 表示数组 a 本身
prt[ 0 ];    //表示数组首元素的地址
*prt[ 0 ]；  //表示数组的首元素的值，即为数组 a 的 1
**prt;         //表示数组的首元素的值，即为数组 a 的 1
*prt[ 1 ] ;   //表示指向数组的下一行元素的首元素的值，但是a是一维数组，只有一行，所以指向的地址中的值不确定

    Adding 1 to an array pointer, the step size is the number of columns of the pointed-to array, that is, the first address of the next row. It is only meaningful in arrays of two or more dimensions; a one-dimensional array has only one row, so it is meaningless.

    指针数组

    int *a[3]: Why is this a pointer array here,[]has higher priority than*, so this is an array, and*modifies the array, so it is a pointer array; the elements of the array are pointers to integers.

    示例:

    int main() {     
   char *str[3];     
   str[0] = "abc";     
   str[1] = "efg";     
   str[2] = "hij";     
   for (int i = 0; i < 3; ++i) {         
      printf("%s\n", str[i]);     
   } 
}

    结果：

    abc 
efg 
hij

    数组指针

    int (*a)[3]: In the same way, first the parentheses have the highest priority, so*a是指针，而[]修饰*a, so it is an array pointer, a pointer to a one-dimensional array of 3 elements.

    示例:

    typedef int arr[3]; 
int main() {     
   arr b = {1, 2, 3};     
   int (*a)[3] = &b;     
   arr *c = a;     
   for (int i = 0; i < 3; ++i) {         
      printf("%d\n", (*a)[i]);     
      
   } 
}

    结果：

    1 
2 
3

    解析：

    Here we use typedef. We define a custom data type, which is an array data type. The data type is an array of three integer elements.

    There are also two ways to define an array pointer: one is to use the array data type we defined above, and the other is to define it directly.

    指针数组：

    int *p1[3];

    The priority of square brackets [] is high, so they combine with p1 first, indicating an array. This array has 3 elements, and all 3 elements are pointers that point to int data.

    数组指针：

    int (*p2)[3];

    The parentheses make p2 combine with *, indicating that p2 is a pointer. This pointer points to an array with 3 elements, and the type of each element is int.
