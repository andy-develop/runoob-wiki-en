C has a large number of functions for manipulating strings:

序号Function & Purpose
1strcpy(s1, s2);
Copy string s2 to string s1.
2strcat(s1, s2);
Concatenates string s2 to the end of string s1.
3strlen(s1);
Return the length of string s1.
4strcmp(s1, s2);
If s1 and s2 are the same, returns 0; if s1<s2, returns a value less than 0; if s1>s2, returns a value greater than 0.
5strchr(s1, ch);
Returns a pointer to the first occurrence of character ch in string s1.
6strstr(s1, s2);
Returns a pointer to the first occurrence of string s2 in string s1.

The following example uses some of the above functions:

实例

#include <stdio.h> #include <string.h> int main () { char str1[14] = "runoob"; char str2[14] = "google"; char str3[14]; int len ; /*复制 str1 到 str3*/ strcpy(str3, str1); printf("strcpy( str3, str1) : %s\n", str3 ); /*连接 str1 和 str2*/ strcat( str1, str2); printf("strcat( str1, str2): %s\n", str1 ); /*连接后，str1 的总长度*/ len = strlen(str1); printf("strlen(str1) : %d\n", len ); return 0; }

When the above code is compiled and executed, it produces the following results:

strcpy( str3, str1) :  runoob
strcat( str1, str2):   runoobgoogle
strlen(str1) :  12

    关于 sizeof() 和 strlen()
    • 1、sizeof()Calculate the length of a string, including the trailing'\0'
    • 2、strlen()Calculates the length of a string, not including the null character at the end of the string.'\0'

    • 例如：

      #include<stdio.h>
#include<stdlib.h>
#include<string.h>

void msg()
{
    char s[] = { "hello,world!" };
    printf("s = %s\n", s);
    printf("sizeof(s) = %d\n", sizeof(s));
    printf("strlen(s) = %d\n", strlen(s));
}

int main(int argc, char* argv[], char* envp[])
{
    msg();
    return 0;
}

    Explanation of the string safe functions strcpy_s and strcat_s in Visual C:

    Since MSVC requires code to use safe functions, compared with the original functions, the safe functions have an additional parameter of type size_t, used as the buffer size. Therefore, you can use _countof(dst) (need to include the header file stdlib.h) to obtain the size of the target string as the buffer size.

    举个例子：

    #include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main()
{
    char s1[] = "Hello world";
    char s2[] = " from secure function";
    char dst[50]; // 此处数组大小根据实际情况调整，或通过calloc、malloc分配动态内存
    strcpy_s(dst, _countof(dst), s1);
    strcat_s(dst, _countof(dst), s2);
    printf_s(dst);
    return 0;
}

    Code execution result:

    Hello world from secure function
