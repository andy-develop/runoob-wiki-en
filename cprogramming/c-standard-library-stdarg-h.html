C Standard Library -<stdarg.h>

<stdarg.h>is a header file in the C standard library, providing a set of macros for accessing a variable number of arguments.

stdarg.hThe header file defines a variable typeva_listand three macros, which can be used to obtain the arguments in a function when the number of arguments is unknown (i.e., the number of arguments is variable).

Functions with variable arguments usually use an ellipsis at the end of the parameter list....定义的。

库变量

The following are the variable types defined in the header file stdarg.h:

序号Variables & Description
1va_list
This is applicable tova_start()、va_arg() 和 va_end()The type in which these three macros store information. The type used to store variable argument information.

库宏

The following are the macros defined in the header file stdarg.h:

序号Macros & Description
1void va_start(va_list ap, last_arg)
This macro initializesap变量，它与va_arg 和 va_endThe macros are used together.last_argis the last known fixed parameter passed to the function, i.e., the parameter before the ellipsis.
2type va_arg(va_list ap, type)
This macro retrieves an argument of typetypethe next parameter.
3void va_end(va_list ap)
This macro is now available for useva_startA function with variable arguments returns via the macro. If it is not called before returning from the functionva_end, the result is undefined.

实例

The following is an example using<stdarg.h>An example of implementing a variadic function. This function calculates the sum of all parameters:

实例

#include <stdio.h>
#include <stdarg.h>

// 计算可变参数的和
int sum(int count, ...) {
    int total = 0;
    va_list args;
   
    // 初始化 args 以访问可变参数
    va_start(args, count);
   
    // 逐个访问可变参数
    for (int i = 0; i < count; i++) {
        total += va_arg(args, int);
    }
   
    // 清理 args
    va_end(args);
   
    return total;
}

int main() {
    printf("Sum of 1, 2, 3: %d\n", sum(3, 1, 2, 3)); // 输出 6
    printf("Sum of 4, 5, 6, 7: %d\n", sum(4, 4, 5, 6, 7)); // 输出 22
    return 0;
}

输出结果:

Sum of 1, 2, 3: 6
Sum of 4, 5, 6, 7: 22

解析

  • va_list args;：声明一个va_listVariable, used to access variadic arguments.
  • va_start(args, count);：初始化argsTo traverse the variadic argument list, starting fromcountThe first parameter after that.
  • total += va_arg(args, int);: Get the next parameter in the variable argument list and accumulate it tototal. The parameter type isint。
  • va_end(args);：清理args。

注意事项

  • The type of each argument in the variable argument list must be explicit and must be passed consistently tova_arg。
  • 使用va_startAfter, must useva_end清理va_list变量。
  • va_start、va_arg 和 va_endThe macros should be used in pairs within a function to avoid undefined behavior.

    The method on the second floor is not safe!!

    I encountered a bug when using the non-fixed-parameter method from the second post. The argument I passed was a structure pointer, and the code is as follows:

    void AddChildren(Node* parent, ...)
{
    if (parent == NULL) return;
    Node* child = NULL;
    va_list child_list;
    va_start(child_list, parent);
    while (child = va_arg(child_list, Node*)) {
        parent->children[parent->child_ptr++] = child;
    }
    va_end(child_list);
    child = NULL;
}

    But when printing the tree structure, an error was reported

    Segmentation fault (core dumped)

    At the time I didn't know the cause of the error, but when I changed the function to:

    void AddChildren(Node* parent, int childnum, ...)
{
    if (parent == NULL) return;
    va_list child_list;
    va_start(child_list, childnum);
    for (int i = 0; i < childnum; i++) {
        parent->children[parent->child_ptr++] = va_arg(child_list, Node*);
    }
    va_end(child_list);
}

    After that, the code can run correctly.

    Later I found a relevant answer on Stackoverflow:https://stackoverflow.com/questions/9774803/stdarg-h-reads-too-many-arguments

    Some content is excerpted as follows:

    Don't use va_list, especially in member functions. And you need to know the number of the arguments, va_arg will happily read the entire memory if it can。

    So one solution is to pass a fixed number of arguments as I did above.

    Another guy gave another solution, which is to still use code similar to the second post, but pass an extra 0 as the termination sentinel for the while loop when passing arguments:

    Variadic function arguments are not typesafe, or any kind of 'safe' for that matter. It is your responsibility to communicate to your function how many arguments there are and what their types are.

    In your code, the only thing that makes the loop terminate is when x evaluates as false. Your data, obscurely typed as it is, seems to consist of integral values, and that would necessitate your last variadic argument to be zero, which it isn't in your example.

    Try calling the function wtih (n, x1, x2, x3, 0).
