C Standard Library -<time.h>

简介

time.hThe header file defines four variable types, two macros, and various functions for manipulating dates and times.

<time.h>It is a header file in the C standard library that provides functions and types for processing and manipulating dates and times. The functions in this header file are used to get the current time, set the time, format time, calculate time differences, and so on.

常量与宏

常量/宏说明
CLOCKS_PER_SECNumber of clock cycles per second.
NULLNull pointer constant.
TIME_UTCRepresents UTC time (C11).

库变量

Below are the variable types defined in the header file time.h:

序号Variable & Description
1size_t
Is an unsigned integer type, which issizeofKeyword result.
2clock_t
This is a type suitable for storing processor time.
3time_t is
This is a type suitable for storing calendar time.
4struct tm
This is a structure used to store time and date.

The tm structure is defined as follows:

struct tm {
   int tm_sec;         /* 秒，范围从 0 到 59        */
   int tm_min;         /* 分，范围从 0 到 59        */
   int tm_hour;        /* 小时，范围从 0 到 23        */
   int tm_mday;        /* 一月中的第几天，范围从 1 到 31    */
   int tm_mon;         /* 月，范围从 0 到 11        */
   int tm_year;        /* 自 1900 年起的年数        */
   int tm_wday;        /* 一周中的第几天，范围从 0 到 6    */
   int tm_yday;        /* 一年中的第几天，范围从 0 到 365    */
   int tm_isdst;       /* 夏令时                */
};

Below are the functions defined in the header file time.h:

序号Function & Description
1char *asctime(const struct tm *timeptr)
Returns a pointer to a string that represents the date and time of the structure timeptr.

Returns the amount of processor time used since program execution began (generally the start of the program).

Returns a string representing the local time, based on the parameter timer.

Formats the time represented by the structure timeptr according to the formatting rules defined in format, and stores it in str.

实例

以下是使用<time.h>Examples of some functions in

Get current time:

实例

#include <stdio.h>
#include <time.h>

int main() {
    time_t current_time;
    time(&current_time);
    printf("Current time: %s", ctime(&current_time));

    return 0;
}

Format time:

实例

#include <stdio.h>
#include <time.h>

int main() {
    time_t current_time;
    struct tm *time_info;
    char buffer[80];

    time(&current_time);
    time_info = localtime(&current_time);

    strftime(buffer, sizeof(buffer), "%Y-%m-%d %H:%M:%S", time_info);
    printf("Formatted time: %s\n", buffer);

    return 0;
}

Calculate time difference:

实例

#include <stdio.h>
#include <time.h>

int main() {
    time_t start_time, end_time;
    double time_diff;

    time(&start_time);
    // 模拟一个耗时操作
    for (int i = 0; i < 100000000; i++);

    time(&end_time);
    time_diff = difftime(end_time, start_time);
    printf("Time difference: %.2f seconds\n", time_diff);

    return 0;
}

使用struct tm:

实例

#include <stdio.h>
#include <time.h>

int main() {
    struct tm time_info;
    char buffer[80];

    time_info.tm_year = 2024 - 1900;  // 年份从 1900 年开始计算
    time_info.tm_mon = 5;             // 六月，范围从 0 到 11
    time_info.tm_mday = 12;
    time_info.tm_hour = 12;
    time_info.tm_min = 0;
    time_info.tm_sec = 0;
    time_info.tm_isdst = -1;          // 自动判断是否为夏令时

    mktime(&time_info);

    strftime(buffer, sizeof(buffer), "%Y-%m-%d %H:%M:%S", &time_info);
    printf("Custom time: %s\n", buffer);

    return 0;
}

注意事项

  • 使用localtime 和 gmtimeWhen, the pointer returned points tostruct tmThe structure is statically stored, and each call overwrites the previous content.
  • 使用mktimeWhen using the function, must ensurestruct tmThe various fields in are valid.
  • 使用strftimeWhen performing time formatting, ensure that the destination buffer is large enough to avoid buffer overflow.
