C 库宏 -errno

C 标准库 - <errno.h>

描述

C 库宏extern int errnois set by system calls, and certain library functions in error events indicate what error occurred.

errnois a macro in the C standard library, defined in<errno.h>In the header file. It is used to indicate errors that occur during program execution.errnois actually an integer variable used to store error codes. When library functions encounter an error, they seterrnoto an appropriate error code so that the program can inspect and handle these errors.

声明

Below is the declaration of the errno macro.

extern int errno

返回值

使用errno的步骤

  1. 包含头文件：在使用errnoBefore, it needs to include<errno.h>头文件。
  2. 调用函数: the call may seterrno的函数。
  3. 检查errno: when the function returns indicating an error, checkerrnoto get the error type.
  4. 处理错误：根据errnovalue, and take appropriate error-handling measures.

实例

The following example demonstrates the usage of the errno macro.

实例

#include <stdio.h> #include <errno.h> #include <string.h> extern int errno ; int main () { FILE *fp; fp = fopen("file.txt", "r"); if( fp == NULL ) { fprintf(stderr, "Value of errno: %d\n", errno); fprintf(stderr, "Error opening file: %s\n", strerror(errno)); } else { fclose(fp); } return(0); }

注意事项

  1. 线程安全: In a multi-threaded environment,errnois usually implemented as thread-local storage (TLS), ensuring that each thread has an independenterrno值。
  2. 初始值: When the function call succeeds,errnois usually not modified. Therefore, before handling errors, you should ensureerrnois set to 0.
  3. 跨平台差异: Different operating systems and C standard library implementations may define additional error codes. Programs should avoid relying on the numeric values of specific error codes.

Error handling suggestions

  1. 检查返回值: When calling functions that may fail, always check their return value.
  2. 设置errno为 0: Before calling the function, you canerrnoset to 0, so that after the function call you can checkerrnowhether it has been modified.
  3. 使用strerror 和 perror：strerror函数将errnoconvert into a readable error message string;perrorfunction prints out the errno value with a descriptive error message.errno值。

Detailed error handling

Below is a more detailed example demonstrating how to handle differenterrno值：

实例

#include <stdio.h>
#include <errno.h>
#include <string.h>

int main() {
    FILE *file = fopen("nonexistent_file.txt", "r");
    if (file == NULL) {
        switch (errno) {
            case EACCES:
                printf("Error: Permission denied\n");
                break;
            case ENOENT:
                printf("Error: No such file or directory\n");
                break;
            default:
                printf("Error opening file: %s\n", strerror(errno));
        }
        return 1;
    }

    // 文件处理代码
    fclose(file);
    return 0;
}

In this example, we checked the specificerrnovalue and handled accordingly. Iferrno 是 EACCES(Permission denied) orENOENT(No such file or directory), we print a specific error message; otherwise, we print a generic error message.

<errno.h>provides a standardized way to report and handle errors in programs, making error handling code more consistent and maintainable.
