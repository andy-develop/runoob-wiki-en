C Standard Library -<ctype.h>

Introduction

C Standard Library'sctype.hThe header file provides some functions that can be used to test and convert characters. These functions are mainly used to check character types (such as letters, digits, whitespace characters, etc.) and to perform character case conversion.

<ctype.h>It provides a convenient set of functions for handling character classification and conversion operations, and is an important tool for character operations in the C standard library.

The following is a simple example demonstrating how to use<ctype.h>Functions provided:

Example

#include <stdio.h>
#include <ctype.h>

int main() {
    char ch;

    // Example characters
    char chars[] = "a1 B? \n";

    // Check the type of each character
    for (int i = 0; chars[i] != '\0'; i++) {
        ch = chars[i];
        printf("Character: '%c'\n", ch);
        if (isalpha(ch)) {
            printf(" - isalpha: Yes\n");
        } else {
            printf(" - isalpha: No\n");
        }
        if (isdigit(ch)) {
            printf(" - isdigit: Yes\n");
        } else {
            printf(" - isdigit: No\n");
        }
        if (isspace(ch)) {
            printf(" - isspace: Yes\n");
        } else {
            printf(" - isspace: No\n");
        }
        if (isprint(ch)) {
            printf(" - isprint: Yes\n");
        } else {
            printf(" - isprint: No\n");
        }
        if (ispunct(ch)) {
            printf(" - ispunct: Yes\n");
        } else {
            printf(" - ispunct: No\n");
        }
    }

    // Character case conversion example
    char lower = 'a';
    char upper = 'A';

    printf("tolower('%c') = '%c'\n", upper, tolower(upper));
    printf("toupper('%c') = '%c'\n", lower, toupper(lower));

    return 0;
}

Library functions

The functions defined in the header file ctype.h are listed below.

These functions are used to test whether a character belongs to a certain type. They acceptintas an argument, whose value must be EOF or representable as an unsigned char.

If the argument c satisfies the described condition, these functions return nonzero (true). If the argument c does not satisfy the described condition, these functions return zero.
