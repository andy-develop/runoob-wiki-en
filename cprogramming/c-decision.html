? : operator (ternary operator)

We have already explained in previous chapters条件运算符 ? :, can be used to replaceif...elsestatement. Its general form is as follows:

Exp1 ? Exp2 : Exp3;

Here, Exp1, Exp2, and Exp3 are expressions. Note the usage and placement of the colons.

The value of the ? expression is determined by Exp1. If Exp1 is true, then Exp2 is evaluated, and the result is the value of the entire expression. If Exp1 is false, then Exp3 is evaluated, and the result is the value of the entire expression.

实例

The following example determines whether a number is odd or even by inputting a number

实例

#include<stdio.h> int main() { int num; printf("输入一个数字 :"); scanf("%d",&num); (num%2==0)?printf("偶数"):printf("奇数"); }

    The general form of the switch statement:

    switch(表达式)
{
    case 常量表达式1:语句1;
    case 常量表达式2:语句2;
    ...
    default:语句n+1;
}

    This means first evaluate the value of the expression, then compare it one by one with the constant expression after each case. If they are not equal, continue comparing downward. If none are equal throughout, execute the statement after default; if it equals a certain constant expression, start executing from the statement after that expression, and execute all statements after all subsequent case labels.

    Difference from the if statement: In an if statement, if the condition is true, only the statement following that condition is executed, and after execution it exits the if statement without executing other if statements. However, a switch statement does not exit after executing the statement following a true condition; instead, it continues to execute all subsequent case statements. Adding a break statement after each case statement allows exiting the switch statement after each execution, thereby avoiding unwanted output.

    #include <stdio.h>

int main()
{
    int a;
    printf("input integer number: ");
    scanf("%d",&a);
    switch(a)
    {
        case 1:printf("Monday\n");
        break;
        case 2:printf("Tuesday\n");
        break;
        case 3:printf("Wednesday\n");
        break;
        case 4:printf("Thursday\n");
        break;
        case 5:printf("Friday\n");
        break;
        case 6:printf("Saturday\n");
        break;
        case 7:printf("Sunday\n");
        break;
        default:printf("error\n");
    }
}
