C 环境设置

If you want to set up a C language environment, you need to make sure the following two pieces of software are available on your computer: a text editor and a C compiler.

文本编辑器

Files created with an editor are usually called source files; source files contain the program's source code.

C program source files usually use the extension.c。

Before starting programming, make sure you have a text editor and enough experience to write a computer program, then save it in a file, compile and execute it.

  • Visual Studio Code: Although it is a general-purpose text editor, it has many plugins supporting C/C++ development, making it a popular choice. By installing C/C++ plugins and adjusting settings, you can turn it into a great C language development environment.

    安装教程：https://www.runoob.com/w3cnote/vscode-tutorial.html

    下载地址：https://code.visualstudio.com/

  • Sublime Text: Sublime Text is a lightweight, fast, and highly customizable text editor with many plugins supporting C language development. It has powerful code editing features and shortcuts, making coding more efficient.

    下载地址：https://www.sublimetext.com/

  • AtomAtom is an open-source text editor developed by GitHub. It has many plugins and themes and can be customized into an environment suitable for C language development.

    下载地址：https://atom-editor.cc/

  • Vim 和 Emacs: These two are traditional text editors. They have powerful editing features and a high degree of customizability. They are very powerful for experienced users, and there are many plugins and configurations that can support C language development.

  • Eclipse: Eclipse is another powerful integrated development environment. Although it was originally designed for Java development, installing C/C++ plugins can make it support C language development.

    The source code written in the source file is human-readable source. It needs to be "compiled" into machine language so that the CPU can execute the program according to the given instructions.

    A C language compiler is used to compile source code into a final executable program. It is assumed here that you already have a basic understanding of programming language compilers.

    The most commonly used freely available compiler is the GNU C/C++ compiler. If you are using HP or Solaris, you can use the compiler on your respective operating system.

    The following sections will guide you on how to install the GNU C/C++ compiler on different operating systems. C/C++ is mentioned here mainly because the GNU gcc compiler is suitable for both C and C++ programming languages.

    Using GCC in the Windows environment

    MinGW is an abbreviation for Minimal GNU on Windows. It allows native Windows programs to be generated on GNU/Linux and Windows platforms without requiring third-party runtime libraries. This article mainly introduces the installation and usage of MinGW.

    (一)安装

    • 1. Download the MinGW installer, the link is:http://sourceforge.net/projects/mingw/files/，下载 mingw-get-setup.exe (86.5 kB)
    • 2. Run mingw-get-setup.exe (86.5 kB), click "Run", then Continue, etc. Remember the installation directory, such asC:\MinGw, it will also be used later when modifying environment variables.
    • 3. Modify environment variables: Select Computer -> Properties -> Advanced system settings -> Environment Variables. In the system variables, find the Path variable, and append the MinGW installation directory to it, such asC:\MinGw\bin
    • 4. In the Start menu, click "Run" and entercmdOpen the command line and enter:mingw-get.exe, if the MinGW Installation Manager window pops up, the installation is normal. At this point, close the MinGW Installation Manager window, otherwise the next steps will fail.
    • 5. Enter the command in cmdmingw-get install gcc, wait a moment, GCC will be installed successfully.

    If you want to install g++ or gdb, just enter the commandmingw-get install g++ 和 mingw-get install gdb

    (二)使用

    Write the C program test.c in the current working directory of cmd:

    # include <stdio.h>
int main()
{
    printf("%s\n","hello world");
    return 0;
}

    Enter the command in cmdgcc test.c

    An executable file a.exe will be generated in the current directory. You can run the program by entering a.exe in cmd.

    If you want to debug the program, you can enter gdb a.exe

    Enter the GDB interface, and you can debug the program using common GDB commands.

    Using gcc to compile C language is divided into four steps:

    1. Preprocessing, generate preprocessed file (.i file):

    gcc –E hello.c –o hello.i

    2. Compilation, generate assembly code (.s file):

    gcc –S hello.i –o hello.s

    3. Assembly, generate object file (.o file):

    gcc –c hello.s –o hello.o

    4. Link to generate the executable file:

    gcc hello.o –o hello

    Sometimes, during debugging, you might need one of the steps.

    Using VSCode to compile C language on Win10. After installing MinGW, find mingw32-gcc.bin, mingw32-gcc-g++.bin, and mingw32-gdb.bin in it. The first is the compiler for C language files, the second is for C++, and the third is used to debug the compiled files. Then set the environment variables, write the .c file, open the folder containing the .c file in VSCode (note: it must be a folder), and then configure the launch.json file as follows:

    {

    "version": "0.2.0",
    "configurations": [
        {
            "name": "(gdb) Launch",
            "type": "cppdbg",
            "request": "launch",
            "program": "${workspaceRoot}/${fileBasenameNoExtension}.exe",
            "args": [],
            "stopAtEntry": false,
            "cwd": "${workspaceRoot}",
            "environment": [],
            "externalConsole": true,
            "MIMode": "gdb",
            "miDebuggerPath": "E:\\MinGW\\bin\\gdb.exe",
            "preLaunchTask": "gcc",//tasks.json里面的名字
            "setupCommands": [
                {
                    "description": "Enable pretty-printing for gdb",
                    "text": "-enable-pretty-printing",
                    "ignoreFailures": true
                }
            ]
            
        }
    ]
}

    The tasks.json file is as follows:

    {

    "version": "2.0.0",
    "tasks": [
        {
            "label": "gcc",
            "type": "shell",
            "command": "gcc",
            "args": [
                "-g", "${file}","-o","${fileBasenameNoExtension}.exe"
            ],
            "group":{
                "kind": "build",
                "isDefault": true
            }
        }

    ]
}

    I am a beginner. I searched online for many methods of creating a C/C++ programming environment on Win10, and found they were all outdated. After struggling for a long time, I finally got it done, and I'd like to share it:

    Win10下使用eclipse创建C/C++编程环境的方法（64位系统）：

    1. 安装eclipse IDE for C/C++：进入https://www.eclipse.org/downloads/packages/release/oxygen/r/eclipse-ide-cc-developersChoose the 64-bit download according to your computer system. After downloading, it is recommended to extract it to the root directory of any drive.
    2. To install tdm-gcc: go to jmeubank.github.io, click download on the left side of the page, select tdm64-gcc and download the exe file. Double-click to open it, click Create, then choose the 64-bit option below, click Next, select the installation location (feel free to choose; it is still recommended to create a folder you can remember in the root directory for installation), and then wait for the installation process to complete.
    3. Setting up the environment variables is very simple: open the installation path of tdm-gcc that you just installed, and double-click mingwvars.bat, and the environment variables are set! (It's really too friendly for computer beginners like us!)
    4. After that, you can use Eclipse for C/C++ programming! Open the Eclipse folder that was downloaded and extracted in the first step, open Eclipse, go to File -> New -> Other -> C/C++ -> C Project. Select Executable -> Empty Project as the Project type, select MinGW GCC in the Toolchains on the right, enter a Project name, and click Finish. In the Project Explorer on the left, right-click the project name you just entered -> New -> File. Enter a name in File name, and be sure to add the ".c" suffix, for example: NewFile.c. Then double-click this .c file to start coding. To run it, first click the dropdown menu to the right of the hammer icon above, select Release, then click the Start button at the top left, and the program will run and produce output!
