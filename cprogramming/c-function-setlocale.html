C library functions -setlocale()

C 标准库 - <locale.h>

描述

setlocaleis the C standard library<locale.h>A function used to set or query the program's localization information. It allows programmers to specify locale settings for character classification, character conversion, currency formatting, date and time formatting, numeric formatting, etc.

声明

Below is the declaration of the setlocale() function.

#include <locale.h>

char *setlocale(int category, const char *locale);

参数

  • category: Specifies the localization category to set or query. It can be one of the following macros:

    • LC_ALL: Set or query all localization categories.
    • LC_COLLATE: Sets or queries localization information for string comparison.
    • LC_CTYPE: Sets or queries localization information for character handling.
    • LC_MONETARY: Sets or queries localization information for currency formatting.
    • LC_NUMERIC: Sets or queries localization information for numeric formatting.
    • LC_TIME: Sets or queries localization information for time formatting.

  • locale: Specifies the localization information to set. It can be one of the following:

    • "": Sets to the default setting in the user's environment variables.
    • NULL: Query current localization information.
    • Specific locale names: Such as "en_US.UTF-8", used to set a specific locale.

返回值

  • 如果locale 为 NULL, returns a pointer to the current locale information string.
  • 如果locale 非 NULLand if set successfully, returns a pointer to that locale information string.
  • 如果locale 非 NULLand if setting fails, returnNULL。

实例

The following is example code using setlocale, demonstrating how to set and query localization information.

Set and query localization information:

实例

#include <stdio.h>
#include <locale.h>

int main() {
    // 查询当前的本地化信息
    printf("Default locale: %s\n", setlocale(LC_ALL, NULL));

    // 设置本地化信息为用户环境变量中的默认设置
    setlocale(LC_ALL, "");

    // 获取和打印当前的本地化信息
    printf("Locale after setting to '': %s\n", setlocale(LC_ALL, NULL));

    // 设置本地化信息为 "en_US.UTF-8"
    if (setlocale(LC_ALL, "en_US.UTF-8") != NULL) {
        printf("Locale after setting to 'en_US.UTF-8': %s\n", setlocale(LC_ALL, NULL));
    } else {
        printf("Unable to set locale to 'en_US.UTF-8'\n");
    }

    return 0;
}

Let us compile and run the above program, this will produce the following result:

Default locale: C
Locale after setting to '': zh_CN.UTF-8
Locale after setting to 'en_US.UTF-8': en_US.UTF-8

Format numbers according to localization information:

实例

#include <stdio.h>
#include <locale.h>

int main() {
    // 设置本地化信息为用户环境变量中的默认设置
    setlocale(LC_NUMERIC, "");

    // 打印本地化的浮点数
    printf("Formatted number: %'.2f\n", 1234567.89);

    // 设置本地化信息为 "de_DE.UTF-8"（德语 - 德国）
    if (setlocale(LC_NUMERIC, "de_DE.UTF-8") != NULL) {
        printf("Locale after setting to 'de_DE.UTF-8': %s\n", setlocale(LC_NUMERIC, NULL));
        printf("Formatted number in German locale: %'.2f\n", 1234567.89);
    } else {
        printf("Unable to set locale to 'de_DE.UTF-8'\n");
    }

    return 0;
}

Let us compile and run the above program, this will produce the following result:

Formatted number: 1,234,567.89
Locale after setting to 'de_DE.UTF-8': de_DE.UTF-8
Formatted number in German locale: 1234567,89

详细说明

1. Set and query localization information

  • At the beginning of the program, you can usesetlocale(LC_ALL, "");Set the program's localization information to the default settings in the user environment variables. User environment variables are usually set by the operating system or the user, specifying the default locale that the program should use at runtime.
  • 可以使用setlocale(LC_ALL, "en_US.UTF-8");or other locale strings to set a specific locale.
  • 使用setlocale(LC_ALL, NULL);Queries the current localization information and returns a string describing the current locale.

2. Localization categories

Each category controls specific aspects of the program:

  • LC_COLLATE: affects string comparison functions (such asstrcoll 和 strxfrm）。
  • LC_CTYPE: affects character classification and conversion functions (such asisalpha 和 toupper）。
  • LC_MONETARY: affects functions related to currency formatting (such aslocaleconv）。
  • LC_NUMERIC: Affects numeric formatting (such as decimal point and thousands separator).
  • LC_TIME: affects date and time formats (such asstrftime）。

总结

setlocalefunction is an important tool for setting and querying program localization information. It allows programs to adapt to different languages and cultural conventions, thereby achieving internationalization and localization. By usingsetlocale, programs can correctly process and display localized information such as strings, numbers, currency, dates, and times.
