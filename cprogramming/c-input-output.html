C 输入 & 输出

当我们提到输入When, this means to fill some data into the program. Input can be from a file or from the command line. C language provides a series of built-in functions to read given input and fill it into the program as needed.

当我们提到输出When, this means to display some data on the screen, printer, or in any file. C language provides a series of built-in functions to output data to the computer screen and save data to text files or binary files.

标准文件

C language treats all devices as files. So devices (such as monitors) are handled in the same way as files. The following three files are automatically opened when the program is executed to access the keyboard and screen.

I/O (Input/Output) in C language usually usesprintf() 和 scanf()两个函数。

The scanf() function is used to read and format from standard input (keyboard), and the printf() function sends formatted output to standard output (screen).

scanf() 函数

The scanf() function is used to read formatted input from the standard input device (usually the keyboard).

语法：

int scanf(const char *format, ...);

参数：

  • format: Format string, specifies the format of the input.

  • ...: Variable argument list, provides the addresses of variables to store the input data based on the format specifiers in the format string.

实例

#include <stdio.h>

int main() {
    int a;
    float b;
    printf("Enter an integer and a float: ");
    scanf("%d %f", &a, &b);
    printf("You entered: %d and %.2f\n", a, b);
    return 0;
}

Execute the above code, then enter:

10 3.14

输出：

You entered: 10 and 3.14

Character input/output

getchar() & putchar() 函数

int getchar(void)The function reads the next available character from the screen and returns it as an integer. This function reads only a single character at a time. You can use this method in a loop to read multiple characters from the screen.

int putchar(int c)The function outputs a character to the screen and returns the same character. This function outputs only a single character at a time. You can use this method in a loop to output multiple characters to the screen.

See the following example:

实例

#include <stdio.h> int main( ) { int c; printf( "Enter a value :"); c = getchar( ); printf( "\nYou entered: "); putchar( c ); printf( "\n"); return 0; }

String input/output

gets() 和 fgets() 函数

The gets() function is used to read a line of string from the standard input device, but it is not recommended because it can easily lead to buffer overflow. It is recommended to usefgets()函数。

语法：

char *fgets(char *str, int n, FILE *stream);

参数：

  • str: Pointer to a character array, used to store the read string.

  • n: The maximum number of characters to read (including the null character\0）。

  • stream: file stream, usually usestdinRepresents standard input.

实例

#include <stdio.h>

int main() {
    char str[100];
    printf("Enter a string: ");
    fgets(str, sizeof(str), stdin);
    printf("You entered: %s", str);
    return 0;
}

puts() 函数

The puts() function is used to output a string to the standard output device and automatically adds a newline at the end.

语法：

int puts(const char *str);

参数：

  • str: the string to be output.

返回值：

  • Returns a non-negative value on success, and returns on failureEOF。

实例

#include <stdio.h>

int main() {
    char str[] = "Hello, World!";
    puts(str);
    return 0;
}

输出：

Hello, World!

fputs() 函数

The fputs() function is used to output a string to a specified stream (such as standard output, a file, etc.), but it does not automatically add a newline at the end of the string.

语法：

int fputs(const char *str, FILE *stream);

参数：

  • str: the string to be output (a character array that ends with a null\0character).

  • stream: Specifies the output stream, which can be standard output (stdout), file streams, etc.

返回值：

  • Returns a non-negative value on success (usually the number of characters output).

  • 失败时返回EOF。

特点：

  1. Does not add a newline character：fputs()It does not automatically add a newline after outputting the string.

  2. Flexible output stream：fputs()It can output to any stream, such as standard output, files, etc.

实例

#include <stdio.h>

int main() {
    char str[] = "Hello, World!";
    fputs(str, stdout);  // 输出 "Hello, World!"，不换行
    return 0;
}

File input and output

C language also provides file input/output capabilities, allowing data to be read from files or written to files.

fopen() 函数

The fopen() function is used to open a file.

语法：

FILE *fopen(const char *filename, const char *mode);

参数：

  • filename: the filename to be opened.

  • mode: the mode in which to open the file, such as"r"（只读）、"w"（只写）、"a"(append), etc.

返回值：

  • On success, returns a pointer toFILEpointer to the object, and on failure returnsNULL。

fclose() 函数

The fclose() function is used to close an opened file.

语法：

int fclose(FILE *stream);

参数：

  • stream：指向FILEa pointer to the object.

返回值：

  • 成功时返回0, on failure, returnsEOF。

实例

#include <stdio.h>

int main() {
    FILE *file;
    file = fopen("example.txt", "w");
    if (file != NULL) {
        fprintf(file, "Hello, world!\n");
        fclose(file);
    }

    char buffer[100];
    file = fopen("example.txt", "r");
    if (file != NULL) {
        fgets(buffer, sizeof(buffer), file);  // 读取整行
        printf("Read from file: %s", buffer);  // fgets 会保留换行符
        fclose(file);
    }
    return 0;
}

输出内容：

Read from file: Hello, world!

    gets()与fgets()

    gets()

    gets function prototype: char*gets(char*buffer);//Reads characters into an array: gets(str); str is the array name.

    Function of gets(): reads characters from the keyboard until a newline character or EOF is received, then stops, and stores the read result in the character array pointed to by the buffer pointer.

    The newline character read is converted to a null value, which is used as the last character of the character array to terminate the string.

    注意：Because the gets function does not specify the input character size, it will read indefinitely. Once the input characters exceed the array length, a memory out-of-bounds will occur,

    Causing program crashes or errors in other data.

    fgets()

    fgets函数原型：char *fgets(char *s, int n, FILE *stream);//我们平时可以这么使用：fgets(str, sizeof(str), stdin);

    Here, str is the first address of the array, sizeof(str) is the size of the array, and stdin means we input data from the keyboard.

    Function of the fgets function: read characters from the file pointer stream, store them into the space starting at address s, until N-1 characters have been read, or a line has been read.

    注意：When calling the fgets function, at most n-1 characters can be read. After reading, the system will automatically add '\0' at the end, and return str as the function value.

    Borrowing the tutorial example, I changed char str

    #include <stdio.h>

int main( )
{
    char str[5];

    printf( "Enter a value :");
    gets( str );

    printf( "\nYou entered: ");
    puts( str );
    return 0;
}

    If 123 is entered (length less than 5), the result is:

    Enter a value :123

You entered: 123

    If 123456789 is entered (length greater than 5), the result is:

    Enter a value :123456789

You entered: 123456789

    Although it displayed normally, the system indicated that the program crashed.

    If the gets() function is not used correctly, the harm it brings is significant. As we saw above, when the length of the input string is greater than the buffer length, it is not truncated; the read string is output as-is, causing the program to crash.

    考虑到程序安全性和健壮性，建议用fgets()来代替gets()。如： 
    #include <stdio.h>

int main( )
{

    printf( "Enter a value :");
    fgets( str,5,stdin );      //fgets()函数;

    printf( "\nYou entered: ");
    puts( str );

    Line break issues in different operating systems Windows, Unix, Mac: carriage return \r and line feed \n

    一、概念：

    Newline character '\n'和Carriage return character '\r'

    (1) Line feed means starting a new line --- '\n' 10 换行（newline）

    (2) Carriage return means returning to the beginning of a line --- '\r' 13 回车（return）

    Therefore, the carriage return character we usually use when writing files should, strictly speaking, be called回车换行符

    CR: 回车(Carriage Return) \rLF: 换行(Line Feed) \n

    二、应用：

    (1) In Microsoft's MS-DOS and Windows, two characters, "carriage return CR ('\r')" and "line feed LF ('\n')", are used as line breaks;

    (2) In the Windows system, each line ends with carriage return + line feed (CR+LF), i.e., "\r\n";

    (3) In Unix systems, there is only a line feed LF at the end of each line, i.e., "\n";

    (4) In Mac systems, the end of each line is carriage return CR, i.e., '\r'.

    The newline character in Mac OS 9 and earlier systems is CR. Starting from Mac OS X (later renamed "OS X"), the newline character is LF, i.e., '\n', which is unified with Unix/Linux.

    三、影响：

    (1) A direct consequence is that if files under Unix/Mac systems are opened in Windows, all text will become one line;

    (2) Conversely, if files from Windows are opened under Unix/Mac, an ^M symbol may appear at the end of each line.

    (3) Files saved in Linux may show black dots when viewed with Notepad on Windows.

    4. They can be converted to each other.：

    Under Linux, the command unix2dos converts Linux file format to Windows file format, and the command dos2unix converts Windows format to Linux file format.

    When transferring files between different platforms using FTP software, in ASCII text mode transfer mode, some FTP client programs automatically convert line break formats. The byte count of files transferred this way may change.

    If you do not want FTP to modify the original file, you can use bin mode (binary mode) to transfer text.

    A program running on Windows generates text files with CR/LF newline format, while running on Linux it generates text files with LF newline format.

    When learning C language, character input once troubled me, for example this code:

    int i;
char c;
scanf("%d%c", &i,&c);

    At this point, what is stored in variable c is often not the character you want to input, but a space. Then we would write it like this:

    int i;
char c;
scanf("%d", &i);
scanf("%c", &c);

    At this point, we find that there is no chance to input character C at all. Why is this? Because the input stream has a buffer; the characters we input are stored there, and then assigned to our variable. We can change it like this:

    int i;
char c;
scanf("%d", &i);
while((c=getchar())==' ' || c=='\n');
c = getchar();

    This method reads continuously, and breaks out of the loop when there are no spaces or newlines, but there is a better solution;

    int i;
char c;
scanf("%d%[^' '^'\n']", &i, &c);

    This uses regular expressions to control the input format to be non-space and non-newline.

    When performing output, if you need to use the format specifier used to output real numbersfformat specifier (output in decimal form), there are the following usages:

    1. Basic type, using %f

    Do not specify the length of the output type; let the system decide based on the situation. Generally, the integer part of a real number is fully output, and the fractional part outputs six digits. Example:

    #include<stdio.h>
int main()
{
    double a=1.0;
    printf("%f\n",a/3);
    return 0;
}

    运行结果：0.333333

    2. Specify the data width and number of decimal places, using%m.nf

    Example: To output the double-precision variable a from the previous program with 15 decimal places, use%20.15fformat declaration, specifying that the output data occupies 20 columns, including 15 decimal places. Modify the above program as follows:

    #include<stdio.h>
int main()
{
    double a=1.0;
    printf("%20.15f\n",a/3);
    return 0;
}

    运行结果：   0.333333333333333

    Note: there are 3 spaces before 0, and double-precision numbers only guarantee accuracy to 15 significant digits.

    3. To left-align the output data, use%-m.nf

    在 m.na minus sign before it; its effect is the same as%m.nfThe formal usage is basically the same, but when the data length does not exceedmwhen, the data aligns to the left and spaces are padded on the right.

    In C language, each data type has its own placeholder for output. Below are the output placeholders for various data types:

    short/int : %d

    int a = 1;
printf("这个整数是：%d", a);

    long: %ld(long is a modifier of int and cannot be considered a separate data type; it just has 4 more bytes of storage space than int.)

    long long : %lld

    char : %c

    float/double : %ffloat defaults to 6 decimal places for output; this can be controlled in %f; for example: %.2f: outputs two decimal places.

    char *s (string):%s

    unsigned: %u(signed: signed type, unsigned: unsigned type; the default is signed.)

    八进制：%o 以 0开头

    十六进制：%x 以 0x开头

    int a = 10;
printf("a的八进制输出是：%o \n", a);//输出是12
printf("a的十六进制输出：%x \n", a);//输出是a

    地址值/指针值：%p，*Gets the value at the location pointed to by the address in the pointer,&Gets the address value of the location where that value is stored.

    There is no placeholder for binary output; it can only be done through other methods.
