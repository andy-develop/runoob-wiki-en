C Input & Output

When we mentionInputWhen, this means to fill some data into the program. Input can be from a file or from the command line. C language provides a series of built-in functions to read given input and fill it into the program as needed.

When we mentionOutputWhen, this means to display some data on the screen, printer, or in any file. C language provides a series of built-in functions to output data to the computer screen and save data to text files or binary files.

standard files

C language treats all devices as files. So devices (such as monitors) are handled in the same way as files. The following three files are automatically opened when the program is executed to access the keyboard and screen.

I/O (Input/Output) in C language usually usesprintf()andscanf()Two functions.

The scanf() function is used to read and format from standard input (keyboard), and the printf() function sends formatted output to standard output (screen).

printf() function

The printf() function is used to output formatted data to the standard output device (usually the screen).

Syntax:

int printf(const char *format, ...);

Parameters:

  • format: Format string, specifies the format of the output.

  • ...: Variable argument list, provides the data to be output according to the format specifiers in the format string.

Example

#include <stdio.h>// Executing the printf() function requires this library int main() { printf("Runoob"); // Display the content in quotes return 0; }

scanf() function

The scanf() function is used to read formatted input from the standard input device (usually the keyboard).

Syntax:

int scanf(const char *format, ...);

Parameters:

  • format: Format string, specifies the format of the input.

  • ...: Variable argument list, provides the addresses of variables to store the input data based on the format specifiers in the format string.

Example

#include <stdio.h>

int main() {
    int a;
    float b;
    printf("Enter an integer and a float: ");
    scanf("%d %f", &a, &b);
    printf("You entered: %d and %.2f\n", a, b);
    return 0;
}

Execute the above code, then enter:

10 3.14

Output:

You entered: 10 and 3.14

String input/output

gets() and fgets() functions

The gets() function is used to read a line of string from the standard input device, but it is not recommended because it can easily lead to buffer overflow. It is recommended to usefgets()function.

Syntax:

char *fgets(char *str, int n, FILE *stream);

Parameters:

  • str: Pointer to a character array, used to store the read string.

  • n: The maximum number of characters to read (including the null character\0）。

  • stream: file stream, usually usestdinRepresents standard input.

Example

#include <stdio.h>

int main() {
    char str[100];
    printf("Enter a string: ");
    fgets(str, sizeof(str), stdin);
    printf("You entered: %s", str);
    return 0;
}

puts() function

The puts() function is used to output a string to the standard output device and automatically adds a newline at the end.

Syntax:

int puts(const char *str);

Parameters:

  • str: the string to be output.

Return value:

  • Returns a non-negative value on success, and returns on failureEOF。

Example

#include <stdio.h>

int main() {
    char str[] = "Hello, World!";
    puts(str);
    return 0;
}

Output:

Hello, World!

fputs() function

The fputs() function is used to output a string to a specified stream (such as standard output, a file, etc.), but it does not automatically add a newline at the end of the string.

Syntax:

int fputs(const char *str, FILE *stream);

Parameters:

  • str: the string to be output (a character array that ends with a null\0character).

  • stream: Specifies the output stream, which can be standard output (stdout), file streams, etc.

Return value:

  • Returns a non-negative value on success (usually the number of characters output).

  • Return on failureEOF。

Features:

  1. Does not add a newline character：fputs()It does not automatically add a newline after outputting the string.

  2. Flexible output stream：fputs()It can output to any stream, such as standard output, files, etc.

Example

#include <stdio.h>

int main() {
    char str[] = "Hello, World!";
    fputs(str, stdout);  // Output "Hello, World!" without newline
    return 0;
}

File input and output

C language also provides file input/output capabilities, allowing data to be read from files or written to files.

fopen() function

The fopen() function is used to open a file.

Syntax:

FILE *fopen(const char *filename, const char *mode);

Parameters:

  • filename: the filename to be opened.

  • mode: the mode in which to open the file, such as"r"(read-only),"w"(write-only),"a"(append), etc.

Return value:

  • On success, returns a pointer toFILEpointer to the object, and on failure returnsNULL。

fclose() function

The fclose() function is used to close an opened file.

Syntax:

int fclose(FILE *stream);

Parameters:

  • stream: points toFILEa pointer to the object.

Return value:

  • returns on success0, on failure, returnsEOF。

Example

#include <stdio.h>

int main() {
    FILE *file;
    file = fopen("example.txt", "w");
    if (file != NULL) {
        fprintf(file, "Hello, world!\n");
        fclose(file);
    }

    char buffer[100];
    file = fopen("example.txt", "r");
    if (file != NULL) {
        fgets(buffer, sizeof(buffer), file);  // Read an entire line
        printf("Read from file: %s", buffer);  // fgets retains the newline character
        fclose(file);
    }
    return 0;
}

Output content:

Read from file: Hello, world!
