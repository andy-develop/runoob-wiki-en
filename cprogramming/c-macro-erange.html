C 库宏 -ERANGE

C 标准库 - <errno.h>

描述

C 库宏ERANGEIndicates a range error, which occurs when the input argument exceeds the range defined by the mathematical function, and errno is set to ERANGE.

ERANGEis a macro in the C standard library, defined in<errno.h>in the header file. It is used to indicate an error where the result exceeds the range defined by the function, usually occurring when the result of a mathematical function or conversion function exceeds the representable range.

声明

Below is the declaration of the ERANGE macro.

#define ERANGE some_value

参数

  • NA

返回值

  • NA

实例

The following are several uses ofERANGEexample demonstrating how to handle an out-of-range result error.

数学函数

In mathematical calculations, such as theexp 或 logfunction, an error may occur.ERANGEerror. For example, when calculating a very large exponent, the result may exceed the representable range of floating-point numbers.

实例

#include <stdio.h>
#include <math.h>
#include <errno.h>

int main() {
    double x = 1000.0;
    double result;

    // 清除之前的错误
    errno = 0;

    // 调用 exp 函数，可能导致结果超出范围
    result = exp(x);

    if (errno == ERANGE) {
        printf("Error: exp() result out of range for input value %f\n", x);
    } else {
        printf("The exp of %f is %f\n", x, result);
    }

    return 0;
}

In this example, computeexp(1000.0)may cause the result to go out of range, in which caseerrno会被设置为ERANGE。

Let us compile and run the above program, which will produce the following result:

The exp of 1000.000000 is inf

转换函数

In numerical conversions, such as thestrtol 或 strtodfunction, if the conversion result exceeds the range of the target type,errnowill also be set toERANGE。

实例

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <limits.h>

int main() {
    const char *str = "99999999999999999999999999";
    long result;

    // 清除之前的错误
    errno = 0;

    // 调用 strtol 函数，可能导致结果超出范围
    result = strtol(str, NULL, 10);

    if (errno == ERANGE) {
        printf("Error: strtol() result out of range for input string %s\n", str);
    } else {
        printf("The converted long value is %ld\n", result);
    }

    return 0;
}

In this example, the string"99999999999999999999999999"转换为longwhen the value is of type, the result exceedslongthe representable range oferrno会被设置为ERANGE。

Let us compile and run the above program, which will produce the following result:

Error: strtol() result out of range for input string 99999999999999999999999999

Usage Precautions

  1. 检查返回值: After calling a function that may produce a range error, the return value should be checked. Typically, these functions return a special value on error (such asHUGE_VAL、HUGE_VALF、HUGE_VALL 或 0）。
  2. 初始化errno: before calling the function, you shoulderrnoset to 0, to ensure that the error code was produced by this call, rather than left over from a previous call.
  3. Handling Range Errors：当检测到ERANGEWhen an error occurs, it should be handled appropriately according to the context, for example by printing an error message, using an alternative value, or retrying the calculation.

Related Functions and Error Codes

  • 数学函数：如exp, log, pow, sin, cos, tan, they may set when the calculation result exceeds the representable range.errno 为 ERANGE。
  • 转换函数：如strtol, strtoll, strtoul, strtoull, strtof, strtod, strtold, they may set when the conversion result exceeds the representable range.errno 为 ERANGE。

Other Related Error Codes

  • EDOM: Indicates a domain error in a mathematical function, i.e., the argument is outside the domain of definition.
  • EILSEQ: Indicates an illegal byte sequence error, which typically occurs when processing multibyte characters or wide characters.

Through the proper use oferrno、ERANGEand its related functions, you can write more robust and reliable code, ensuring that the program can still handle and respond properly under various abnormal conditions.
