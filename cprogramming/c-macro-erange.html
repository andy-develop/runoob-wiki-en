C Library Macro -ERANGE

C Standard Library - <errno.h>

Description

C Library MacroERANGEIndicates a range error, which occurs when the input argument exceeds the range defined by the mathematical function, and errno is set to ERANGE.

ERANGEis a macro in the C standard library, defined in<errno.h>in the header file. It is used to indicate an error where the result exceeds the range defined by the function, usually occurring when the result of a mathematical function or conversion function exceeds the representable range.

Mathematical Functions

In mathematical calculations, such as theexporlogfunction, an error may occur.ERANGEerror. For example, when calculating a very large exponent, the result may exceed the representable range of floating-point numbers.

Example

#include <math.h>
#include <errno.h>

int main() {
    double x = 1000.0;
    double result;

    // Clear previous error
    errno = 0;

    // Call exp function, may cause result out of range
    result = exp(x);

    if (errno == ERANGE) {
        printf("Error: exp() result out of range for input value %f\n", x);
    } else {
        printf("The exp of %f is %f\n", x, result);
    }

    return 0;
}
