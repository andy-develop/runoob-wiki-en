Error Handling

ldexp()The function does not return an error status, but in some cases, the input may cause overflow or underflow. For results that are too large or too small, positive infinity, negative infinity, or zero may be returned. Using theisinf()andisnan()function can detect these conditions.

The following example shows how to handle possible overflow and underflow conditions:

Example

#include <stdio.h>
#include <math.h>
#include <errno.h>

int main() {
    double x = 1.0;
    int exponent = 1024;
    double result = ldexp(x, exponent);

    if (isinf(result)) {
        printf("Overflow: ldexp(%f, %d) results in infinity.\n", x, exponent);
    } else if (result == 0.0 && errno == ERANGE) {
        printf("Underflow: ldexp(%f, %d) results in zero.\n", x, exponent);
    } else {
        printf("ldexp(%f, %d) = %f\n", x, exponent, result);
    }

    return 0;
}

Let us compile and run the above program, which will produce the following result:

Overflow: ldexp(1.000000, 1024) results in infinity.
