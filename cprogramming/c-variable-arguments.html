C 可变参数

Sometimes, you may encounter a situation where you want a function to have a variable number of arguments, rather than a predefined number of arguments.

The C language provides a solution for this situation, allowing you to define a function that can accept a variable number of arguments according to specific requirements.

The declaration method is:

int func_name(int arg1, ...);

Where, the ellipsis...Represents a variable argument list.

The following example demonstrates the use of this function:

int func(int, ... ) { . . . } int main() { func(2, 2, 3); func(3, 2, 3, 4); }

Please note, the functionfunc()The last parameter is written as an ellipsis, i.e., three dots (...), the parameter before the ellipsis isint, which represents the total number of variable arguments to be passed. In order to use this feature, you need to use thestdarg.hheader file, which provides functions and macros for implementing variable arguments. The specific steps are as follows:

  • Define a function whose last parameter is an ellipsis, and custom parameters can be set before the ellipsis.
  • In the function definition, create ava_listtype variable, this type is defined in the stdarg.h header file.
  • 使用int参数和va_start()宏来初始化va_listvariable as a parameter list. The macrova_start()is defined in the stdarg.h header file.
  • 使用va_arg()宏和va_listvariable to access each item in the argument list.
  • 使用宏va_end()来清理赋予va_listThe variable's memory.

Commonly used macros include:

  • va_start(ap, last_arg): Initializes the variable argument list.ap是一个va_listA variable of type,last_argis the name of the last fixed parameter (that is, the parameter before the variable argument list). This macro causesapto point to the first parameter in the variable argument list.

  • va_arg(ap, type): Obtain the next parameter in the variable argument list.ap是一个va_listA variable of type,typeis the type of the next parameter. This macro returns a value of typetype的值，并将apPoints to the next argument.

  • va_end(ap): Ends access to the variable argument list.ap是一个va_listvariable of type. This macroap置为NULL。

Now let us follow the above steps to write a function with a variable number of parameters and return their average:

实例

#include <stdio.h> #include <stdarg.h> double average(int num,...) { va_list valist; double sum = 0.0; int i; /*为 num 个参数初始化 valist*/ va_start(valist, num); /*访问所有赋给 valist 的参数*/ for (i = 0; i < num; i++) { sum += va_arg(valist, int); } /*清理为 valist 保留的内存*/ va_end(valist); return sum/num; } int main() { printf("Average of 2, 3, 4, 5 = %f\n", average(4, 2,3,4,5)); printf("Average of 5, 10, 15 = %f\n", average(3, 5,10,15)); }

In the above example, the average() function accepts an integer num and any number of integer arguments. Inside the function, a variable va_list of type va_list is used to access the variable argument list. In the loop, each time the va_arg() macro is used to obtain the next integer argument and output it. Finally, at the end of the function, the va_end() macro is used to end the access to the variable argument list.

When the above code is compiled and executed, it produces the following results. It should be noted that the function average()is called twice, and each time the first parameter indicates the total number of variable arguments passed. The ellipsis is used to pass a variable number of arguments.

Average of 2, 3, 4, 5 = 3.500000
Average of 5, 10, 15 = 10.000000

    1. Variable Arguments

    #include <stdio.h>

void debug_arg(unsigned int num, ...) 
{
    unsigned int i = 0;
    unsigned int *addr = &num;
    for (i = 0; i <= num; i++) 
    {
        /* *(addr + i) 从左往右依次取出传递进来的参数,类似于出栈过程 */
        printf("i=%d,value=%d\r\n", i, *(addr + i));
    }
}
int main(void)
{
    debug_arg(3, 66, 88, 666);
    return 0;
}

    The working principle of variable arguments, taking a 32-bit machine as an example:

    • 1. Function argument passing is stored on the stack, pushed from right to left, and the pushing process is decreasing.
    • 2. Argument passing is aligned to 4 bytes; float/double is not discussed here.

    C functions need to use the following macros in a program:

    void va_start( va_list arg_ptr, prev_param ); 
type va_arg( va_list arg_ptr, type ); 
void va_end( va_list arg_ptr );

    va_list: A type used to save the information required by the macros va_start, va_arg, and va_end. In order to access the arguments in a variable-length argument list, you must declare an object of type va_list, defined as:typedef char * va_list;

    va_start: The macro used before accessing parameters in the variable argument list. It initializes the object declared with va_list, and the initialization result is used by the macros va_arg and va_end;

    va_arg: A macro that expands into an expression that has the value and type of the next argument in the variable-length argument list. Each call to va_arg modifies the object declared with va_list so that the object points to the next argument in the argument list;

    va_end: This macro enables the program to return normally from a function whose variable-length argument list was referenced by the macro va_start.

    vaHere it means variable-argument (variable parameters).

    These macros are defined in stdarg.h, so programs using variable arguments should include this header file.

    Below we write a simple function with variable arguments. The function has at least one integer parameter, and the second parameter is also an integer and is optional. The function simply prints the values of these two parameters.

    #include <stdio.h>;  
#include <string.h>;  
#include <stdarg.h>;  

/* ANSI标准形式的声明方式，括号内的省略号表示可选参数 */  
int demo(char *msg, ... )  
{  
    va_list argp;                    /* 定义保存函数参数的结构 */  
    int argno = 0;                    /* 纪录参数个数 */  
    char *para;                        /* 存放取出的字符串参数 */                                      
    va_start( argp, msg );          /* argp指向传入的第一个可选参数，      msg是最后一个确定的参数 */  
    
    while (1) 
    {  
        para = va_arg( argp, char *);                 /*      取出当前的参数，类型为char *. */  
        if ( strcmp( para, "/0") == 0 )  
                                                      /* 采用空串指示参数输入结束 */  
            break;  
        printf("Parameter #%d is: %s/n", argno, para);  
        argno++;  
    }  
    va_end( argp );                                   /* 将argp置为NULL */  
    return 0;  
}

int main( void )  
{  
    demo("DEMO", "This", "is", "a", "demo!" ,"333333", "/0");  
}

    From the implementation of this function, we can see that using variable arguments should follow the following steps:

    • 1) First, define a variable of type va_list in the function, here arg_ptr. This variable is a pointer to the arguments.
    • 2) Then use the va_start macro to initialize the variable arg_ptr. The second parameter of this macro is the parameter before the first variable argument, which is a fixed parameter.
    • 3) Then use va_arg to return the variable argument and assign it to the integer j. The second parameter of va_arg is the type of the parameter you want to return; here it is int.
    • 4) Finally, use the va_end macro to end the retrieval of variable arguments. Then you can use the second parameter in the function. If the function has multiple variable arguments, call va_arg in sequence to obtain each argument.

    Throughout the entire tutorial up to this point, this is the section I found the most difficult to understand. After referring to other people's annotations on stdarg.h, it took me a long time to figure it out. I added some of my own comments to the stdarg.h function source code used in this section:

    // 本质上，va_list 类型，就是「char指针」类型，指向 1B 大小的内存地址
typedef char* va_list;

// 把 n 圆整到 sizeof(int) 的倍数，和内存的边界对齐有关，下面移动指针、计算地址时会用到
// 函数的参数都是压栈传递，在内存中连续分布，每个参数的地址均为 sizeof(int) 的整数倍
#define _INTSIZEOF(n)       ( (sizeof(n)+sizeof(int)-1) & ~(sizeof(int)-1) )

// 初始化 ap 指针，使其指向第一个可变参数。v 是变参列表的前一个参数
// 对参数 v 取地址，转成 char* 类型的地址，再加上 v 的大小，ap 就指向了下一个参数地址，
// 即第一个「可变参数」的地址
#define va_start(ap,v)      ( ap = (va_list)&v + _INTSIZEOF(v) )

// 该宏返回「当前变参值」,并使 ap 指向列表中的「下个变参」
// 把当前 ap 所指参数称为「第i个参数」
// 获取「第i个参数」的大小，圆整到 int 大小的整数倍（为了边界对齐）：_INTSIZEOF(type)
// 为 ap 加上「圆整后的大小」，使 ap 更新，指向「第i+1个参数」的地址
// 此刻，「更新后的 ap 」减「圆整后的大小」，就是「第i个参数」的地址，类型为 char*
// 「第i个参数」的地址转为「type*」类型：(type*)
// 再用 * 对「转换类型后的地址」取值
// 最终，就得到了「第i个参数」，同时 ap 也指向了「第i+1个参数」地址
#define va_arg(ap, type)    ( *(type*)((ap += _INTSIZEOF(type)) - _INTSIZEOF(type)) )

// 将指针 ap 置为无效，结束变参的获取
// 本质上就是将一个 char* 指针指向 0 地址
#define va_end(ap)             ( ap = (va_list)0 )

    The C language provides support for variable arguments, which can be implemented by using the macros and functions in the <stdarg.h> header file. The main functions and macros involved are as follows:

    • va_start(va_list ap, last_arg) macro: used to make ap point to the first parameter of the variable argument list; last_arg is the last known parameter in the variable argument list, usually a function parameter. This macro should be called before using variable arguments.
    • va_arg(va_list ap, type) macro: used to obtain the current argument pointed to by ap and move the pointer to the next argument. type indicates the type of the current argument.
    • The va_copy(va_list dest, va_list src) macro: Used to copy the parameters pointed to by src into dest.
    • va_end(va_list ap) macro: used to end the retrieval of variable arguments and release resources.

    The following is an example program showing how to use variable arguments:

    #include <stdarg.h>
#include <stdio.h>

int sum(int count, ...) {
    va_list ap;  // 定义可变参数列表
    int result = 0;
    va_start(ap, count);  // 将ap指向可变参数列表的第一个参数
    for (int i = 0; i < count; ++i) {
        result += va_arg(ap, int);  // 获取当前参数，并将指针移动到下一个参数
    }
    va_end(ap);  // 结束可变参数的获取
    return result;
}

int main() {
    printf("sum(3, 1, 2, 3) = %d\n", sum(3, 1, 2, 3));
    printf("sum(5, 1, 2, 3, 4, 5) = %d\n", sum(5, 1, 2, 3, 4, 5));
    return 0;
}

    The output result is:

    sum(3, 1, 2, 3) = 6
sum(5, 1, 2, 3, 4, 5) = 15
