C Standard Library -<signal.h>

简介

<signal.h>It is a header file in the C standard library used for handling signals.

signal.hThe header file defines a variable typesig_atomic_ttwo function calls, and some macros to handle different signals reported during program execution.

A signal is an asynchronous notification mechanism that allows a process to execute a predefined handler function when a specific event occurs.

Below is a simple example program demonstrating how to use the signal function to catch the SIGINT signal (usually generated by Ctrl+C).

实例

#include <stdio.h>
#include <signal.h>
#include <unistd.h>

// 全局变量，指示程序是否应退出
volatile sig_atomic_t stop = 0;

void handle_sigint(int sig) {
    printf("Caught signal %d\n", sig);
    stop = 1; // 设置退出标志
}

int main() {
    // 将 SIGINT 信号的处理程序设置为 handle_sigint 函数
    signal(SIGINT, handle_sigint);

    while (!stop) { // 检查是否应退出
        printf("Running...\n");
        sleep(1);
    }

    printf("Exiting...\n");

    return 0;
}

In the above code, when the program is running, if the user pressesCtrl+C, it will catch the SIGINT signal and call the handle_sigint function, printing the signal number.

Compile and execute the above code, the output is as follows:

Running...
Running...
Running...
^CCaught signal 2
Exiting...

代码解析：

  • volatile sig_atomic_t stop = 0;: define a global variablestop, used to indicate whether the program should exit. Usingvolatilethe keyword ensures that the compiler will not optimize away accesses to this variable, because it may be modified in a signal handler.sig_atomic_tThe type guarantees that accesses to this variable are atomic.
  • 在 handle_sigintIn the signal handler function, setstopto 1, indicating the program should exit.
  • In the main loop, checkstopthe value of the variable; if it is set to 1, break out of the loop and end the program.
