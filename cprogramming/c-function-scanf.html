C 库函数 – sscanf()

C library functions -scanf()

C 标准库 - <stdio.h>

描述

C 库函数int scanf(const char *format, ...)Read formatted input from standard input stdin.

声明

The following is the declaration of the scanf() function.

int scanf(const char *format, ...)

参数

  • format-- This is a C string, containing one or more of the following items:空格字符、非空格字符 和 format 说明符。

The format specifier has the form:

[=%[*][width][modifiers]type=]

The specific explanation is as follows:

参数描述
*This is an optional asterisk, indicating that the data is read from the stream but can be ignored, i.e., it is not stored in the corresponding argument.
widthThis specifies the maximum number of characters to be read in the current read operation.
modifiersSpecifies a size different from integer (for d, i, and n), unsigned integer (for o, u, and x), or floating-point (for e, f, and g) for the data pointed to by the corresponding additional argument: h: short integer (for d, i, and n), or unsigned short integer (for o, u, and x) l: long integer (for d, i, and n), or unsigned long integer (for o, u, and x), or double precision (for e, f, and g) L: long double precision (for e, f, and g)
typeA character specifying the type of data to be read and the way the data is read. See the next table for details.

scanf 类型说明符：

类型合格的输入参数的类型
%a、%A Reads in a floating-point value (valid only in C99).float *
%cSingle character: reads the next character. If a width other than 1 is specified, the function reads width characters and, through the argument, stores them in consecutive positions in the array. No null character is appended at the end.char *
%dDecimal integer: the + or - sign before the number is optional.int *
%e、%E、%f、%F、%g、%GFloating point: contains a decimal point, an optional leading sign + or -, an optional trailing character e or E, and a decimal number. Two valid examples are -732.103 and 7.12e4float *
%iReads in decimal, octal, and hexadecimal integers.int *
%oOctal integer.int *
%sString. This reads consecutive characters until a whitespace character is encountered (whitespace characters can be spaces, newlines, and tabs).char *
%uAn unsigned decimal integer.unsigned int *
%x、%XHexadecimal integer.int *
%p Reads a pointer. 
%[] Scans a character set. 
%% Read the % sign. 
  • 附加参数-- Depending on the different format string, the function may require a series of additional arguments, each containing a value to be inserted, replacing each % tag specified in the format argument. The number of arguments should be the same as the number of % tags.

返回值

If successful, the function returns the number of successfully matched and assigned items. If the end of the file is reached or a read error occurs, it returns EOF.

实例

The following example demonstrates the usage of the scanf() function.

实例

#include<stdio.h> int main(void) { int a,b,c; printf("请输入三个数字："); scanf("%d%d%d",&a,&b,&c); printf("%d,%d,%d\n",a,b,c); return 0; }

Let us compile and run the above program, which will produce the following result in interactive mode:

请输入三个数字：1 2 3
1,2,3

解析说明：

  • 1、&a、&b、&c中的&Is the address operator, which respectively obtains the memory addresses of these three variables.
  • 2、%d%d%dIt inputs three numeric values in decimal format. When inputting, one or more spaces, Tab keys, or Enter keys can be used to separate the two data items.
如果使用,来分隔输入的%d, 相应的输入时也需要添加,:

实例

#include<stdio.h> int main(void) { int a,b,c; printf("请输入三个数字："); scanf("%d, %d, %d",&a,&b,&c); printf("%d, %d, %d\n",a,b,c); return 0; }

Let us compile and run the above program, which will produce the following result in interactive mode:

请输入三个数字：1, 2, 3
1, 2, 3

注意：输入时,Must immediately follow the number; the number and,No spaces are allowed between them.

When using %c for input, spaces and "escape characters" are both treated as valid characters.

实例

#include<stdio.h> int main(void) { char a,b,c; printf("请输入三个字符："); scanf("%c%c%c",&a,&b,&c); printf("%c,%c,%c\n", a,b,c); return 0; }

Let us compile and run the above program, which will produce the following result in interactive mode:

$ ./a.out 
请输入三个字符：run
r,u,n
$ ./a.out 
请输入三个字符：r u n
r, ,u

The following example demonstrates receiving a string:

实例

#include <stdio.h> int main() { char str1[20], str2[30]; printf("请输入用户名："); scanf("%s", str1); printf("请输入您的网站："); scanf("%s", str2); printf("输入的用户名：%s\n", str1); printf("输入的网站：%s", str2); return(0); }

Let us compile and run the above program, which will produce the following result in interactive mode:

请输入用户名：admin
请输入您的网站：www.runoob.com
输入的用户名：admin
输入的网站：www.runoob.com

    When inputting strings in newer versions of VS, you need to specify a parameter for the scanf_s function, telling the compiler how much space to reserve to store the string, using sizeof() or directly giving a numeric size; as long as it is sufficient.

    例:

    #include <stdio.h>
 
int main()
{
   char str1[20], str2[30];
 
   printf("请输入用户名：");
   scanf("%s", str1, sizeof(str1));
 
   printf("请输入您的网站：");
   scanf("%s", str2, sizeof(str2));
 
   printf("输入的用户名：%s\n", str1);
   printf("输入的网站：%s", str2);
   
   return(0);
}

    使用scanf 和 printfSome tips.

    When using it multiple times in a rowscanfMay recognize the carriage return at the end of the previous input as a newline character; you can usegetcharThe function consumes:

    #include<stdio.h>

int main(void) 
{ 

    //从键盘输入整数
    int     temp1; 
    printf("请输入1个整数>");
    scanf("%d", &temp1); 
    printf("确认返回>%d\n", temp1);

    //从键盘输入float浮点数
    float   temp2;
    printf("请输入1个浮点数>");
    scanf("%f", &temp2); 
    // 当使用%.0f输出浮点数时，会四舍五入自动取整
    printf("确认返回>%f |精确到2位小数>%.2f |取整数>%.0f\n", temp2,temp2,temp2);
 
    //从键盘输入double浮点数
    double  temp3;
    printf("请输入1个浮点数>");
    scanf("%lf", &temp3);   //接收变量如果是double类型，必须用 %lf接收
    printf("确认返回>%f\n", temp3);
 
    //从键盘输入单个字符
    char    temp4;
    printf("请输入1个字母>");
    /*
        在连续多次调用scanf函数时，
        scanf函数有可能把上次输入结束时的回车识别成新输入的换行符，
        通过调用getchar函数可以消耗多余的换行符
    */
    getchar();  
    scanf("%c", &temp4); 
    printf("确认返回>%c\n", temp4);

    //从键盘输入字符串
    char    temp5[30];
    printf("请输入1个字符串>");
    scanf("%s", &temp5); 
    printf("确认返回>%s\n", temp5);


    return 0; 
}
