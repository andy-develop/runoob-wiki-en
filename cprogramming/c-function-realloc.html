C library functions -realloc()

C 标准库 - <stdlib.h>

realloc() is a function in the C standard library used to reallocate memory space. It is very important in dynamic memory management, especially when the size of allocated memory needs to be adjusted.

C 库函数void *realloc(void *ptr, size_t size)Attempt to readjust before callingmalloc 或 calloc所分配的ptrThe size of the memory block pointed to.

声明

Below is the declaration of the realloc() function:

void *realloc(void *ptr, size_t size)

参数

  • ptr-- ptr points to a memory block to be reallocated, which was previously allocated by calling malloc, calloc, or realloc. If it is a null pointer, a new memory block will be allocated, and the function returns a pointer to it.
  • size-- The new size of the memory block, in bytes. If the size is 0 and ptr points to an existing memory block, the memory block pointed to by ptr is freed, and a null pointer is returned.

返回值

  • 如果成功，realloc()Returns a pointer to the new memory block.
  • If it fails, returnNULL, and the original memory block remains unchanged (not freed).

使用说明

  • realloc()It may move the memory block to a new location (if there is not enough space at the original location to accommodate the new size). If the move succeeds,ptrit will point to the new location. Special attention is needed: the oldptrThe pointer needs to be updated torealloc()the returned new address.
  • If memory allocation fails,realloc()返回NULL, and the original memory block is not freed. To avoid memory leaks, a temporary pointer should be used to receiverealloc()the return value, and check whether it isNULL。

实例

The following example demonstrates the usage of the realloc() function.

实例 1

#include <stdio.h> #include <stdlib.h> #include <string.h> int main() { char *str; /*最初的内存分配*/ str = (char *) malloc(15); strcpy(str, "runoob"); printf("String = %s, Address = %p\n", str, str); /*重新分配内存*/ str = (char *) realloc(str, 25); strcat(str, ".com"); printf("String = %s, Address = %p\n", str, str); free(str); return(0); }

Let us compile and run the above program, which will produce the following result:

String = runoob,  Address = 0x7fa2f8c02b10
String = runoob.com,  Address = 0x7fa2f8c02b10

实例 2

#include <stdio.h>
#include <stdlib.h>

int main() {
    int *arr = malloc(5 * sizeof(int));  // 分配 5 个整数大小的内存

    if (arr == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    // 填充数组
    for (int i = 0; i < 5; i++) {
        arr[i] = i * 2;
    }

    // 重新分配内存，调整为 10 个整数的大小
    int *new_arr = realloc(arr, 10 * sizeof(int));

    if (new_arr == NULL) {
        printf("Reallocation failed\n");
        free(arr);  // 失败时释放原始内存
        return 1;
    }

    // 填充新的部分
    for (int i = 5; i < 10; i++) {
        new_arr[i] = i * 2;
    }

    // 打印新数组
    for (int i = 0; i < 10; i++) {
        printf("%d ", new_arr[i]);
    }

    free(new_arr);  // 最后释放内存
    return 0;
}

注意事项

  • 检查返回值：总是检查realloc()the return value. If it returnsNULL, do not directly discard the original pointer.
  • 内存泄漏：如果realloc()返回NULL, the original memory block will not be freed. At this point, the original memory should be freed and error handling should be performed.
  • 指针失效: If you directly use the original pointer to receiverealloc()the returned new pointer, which may cause memory leaks, especially whenrealloc()it fails. Therefore, it is common to first use a temporary pointer to receive the return value.

常见用途

  • Dynamically expand the size of arrays or other data structures.
  • Used to handle variable-sized data sets at runtime, such as dynamically generated lists, strings, or caches, etc.

If the address space to be extended is not occupied, then the adjusted memory space after subsequent expansion and the original memory space remain the same memory始址. Otherwise, the program will find a new free address space in the heap area of memory and return新的内存始址. Therefore, the pointer returned by realloc is likely to point to a new address.
