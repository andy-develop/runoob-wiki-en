C 循环

Sometimes, we may need to execute the same block of code multiple times. In general, statements are executed sequentially: the first statement in a function executes first, followed by the second statement, and so on.

Programming languages provide various control structures that allow more complex execution paths.

Loop statements allow us to execute a statement or a group of statements multiple times. The following is a flowchart of loop statements in most programming languages:

循环类型

The C language provides the following types of loops. Click the link to view details of each type.

循环类型描述
while 循环Repeats a statement or group of statements while a given condition is true. It tests the condition before executing the body of the loop.
for 循环Executes a sequence of statements multiple times, simplifying the code that manages the loop variable.
do...while 循环It is similar to the while statement, except that it tests the condition at the end of the loop body.
嵌套循环You can use one or more loops inside any while, for, or do..while loop.

更多内容：C while 和 do while 区别


Loop Control Statements

Loop control statements change the execution order of your code. With them, you can achieve jumps in code.

C provides the following loop control statements. Click the link to view details of each statement.

控制语句描述
break 语句终止循环或 switchstatement, the program flow will continue to execute the next statement immediately following the loop or switch.
continue 语句Tells a loop body to immediately stop the current loop iteration and begin the next loop iteration.
goto 语句Transfers control to a labeled statement. However, it is not recommended to use the goto statement in programs.

无限循环

If the condition never becomes false, the loop becomes an infinite loop.forA loop can be used to implement an infinite loop in the traditional sense. Since none of the three expressions that form the loop are required, you can leave some conditional expressions blank to form an infinite loop.

实例

#include <stdio.h> int main () { for( ; ; ) { printf("该循环会永远执行下去！\n"); } return 0; }

When the condition expression is absent, it is assumed to be true. You can also set an initial value and an increment expression, but in general, C programmers tend to use the for(;;) construct to represent an infinite loop.

注意：您可以按Ctrl + CA key terminates an infinite loop.

    Use the continue statement to output numbers between 100 and 200 that are not divisible by 3.

    #include<stdio.h>
int main()
{
    int n;
    for(n=100;n<=200;n++)
    {
        if(n%3==0)
            continue;
        printf("%d",n);
    }
    printf("\n");
    return 0;
}

    Be sure to note the difference between the break statement and the continue statement. The former ends the entire loop process, while the latter ends the current loop iteration. They should be used flexibly according to the requirements of the problem.
