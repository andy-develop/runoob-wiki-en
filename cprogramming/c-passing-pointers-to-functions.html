C 指针

C language allows you to pass pointers to functions; you simply need to declare the function parameters as pointer types.

In the following example, we pass a pointer to an unsigned long to the function, and change this value within the function:

实例

#include <stdio.h>
#include <time.h>
 
void getSeconds(unsigned long *par);

int main ()
{
   unsigned long sec;


   getSeconds( &sec );

   /* 输出实际值 */
   printf("Number of seconds: %ld\n", sec );

   return 0;
}

void getSeconds(unsigned long *par)
{
   /* 获取当前的秒数 */
   *par = time( NULL );
   return;
}

Functions that can accept pointers as parameters can also accept arrays as parameters, as shown below:

实例

#include <stdio.h>
 
/* 函数声明 */
double getAverage(int *arr, int size);
 
int main ()
{
   /* 带有 5 个元素的整型数组  */
   int balance[5] = {1000, 2, 3, 17, 50};
   double avg;
 
   /* 传递一个指向数组的指针作为参数 */
   avg = getAverage( balance, 5 ) ;
 
   /* 输出返回值  */
   printf("Average value is: %f\n", avg );
   
   return 0;
}

double getAverage(int *arr, int size)
{
  int    i, sum = 0;      
  double avg;          
 
  for (i = 0; i < size; ++i)
  {
    sum += arr[i];
  }
 
  avg = (double)sum / size;
 
  return avg;
}

    The relationship between pointers and functions

    1. Function pointers (pointers to functions)

    After a function is compiled, it occupies a portion of memory, and its function name is the starting address of that function code.

    You can declare a pointer as a pointer to a function.

    C language stipulates that a function name is converted to a pointer to that function, unless the function name is used as an operand of the & operator or the sizeof operator (note: using a function name as an operand of sizeof is illegal). That is, in `f = test;`, `test` is automatically converted to `&test`, while in `f = &test;`, `&test` is explicitly used, so `test` will not undergo conversion. Therefore, directly referencing a function name is equivalent to applying the & operator to the function name; both methods yield a pointer to that function.

    A pointer to a function must be initialized, or have a value of 0, before it can be used in a function call.

    Same as with arrays:

    • (1) Incrementing (++) a pointer to a function is prohibited.
    • (2) Assigning to a function name is prohibited, and function names cannot be used in arithmetic operations.

    The mystery here is why `*test` can produce the same value as the two previously introduced outputs.

    First, look at the function name `test`. It is a symbol used to identify the entry address of a function. When used, the function name is converted to a pointer to that function, and the pointer's value is the function's entry address. As for `&test`, it was already mentioned earlier: it explicitly obtains the function's address. For `*test`, it can be considered that since `test` has already been converted to a function pointer pointing to this function, `*test` takes the function name pointed to by this pointer; then, according to the rule that a function name is converted to a pointer to that function, this function also becomes a pointer, so `*test` ultimately is also a pointer to the function `test`. That is:*test --> *(&test) --> test --> &test。

    3. Mixing the two (not commonly used)

    Note that the return value of a function is not limited to pointers to variables; it can also be a pointer to a function.

    First, look at this declaration: `*int (*function(int)) (double*, char);` To understand the meaning of this declaration, first look at `function(int)`, which declares `function` as a function with an `int` formal parameter. The return value of this function is a pointer, namely the function pointer `int (*) (double*, char);` This pointer points to a function that returns `int` and has two formal parameters, one of type `double*` and one of type `char`.

    If `typedef` is used, this declaration can be simplified: (I didn't quite understand.... will supplement later in the structures section)

    typedef  int (*ptf) (double*, char);​
ptf  function( int );

    Another example:

    void (*signal (int sig, void (*func) (int siga)) ) ( int siga );

    Now we need to analyze `signal`. Since what is immediately next to `signal` is the parentheses with the highest priority, it first binds with the parentheses, so `signal` is a function. Inside the parentheses are `signal`'s two formal parameters: one of `int` type, and one a pointer to a function. Next, looking to the left from there, `*` represents a pointer to some object, and its position indicates that it is the return type of `signal`. Now we can remove the already-analyzed `signal` as a whole, obtaining `void (*) (int siga)`. This is again a function pointer. This pointer is the same type as the second parameter in `signal`'s parameter list; both are pointers to functions that take one `int` formal parameter and return no value.

    Using `typedef`, this declaration can be simplified:

    typedef int (*p_sig) (double*, char);​
p_sig signal(int sig, p_sig func);

    This `signal` function is a C library function, defined in `signal.h`, used to handle signals generated in the system.

    4. Array of function pointers

    Suppose there is a file processing program that selects the corresponding operation through a menu button (open file, read file, write file, close file). These operations are all implemented as functions with the same type, respectively:

    void open();
void read();
void write();
void close();

    Now define an alias `PF` for a function pointer type:

    typedef void (*PF) ( );

    Take the addresses of the above four operations and put them into an array, yielding:

    PF file_options[ ] = {
    &open,
    &read,
    &write,
    &close
};

    If typedef is not used, the analysis becomes more complex, resulting in void (*file_options[ ]) ( );

    The elements in this array are all pointers to functions that take no parameters and return no value, so this is an array of function pointers. Next, define a pointer `action` of the function pointer type and initialize it to the first element of the function pointer array: `PF* action = file_options;`. If this is not easy to understand, you can draw an analogy:

    int ia[4] = {0, 1, 2, 3};
int *ip = ia;，
