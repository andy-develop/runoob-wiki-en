C 函数

; ... ... and so on.main(), and all simple programs can define other additional functions.

You can divide your code into different functions. How you divide the code into different functions is up to you, but logically, division is usually based on each function performing a specific task.

函数声明Tells the compiler the function's name, return type, and parameters. A function定义Provides the actual body of the function.

The C standard library provides a large number of built-in functions that programs can call. For example, the functionstrcat()Used to concatenate two strings, the functionmemcpy()Used to copy memory to another location.

Functions have many other names, such as methods, subroutines, or procedures, and so on.

定义函数

The general form of a function definition in C is as follows:

return_type function_name( parameter list )
{
   body of the function
}

In C, a function consists of a function header and a function body. Below is a list of all the parts of a function:

  • 返回类型：A function can return a value.return_typeIs the data type of the value returned by the function. Some functions perform the desired operations without returning a value; in this case, return_type is the keywordvoid。
  • 函数名称：This is the actual name of the function. The function name and the parameter list together constitute the function signature.
  • 参数：Parameters act like placeholders. When a function is called, you pass a value to the parameter, and this value is called an actual parameter. The parameter list includes the type, order, and number of the function's parameters. Parameters are optional; that is, a function may contain no parameters.
  • 函数主体：The function body contains a set of statements that define what the function does.

实例

以下是max()The source code of the function. This function has two parameters, num1 and num2, and returns the larger of the two numbers:

/*函数返回两个数中较大的那个数*/ int max(int num1, int num2) { /*局部变量声明*/ int result; if (num1 > num2) { result = num1; } else { result = num2; } return result; }

函数声明

函数声明Tells the compiler the function name and how to call the function. The actual body of the function can be defined separately.

A function declaration consists of the following parts:

return_type function_name( parameter list );

For the function max() defined above, the following is the function declaration:

int max(int num1, int num2);

In a function declaration, the parameter names are not important; only the parameter types are required. Therefore, the following is also a valid declaration:

int max(int, int);

When you define a function in one source file and call it in another file, a function declaration is required. In this case, you should declare the function at the top of the file that calls the function.

调用函数

When you create a C function, you define what the function does, and then complete the defined task by calling the function.

When a program calls a function, program control is transferred to the called function. The called function performs the defined task. When the function's return statement is executed, or when the function's closing brace is reached, program control is returned to the main program.

When calling a function, pass the required parameters, and if the function returns a value, you can store the returned value. For example:

实例

#include <stdio.h> /*函数声明*/ int max(int num1, int num2); int main () { /*局部变量定义*/ int a = 100; int b = 200; int ret; /*调用函数来获取最大值*/ ret = max(a, b); printf( "Max value is : %d\n", ret ); return 0; } /*函数返回两个数中较大的那个数*/ int max(int num1, int num2) { /*局部变量声明*/ int result; if (num1 > num2) result = num1; else result = num2; return result; }

Put the max() function and the main() function together, compile the source code. When the final executable file is run, the following results are produced:

Max value is : 200

函数参数

If the function is to use parameters, you must declare variables that accept the parameter values. These variables are called the function's形式参数。

Formal parameters are like other local variables inside a function; they are created when entering the function and destroyed when exiting the function.

When calling a function, there are two ways to pass parameters to the function:

调用类型描述
传值调用This method copies the actual values of the arguments to the function's formal parameters. In this case, modifying the formal parameters inside the function does not affect the actual arguments.
引用调用In pointer passing, the formal parameter is a pointer to the address of the actual argument. When an operation is performed on the formal parameter's pointing, it is equivalent to operating on the actual argument itself.

By default, C uses传值调用to pass parameters. Generally speaking, this means that the code inside the function cannot change the actual arguments used to call the function.

    According to whether a function can be called by other source files, functions are divided into internal functions and external functions.

    内部函数

    If a function can only be called by other functions in the same file, it is called an internal function. When defining an internal function, add static before the function name and function type, that is

    static 类型名 函数名 （形参表）

    For example, the first line of the function:

    static int max(int a,int b)

    Internal functions are also called static functions. Using internal functions can limit the scope of a function to the file in which it resides. Even if there are internal functions with the same name in different files, they do not interfere with each other. This improves program reliability.

    外部函数

    If, when defining a function, the keyword extern is added to the leftmost position of the function header, then this function is an external function and can be called by other files.

    For instance, the function header can be

    extern int max (int a,int b)

    C language rules state that if extern is omitted when defining a function, it defaults to an external function.

    In other files that need to call this function, a declaration of this function is required (do not forget that even when calling a function in the same file, you must declare it with a function prototype). When declaring this function, add the keyword extern, indicating that this function is an external function defined in another file.

    实例

    The following example uses functions across multiple files to input a string and then delete a specified character:

    file1.c(文件1)

    #include <stdio.h>

static void delete_string(char str[],char ch);
int main()
{
    extern void enter(char str[]); // 对函数的声明
    extern void print(char str[]); // 对函数的声明
    char c,str[100];
    enter(str);
    scanf("%c",&c);
    delete_string(str,c);
    print(str);
    return 0;
}

static void delete_string(char str[],char ch)//内部函数
{
    int i,j;
    for(i=j=0;str[i]!='\0';i++)
    if(str[i]!=ch)
    str[j++]=str[i];
    str[j]='\0';
}

void enter(char str[100]) // 定义外部函数 enter
{
    fgets(str, 100, stdin); // 向字符数组输入字符串
}

    file3.c(文件3)

    #include <stdio.h>

void print(char str[]) // 定义外部函数 print
{
    printf("%s\n",str);
}

    内联函数

    An inline function refers to a function modified with the inline keyword. Functions defined inside a class are treated as inline functions by default. From the source code level, an inline function has the structure of a function, but after compilation, it does not have the nature of a function.

    Inline expansion is used toeliminate the time overhead of function callswhen calling.. It is usually used for frequently executed functions and is very beneficial for functions that occupy small memory space.

    When using inline functions, note the following:

    • Recursive functions cannot be defined as inline functions.
    • Inline functions are generally suitable for small functions that do not contain complex structures such as while and switch and have only 1 to 5 statements; otherwise, the compilation system will treat the function as an ordinary function.
    • An inline function must be defined before it is used; otherwise, the compilation system will also regard it as an ordinary function.
    • Exception interface declarations cannot be made for inline functions.

    示例：A simple swap function

    inline void swap(int *a, int *b)
{
    int t = *a;
    *a = *b;
    *b = t;
}

    Regarding the parameters of the main function

    In some very professional books, you will see the following code

    int main( int argc, char *argv[] )

    In the code above, the main function has parameters.

    But sometimes you will also see the main function without parameters, as follows:

    int main()

    So does the main function have parameters or not, and does having parameters or not have any effect?

    The main function is actually no different from the functions we write; it also has its own parameters.

    argc and argv are formal parameters of the main function.

    The types of these two formal parameters are specified by the system. If the main function is to have parameters, they are parameters of these two types; otherwise, the main function has no parameters.

    The variable names argc and argv are conventional names, and of course, they can be replaced with other names. After parameters are passed in, the main function receives them and then does its own work. So how are actual arguments passed to argc and argv of the main function? We know that after a C program is compiled and linked, an exe file is generated. When executing this exe file, it can be executed directly, or it can be executed with parameters on the command line. The command-line execution form is: executable file name parameter 1 parameter 2 ... ... parameter n. The executable file name and parameters, as well as between parameters, are separated by spaces.

    If it is executed in this way, the command-line string will be passed to the main function as actual arguments. Specifically:

    • (1) The sum of the number of the executable file name and all parameters is passed to argc;
    • (2) The executable file name (including the path name) is used as a string, and its first address is assigned to argv

    Three common ways to pass function parameters

    The example programs all use the exchange of two integers as an example.

    1. Pass by value

    #include <stdio.h>

void swap(int x, int y);
void swap(int x, int y)
{
    int temp;
    temp = x;
    x = y;
    y = temp;
}

int main( int argc, char *argv[] )
{
    int a = 5;
    int b = 10;
    swap(a, b); //调用交换函数
    printf("交换结果为 a = %d, b = %d\n",a,b);
    return 0;
}

    Since value passing is one-way passing, only the values of the formal parameters are changed during the passing process, and the values of the actual arguments are not changed. Therefore, the original values of a and b are not changed.

    2. Pass by pointer

    #include <stdio.h>

void swap(int *x, int *y);
void swap(int *x, int *y)
{
    int temp;
    temp = *x;
    *x = *y;
    *y = temp;
}

int main( int argc, char *argv[] )
{
    int a = 5;
    int b = 10;
    swap(&a, &b); //调用交换函数
    printf("交换结果为 a = %d, b = %d\n",a,b);
    return 0;
}

    In pointer passing, the addresses of a and b are passed to x and y respectively. Inside the function body, the values at the addresses of a and b are changed, that is, the values of a and b are exchanged.

    3. Pass by reference

    #include <stdio.h>

void swap(int &x, int &y);
void swap(int &x, int &y)
{
    int temp;
    temp = x;
    x = y;
    y = temp;
}

int main( int argc, char *argv[] )
{
    int a = 5;
    int b = 10;
    swap(a, b); //调用交换函数
    printf("交换结果为 a = %d, b = %d\n",a,b);
    return 0;
}

    In reference passing, when calling swap(a, b); the function uses a and b to replace x and y respectively, that is, x and y respectively refer to the variables a and b. In this way, what actually participates in the operation in the function body is the actual arguments a and b themselves, so the purpose of exchanging values can also be achieved.

    注：Strictly speaking, reference passing does not exist in C; it is a language feature in C++. Therefore, using reference passing in a .c file will cause a compilation error.

    Functions realize code reuse, greatly simplifying and shortening the programmer's workload, and greatly improving program readability. Recursive function calls are also a way to simplify program code; a recursive call is actually a function calling itself.

    The following example is a recursive instance for calculating 1+2+3.....+n:

    #include <stdio.h>  //导如输入输出头文件

int sum(int n);//声明函数 
int main(){
    //主函数 
    int a=sum(4);
    printf("%d",a);
  return 0;
}
int sum(int n){
    //求和函数实现 
    //如果n为1，无需求和，直接返回1 
    if(n==1){
        return 1;
    }
    //如果n大于1，就返回n加上1+2+3.....+n-1的和 
    return n+sum(n-1);
}

    It can be seen that recursive code is very small. However, recursion also has disadvantages: recursion occupies more memory than iteration, and also takes longer than iteration.

    A placeholder is a symbol that first occupies a fixed position and waits for you to add content to it. It is widely used in the editing of various kinds of computer documents.

    The format placeholder (%) is used in format input functions in C/C++, such as scanf, printf, and other functions. Its meaning is to serve as a format placeholder, indicating that there is input or output at that position.

    • %d, %i代表整数
    • %f浮点
    • %s字符串
    • %c char
    • %p指针
    • %fL长log
    • %e科学计数
    • %gDecimal or scientific notation.
    • %a,%AReads a floating-point value (valid only in C99).
    • %cRead in a character.
    • %dRead a decimal integer.
    • %iReads a decimal, octal, or hexadecimal integer.
    • %oRead an octal integer.
    • %x,%XRead a hexadecimal integer.
    • %sReads a string, ending at a space, tab, or newline character.
    • %f,%F,%e,%E,%g,%GUsed to input a real number, which can be entered in decimal form or exponential form.
    • %pRead in a pointer.
    • %u Read an unsigned decimal integer.
    • %nThe equivalent character count of the value read so far.
    • %[]Scan a character set.
    • %%Read the % symbol.

    #include<stdio.h>

void f(void)  /*定义函数*/
{
    printf("我是一个函数，我将在主函数中输出\n");
}

int main(void)
{
    f();  /*调用函数*/
}

    In the above example, the function is called in the main function.f(), and the declaration of the function is before the call.

    2. This way of writing is wrong.

    #include<stdio.h>

int main(void)
{
    f();/*调用函数*/

void f(void)  /*定义函数*/
{
    printf("我是一个函数，我将在主函数中输出\n");

    The reason pointer passing can change the value of the passed parameter variable is that the swap function does not exchange the pointers themselves that were passed in, but the values the pointers point to.

    void swap(int *x, int *y);
void swap(int *x, int *y){
    int temp;
    //这里操作的是指针指向的值 而不是指针
    temp = *x;
    *x = *y;
    *y = temp;
//   倘若直接交换指针 a、b的值不会交换
//    temp = x;
//    x = y;
//    y = temp;
}

int main( int argc, char *argv[] )
{
    int a = 5;
    int b = 10;
    swap(&a, &b); //调用交换函数
    printf("交换结果为 a = %d, b = %d\n",a,b);
    return 0;
}
