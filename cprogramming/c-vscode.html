C VScode

In the previous chapter, we introduced the basic concepts and examples of C. In this chapter, we will introduce the editor for C code -- VScode.

VSCode (full name: Visual Studio Code) is a free source code editor developed by Microsoft that is cross-platform. The VSCode development environment is very simple and easy to use.

VSCode's support for C/C++ is provided by an extension for Visual Studio Code offered by Microsoft, which enables cross-platform C and C++ development on Windows, Linux, and macOS.

When you create a*.cor*.cppFor files, this extension adds features such as syntax highlighting (coloring), intelligent completion and hover, and error checking.
