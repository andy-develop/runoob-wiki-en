Foundation Default Settings

Foundation uses the browser default font size (font-size:100%). For most desktop browsers, the default font size is 16px. For most mobile browsers, the default font size is 12px. The default font is"Helvetica Neue", line-height defaults to1.5。

The default settings above all apply to<body>Element.
