Foundation Button Group

按钮组

Foundation can create a series of buttons in the same row.

可以使用<ul>元素并添加.button-groupClass to create a button group:

实例

<ul class="button-group">
  <li><button type="button" class="button">Apple</button></li>
  <li><button type="button" class="button">Samsung</button></li>
  <li><button type="button" class="button">Sony</button></li>
</ul>

Dropdown Menu Button

Dropdown menu buttons allow users to select preset values:

实例

<!-- Trigger the dropdown -->
<a href="#" data-dropdown="id01" class="button dropdown">Dropdown Button</a>

<!-- The actual dropdown -->
<ul id="id01" data-dropdown-content class="f-dropdown">
  <li><a href="#">Link 1</a></li>
  <li><a href="#">Link 2</a></li>
  <li><a href="#">Link 3</a></li>
</ul>

<!-- Initialize Foundation JS -->
<script>
$(document).ready(function() {
    $(document).foundation();
})
</script>

实例解析

.dropdownClass to create a dropdown menu button.

使用带有data-dropdown="id"The button or link with the attribute opens the dropdown menu.

idThe value needs to match the content of the dropdown menu (id01).

在 <ul>中添加.f-dropdown类和data-dropdown-contentAttribute to create the content of the dropdown menu.

Finally, initialize Foundation JS.

分割按钮

We can also create a split button dropdown menu. Just add in the button.splitclass and use a span element to create a directional arrow button:

实例

<button class="button split">Split Button
  <span data-dropdown="id01"></span>
</button>

<ul id="id01" data-dropdown-content class="f-dropdown">
