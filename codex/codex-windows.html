Codex Native Windows Support

Codex offers native support on Windows and can run without WSL. This section covers Windows-specific features and configuration.

Windows Support Overview

Codex supports the following Windows environments:

环境支持状态
Windows 11（原生）官方支持
Windows 10官方支持
Windows 11 + WSL2完整支持

Codex can run natively on Windows, maintaining the Windows workflow.

安装

Installing with winget

winget 安装

# 使用 winget 安装
winget install OpenAI.Codex

# 或者安装预览版
winget install OpenAI.Codex --source winget --accept-source-agreements --accept-package-agreements

使用 Chocolatey

Chocolatey 安装

# 使用 Chocolatey 安装
choco install codex -y

手动安装

Download the Windows version from GitHub:

https://github.com/openai/codex/releases

Download the .exe installer and run it.

Installing via winget or Chocolatey is recommended for automatic updates.

原生沙箱

Codex can run natively in Windows PowerShell:

  • No WSL or virtual machine required
  • Keep the Windows workflow
  • Seamless integration with Windows tools

Sandbox mode configuration

配置沙箱

# Windows 沙箱配置
[windows]
# 沙箱模式：unelevated | elevated
sandbox = "unelevated"

# 在私有桌面运行沙盒子进程
sandbox_private_desktop = true

Sandbox mode description

模式说明
unelevatedRun with standard user permissions (recommended)
elevatedRun with administrator permissions
Unelevated mode is recommended to maintain security.

PowerShell 集成

Codex can be used directly in PowerShell:

Use in PowerShell

# 启动 Codex
codex

# 非交互模式
codex exec "审查代码"

# 使用 PowerShell 命令
codex ! Get-Process

CMD 支持

Codex also supports the traditional CMD environment:

Use in CMD

# 在 CMD 中运行
codex exec "列出文件"
Codex automatically detects the terminal type and optimizes output.

Windows-Specific Configuration

路径处理

Windows paths differ from Unix; Codex handles this automatically:

  • Backslash to forward slash conversion
  • 盘符处理
  • UNC path support

环境变量

Windows environment variables

# 设置 Codex 特定的环境变量
set CODEX_HOME=C:\Users\YourName\.codex
set CODEX_SQLITE_HOME=C:\Users\YourName\.codex

代理配置

代理设置

# 设置代理
set HTTP_PROXY=http://proxy.example.com:8080
set HTTPS_PROXY=http://proxy.example.com:8080

# 然后运行 Codex
codex
If your network requires a proxy, just configure the environment variables.

故障排除

常见问题

无法启动？

  • Check that the required Visual C++ runtime libraries are installed
  • Try running with administrator permissions
  • Check whether antivirus software is blocking it

PowerShell commands not executing?

Ensure the PowerShell executable is in PATH.

Chinese path issue?

Codex supports Unicode, but some older terminals may have issues.

Most issues can be resolved by reinstalling or updating.

日志位置

Windows log locations:

%USERPROFILE%\.codex\log\codex-tui.log
Check the logs to see detailed error messages.

Comparison with WSL2

特性原生 WindowsWSL2
性能更快稍慢
设置简单WSL installation required
兼容性Windows 工具Linux 工具
维护自动更新独立更新
For most Windows users, the native version is recommended.

最佳实践

  • Install using winget or Chocolatey
  • Keep the system and Codex updated
  • Use unelevated sandbox mode
  • Configure a suitable proxy (if needed)
Native Windows support lets Codex seamlessly fit into your Windows workflow.

常见问题

Q: Which is better, the native Windows version or the WSL version?

For most users, the native version is better - faster and simpler.

Q: Can it coexist with WSL?

Yes, both can be installed and used at the same time.

Q: Does it require administrator privileges?

No, unelevated mode does not require administrator privileges.

Q: 支持 PowerShell ISE 吗？

推荐使用 Windows Terminal 或新版 PowerShell。
