Codex IDE 扩展

The Codex IDE extension lets you use Codex directly in your familiar development environment, seamlessly integrating into your daily coding workflow.

Supported IDEs

Codex officially supports the following IDEs:

IDE扩展 ID安装方式
VS Codeopenai.chatgptvscode:extension/openai.chatgpt
VS Code Insidersopenai.chatgpt扩展市场
Cursoropenai.chatgptcursor:extension/openai.chatgpt
Windsurfopenai.chatgptwindsurf:extension/openai.chatgpt

安装扩展

VS Code 安装

VS Code 安装

# 方法一：命令行安装
code --install-extension openai.chatgpt

# 方法二：在 VS Code 中
# 1. 打开扩展面板 (Cmd+Shift+X)
# 2. 搜索 "Codex" 或 "ChatGPT"
# 3. 点击安装

Cursor 安装

Cursor 安装

# 方法一：命令行
cursor --install-extension openai.chatgpt

# 方法二：在 Cursor 中
# 1. 打开扩展面板
# 2. 搜索 "Codex"
# 3. 点击安装

After installation, you need to log in with a ChatGPT account or OpenAI API Key to use it.

核心功能

自动上下文

The IDE extension automatically passes the following content to Codex as context:

  • Currently open file list
  • The text range selected in the editor
  • Current working directory info

AI 对话

Chat directly with Codex in the IDE:

  • Open the Codex panel (via shortcut key or sidebar)
  • Enter a question or task description
  • Codex analyzes the current file and project, then replies.

代码操作

After selecting code, right-click to execute:

操作功能
解释Codex explains the functionality of the selected code.
重写Rewrite the selected code as required
审查Check code issues and improvement suggestions
生成测试Generate unit tests for the selected code

斜杠命令

Use slash commands in the Codex panel:

命令功能
/explainExplain selected code
/fixFix issues in the selected code
/testGenerate tests for the selected code
/reviewReview selected code
/planPlan first, then execute

Slash command examples

# 解释代码
/explain

# 修复 Bug
/fix this function throws error for null input

# 规划新功能
/plan implement user authentication with JWT

Below the input box, you can switch models:

模型特点

GPT-5.4-miniLightweight and fast, suitable for simple tasks

快捷键

快捷键功能
Cmd+Shift+COpen the Codex panel
Cmd+Shift+Enter代码补全
Cmd+Shift+RRewrite selected code
Cmd+Shift+EExplain selected code

Shortcut keys can be customized in IDE settings to avoid conflicts with other extensions.

Cloud task delegation

Start cloud tasks from the IDE extension:

  • Select Cloud mode to create a thread.
  • Tasks run in an isolated cloud environment
  • After completion, view results via notification or PR

适用场景

  • Need to process multiple tasks in parallel
  • Delegate large tasks from low-configuration devices
  • Cross-device collaboration

IDE 配置

Set file opening method

Configuration file opened

# ~/.codex/config.toml

# 指定打开文件的编辑器
file_opener = "vscode"
# 可选值: vscode, vscode-insiders, windsurf, cursor, none

Set default model

Configure default model

# ~/.codex/config.toml

model = "gpt-5.4"

使用技巧

Select code as context

After selecting code, Codex automatically uses it as context.

The more code you select, the more accurate Codex's replies will be.

多文件操作

When multiple files are open, Codex can handle them simultaneously.

Simply describe the file you need to modify in the panel.

Use built-in terminal

The IDE built-in terminal can directly run Codex CLI.

This way, you can enjoy the full functionality of the CLI.

常见问题

Q: Extension cannot connect?

Make sure you are logged in to your Codex account, and check the network connection and proxy settings.

Q: Keyboard shortcuts conflict with other extensions?

Search for "Codex" in the IDE settings and customize the keyboard shortcuts.

Q: How to update the extension?

The extension updates automatically with Codex, or you can manually update it in the IDE extensions panel.

Q: What is the difference between IDE extensions and App?

The IDE extension deeply integrates with the development environment and automatically reads file context; the App offers full functionality and multi-project management.
