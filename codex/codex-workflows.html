Codex Workflow Patterns

Codex can be integrated into various development workflows, from daily coding to complex refactoring, significantly improving efficiency.

Daily development workflow

Daily development is the most common workflow pattern, suitable for building new features or small-scale modifications.

工作流步骤

步骤操作Codex 交互
1明确需求Describe the functionality you want to implement
2Codex 分析Codex understands project structure and conventions
3方案讨论Confirm the implementation approach with Codex
4代码生成Codex writes code and modifies files
5验证测试Run tests to confirm functionality is correct
6迭代优化Adjust code based on feedback

Example: Adding a New API Endpoint

Daily development process

# 步骤 1：描述需求
"在 /api/users 路径添加一个 GET 端点，返回用户列表，
支持分页参数 page 和 limit"

# 步骤 2-3：Codex 分析并确认方案
Codex 会分析现有 API 结构，确认：
- 路由定义位置
- 数据库查询方式
- 响应格式规范

# 步骤 4：代码生成
Codex 自动创建：
- 路由定义
- 数据查询逻辑
- 错误处理
- 响应格式化

# 步骤 5：验证测试
"运行测试并检查新端点"

# 步骤 6：迭代优化
"添加缓存支持，响应时间应小于 100ms"

Code comprehension workflow

Exploratory workflow

  1. Start from the entry point and let Codex explain the overall architecture
  2. Gradually dive into key modules to understand the core logic
  3. Trace data flow and call chains
  4. Summarize key points and considerations

重构工作流

Refactoring requires careful handling; Codex can help you systematically improve code structure.

重构原则

  • First understand the existing code structure
  • Refactor in small steps, improve gradually
  • Validate at each step to ensure functionality remains unchanged
  • Maintaining test coverage

Refactoring workflow steps

步骤说明
识别问题Codex analyzes code and identifies areas that need improvement
制定方案Discuss the refactoring plan, confirm the improvement direction
分步执行Make small-scale changes, validate after each modification
测试验证Run all tests to ensure functionality is correct
清理优化Remove redundant code, optimize naming

重构示例

# 识别问题
"分析 src/utils 模块，识别代码重复和不合理的设计"

# 制定方案
"讨论如何重构这个模块，保持向后兼容"

# 分步执行
"第一步：提取公共函数到 utils/common.py"

# 测试验证
"运行所有测试，确认重构没有破坏功能"

# 继续下一步
"第二步：简化复杂的函数，拆分成更小的单元"

When refactoring, use /plan mode to create a plan first, then execute step by step to avoid large one-time changes.

Bug Fix Workflow

Codex can help you quickly locate and fix bugs.

修复流程

步骤操作
描述问题Describe the bug's symptoms and trigger conditions
提供信息Share error messages, logs, and screenshots
定位根因Codex analyzes and finds the root cause
生成修复Codex proposes a fix
验证修复Run tests to confirm issues are resolved
防止复发Add tests to cover this scenario

Bug Fix Example

# 描述问题
"用户登录时偶尔出现 500 错误，错误日志显示：
TypeError: Cannot read property 'id' of undefined"

# 提供信息
"这是完整的错误堆栈：[粘贴堆栈信息]"

# 定位根因
Codex 分析后发现问题：用户对象在某些情况下为 null

# 生成修复
"修复这个问题，并确保不会影响正常登录流程"

# 验证修复
"运行登录相关的所有测试"

# 防止复发
"添加一个测试覆盖用户对象为 null 的场景"

最佳实践

工作流选择

  • Daily development: continuous interaction, iterative improvement
  • Refactoring: plan first, then execute, validate in small steps
  • Bug Fix: Provide sufficient information and verify the root cause
  • Review: Conduct regularly, focus on security issues

效率技巧

  • Use AGENTS.md to define project conventions, reducing repeated instructions
  • Use Skills to encapsulate common workflows
  • Use Worktree to isolate different tasks
  • Configure a reasonable Approval policy

常见问题

Q: How to handle large-scale refactoring?

Use /plan mode to create a step-by-step plan, verifying after each step.

Q: How to prevent bugs from recurring after fixing?

Add dedicated tests to cover this scenario, and add relevant check rules in AGENTS.md.

Q: How to help Codex understand project conventions?

Create an AGENTS.md file to define the project's tech stack, code conventions, testing requirements, etc.

Q: How are review results shared with the team?

Use GitHub integration to review in the PR, results will be automatically added as comments.
