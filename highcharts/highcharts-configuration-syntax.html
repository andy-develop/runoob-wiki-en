Highcharts Configuration Syntax

This chapter will introduce some configurations for generating charts using Highcharts.

Step 1: Create an HTML Page

Create an HTML page and include the jQuery and Highcharts libraries:

File name: HighchartsTest.htm

<html>
<head>
<title>Highcharts Tutorial | Runoob</title>
    <script src="https://apps.bdimg.com/libs/jquery/2.1.4/jquery.min.js"></script>
   <script src="/try/demo_source/highcharts.js"></script>
</head>
<body>
<div id="container" style="width: 550px; height: 400px; margin: 0 auto"></div>
<script language="JavaScript">
$(document).ready(function() {
     
});
</script>
</body>
</html>

In the example, the div with id 'container' is used to contain the chart drawn by Highcharts.

Step 2: Create the Configuration File

The Highcharts library uses JSON format for configuration.

$('#container').highcharts(json);

Here, "json" means using JSON data format and JSON format configuration to draw the chart. The steps are as follows:

Title

Configure the title for the chart:

var title = {
  text: '月平均气温'   
};

Subtitle

Configure the subtitle for the chart:

var subtitle = {
  text: 'Source: runoob.com'
};

X Axis

Configure the items to be displayed on the X axis.

var xAxis = {
   categories: ['一月', '二月', '三月', '四月', '五月', '六月'
      ,'七月', '八月', '九月', '十月', '十一月', '十二月']
};

Y Axis

Configure the items to be displayed on the Y axis.

var yAxis = {
   title: {
      text: 'Temperature (\xB0C)'
   },
   plotLines: [{
      value: 0,
      width: 1,
      color: '#808080'
   }]
};

Tooltip

Configuration prompt message:

var tooltip = {
   valueSuffix: '\xB0C'
}

Display Mode

Configure the chart to align to the right:

var legend = {
   layout: 'vertical',
   align: 'right',
   verticalAlign: 'middle',
   borderWidth: 0
};

Data

Configure the data to be displayed in the chart. Each series is an array, and each item will generate a curve in the chart.

var series =  [
   {
      name: 'Tokyo',
      data: [7.0, 6.9, 9.5, 14.5, 18.2, 21.5, 25.2, 
         26.5, 23.3, 18.3, 13.9, 9.6]
   }, 
   {
      name: 'New York',
      data: [-0.2, 0.8, 5.7, 11.3, 17.0, 22.0, 24.8, 
         24.1, 20.1, 14.1, 8.6, 2.5]
   }, 
   {
      name: 'Berlin',
      data: [-0.9, 0.6, 3.5, 8.4, 13.5, 17.0, 18.6, 
         17.9, 14.3, 9.0, 3.9, 1.0]
   }, 
   {
      name: 'London',
      data: [3.9, 4.2, 5.7, 8.5, 11.9, 15.2, 17.0, 
         16.6, 14.2, 10.3, 6.6, 4.8]
   }
];

Step 3: Create the JSON data.

The combination is composed of configuration information:

var json = {};

json.title = title;
json.subtitle = subtitle;
json.xAxis = xAxis;
json.yAxis = yAxis;
json.tooltip = tooltip;
json.legend = legend;
json.series = series;
Step 4: Draw the chart
$('#container').highcharts(json);

   var json = {};

   json.title = title;
   json.subtitle = subtitle;

   json.yAxis = yAxis;

</script>
