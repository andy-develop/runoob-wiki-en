导航栏

Skilled use of the navigation bar is very important for any website.

With CSS you can transform it into a good-looking navigation bar instead of a boring HTML menu.

Navigation bar = list of links

As a standard HTML foundation, a navigation bar is necessary.

In our example we will build a standard HTML list navigation bar.

A navigation bar is basically a list of links, so using the <ul> and <li> elements makes perfect sense:

实例

<ul> <li><a href="#home">主页</a></li> <li><a href="#news">新闻</a></li> <li><a href="#contact">联系</a></li> <li><a href="#about">关于</a></li> </ul>

尝试一下 »

Now, let's remove margins and padding from the list:

实例

ul { list-style-type: none; margin: 0; padding: 0; }

尝试一下 »

例子解析：

  • list-style-type:none - Removes the markers before list items. A navigation bar does not need list markers.
  • Remove the browser's default settings and set margin and padding to 0.

The code in the above example is the standard code used for both vertical and horizontal navigation bars.

垂直导航栏

With the above code, we only need to style the <a> element to build a vertical navigation bar:

实例

a { display:block; width:60px; }

尝试一下 »

示例说明：

  • display:block - Displays the link as a block element, making the whole area a clickable link area (not just text), and it allows us to specify a width.
  • width:60px - By default, block elements take up the maximum width. We want to specify a width of 60 pixels.

提示：查看完整样式的垂直导航栏的示例。

注意：Be sure to specify the width of the <a> element in a vertical navigation bar. If the width is omitted, IE6 may produce unexpected results.

Vertical Navigation Bar Example

Create a simple vertical navigation bar example, and change the background color when the mouse moves over an option:

实例

ul { list-style-type: none; margin: 0; padding: 0; width: 200px; background-color: #f1f1f1; } li a { display: block; color: #000; padding: 8px 16px; text-decoration: none; } /*鼠标移动到选项上修改背景颜色*/ li a:hover { background-color: #555; color: white; }

Fixed navigation bar with full-screen height

Next we create a fixed navigation bar of full screen height on the left, with scrollable content on the right.

实例

ul { list-style-type: none; margin: 0; padding: 0; width: 25%; background-color: #f1f1f1; height: 100%; /*全屏高度*/ position: fixed; overflow: auto; /*如果导航栏选项多，允许滚动*/ }

水平导航栏

There are two ways to create a horizontal navigation bar. Use内联(inline)或浮动(float)的列表项。

Both methods are good, but if you want the links to have the same size, you must use the floating method.

内联列表项

One way to build a horizontal navigation bar is to specify the elements as inline; the following code is the standard inline:

实例

li { display:inline; }

尝试一下 »

实例解析：

  • display:inline; - by default,<li>The <li> element is a block element. Here, we remove the line breaks before and after each list item to display them in one line.

提示:查看完整样式的水平导航栏的示例。

浮动列表项

In the above example, the links have different widths.

For all links to have equal width, float the <li> elements and specify the width of the <a> elements:

实例

li { float:left; } a { display:block; width:60px; }

尝试一下 »

实例解析：

  • float:left - Use float to make block elements slide next to each other.
  • display:block - Displays the link as a block element, making the whole area a clickable link area (not just text), and it allows us to specify a width.
  • width:60px - By default, block elements take up the maximum width. We want to specify a width of 60 pixels.

提示:查看完全样式的横向导航栏的示例。

Horizontal Navigation Bar Example

Create a horizontal navigation bar and change the background color when the mouse moves over an option.

实例

ul { list-style-type: none; margin: 0; padding: 0; overflow: hidden; background-color: #333; } li { float: left; } li a { display: block; color: white; text-align: center; padding: 14px 16px; text-decoration: none; } /*鼠标移动到选项上修改背景颜色*/ li a:hover { background-color: #111; }
