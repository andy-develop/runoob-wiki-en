CSS id 和 class

id and class selectors

If you want to set CSS styles on HTML elements, you need to set "id" and "class" selectors on the elements.

id selector

The id selector can specify particular styles for HTML elements with a specific id.

HTML elements use the id attribute to set the id selector. In CSS, the id selector is defined with "#".

The following style rule applies to the element attribute id="para1":

实例

#para1 { text-align:center; color:red; }

ID attributes should not start with a number. IDs that start with a number do not work in Mozilla/Firefox browsers.

class selector

The class selector is used to describe styles for a group of elements. The class selector is different from the id selector; class can be used on multiple elements.

The class selector is represented by the class attribute in HTML. In CSS, the class selector is represented by a dot..号显示：

In the following example, all HTML elements with the center class are centered.

实例

.center {text-align:center;}

尝试一下 »

You can also specify particular HTML elements to use a class.

In the following example, all p elements use class="center" to center the text of the element:

实例

p.center {text-align:center;}

尝试一下 »

Multiple class selectors can be separated by spaces:

实例

.center { text-align:center; } .color { color:#ff0000; }

尝试一下 »

The first character of a class name cannot be a number! It will not work in Mozilla or Firefox.

    css selector

    If you want to set CSS styles in HTML tags, you have four methods, that is, there are four CSS selectors.

    Besides the mentioned id and class selectors, the third selector is the tag selector, that is, using HTML tags as the selectors for CSS styling.

    实例

    <style>
h3{
    color:red;
}
</style>
<h3>菜鸟教程</h3>

    The fourth selector is writing CSS code directly inside the tag.

    实例

    <h3 style="color:red;">菜鸟教程</h3>

    These four CSS selectors have a priority in styling, namely:

    第四种 > id > class > 第三种

    In addition to the id selectors and class selectors in the tutorial, there are also element selectors, attribute selectors, descendant selectors, child selectors, and sibling selectors newly added in CSS3. The following examples are given together with ID selectors and class selectors.

    1. ID selector (ID selector, IS): uses # to identify the selector, syntax format:#S{...}(S is the selector name.) Example: a tag with id name will match the following style.

    <style>
#name{
  color:red;
}
</style>
<!--下面文字是红色的-->
<p id="name">red text</p>

    2. Class selector (class selector, CS): uses . to identify the selector, syntax format:.S{...}(S is the selector name.) Example: a tag with class attribute value value will match the following style.

    <style>
.value{
  text-align:center;
}
</style>
<!--下面的文字是居中对齐的-->
<p class="value">center text</p>

    3. Element selector (ES): also called tag selector, uses the tag name as the selector name. Syntax:S{...}(S is the selector name.) Example: all p tags will match the following style.

    <style>
p{
  font-style:italic;
}
</style>
<!--下面的文字是斜体的-->
<p style="font-style:italic">italic text</p>

    4. Attribute selector (AS): ES is actually a special case of AS. On the basis of AS, the selector can be described more specifically. The syntax format is:E[attr[~=][|=][^=][$=][*=]VALUE]{...}It is a selector not supported by all browsers, so no example is given.

    5. Containment selector (package selector, PS): specifies that the target selector must be inside the element corresponding to a certain selector. Syntax:A B{...}(A and B are HTML elements/tags, meaning it applies to B tags that are inside A.) Example: p tags inside the following div and p tags outside the div match different styles.

    <style>
p{
  color:red;
}
div p{
  color:yellow;
}
</style>
<p>red text</p><!--文字是红色的-->
<div>
  <p>yellow text</p><!--文字是黄色的-->
</div>

    6. Child selector (sub-selector, SS): similar to PS, it specifies that the target selector must be inside the element corresponding to a certain selector. The difference is that PS allows "child tags", even "grandchild tags", and more deeply nested tags to match the corresponding styles, while SS forces the target selector to be a tag inside the tag corresponding to the containment selector. Syntax:：A>B{...}(A and B are HTML elements/tags.) Example: p tags inside the following div match the style; p tags inside a table inside the div do not match.

    <style>
div>p{
  color:red;
}
</style>
<div>
  <p>red text</p><!--文字是红色的-->
  <table>
    <tr>
      <td>
        <p>no red text;</p><!--文字是非红色的-->
      </td>
    </tr>
  </table>
</div>

    7. Brother selector (brother selector, BS): BS is a selector newly introduced in CSS3.0, syntax format:A~B{...}(A and B are HTML elements/tags. It means when A tag matches selector A and B tag matches selector B, B tag matches the style.)

    <style>
div~p{
  color:red;
}
</style>
<div>
  <p>no red text</p><!--文字是非红色的-->
  <div>no red text</div>
  <p>red text</p><!--文字是红色的-->
</div>

  color:red;

<body>

    In addition to child selectors, there areA >B{...}Besides the form (A and B are both tags), it can also have this form:.A >B{...}The form (A is a class name, B is a tag).

    Let me supplement the meanings of punctuation marks; mainly the comma that often appears, which I see no one has mentioned.

    The meanings of comma, space, colon, and dot in CSS.

    一：#a,b{…………｝

    二：#a b{…………｝

    三：#a:b{…………｝

    四：#a.b{…………｝

    What do these four represent respectively?

    One: the style of an id named a and a tag b.

    Two: the style of a tag b under an id named a.

    Three: a pseudo-class b of an id named a, for example: a:hover

    Four: the style of a class named b under an id named a.

    The above posts are all very detailed. Here is a summary and my humble attempt to spark further discussion.

    1. Tag selector Description: selects the specified tag, also called element selector.
    2. id selector # Description: selects the id attribute
    3. class selector . Description: selects the class attribute
    4. Attribute selector [] Description: writing "a[id]" like this selects the tag with the specified attribute rule.
    5. Containment selector (space) Description: selects all children, grandchildren, etc.
    6. Child selector > Description: selects all children, but not grandchildren, etc.
    7. Sibling selector ~ Description: selects one or more following siblings.
    8. Adjacent sibling selector + Description: selects the next sibling.
    9. Pseudo-class selector : Description: mainly selects based on user actions, tag position, and tag state.
    10. Pseudo-element selector :: Description: mainly selects a line or first character of a piece of text, or adds styles before/after.

    All kinds of selectors involve priority and compatibility, so I will not summarize them here.
