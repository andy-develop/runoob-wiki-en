CSS 伪类(Pseudo-classes)

CSS pseudo-classes are used to add special effects to some selectors.

语法

Pseudo-class syntax

selector:pseudo-class {property:value;}

CSS classes can also use pseudo-classes:

selector.class:pseudo-class {property:value;}

anchor伪类

In browsers that support CSS, different states of links can be displayed in different ways.

实例

a:link {color:#FF0000;} /*未访问的链接*/ a:visited {color:#00FF00;} /*已访问的链接*/ a:hover {color:#FF00FF;} /*鼠标划过链接*/ a:active {color:#0000FF;} /*已选中的链接*/

尝试一下 »

注意：In CSS definitions, a:hover must be placed after a:link and a:visited to be valid.

注意：In CSS definitions, a:active must be placed after a:hover to be valid.

注意：The names of pseudo-classes are case-insensitive.

Pseudo-classes and CSS classes

Pseudo-classes can be used together with CSS classes:

a.red:visited {color:#FF0000;} <a class="red" href="css-syntax.html">CSS语法</a>

If the link in the above example has been visited, it will be displayed in red.

CSS :first-child 伪类

You can use the :first-child pseudo-class to select the first child element of a parent element.

注意：Must be declared in versions before IE8<!DOCTYPE>, so that :first-child can take effect.

Matches the first <p> element

In the following example, the selector matches <p> elements that are the first child of any element:

实例

p:first-child { color:blue; }

Matches the first <i> element in all <p> elements.

In the following example, the selector matches the first <i> element in all <p> elements:

实例

p > i:first-child { color:blue; }

Matches all <i> elements in <p> elements that are the first child.

In the following example, the selector matches all <i> elements in <p> elements that are the first child of an element:

实例

p:first-child i { color:blue; }

CSS - :lang 伪类

The :lang pseudo-class gives you the ability to define special rules for different languages.

注意：IE8 must declare<!DOCTYPE>to support the :lang pseudo-class.

In the following example, the :lang class defines the type of quotation marks for q elements with an attribute value of no:

实例

q:lang(no) {quotes: "~" "~";}
