CSS Layout - Horizontal & Vertical Align

Horizontal & vertical center alignment

Element center alignment

To horizontally center-align an element (such as <div>), you can usemargin: auto;。

Setting the width of the element will prevent it from overflowing to the edges of the container.

The element is centered by specifying a width and distributing the empty margins on both sides equally:

The div element is centered


实例

.center { margin: auto; width: 50%; border: 3px solid green; padding: 10px; }

注意:If not setwidthproperty (or setting it to 100%), the center alignment will not work.

Text center alignment

If you only want to center the text within an element, you can usetext-align: center;

Text center alignment


实例

.center { text-align: center; border: 3px solid green; }

Image center alignment

To center an image, you can usemargin: auto;并将它放到块元素中:


实例

img { display: block; margin: auto; width: 40%; }

Left/right alignment - using positioning

We can useposition: absolute;property to align elements:

注释：Absolutely positioned elements are removed from the normal flow and can overlap other elements.

提示:当使用positionWhen aligning elements, usually<body>元素会设置margin 和 padding. This can avoid visible differences in different browsers.

When using the position property, IE8 and earlier versions have a problem. If the container element (in our case <div class="container">) has a specified width and the !DOCTYPE declaration is omitted, then IE8 and earlier versions will add an extra 17px margin on the right side. This seems to be space reserved for the scrollbar. When using the position property, always set the !DOCTYPE declaration:


实例

body { margin: 0; padding: 0; } .container { position: relative; width: 100%; } .right { position: absolute; right: 0px; width: 300px; background-color: #b0e0e6; }

Left/Right Align - Using the float Method

We can also usefloatproperty to align elements:

实例

.right { float: right; width: 300px; border: 3px solid #73AD21; padding: 10px; }

尝试一下 »

When aligning elements like this, it is a good idea to predefine the margin and padding of the <body> element. This avoids visible differences in different browsers.

Note: If the child element's height is greater than the parent element, and the child element is set to float, then the child element will overflow. At this point, you can use "clearfix(clear float)" to solve this problem.

We can add overflow: auto; to the parent element to solve the problem of child element overflow:

实例

.clearfix { overflow: auto; }

Vertical Center Alignment - Using padding

There are many ways in CSS to achieve vertical centering. A simple way is to use at the top of the headerpadding:

I am vertically centered.


实例

.center { padding: 70px 0; border: 3px solid green; }

If you want to center both horizontally and vertically, you can usepadding 和 text-align: center:

I am centered both horizontally and vertically.


实例

.center { padding: 70px 0; border: 3px solid green; text-align: center; }

Vertical centering - using line-height

I am vertically centered.


实例

    Achieving vertical centering by setting the container's top and bottom padding the same, and using line-height=height to achieve vertical centering, is only effective for single-line text. When the text spans more than one line:

    • 1）padding: The text remains in the vertically centered position of the container, but the height of the container will increase as the number of text lines increases;
    • 2）line-height=height: The height of the container remains unchanged. line-height is the line spacing of the text, and the text will overflow the container when displayed;

    For multi-line text, you can usevertical-align: middle;to achieve vertical centering of the element, but if the content size of the child element is greater than the content size of the parent element, it will still overflow. Later, you need to use text overflow handling to solve it.
