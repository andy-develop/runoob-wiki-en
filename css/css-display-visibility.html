CSS Display(显示) 与 Visibility（可见性）

The display property sets how an element should be displayed, and the visibility property specifies whether an element should be visible or hidden.

Box 2

隐藏元素 - display:none或visibility:hidden

Hiding an element can be done by setting the display property to "none", or setting the visibility property to "hidden". However, please note that these two methods produce different results.

visibility:hidden can hide an element, but the hidden element still occupies the same space as before it was hidden. In other words, although the element is hidden, it still affects the layout.

实例

h1.hidden {visibility:hidden;}

display:none can hide an element, and the hidden element does not occupy any space. In other words, not only is the element hidden, but the space it originally occupied also disappears from the page layout.

实例

h1.hidden {display:none;}

CSS Display - Block and Inline Elements

A block element is an element that takes up the full width and has line breaks before and after it.

Examples of block elements:

  • <h1>
  • <p>
  • <div>

An inline element only takes up the necessary width and does not force line breaks.

Examples of inline elements:

  • <span>
  • <a>

How to change an element's display

You can change inline elements to block elements and vice versa, which can make the page look as if it is assembled in a specific way while still following web standards.

The following example displays list items as inline elements:

实例

li {display:inline;}

尝试一下 »

The following example displays a span element as a block element:

实例

span {display:block;}

尝试一下 »

注意：Changing the display type of an element affects how it is displayed, not what kind of element it is. For example, an inline element set to display:block is not allowed to have nested block elements inside it.

    Characteristics of block-level elements (block):

    • Always occupies its own line, starting on a new line, and the elements after it must also start on a new line.
    • Width, height, padding, and margin can all be controlled;

    Characteristics of inline elements:

    • On the same line as adjacent inline elements;
    • Width, height, padding-top/bottom, and margin-top/bottom cannot be changed; they are determined by the size of the text or image inside;

    The main block-level elements are:

    •  address , blockquote , center , dir , div , dl , fieldset , form , h1 , h2 , h3 , h4 , h5 , h6 , hr , isindex , menu , noframes , noscript , ol , p , pre , table , ul , li

    The main inline elements are:

    • a , abbr , acronym , b , bdo , big , br , cite , code , dfn , em , font , i , img , input , kbd , label , q , s , samp , select , small , span , strike , strong , sub , sup ,textarea , tt , u , var

    Variable elements (determine whether the element is a block element or an inline element based on the context):

    • applet ,button ,del ,iframe , ins ,map ,object , script

    Application of block-level and inline elements in CSS:

    With CSS, we can break free from the constraints of the HTML tag classification in the table above and freely apply the attributes we need to different tags/elements.

    The main CSS styles used are the following three:

    • display:block -- displays as a block-level element
    • display:inline -- displays as an inline element
    • display:inline-block -- displayed as an inline-block element, appearing on the same line and allowing attributes such as width, height, padding, and margin to be modified.

    We often add the display:inline-block style to all <li> elements, so the originally vertical list can be displayed horizontally.

    display is one of the CSS properties of a control, indicating the display mode. none means it is not displayed on the webpage, but the code still exists; block means this element will be displayed as a block-level element, and line breaks will be added before and after the element.

    In CSS, block-level object elements are displayed on their own line, multiple block elements each start on a new line, and the width and height properties can be set; however, inline object elements do not produce line breaks before or after them, and a series of inline elements are displayed on one line until the line is full. Setting the width and height properties on inline elements has no effect.

    Sometimes we want an element to have both width and height characteristics and the same-line characteristic. In this case, we can use inline-block. In CSS, by applying display:inline-block to an object, you specify the inline-block attribute. In simple terms, the object is rendered as an inline object, but its content is rendered as a block object. Subsequent inline objects are arranged on the same line. For example, we can give a link (an <a> element) the inline-block attribute value, so that it has both the width and height characteristics of block and the same-line characteristic of inline.
