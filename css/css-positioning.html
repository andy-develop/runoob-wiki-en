CSS Position(定位)

positionThe property is used to specify the positioning method of an element.

The five common values are as follows:

值 说明 锚点
static Default value. Elements are arranged according to the normal document flow and are not affected by top/right/bottom/left. 查看示例
relative Offset relative to its own original position, and it does not leave the document flow. 查看示例
absolute Positioned relative to the nearest positioned ancestor element (otherwise relative to the body), and it leaves the document flow. 查看示例
fixed Positioned relative to the browser window; the position does not change when the page is scrolled. 查看示例
sticky Before scrolling to the specified position, it behaves as relative; after that, it behaves as fixed. 查看示例

Elements can betop、right、bottom 和 leftAdjust the position with these properties, but these properties only take effect whenposition（且值不为static) is set.

static 定位

The default value for HTML elements, i.e., no positioning, follows the normal document flow object.

Statically positioned elements are not affected by top, bottom, left, right.

实例

div.static { position: static; border: 3px solid #73AD21; }

fixed 定位

The element's position is fixed relative to the browser window.

It will not move even if the window is scrolled:

实例

p.pos_fixed { position:fixed; top:30px; right:5px; }

尝试一下 »

注意：Fixed positioning requires a !DOCTYPE declaration to be supported in IE7 and IE8.

Fixed positioning makes the element's position irrelevant to the document flow, so it does not occupy space.

Fixed positioned elements overlap with other elements.

relative 定位

The positioning of a relatively positioned element is relative to its normal position.

实例

h2.pos_left { position:relative; left:-20px; } h2.pos_right { position:relative; left:20px; }

尝试一下 »

Moving a relatively positioned element does not change the space it originally occupied.

实例

h2.pos_top { position:relative; top:-50px; }

尝试一下 »

Relatively positioned elements are often used as containing blocks for absolutely positioned elements.

absolute 定位

The position of an absolutely positioned element is relative to its nearest positioned parent element. If the element has no positioned parent, then its position is relative to <html>:

实例

h2 { position:absolute; left:100px; top:150px; }

尝试一下 »

Absolute positioning makes the element's position irrelevant to the document flow, so it does not occupy space.

Absolutely positioned elements overlap with other elements.

sticky 定位

The English literal meaning of sticky is "stick" or "adhere", so it can be called sticky positioning.

position: sticky;Position based on the user's scroll position.

Sticky positioned elements depend on the user's scroll, and whenposition:relative 与 position:fixedSwitch between positions.

It behaves just likeposition:relative;And when the page scrolls beyond the target area, its behavior is likeposition:fixed;, it will be fixed at the target position.

The element's positioning behaves as relative before crossing a specific threshold, and as fixed after that.

This specific threshold refers to one of top, right, bottom, or left. In other words, sticky positioning takes effect only when one of the four thresholds top, right, bottom, or left is specified. Otherwise, its behavior is the same as relative positioning.

注意:Internet Explorer, Edge 15 and earlier IE versions do not support sticky positioning. Safari requires the -webkit- prefix (see the example below).

实例

div.sticky { position: -webkit-sticky; /* Safari */ position: sticky; top: 0; background-color: green; border: 2px solid #4CAF50; }

重叠的元素

The positioning of elements is irrelevant to the document flow, so they can cover other elements on the page.

The z-index property specifies the stacking order of an element (which element should be in front, or behind).

An element can have a positive or negative stacking order:

实例

img { position:absolute; left:0px; top:0px; z-index:-1; }

尝试一下 »

Elements with a higher stacking order are always in front of elements with a lower stacking order.

注意：If two positioned elements overlap and no z-index is specified, the element positioned last in the HTML code will be displayed in front.

    relative: Positioning is relative to its own position (when setting offsets, it will offset relative to its own position). An element with relative set remains in the document flow, the element's width and height do not change, and setting offsets does not affect the positions of other elements. When the outermost container is set to relative positioning, without a set width, its width is the entire browser width.

    absolute: Positioning is determined relative to the nearest parent element that has absolute or relative positioning set. If no parent element has absolute or relative positioning set, the element is positioned relative to the root element, i.e., the html element. An element with absolute set leaves the document flow. Without a set width, the element's width is determined by its content. After leaving the document flow, the original position is effectively empty, and elements below will occupy that position.

    Layering issue (which one is higher)

    总结：Boxes in the standard flow are lower than floated boxes, and floated boxes are lower than positioned boxes.

    Positioned is higher than floated, and floated is higher than standard flow. (The level has nothing to do with whether space is occupied.)

    用法：

    1. Must have positioning. (Except static.)

    2. Set the value of z-index as the level value. (If not given, the default is 0)

    • a. A box with level 0 is also higher than standard flow and floated boxes.
    • b. A box with a negative level is lower than standard flow and floated boxes.
    • c. The stacking level does not take decimals.)
    • d. If the level is the same, the box later in the code has a higher level than the one before it.
    • e. For floated or standard flow boxes, the box later in the code has a higher level than the one before it.
    • f. absolute does not occupy space, while relative occupies space. But the stacking level has nothing to do with whether space is occupied.

    4. absolute: Breaks out of the document flow; position is relative to...非static的父元素。

    5. sticky: a. The case where the display does not exceed the page equalsrelative。b. Display the overflow situation beyond the page equalsfixed
