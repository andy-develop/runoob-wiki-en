C# 接口（Interface）

An interface defines a syntactic contract that all classes should follow when inheriting the interface. An interface defines a syntactic contract."是什么"In part, derived classes define the syntax contract"怎么做"部分。

An interface defines properties, methods, and events, all of which are members of the interface. The interface only contains declarations of members. The definition of members is the responsibility of derived classes. The interface provides a standard structure that derived classes should follow.

An interface makes the classes or structs that implement it consistent in form.

Abstract classes are somewhat similar to interfaces, but they are mostly used only when a few methods are declared by the base class and implemented by derived classes.

The interface itself does not implement any functionality; it merely establishes a contract with the object that declares to implement the interface, specifying which behaviors must be implemented.

Abstract classes cannot be instantiated directly, but they allow deriving concrete classes with actual functionality.

Define interface: MyInterface.cs

接口使用interfaceKeyword declaration, which is similar to class declaration. Interface declarations are public by default. The following is an example of an interface declaration:

interface IMyInterface
{
    void MethodToImplement();
}

The above code defines the interface IMyInterface. Usually interface names start withIthe letter I. This interface has only one method, MethodToImplement(), with no parameters and no return value. Of course, we can set parameters and return values as needed.

It is worth noting that this method does not have a concrete implementation.

Next, let's implement the above interface: InterfaceImplementer.cs

实例

using System;

interface IMyInterface
{
        // 接口成员
    void MethodToImplement();
}

class InterfaceImplementer : IMyInterface
{
    static void Main()
    {
        InterfaceImplementer iImp = new InterfaceImplementer();
        iImp.MethodToImplement();
    }

    public void MethodToImplement()
    {
        Console.WriteLine("MethodToImplement() called.");
    }
}

The InterfaceImplementer class implements the IMyInterface interface. Implementing an interface is similar in syntax to class inheritance:

class InterfaceImplementer : IMyInterface

After inheriting the interface, we need to implement the interface's method MethodToImplement(). The method name must match the method name defined in the interface.

接口继承: InterfaceInheritance.cs

The following example defines two interfaces, IMyInterface and IParentInterface.

If an interface inherits other interfaces, then the implementing class or struct must implement all members of the interfaces.

The following example IMyInterface inherits the IParentInterface interface; therefore, the interface implementation class must implement the MethodToImplement() and ParentInterfaceMethod() methods:

实例

using System;

interface IParentInterface
{
    void ParentInterfaceMethod();
}

interface IMyInterface : IParentInterface
{
    void MethodToImplement();
}

class InterfaceImplementer : IMyInterface
{
    static void Main()
    {
        InterfaceImplementer iImp = new InterfaceImplementer();
        iImp.MethodToImplement();
        iImp.ParentInterfaceMethod();
    }

    public void MethodToImplement()
    {
        Console.WriteLine("MethodToImplement() called.");
    }

    public void ParentInterfaceMethod()
    {
        Console.WriteLine("ParentInterfaceMethod() called.");
    }
}

The example output result is:

MethodToImplement() called.
ParentInterfaceMethod() called.

    1. Characteristics of interfaces

    An interface is defined as a reference type that specifies a set of function members without implementing them. Other types and interfaces can inherit interfaces. The definition is easy to understand, but it does not reflect the characteristics. Interfaces mainly have the following characteristics:

    • (1) Multiple inheritance can be achieved through interfaces. Members of C# interfaces cannot have modifiers such as public, protected, internal, or private. The reason is simple: methods in an interface need to have their method bodies implemented by the external implementer of the interface, so their modifier must be public. Members in C# interfaces are public by default, while in Java they can be explicitly marked public.
    • (2) Interface members cannot have new, static, abstract, override, or virtual modifiers. One thing to note: when an interface implements another interface and the two interfaces have the same method, the new keyword can be used to hide the method of the parent interface.
    • (3) An interface only contains member signatures. An interface has no constructor, so it cannot be instantiated directly with new. An interface can only contain a combination of methods, properties, events, and indexers. Once an interface is implemented, the implementing class must implement all members of the interface, unless the implementing class itself is an abstract class.
    • (4) C# is single inheritance; interfaces solve the problem in C# where classes need to inherit from multiple base classes simultaneously.

    2. Simple usage of interfaces

    class Program
{
    static void Main(string[] args)
    {
        IWorker james1 = new James1();
        IWorker james2 = new James2();
        james1.work("设计");
        james2.work("编程");
        //从这个例子我体会到了有接口的好处，可以想象如果又来了新的员工。
        //如果不采用接口，而是每个员工都有一个单独的类，这样就会容易出错。
        //如果有接口这种协议约束的话，那么只要实现了接口就肯定有接口里声明的方法，我们只需拿来调用。
    }
}
public interface IWorker{ void work(string s); }
class James1 : IWorker
{
    public void work(string s)
    {
        Console.WriteLine("我的名字是James1，我的工作是" +s);
    }
}
class James2 : IWorker
{
    public void work(string s)
    {
        Console.WriteLine("我的名字是James2，我的工作是"+s);
    }
}

    4. Differences between interfaces and abstract classes

    Interfaces are used for specification, abstract classes for commonality. Abstract classes are classes, so they can only be singly inherited, whereas an interface can be implemented multiple at once.

    An interface can only declare methods, properties, events, and indexers. An abstract class, on the other hand, can have method implementations and can also define non-static class variables.

    Abstract classes can provide partial implementations of some methods; interfaces cannot. An instance of an abstract class is provided by its subclasses. An instance of an interface is provided by the class that implements the interface.

    If you add a method to an abstract class, its subclasses immediately have that method as well. However, if you add a new method to an interface, the classes that implement it must be rewritten (this is why an interface is said to be a specification for a class).

    Interface members are defined as public, but members of an abstract class can also be private, protected, internal, or protected internal members (where protected internal members can only be accessed in the application's code or by derived classes).

    In addition, interfaces cannot contain fields, constructors, destructors, static members, or constants.

    One more thing: when we implement an interface in VS, we find there are two options: one is Implement Interface, and the other is Explicitly Implement Interface. Implement Interface is what we normally understand as implementing an interface, while with Explicitly Implement Interface, the implemented methods belong to the interface, not to the implementing class.

    The difference between an interface and an abstract class.

    • 1. Interfaces support multiple inheritance; abstract classes cannot achieve multiple inheritance.
    • 2. Interfaces can only define abstract rules; abstract classes can both define rules and provide implemented members.
    • 3. An interface is a set of behavior specifications, while an abstract class is an incomplete class that emphasizes the concept of a family.
    • 4. Interfaces can be used to support callbacks; abstract classes cannot implement callbacks because inheritance does not support it.
    • 5. Interfaces only contain signatures of methods, properties, indexers, and events, but cannot define fields or methods with implementations. Abstract classes can define fields, properties, and methods with implementations.
    • 6. Interfaces can be applied to value types and reference types; abstract classes can only be applied to reference types. For example, a struct can implement an interface, but cannot inherit a class.
    abstract class A
{
    public int a = 0;   // 正确
    abstract public void func();  // 抽象方法
}
interface B
{
    public int a = 0;  // 错误
    public static int b = 0;  // 正确
    public void func();  // 接口方法不需要添加 abstract 关键字
}

    using System;
namespace InterfaceExAppliction{

interface shap{
    int volumn();
    int weight();
}
    
class RectAngle{
     private int length;
    private int breadth;
    private int height;
    private int density;
    public RectAngle(int len,int bre,int hei,int den){
        length=len;
        breadth=bre;
        height=hei;
        density=den;
    }
    public int volumn(){
        return length*breadth*height;
    }
    public int weight(){
        return length*breadth*height*density;
    }

}
    
class Ball{
    private int radius;
    private int density;
    public Ball(int r,int d){
        radius=r;
        density=d;
    }
    
    public int volumn(){
        return 3*radius*radius*radius*4/3;
    }
    public int weight(){
        return density*3*radius*radius*radius*4/3;
    }
    
}
