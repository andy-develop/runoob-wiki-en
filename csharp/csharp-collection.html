C# 集合（Collection）

在 C# 中，Collection class是Specifically used for data storage and retrieval的一类类。

Collections allow us to easily store, manage, and operate on a set of data, such as:

  • Access items in a list by index;
  • Access values in a dictionary by key;
  • Dynamically add or remove elements, etc.

Collection classes provide support for a variety of common data structures, such as:

  • 栈（Stack）— Last-In, First-Out (LIFO) structure;
  • 队列（Queue）— First-In, First-Out (FIFO) structure;
  • 列表（List）— an ordered sequence that can be dynamically expanded;
  • HashTable— Quickly look up data through key-value pairs.

Furthermore, most collection classes implement相同的接口，
This means they have similar operation methods, such as adding, removing, iterating, and so on.

In early C# versions, elements in collections were typically stored asObjectthe object type, and we could put any data into the collection because objectObjects of any type. This is because in C#,Objectis the base class for all data types—whetherint、stringor custom classes, ultimately inherit fromObject。

类描述和用法
动态数组（ArrayList）It represents [objects] that can be individually索引an ordered collection of objects.

It can basically replace an array. However, unlike arrays, you can use索引Add and remove items at the specified position, and the dynamic array will automatically resize itself. It also allows dynamic memory allocation, addition, search, and sorting of items in the list.

哈希表（Hashtable）它使用键to access elements in the collection.

When you access elements by key, you use a hashtable, and you can identify a useful key value. Each item in a hashtable has a键/值Correct. Keys are used to access items in the collection.

排序列表（SortedList）它可以使用键和索引to access items in the list.

A sorted list is a combination of an array and a hashtable. It contains a list whose items can be accessed by key or index. If you access items by index, it is a dynamic array (ArrayList); if you access items by key, it is a hashtable (Hashtable). Items in the collection are always sorted by key value.

堆栈（Stack）It represents a后进先出collection of objects.

When you need last-in, first-out access to items, use a stack. When you add an item to the list, it is called推入an element, and when you remove an item from the list, it is called弹出元素。

队列（Queue）It represents a先进先出collection of objects.

When you need first-in, first-out access to items, use a queue. When you add an item to the list, it is called入队, and when you remove an item from the list, it is called出队。

点阵列（BitArray）It represents a value expressed using the values 1 and 0, a二进制数组。

When you need to store bits but do not know the number of bits in advance, use a bit array. You can use整型索引to access items from the bit array collection; the index starts at zero.

    Here is something that seems to have not been covered above --List。

    First, let's see how to construct it:

    var list=new List<int>();

    首先，ListIt is strongly typed and very safe. Secondly, look at the angle brackets; it is generics added in C# 2.0, so there is noArrayList。

    unboxing/boxing like that, which causes performance waste.

    然后，ListAssigned by index; the index, like arrays, starts at 0. It can read values by index:

    var a=new List<int>();
a.Add(12);
a.Add(10);
Console.WriteLine(a[0]);

    Lists can have duplicate items, and the items are manually sorted.

    After changing items, note that the indexes of items will change:

    var a=new List<int>();
a.Add(12);
a.Add(10);
Console.WriteLine(a[0]);
a.Remove(12);
Console.WriteLine(a[0]);

    Here are some commonly used list methods:

    • 1、Add()Add something to the end of the list.
    • 2、Remove()Remove the first item in the list that matches the condition you want to delete (removes the first item that matches this condition).
    • 3、Clear()Clear all items.
    • 4、Sort()Sort the items using the system default method.
    • 5、Contains()Check whether an item exists in the list.

    看例子：

    using System;
using static System.Console;
using System.Collections.Generic;
namespace HelloWorldApplication
{
   class HelloWorld
   {
      static void Main(string[] args)
      {
          var a=new List<int>();
          a.Add(2);
          a.Add(6);
          a.Add(2);
          a.Add(10);
         Console.WriteLine($"第一个数为{a[0]}");
          a.Remove(2);//删去第一个匹配此条件的项
          a.Sort();
          foreach(var a2 in a)
          {
              WriteLine(a2);
          }
          bool a3=a.Contains(2);
          WriteLine(a3);
         Console.ReadKey();
      }
   }
}

    Let me share the usage of dictionaries:

    First, let's see how to construct it:

    var a=new Dictionary<TKey,TValue>();

    Seeing the angle brackets, you know it is C# 2.0 generics, so it can hold any type.

    First, a dictionary has a key <TKey> and a value <TValue>, where键必须是唯一的，不能重复。

    键不能是空引用

    Second, we can use the key to index, instead of using the index value to index.

    WriteLine(a[TKey]);

    Come, let me introduce some common dictionary stuff:

    1 Add(): Add a key and a value

    2 Clean(): Clears all keys and values in the dictionary.

    3 Count: Gets how many key-value pairs are in the dictionary.

    4 Remove(): Removes a key and value;

    5—6：ContainsKey()/ContainsValue(): Check whether the specified key/value is contained;

    看例子：

    using System;
using System.Collections.Generic;
namespace HelloWorldApplication
{
   class A
   {
      static void Main(string[] args)
      {
          var a=new Dictionary<int,int>();
          a.Add(12,14);
          a.Add(0,1);
          Console.WriteLine("删去前的Count"+a.Count);
          a.Remove(0);
          Console.WriteLine(a[12]);
          Console.WriteLine(a.Count);
         Console.WriteLine(a.ContainsKey(12));
         Console.ReadKey();
      }
   }
}

    最后，字典,堆栈，队列不能排序, if you want to sort the dictionary, you need to use other methods or collections, such as SortedDictionary<TKey,TValue>.

    There are many types of automatic sorting, and their performance has subtle differences, so carefully choose the best auto-sorting collection for your project.
