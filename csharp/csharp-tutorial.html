    Here is a brief introduction to the purpose of the following statement:

    Console.ReadKey();

    编写Console.Readkey();This function is to make the console window pause until a key is pressed.

    Otherwise, when running, the phrase "Hello World!" will flash by in the console window and you won't be able to see it.

    Console.Readkey();
//与
Console.Readline();
//与
Console.Read();

    区别：The first one exits when any key is pressed on the keyboard; the latter two are similar, both require entering any input and pressing Enter to exit.

    class Program
{
   private List<Student> allStu = newList<Student>();
   string yesORno;
   bool flag = true;
   
   public void AddStudent()
   {
       while (flag)
       {
           Student s = new Student();
           Console.WriteLine("请输入学生姓名:");
           s.StuName = Console.ReadLine();
           Console.WriteLine("请输入学生学号");
           s.StuNum = Console.ReadLine();
           allStu.Add(s);

           Console.WriteLine("是否继续输入:请输入y或者n");
           yesORno =Console.ReadKey().Key.ToString();
           
           switch (yesORno)
           {
               case "Y":
                   flag = true;
                   break;
               case "N":
                   flag = false;
                   break;
           }
       }
   }

   public void ShowStu()
   {
       for (int i = 0; i < allStu.Count; i++)
       {
           Console.WriteLine(allStu[i].ToString());
       }
   }

   static void Main(string[] args)
   {
       Program p = new Program();
       p.AddStudent();
       p.ShowStu();
       Console.ReadLine();
   }
}

    The differences among .NET, C#, and ASP.NET are as follows:

    1. What is .NET?

    .NET is a development platform under Microsoft. The core of .NET is .NET Framework, which is the environment for developing and running .NET programs. Under this platform, different languages can be used for development because .NET is a cross-language platform. The languages can be C#, F#, J#, VB.NET, etc. One difference between Java and .NET is that Java is cross-platform but not cross-language. .NET's cross-platform capability is limited to the Android system and iOS (Apple) systems.

    1. The .NET Framework consists of two parts:

    • CLR: Common Language Runtime, providing functions such as memory management and code security checking.
    • FLC: .NET Framework Class Library, providing a large number of application class libraries. The class library contains many ready-made resources that can be used (such as classes, methods, properties), improving development efficiency.

    2. The structure of CLR:

    • CLS: Common Language Specification, converts various languages into a unified grammatical specification.
    • CTS: Common Type System, converts data types in various languages into unified types.
    • JIT: Real-time compiler (Just-In-Time compiler) used to compile the converted language into binary language and hand it to the CPU for execution.

    3. The mechanism and process of .NET operation

    Various languages (source programs such as C#, F#, J#, etc.) —> First compilation through CLS and CTS —> Unified standardized language (intermediate language) MSIL (.EXE, .DLL) —> Second compilation through JIT —> Binary language —> Runs on the CPU

    Java's operating mechanism:

    Java —> Compilation —> Bytecode file (.CLASS) —> JVM interpretation (JVM virtual machine) —> Binary language —> Runs on the CPU

    2. What is C#?

    C# is a programming language under the .NET platform; it is merely a language. It is a high-level language that runs on the .NET CLR and is used for creating applications. A programming language is a tool for facilitating communication between developers and computers.

    3. What is ASP.NET?

    ASP.NET is a website development technology and an application model within the .NET framework. It is a content-rich programming framework used for generating Web-based applications. Developing Web applications with ASP.NET and maintaining their operation is simpler than with other development languages. Compared with advanced technologies such as Java, PHP, and Perl, ASP.NET has advantages such as convenience, flexibility, high production efficiency, high security, and object-orientation. It is currently one of the mainstream web programming technologies.
