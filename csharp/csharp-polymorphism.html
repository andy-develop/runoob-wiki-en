C# 多态性

Polymorphism is the ability of the same behavior to have multiple different forms or manifestations.

多态性It means having multiple forms. In the object-oriented programming paradigm, polymorphism often manifests as "one interface, multiple functions."

Polymorphism can be static or dynamic. In静态多态性this case, the response of a function occurs at compile time. In动态多态性Wherein, the function's response occurs at runtime.

In C#, every type is polymorphic because all types, including user-defined types, inherit from Object.

Polymorphism means the same interface, using different instances to perform different operations, as shown in the figure:

In real life, for example, the action of pressing the F1 key:

  • If currently in the Flash interface, the pop-up is the AS 3 help document;
  • If currently in Word, the pop-up is Word Help;
  • If under Windows, the pop-up is Windows Help and Support.

The same event occurring on different objects will produce different results.

静态多态性

At compile time, the mechanism that connects functions and objects is called early binding, also known as static binding. C# provides two techniques to implement static polymorphism. They are:

  • 函数重载
  • 运算符重载

Operator overloading will be discussed in the next chapter; next, we will discuss function overloading.

函数重载

You can have multiple definitions of the same function name in the same scope. The definitions of the function must differ from each other, either in the types of parameters in the parameter list or in the number of parameters. Different overloads are not function declarations that differ only in return type.

The following example demonstrates several identical functionsAdd(), used to perform addition on different numbers of parameters:

实例

using System;
namespace PolymorphismApplication
{
    public class TestData  
    {  
        public int Add(int a, int b, int c)  
        {  
            return a + b + c;  
        }  
        public int Add(int a, int b)  
        {  
            return a + b;  
        }  
    }  
    class Program  
    {  
        static void Main(string[] args)  
        {  
            TestData dataClass = new TestData();
            int add1 = dataClass.Add(1, 2);  
            int add2 = dataClass.Add(1, 2, 3);

            Console.WriteLine("add1 :" + add1);
            Console.WriteLine("add2 :" + add2);  
        }  
    }  
}

动态多态性

C# allows you to use the keywordabstractCreate an abstract class to provide a partial implementation of an interface. When a derived class inherits from the abstract class, the implementation is complete.抽象类Contains abstract methods, which can be implemented by derived classes. Derived classes have more specialized functionality.

Please note, below are some rules regarding abstract classes:

  • You cannot create an instance of an abstract class.
  • You cannot declare an abstract method outside an abstract class.
  • By placing the keyword before the class definitionsealed, the class can be declared as密封类. When a class is declared assealedWhen sealed, it cannot be inherited. An abstract class cannot be declared as sealed.

The following program demonstrates an abstract class:

实例

using System;
namespace PolymorphismApplication
{
   abstract class Shape
   {
       abstract public int area();
   }
   class Rectangle:  Shape
   {
      private int length;
      private int width;
      public Rectangle( int a=0, int b=0)
      {
         length = a;
         width = b;
      }
      public override int area ()
      {
         Console.WriteLine("Rectangle 类的面积：");
         return (width * length);
      }
   }

   class RectangleTester
   {
      static void Main(string[] args)
      {
         Rectangle r = new Rectangle(10, 7);
         double a = r.area();
         Console.WriteLine("面积： {0}",a);
         Console.ReadKey();
      }
   }
}

When there is a function defined in a class that needs to be implemented in an inherited class, you can use虚方法。

A virtual method is declared using the keywordvirtual声明的。

Virtual methods can have different implementations in different inherited classes.

The call to a virtual method occurs at runtime.

Dynamic polymorphism is achieved through抽象类 和 虚方法实现的。

The following example creates a Shape base class and derived classes Circle, Rectangle, Triangle. The Shape class provides a virtual method named Draw, which is overridden in each derived class to draw the specified shape for that class.

实例

using System;
using System.Collections.Generic;

public class Shape
{
    public int X { get; private set; }
    public int Y { get; private set; }
    public int Height { get; set; }
    public int Width { get; set; }
   
    // 虚方法
    public virtual void Draw()
    {
        Console.WriteLine("执行基类的画图任务");
    }
}

class Circle : Shape
{
    public override void Draw()
    {
        Console.WriteLine("画一个圆形");
        base.Draw();
    }
}
class Rectangle : Shape
{
    public override void Draw()
    {
        Console.WriteLine("画一个长方形");
        base.Draw();
    }
}
class Triangle : Shape
{
    public override void Draw()
    {
        Console.WriteLine("画一个三角形");
        base.Draw();
    }
}

class Program
{
    static void Main(string[] args)
    {
        // 创建一个 List<Shape> 对象，并向该对象添加 Circle、Triangle 和 Rectangle
        var shapes = new List<Shape>
        {
            new Rectangle(),
            new Triangle(),
            new Circle()
        };

        // 使用 foreach 循环对该列表的派生类进行循环访问，并对其中的每个 Shape 对象调用 Draw 方法
        foreach (var shape in shapes)
        {
            shape.Draw();
        }

        Console.WriteLine("按下任意键退出。");
        Console.ReadKey();
    }

}

When the above code is compiled and executed, it produces the following results:

Draw a rectangle
Execute the base class drawing task
Draw a triangle
Execute the base class drawing task
Draw a circle
Execute the base class drawing task
Press any key to exit.

    C# Polymorphism

    多态：One interface, multiple functions.

    Static polymorphism:The function response (call) occurs at compile time;

    Dynamic polymorphism:The function response occurs at runtime.

    Static binding (early binding):The mechanism for connecting functions and objects at compile time. Two techniques implement static polymorphism: function overloading / operator overloading.

    函数重载：Having multiple definitions of the same function name in the same scope, which may differ in parameter types or parameter count, but must not differ only in return type.

    Operator overloading:

    The keyword abstract declares an abstract class: used to provide a partial implementation of an interface (when a derived class inherits the abstract class, the implementation is complete). Abstract classes contain abstract methods, which can be implemented by derived classes.

    Abstract class rules:

    • 1. Cannot create an instance of an abstract class
    • 2. Abstract methods cannot be defined outside an abstract class.
    • 3. An abstract class cannot be declared as sealed (the keyword sealed before a class indicates that the class is a sealed class and cannot be inherited).

    The keyword virtual declares virtual methods: used for implementing methods in inherited classes (with different implementations in different inherited classes).

    Abstract classes and virtual methods together implement dynamic polymorphism.

    Note: overriding a virtual function in an inherited class requires declaring the keyword override. In method parameter passing, write (class name parameter name), for example public void CallArea(Shape sh), which means passing in a parameter of type Shape.

    virtual 和 abstract

    virtual and abstract are both used to modify the parent class, allowing the child class to redefine by overriding the parent class's definition.

    • 1. Methods modified by virtual must have an implementation (even if it is just adding a pair of braces), while methods modified by abstract must not have an implementation.
    • 2. virtual methods can be overridden by subclasses, while abstract methods must be overridden by subclasses.
    • 3. If a class member is modified by abstract, the class must also be declared with abstract, because only abstract classes can have abstract methods.
    • 4. It is impossible to create an instance of an abstract class; it can only be inherited and cannot be instantiated.

    重载和重写

    Overloading provides a mechanism for distinguishing the same function name through different return types and parameters.

    见：函数重载

    Overriding is used to override a virtual method of the base class, thus providing a new method in the derived class.

    见：动态多态性

    The difference between abstract methods and virtual methods

    • 1. A virtual method must have an implementation part, while an abstract method does not provide an implementation part. An abstract method is a method that forces derived classes to override it; otherwise, the derived class cannot be instantiated.
    • 2. Abstract methods can only be declared in abstract classes; virtual methods are not. If a class contains an abstract method, then the class is also abstract and must also be declared abstract.
    • 3. Abstract methods must be overridden in derived classes, which is similar to interfaces; virtual methods do not need to be overridden in derived classes.

    Simply put, abstract methods need to be implemented by subclasses. Virtual methods are already implemented and can be overridden by subclasses, or not, depending on requirements.

    Both abstract methods and virtual methods can be overridden by derived classes.

    1、重载(overload)In the same scope (generally referring to a class), two or more methods with the same method name but different parameter lists are called overloading. They have three characteristics (commonly known as "two musts and one may"):

    • The method name must be the same
    • The parameter lists must be different
    • The return value types can be different

    例如：

    public void Sleep()
{
    Console.WriteLine("Animal睡觉");
}
public int Sleep(int time)
{
    Console.WriteLine("Animal{0}点睡觉", time);
    return time;
}

    2、重写(override)In a subclass, to repeatedly define a different implementation of a method to meet its own needs, the override keyword is required. The method being overridden must be a virtual method, using the virtual keyword. Its characteristics are (three same things):

    • Same method name
    • Same parameter list
    • Same return value

    For example: the definition in the base class:

    public virtual void EatFood()
{
    Console.WriteLine("Animal吃东西");
}

    Definition in the subclass:

    public override void EatFood()
{
    Console.WriteLine("Cat吃东西");
    //base.EatFood();
}

    小提示：People often ask about the difference between overloading and overriding, and on the internet, this difference is one of the frequently asked C# interview questions. Actually, these two concepts have nothing to do with each other; they merely both contain the character "重" (meaning "re-"). There is no point in comparing them; just distinguish their different definitions.

    3、虚方法: It is a method defined in the base class that is allowed to be overridden in derived classes, defined using the virtual keyword. For example:

    public virtual void EatFood()
{
    Console.WriteLine("Animal吃东西");
}

    注意: Virtual methods can also be called directly. For example:

    Animal a = new Animal();
a.EatFood();

    The execution output is:

    Animal吃东西

    4、抽象方法: A method defined in the base class and must be overridden in derived classes, usingabstractKeyword definition. For example:

    public abstract class Biology
{
    public abstract void Live();
}
public class Animal : Biology
{
    public override void Live()
    {
        Console.WriteLine("Animal重写的抽象方法");
        //throw new NotImplementedException();
    } 
}

    注意：Abstract methods can only be defined in abstract classes. If defined outside an abstract class, the following error will be reported:

    The difference between virtual methods and abstract methods is: Because an abstract class cannot be instantiated, an abstract method cannot be called; that is, an abstract method can never be implemented.

    5、隐藏方法: A method defined in a derived class with the same name as a method in the base class, defined using the new keyword. For example, if the base class Animal has a method Sleep():

    public void Sleep()
{
    Console.WriteLine("Animal Sleep");
}

    Then the code for defining the hiding method in the derived class Cat is:

    new public void Sleep()
{
    Console.WriteLine("Cat Sleep");
}

    或者为：

    public new void Sleep()
{
    Console.WriteLine("Cat Sleep");
}

    注意：

    • (1) Hiding methods can hide not only virtual methods in the base class, but also non-virtual methods in the base class.
    • (2) In hidden methods, an instance of the parent class calls the parent class's method, and an instance of the child class calls the child class's method.
    • (3) In contrast to the previous point: in overriding methods, a variable of the derived class calls the overridden method of the derived class. For a variable of the base class, it depends on whether the base class reference points to an instance of the derived class or an instance of itself. If it references an instance of the base class, it calls the base class method; if it references an instance of the derived class, it calls the derived class method.

    using System;
namespace PolymorphismApplication
{
    abstract class Shape
    {
        public abstract int area();
    }

    {
        private int length;
        private int width;

            length = a;

            //Console.WriteLine("Rectangle 类的面积：");

        private int height;

        {
            baseLine = a;
            height = b;
        }
        public override int area()
        {
            //Console.WriteLine("三角形类的面积：");

    {

    I wrote an inheritance example myself, including a hidden method and an overridden method, and created three instances to demonstrate.

    namespace MySpace
{

    {

            name = n;

            //name = n;
        }

        {
            Console.WriteLine("I am {0} and a son.",name);

        {
            //base.growup();

        {
            dad grandpa = new dad("grandpa");

            grandpa.growup();
            dad father = new son("father");

            father.growup();

    I am grandpa.
grandpa has grown old.

I am Tom and a son.

    The above result:

    • 1) Using a parent-class object instantiated by the parent class, grandpa, accessing a hiding method is the parent class's method; accessing an overriding method is the parent class's method.
    • 2) Using a parent-class object instantiated by the subclass, father, accessing a hiding method is the parent class's method; accessing an overriding method is the subclass's method.
    • 3) Using a subclass object instantiated by the subclass, son, accessing a hiding method is the subclass's method; accessing an overriding method is the subclass's method.

    Abstract classes, abstract methods, and virtual methods are all important concepts in object-oriented programming, used to implement polymorphism and inheritance.

    Abstract classes and abstract methods are suitable for the following scenarios:

    • When you need to define a class, but the concrete implementation of this class is to be completed by subclasses, you can define an abstract class and define abstract methods in it. In this way, subclasses must implement these abstract methods to complete the concrete implementation.
    • When you need to constrain some subclasses to implement certain methods, you can use abstract classes and abstract methods.

    Virtual methods are suitable for the following scenarios:

    • When you need to provide a default implementation in the base class, but subclasses can choose to override this implementation, you can use virtual methods. In this way, in subclasses you can useoverridethe keyword to override the virtual method in the base class, thereby implementing your own logic.

    Overall, abstract classes and abstract methods are more suitable for constraining and standardizing the inheritance structure of classes and the implementation of methods, while virtual methods are more suitable for scenarios that provide default implementations and allow subclasses to override.

    In an abstract class, in addition to abstract methods, the following members can also be declared as abstract members:

    1. Abstract properties: similar to abstract methods, they have no implementation body, only declarations, and need to be implemented in concrete subclasses.

    2. Abstract events: similar to abstract methods and properties, they need to be implemented in concrete subclasses.

    3. Abstract indexers: similar to abstract properties, they have no implementation body, only declarations, and need to be implemented in concrete subclasses.

    In addition to virtual methods, a class can also have the following virtual members:
