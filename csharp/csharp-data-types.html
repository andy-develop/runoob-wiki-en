C# Data types

In C#, variables can be divided into the following types:

  • Value types
  • Reference types
  • Pointer types

Reference types

Reference types do not contain the actual data stored in the variable, but they contain references to the variable.

In other words, they refer to a memory location. When multiple variables are used, reference types can point to a memory location. If the data at the memory location is changed by one variable, other variables will automatically reflect this change in value.built-inReference types include:object、dynamicandstring。

Object type

Object Typeis the ultimate base class of all data types in the C# Common Type System (CTS). Object is an alias for the System.Object class. Therefore, the object (Object) type can be assigned values of any other type (value types, reference types, predefined types, or user-defined types). However, before assigning a value, type conversion is required.

When a value type is converted to an object type, it is calledBoxing; on the other hand, when an object type is converted to a value type, it is calledUnboxing。

object obj;
obj = 100; // 这是装箱

Dynamic type

You can store any type of value in a dynamic data type variable. Type checking for these variables occurs at runtime.

Syntax for declaring a dynamic type:

dynamic <variable_name> = value;

For example:

dynamic d = 20;

Dynamic types are similar to object types, but type checking for object type variables occurs at compile time, while type checking for dynamic type variables occurs at runtime.

String type

String typeallows you to assign any string value to a variable. The string (String) type is an alias for the System.String class. It is derived from the object (Object) type. Values of the string (String) type can be assigned in two forms: quotation marks and @ quotation marks.

For example:

String str = "example.com";

A @-quoted string:

@"example.com";

In C#, a string can be prefixed with @ (called a "verbatim string") to treat escape characters (\) as ordinary characters, for example:

string str = @"C:\Windows";

Equivalent to:

string str = "C:\\Windows";

In an @ string, you can break lines arbitrarily; line breaks and indentation spaces are all counted within the string length.

string str = @"<script type=""text/javascript"">
    <!--
    -->
</script>";

User-defined reference types include: class, interface, or delegate. We will discuss these types in later chapters.

Pointer types

Pointer type variables store the memory address of another type. Pointers in C# have the same functionality as pointers in C or C++.

Syntax for declaring a pointer type:

type* identifier;

For example:

char* cptr;
int* iptr;

We will discuss pointer types in the chapter "Unsafe Code."
