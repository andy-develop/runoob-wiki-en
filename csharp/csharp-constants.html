C# 常量

Constants are fixed values that do not change during program execution. Constants can be of any basic data type, such as integer constants, floating-point constants, character constants, string constants, and enumeration constants.

Constants can be treated like regular variables, except that their values cannot be modified after definition.

整数常量

Integer constants can be decimal, octal, or hexadecimal constants. The prefix specifies the radix: 0x or 0X indicates hexadecimal, 0 indicates octal, and no prefix indicates decimal.

Integer constants can also have suffixes, which can be a combination of U and L, where U and L represent unsigned and long, respectively. The suffix can be uppercase or lowercase, and multiple suffixes can be combined in any order.

Here are some examples of integer constants:

212         /* 合法 */
215u        /* 合法 */
0xFeeL      /* 合法 */
078         /* 非法：8 不是一个八进制数字 */
032UU       /* 非法：不能重复后缀 */

The following are examples of integer constants of various types:

85         /* 十进制 */
0213       /* 八进制 */
0x4b       /* 十六进制 */
30         /* int */
30u        /* 无符号 int */
30l        /* long */
30ul       /* 无符号 long */

浮点常量

A floating-point constant consists of an integer part, a decimal point, a fractional part, and an exponent part. You can express floating-point constants in decimal form or exponential form.

Here are some examples of floating-point constants:

3.14159       /* 合法 */
314159E-5L    /* 合法 */
510E          /* 非法：不完全指数 */
210f          /* 非法：没有小数或指数 */
.e55          /* 非法：缺少整数或小数 */

When expressed in floating-point form, it must include a decimal point, an exponent, or both. When expressed in exponential form, it must include an integer part, a fractional part, or both. A signed exponent is represented with e or E.

字符常量

Character constants are enclosed in single quotes, for example, 'x', and can be stored in a simple variable of character type. A character constant can be an ordinary character (e.g., 'x'), an escape sequence (e.g., '\t'), or a universal character (e.g., '\u02C0').

In C#, there are certain characters that have special meaning when preceded by a backslash. They can be used to represent a newline (\n) or a tab (\t). Here, some escape sequence codes are listed:

转义序列含义
\\\ 字符
\'' 字符
\"" 字符
\?? 字符
\aAlert 或 bell
\bBackspace key
\fForm feed
\nNewline
\r回车
\tHorizontal tab (tab)
\vVertical tab (tab)
\oooOctal number of one to three digits
\xhh . . .Hexadecimal number of one or more digits

The following are some examples of escape sequence characters:

namespace EscapeChar
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello\tWorld\n\n");
            Console.ReadLine();
        }
    }
}

When the above code is compiled and executed, it produces the following results:

Hello   World

字符串常量

String constants are enclosed in double quotes""inside, or enclosed in@""Inside. String constants contain characters similar to character constants, which can be: ordinary characters, escape sequences, and universal characters.

When using string constants, you can break a very long line into multiple lines, and you can use spaces to separate the parts.

Here are some examples of string constants. The various forms listed below represent the same string.

string a = "hello, world";                  // hello, world
string b = @"hello, world";               // hello, world
string c = "hello \t world";               // hello     world
string d = @"hello \t world";               // hello \t world
string e = "Joe said \"Hello\" to me";      // Joe said "Hello" to me
string f = @"Joe said ""Hello"" to me";   // Joe said "Hello" to me
string g = "\\\\server\\share\\file.txt";   // \\server\share\file.txt
string h = @"\\server\share\file.txt";      // \\server\share\file.txt
string i = "one\r\ntwo\r\nthree";
string j = @"one
two
three";

定义常量

常量是使用constdefined by keywords. The syntax for defining a constant is as follows:

const <data_type> <constant_name> = value;

The following code demonstrates how to define and use constants in a program:

实例

using System;

public class ConstTest
{
    class SampleClass
    {
        public int x;
        public int y;
        public const int c1 = 5;
        public const int c2 = c1 + 5;

        public SampleClass(int p1, int p2)
        {
            x = p1;
            y = p2;
        }
    }

    static void Main()
    {
        SampleClass mC = new SampleClass(11, 22);
        Console.WriteLine("x = {0}, y = {1}", mC.x, mC.y);
        Console.WriteLine("c1 = {0}, c2 = {1}",
                          SampleClass.c1, SampleClass.c2);
    }
}

When the above code is compiled and executed, it produces the following results:

x = 11, y = 22
c1 = 5, c2 = 10

    1、Convert.ToDouble 与 Double.Parse 的区别。实际上 Convert.ToDouble 与 Double.Parse 较为类似，实际上 Convert.ToDouble内部调用了 Double.Parse：

    (1) When the parameter is null:

    • Convert.ToDouble参数为 null 时，返回 0.0；
    • Double.Parse throws an exception when the parameter is null.

    (2) When the parameter is "":

    • When the parameter of Convert.ToDouble is "", it throws an exception;
    • Double.Parse throws an exception when the parameter is "".

    (3) Other differences:

    • Convert.ToDouble can convert more types;
    • Double.Parse can only convert strings of numeric types.
    • Double.TryParse is somewhat similar to Double.Parse, but it does not throw exceptions. It returns true on successful conversion and false on failure. The last parameter is the output value; if conversion fails, the output value is 0.0.

    Attached test code:

    2.Convert.ToInt32() 与 int.Parse() 的区别

    If you have not clearly understood the subtle differences between Convert.ToInt32 and int.Parse(), never use them carelessly, otherwise unexpected results may occur. For example: suppose you take the value of a parameter page from the URL. We know this value is an int, so you can use either Convert.ToInt32(Request.QueryString["page"]) or int.Parse(Request.QueryString["page"]). But if the page parameter does not exist in the URL, the former will return 0. 0 may be a valid value, so you do not know that the parameter was not originally present in the URL at all and continue to the next step of processing, which may produce unexpected effects. With the latter method, if there is no page parameter, an exception will be thrown. We can catch the exception and then handle it accordingly, such as prompting the user that the parameter is missing, rather than treating the parameter value as 0.

    (1) The biggest difference between these two methods is how they handle null values:

    Convert.ToInt32(null) returns 0 without throwing any exception, but int.Parse(null) throws an exception.

    (2) The difference when rounding data

    a. Convert.ToInt32(double value)

    If value is a number halfway between two integers, the even one is returned; that is, 3.5 converts to 4, 4.5 converts to 4, and 5.5 converts to 6. However, 4.6 can convert to 5, and 4.4 converts to 4.

    b. int.Parse("4.5")

    It directly throws an error: "The input string is not in the correct format."

    c. int(4.6) = 4

    When converting other numeric types to Int, Int does not round; it performs a forced conversion.

    (3) Differences in the types being converted

    int.Parse 是转换 String为int

    Convert.ToInt32 converts objects inherited from Object to int (which can have many other types of data).

    If you get an object and want to convert it to int, int.Parse will not work; you need to use Convert.ToInt32.

    1. Static constant (compile-time constant) const

    Its value is determined at compile time. It must be initialized at declaration and cannot be changed afterwards. It can be defined in classes and methods. The definition method is as follows:

    const double a=3.14；// 正确声明常量的方法
const int b;         // 错误，没有初始化

    2. Dynamic constants (run-time constants) readonly

    The value is determined at runtime. It can only be initialized at declaration or in a constructor, and can only be defined in a class. The way to define it is as follows:

    class Program
{
    readonly int a=1;  // 声明时初始化
    readonly int b;    // 构造函数中初始化
    Program()
    {
        b=2;
    }
    static void Main()
    {
    }
}

    Rules for naming constant variables:

    Constants with the private access modifier should be named using camel case, that is, starting with an underscore, with the first word's first letter in lowercase and the first letters of remaining words in uppercase.

    private const string _bookName = "新华字典";

    Constants with public, protected, or other access modifiers should be named using Pascal case, that is, the first letter of each word should be capitalized.

    public const int BookPrice = 10;

    The value of const must be known at compile time. In other words, you must give the constant an initial value, and you cannot use a variable to initialize the constant:

    static void Main(string[] args)
{
  int a=14;//必须要有初始值
  const int b=a;//报错
}

    When a constant is compiled, it is replaced by its value, which improves runtime efficiency.

    However, if you change the value of a constant (a) in an assembly (A) (from 12 to 14) but you have not recompiled assembly A, then for assembly (B) that references this constant (a), its constant value is still 12.

    Moreover, not all values can be used to initialize constants. If you want to use a value that is not supported by constants, use readonly.

    static A a;
readonly A a1=a;
const A a2=a;// 只能为 null

    Whereas readonly solves the disadvantages of const:

    It is translated as a read-only field, so it can only be declared within a class.

    It can be calculated or loaded at runtime, and can also be initialized in the constructor:

    int a1=14;
readonly int a;
A()
{
  a=a1;
}

    Using readonly also avoids the shortcomings of const regarding assemblies.
