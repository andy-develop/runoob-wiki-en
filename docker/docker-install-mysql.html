Docker Install MySQL

MySQL is the world's most popular open-source database. With its reliability, ease of use, and performance, MySQL has become the preferred database for web applications.

2. Pull the MySQL image

Here we pull the official latest version of the image:

$ docker pull mysql:latest

3. View local images

Use the following command to check if mysql is installed:
$ docker images

In the figure above, we can see that we have installed the latest version (latest) of the mysql image.

4. Run the container

After the installation is complete, we can use the following command to run the mysql container:

$ docker run -itd --name mysql-test -p 3306:3306 -e MYSQL_ROOT_PASSWORD=123456 mysql

Parameter description:

  • -p 3306:3306: Map the container service's port 3306 to the host machine's port 3306, allowing external hosts to directly connect through.Host IP:3306Access the MySQL service.
  • MYSQL_ROOT_PASSWORD=123456: Set the password for the MySQL service's root user.

5. Installation successful

Throughdocker psCommand to check whether the installation was successful:

The local machine can access the MySQL service with root and password 123456.
