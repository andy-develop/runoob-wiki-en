Nginx + PHP 部署

For Nginx deployment, you can view:Docker 安装 NginxRefer to this article for some Nginx configuration.

启动 PHP：

$ docker run --name  myphp-fpm -v ~/nginx/www:/www  -d php:5.6-fpm

命令说明：

  • --name myphp-fpm: Name the container myphp-fpm.

  • -v ~/nginx/www:/www: Mount the host project's www directory to the container's /www.

创建 ~/nginx/conf/conf.d 目录：

mkdir ~/nginx/conf/conf.d

Add in this directory~/nginx/conf/conf.d/runoob-test-php.conffile, with the following content:

server {
    listen       80;
    server_name  localhost;

    location / {
        root   /usr/share/nginx/html;
        index  index.html index.htm index.php;
    }

    error_page   500 502 503 504  /50x.html;
    location = /50x.html {
        root   /usr/share/nginx/html;
    }

    location ~ \.php$ {
        fastcgi_pass   php:9000;
        fastcgi_index  index.php;
        fastcgi_param  SCRIPT_FILENAME  /www/$fastcgi_script_name;
        include        fastcgi_params;
    }
}

Configuration file description:

  • php:9000: indicates the URL of the php-fpm service, which we will explain in detail below.
  • /www/: 是myphp-fpmThe storage path for php files inside, mapped to the local ~/nginx/www directory.

启动 nginx：

docker run --name runoob-php-nginx -p 8083:80 -d \
    -v ~/nginx/www:/usr/share/nginx/html:ro \
    -v ~/nginx/conf/conf.d:/etc/nginx/conf.d:ro \
    --link myphp-fpm:php \
    nginx
  • -p 8083:80: Port mapping, mappingnginxThe 80 in it maps to local port 8083.
  • ~/nginx/www: is the local storage directory for html files, and /usr/share/nginx/html is the storage directory for html files inside the container.
  • ~/nginx/conf/conf.d: is the local storage directory for nginx configuration files, and /etc/nginx/conf.d is the storage directory for nginx configuration files inside the container.
  • --link myphp-fpm:php: 把myphp-fpm的网络并入nginx, and by modifyingnginxThe container's /etc/hosts, mapping the domainphp映射成 127.0.0.1，让 nginx 通过 php:9000 访问 php-fpm。

Next, we create index.php in the ~/nginx/www directory, with the following code:

<?php
echo phpinfo();
?>

    Docker 配置 nginx、php-fpm、mysql

    运行环境

    创建目录

    mkdir -p /Users/sui/docker/nginx/conf.d && mkdir /Users/sui/www &&  cd /Users/sui/docker/nginx/conf.d && sudo touch default.conf

    启动 php-fpm

    Interpreting and executing php requires php-fpm; let's get it running first:

    docker run --name sui-php -d \
    -v /Users/sui/www:/var/www/html:ro \
    php:7.1-fpm

    --name sui-phpis the name of the container.

    /Users/sui/wwwis the local storage directory for php files, /var/www/html is the storage directory for php files inside the container, and ro means read-only.

    Edit the nginx configuration file

    配置文件位置：/Users/sui/docker/nginx/conf.d/default.conf。

    server {
    listen       80;
    server_name  localhost;

    location / {
        root   /usr/share/nginx/html;
        index  index.html index.htm;
    }

    error_page   500 502 503 504  /50x.html;
    location = /50x.html {
        root   /usr/share/nginx/html;
    }

    location ~ \.php$ {
        fastcgi_pass   php:9000;
        fastcgi_index  index.php;
        fastcgi_param  SCRIPT_FILENAME  /var/www/html/$fastcgi_script_name;
        include        fastcgi_params;
    }
}

    说明：

    • php:9000 indicates the access path of the php-fpm service, which will also be mentioned later.
    • /var/www/html 是 sui-phpThe storage path of php files in it, after docker mapping, becomes the local path /Users/sui/www (you can take another look at the php-fpm startup command

    启动 nginx:

    docker run --name sui-nginx -p 80:80 -d \
    -v /Users/sui/www:/usr/share/nginx/html:ro \
    -v /Users/sui/docker/nginx/conf.d:/etc/nginx/conf.d:ro \
    --link sui-php:php \
    nginx
    • -p 80:80 is used to add port mapping, mapping thesui-nginxExpose port 80 in the container.
    • /Users/sui/www is the local storage directory for html files, and /usr/share/nginx/html is the storage directory for html files inside the container.
    • /Users/sui/docker/nginx/conf.d is the local storage directory for nginx configuration files, and /etc/nginx/conf.d is the storage directory for nginx configuration files inside the container.
    • --link sui-php:php 把sui-php的网络并入sui-nginx, and by modifyingsui-nginxThe container's /etc/hosts, mapping the domainphp映射成 127.0.0.1，让 nginx 通过 php:9000 访问 php-fpm。

    测试结果

    在 /Users/sui/www 下放两个文件：index.html index.php

    mysql 和 phpmyadmin

    mysql server

    sudo mkdir -p /Users/sui/docker/mysql/data /Users/sui/docker/mysql/logs /Users/sui/docker/mysql/conf
    • The data directory will be mapped to the data file storage path of the mysql container configuration.
    • The logs directory will be mapped to the log directory of the mysql container.
    • The configuration files in the conf directory will be mapped to the configuration files of the mysql container.
    docker run -p 3307:3306 --name sui-mysql -v /Users/sui/docker/mysql/conf:/etc/mysql -v /Users/sui/docker/mysql/logs:/logs -v /Users/sui/docker/mysql/data:/mysql_data -e MYSQL_ROOT_PASSWORD=123456 -d --link sui-php mysql

    Enter the mysql client:

    docker run -it --link sui-mysql:mysql --rm mysql sh -c 'exec mysql -h"$MYSQL_PORT_3306_TCP_ADDR" -P"$MYSQL_PORT_3306_TCP_PORT" -uroot -p"$MYSQL_ENV_MYSQL_ROOT_PASSWORD"'

    Note: I have MySQL on local port 3306, so port 3307 is used here.

    phpmyadmin

    docker run --name sui-myadmin -d --link sui-mysql:db -p 8080:80 phpmyadmin/phpmyadmin
