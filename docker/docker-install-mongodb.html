2. Pull the latest MongoDB image

Here we pull the official latest version image:

$ docker pull mongo:latest

3. View local images

Use the following command to check whether mongo is installed:

$ docker images

In the above figure, we can see that we have installed the latest version (latest) of the mongo image.

4. Run the container

After installation, we can use the following command to run the mongo container:

docker run -d -p 27017:27017 --name my-mongo-container mongo

Parameter description:

  • -d: Run the container in the background.
  • -p 27017:27017: Map port 27017 of the host to port 27017 of the container.
  • --name my-mongo-container: Specify a name for the container, here it ismy-mongo-container, you can change it as needed.

5. Installation successful

Finally, we can usedocker psUse the command to view the container's running information:

Next, we can use a MongoDB client (such as mongo shell) to connect to the running MongoDB container.

You can use the following command to connect to MongoDB:

$ mongosh --host 127.0.0.1 --port 27017

This will connect to port 27017 on the local host. You can adjust it according to the port mapped earlier.

The bash shell command to enter the MongoDB container is as follows:

docker exec -it my-mongo-container bash
Remember to stop and delete containers when they are no longer needed. You can use the following commands:
docker stop my-mongo-container
docker rm my-mongo-container
