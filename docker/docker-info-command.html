docker info Command

Docker command reference

The docker info command is used to display detailed information about the Docker system, including the Docker version, storage driver, number of images, number of containers, and other important configuration information.

The docker info command is very useful, helping users understand the overall status of the Docker environment.

Syntax

docker info [OPTIONS]

Output explanation

Client: Information related to the Docker client.

  • ContextCurrent Docker context.
  • Debug Mode: Whether the client has debug mode enabled.
  • Plugins: Installed client plugins, such asbuildxandcompose。

Server: Information related to the Docker server (daemon).

  • Containers: Total number of containers.
    • Running: Number of running containers.
    • Paused: Number of paused containers.
    • Stopped: Number of stopped containers.
  • Images: Total number of images.
  • Server Version: The version number of the Docker daemon.
  • Storage Driver: Storage driver in use (such asoverlay2）。
  • Backing Filesystem: Backend filesystem type.
  • Supports d_type: Support statusd_type。
  • Native Overlay Diff: Whether the native Overlay filesystem is supported.
  • Logging Driver: Logging driver in use (such asjson-file）。
  • Cgroup Driver: The Cgroup driver in use (e.g.cgroupfs）。
  • Cgroup Version: Cgroup version (such as1）。
  • Plugins: List of server-side plugins, including volume, network, and logging plugins.
  • Swarm: The status of Swarm mode (e.g.inactive）。
  • Runtimes: Supported runtimes (e.g.runc）。
  • Default Runtime: Default runtime (e.g.runc）。
  • Init Binary: Init binary (such asdocker-init）。
  • containerd version: usedcontainerdversion.
  • runc version: usedruncversion.
  • init version: usedinitversion.
  • Security Options: Security options enabled (such asseccompandselinux）。
  • Kernel Version: Kernel version.
  • Operating System: Operating system name.
  • OSType: Operating system type (such aslinux）。
  • Architecture: System architecture (such asx86_64）。
  • CPUs: number of CPUs.
  • Total Memory: Total memory.
  • Name: Docker hostname.
  • ID: Docker instance ID.
  • Docker Root Dir: Docker root directory.
  • Debug Mode: Whether the server has debug mode enabled.
    • File Descriptors: Number of file descriptors.
    • Goroutines: number of Goroutines.
    • System Time: System time.
    • EventsListeners: Number of event listeners.
  • HTTP Proxy: Configured HTTP proxy.
  • HTTPS ProxyConfigured HTTPS proxy.
  • No Proxy: List of addresses not using proxy.
  • Registry: Registry address in use.
  • Labels: Configured labels.
  • Experimental: Whether experimental features are enabled.
  • Insecure Registries: List of configured insecure registries.
  • Registry Mirrors: List of registry mirrors.
  • Live Restore Enabled: Whether live restore is enabled.

WARNING: Warning messages (e.g., swap limit support not enabled).
