    C++中"\n" 与 endlWhat is the difference?

    "\n" denotes a string whose content is a carriage return character. std::endl is a stream manipulator; its output effect is similar to outputting "\n", but there may be slight differences.

    std::endl outputs a newline character and immediately flushes the buffer.

    例如:

    std::cout << std::endl;

    相当于:

    std::cout << '\n' << std::flush;
或者
std::cout << '\n'; std::fflush(stdout);

    Due to the overloading of the stream operator <<, the output effect is the same for '\n' and "\n".

    For streams with output buffering (e.g., cout, clog), if you do not manually flush the buffer, the output will be flushed automatically when the buffer becomes full. However, for cout (compared to file output streams, etc.), buffering is generally not very noticeable. But when necessary, using endl instead of '\n' is generally a good habit.

    For unbuffered streams (e.g., the standard error output stream cerr), flushing is unnecessary, so '\n' can be used directly.

    在 C++ 中，分别使用.h 和.cpp 来定义一个类。

    .hIn it, store the class declaration and function prototypes (placed in the class declaration).

    .cppStores the function body.

    That is, one stores declarations and the other stores definitions.

    If we declare a function in a header file, then when we need to define this function (the definition is unique, i.e., it can only be defined once), or when we need to use this function, we need to include this header file in the cpp file.

    Similarly, if we declare a class in a header file, then when we need to define the member functions of the class, or when we need to use this class, we need to include this header file in the cpp file.

    For class designers, the header file is like a contract between them and the class users. The compiler enforces this contract; it requires you to make declarations when using the functions or structures in these classes.

    "\n"Represents a string whose only data is a carriage return character.

    '\n'Represents a character.

    These two are the same in output!

    关于 endl:

    1. In C++, when the terminal outputs a newline, usecout<<......<<endlBoth this and "\n" are fine; this is a basic understanding. But there is a small difference between the two: using endl flushes the buffer, causing the things in the stack to be flushed once, while using "\n" does not flush; it only breaks the line, and the data in the stack does not change. But in general, this difference is very small and may be used in large programs. It is recommended to use endl for line breaks.

    2. endl not only writes '\n' but also calls the flush function, flushes the buffer, and writes the buffered data to the file or screen. For efficiency, use '\n'.

    3. cout << endl; besides inserting a '\n' into the output stream, it also flushes the output stream.

    cout << endl; 
等价于: 
\cout << '\n' << flush;

    When it is not necessary to flush the output stream, try to usecout << '\n'too many endl is one of the factors affecting program execution efficiency.

    What exactly does using namespace std mean in C++?

    It means declaring a namespace. Namespaces are very useful in multi-person collaboration, because if you define variable a, and someone else also defines variable a, that would be a duplicate definition. If you define a in your own namespace, and someone else defines a in their own namespace, then there is no duplication. For example:

    using namespace xx;
using namespace yy;

    xx::a 和 yy::aAlthough both are called a, they are not the same variable.

    std is the system standard namespace. In order not to duplicate user-defined names, it is declared in the std namespace. In addition, this namespace is like a big bag that contains all the system support.

    ::In C++, it represents scope and ownership.::It has the highest precedence among operators. It is divided into three types, as follows:

    1. Scope symbol:

    作用域符号::The part before :: is generally the class name, and the part after it is generally the member name of that class. In C++, to avoid different classes having members with the same name, scope is used to distinguish them.

    For example: A and B represent two classes, and both A and B have a member member.

    那么：

    • 1. A::member represents the member member in class A.
    • 2. B::member represents the member member in class B.

    2. Global scope symbol:

    Global scope symbol: when a global variable has the same name as a local variable in a function, you can use::To distinguish, for example:

    char  zhou;  //全局变量
void  sleep()
{
  char  zhou; //全局变量
  char(局部变量) = char(局部变量)*char(局部变量);
  ::char(全局变量) =::(全局变量) *char(全局变量)
}

    3. Scope resolution operator:

    :: is the scope resolution operator in C++. For example, if a class A is declared, and a member function void f() is declared in class A, but the definition of f is not given in the class declaration, then when defining f outside the class, you must write void A::f(), indicating that this f() function is a member function of class A. For example:

    class CA 
{
public:
  int ca_var;
  int add(int a, int b);
  int add(int a);
}
//那么在实现这个函数时，必须这样写：
int CA::add(int a, int b)
{
  return a + b;
}
//另外，双冒号也常常用于在类变量内部作为当前类实例的元素进行表示，比如：
int CA::add(int a)
{
  return a + ::ca_var;
}
//表示当前类实例中的变量ca_var。

    1、.cpp文件和.hThe difference between files:

    The cpp file is used to store the definition of the class, and the h file is used to store the declaration of the class.

    If a function or class is declared in a header file, then when you need to define or use this function or class, you need to include this header file in the cpp file.

    2. When including header files<> 和 ""的区别：

    <>: It will first search for the header file in the system directory; if not found, then search in the current directory. This method is used for standard header files, such as stdio.h, stdlib.h.

    "": It will first search in the current directory; if not found, then search in the system directory. This is suitable for self-defined header files.

    3、using namespace std;The purpose of this line of code:

    Declare a namespace. In multi-person collaboration, even if functions have the same name, because the namespaces they belong to are different, no errors will occur.

    stdis the system standard namespace.
